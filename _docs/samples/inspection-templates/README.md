# 検査表テンプレートの見本（MS09）

**動作確認用の作り話のデータ**です。実物の検査表ではありません
（そのつもりで作った台紙もありません — この形で作ると何ができるかを
見るための見本です）。

`sample-sheets.json` は **書き出し / 取込がそのまま受け付ける形**なので、
検査表テンプレート（MS09）の「書き出し / 取込」から取り込めます。

| コード | 内容 | 見どころ |
|---|---|---|
| `INS-DRILL-DIM` | 超硬ドリル 寸法検査 | 数値項目 + 公差 + 目標値、抜取 10%、実測値方式 |
| `INS-VISUAL` | 外観検査 | 真偽・単一選択・複数選択、全数、合格数のみ方式 |
| `INS-COATING` | コーティング検査 | 数値と選択の混在、抜取 3 本 |

3 枚で、検査項目の 4 つの型・抜取の 3 通り・記録方式の 2 通りが一通り出ます。

## 使い方

1. 検査表テンプレート（MS09）→「書き出し / 取込」
2. 「ファイルを選ぶ」で `sample-sheets.json` を選ぶ
3. 同じコードが既にあれば、**新しいバージョンとして追加**されます
   （既存の版は書き換えません）

Excel から作りたいときは、同じ画面の「Excel の雛形を落とす」から雛形を取って
書き足してください。列の意味は雛形の見出しのとおりです。

## 関連工程について

`relatedProcessStepCode` は**工程コード**で書きます（id は環境ごとに違うため）。
このファイルは `FAB_INSPECTION` / `PRE_SHIP_INSPECTION` /
`CUSTOMER_INSPECTION_1` を使います。取り込む環境にその工程が無ければ、
その 1 枚だけ取り込まれず理由が出ます。
