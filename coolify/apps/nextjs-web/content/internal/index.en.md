Internal documentation for CKK staff (login required). Covers system administration guides and kiosk device setup.

- **System Administration Guides** — user management, app management, file management, activity log, QR card management, kiosk device management and setup
- **Roles and permissions** — every role, the permission matrix (who may do what) and how to assign roles to users
- **System URLs** — the address of every system (business app, kiosk, admin tools, database browsers, monitoring) and which environment it points at
