Internal documentation for CKK staff (login required). Covers system administration guides and shared device setup.

- **System Administration Guides** — user management, app management, file management, activity log, order intake by email, QR card management, device management, shared device setup, displays and how to install them, partner portal
- **Roles and permissions** — every role, the permission matrix (who may do what) and how to assign roles to users
- **System URLs** — the address of every system (business app, shared devices, admin tools, database browsers, monitoring), which environment it points at, and the path of each system settings screen
