操作コード **SY07**。システム全体の操作履歴（監査ログ）を横断的に確認できる管理者向けアプリです。「誰が・いつ・どのデータを・どう変更したか」を一覧で追跡できます。

> このアプリは **システム権限** が必要です。履歴は **閲覧専用** で、この画面から編集・削除はできません。

## このアプリでできること

- 全アプリ・全レコード横断で、データの作成・更新・削除の履歴を確認できます。
- レコード・ユーザー・変更内容での検索と、操作種別・対象での絞り込みができます。
- 各文書の詳細画面にある「履歴」タブと同じデータ源です — こちらは全体を横断して見るための画面です。

## 開き方

- ホーム（システム）→ **操作履歴**、または検索ボックスで `SY07`。

## 記録される操作

業務データが保存されるたびに、変更前後のスナップショット付きで自動記録されます。操作種別は次のとおりです。

- **作成** … レコードの新規作成。
- **更新** … 既存レコードの変更（変更されたフィールドの差分が要約されます）。
- **削除** … レコードの削除。
- **初期データ** / **マイグレーション** … システムによる初期投入・移行処理。

閲覧や PDF ダウンロードなどの「見るだけ」の操作は対象外です（データの変更のみ記録されます）。

## 一覧の見方

- **日時** … 操作が行われた日時。既定で新しい順に並びます。
- **操作** … 作成 / 更新 / 削除 など。
- **対象** … 変更されたデータの種類。例: 見積書、試算、価格表、製品、取引先、アプリ管理。
- **レコード** … 業務識別子（文書番号 `QOT-…` / `EST-…`、マスタの ID など。等幅表示）。
- **ユーザー** … 操作したユーザーの表示名。システムによる処理は「システム」と表示されます。共有タブレット（キオスク端末）経由の操作には、名前の下に**端末名のバッジ**が付きます（Web からの操作にはバッジは付きません）。
- **変更内容** … 変更の要約。更新の場合は「ステータス: 下書き → 確定」のように変更フィールドごとの差分が表示されます。

一覧には最新 **300 件** が表示されます。

## 検索・絞り込み

- 検索ボックスはレコード（文書番号など）・ユーザー名・変更内容を横断して検索します。
- **操作** セレクトで操作種別（作成/更新/削除 など）を絞り込めます。
- **対象** セレクトでデータの種類（見積書・製品 など）を絞り込めます。
- **リセット** で条件を全部クリアします。

## よくある質問

- **特定の文書の履歴だけ見たい** … その文書の詳細画面を開き、「履歴」タブを確認するのが早いです。この画面では文書番号で検索してください。
- **古い履歴が出てこない** … この画面に表示されるのは最新 300 件です。それより前の調査はシステム管理者に相談してください。
- **ログインや PDF 出力の記録が無い** … それらはこの履歴の対象外です（データの作成・更新・削除のみ記録されます）。
- **「アプリ管理」という対象は何か** … [アプリ管理](/admin-manual/ja/system/app-management) でのアプリ表示 ON/OFF の切り替え記録です。
- ユーザーと権限の確認は [ユーザー管理](/admin-manual/ja/system/user-management) を参照してください。
