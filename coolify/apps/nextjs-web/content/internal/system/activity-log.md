操作コード **SY07**。システム全体の操作履歴（監査ログ）を横断的に確認できる管理者向けアプリです。「誰が・いつ・どのデータを・どう変更したか」を一覧で追跡できます。

> 入口の権限は **`personal_data`（個人データの閲覧）** です（`system` ではありません）。さらに、横断検索（一覧）と 1 件の詳細はそれぞれ特権操作 `personal_data.activity_search` / `personal_data.activity_detail` で、[特権アクセス](/manual/ja/operations/system/privileged-access/user)（SY0G）の申請・承認を経た期間だけ開けます。各書類の「履歴」タブはこの承認の対象外です。履歴は **閲覧専用** で、この画面から編集・削除はできません。

## このアプリでできること

- 全アプリ・全レコード横断で、データの作成・更新・削除の履歴を確認できます。
- レコード・ユーザー名での検索と、期間・操作種別・対象・操作者での絞り込みができます（絞り込み・並べ替え・ページングはサーバー側）。
- 各文書の詳細画面にある「履歴」タブと同じデータ源です — こちらは全体を横断して見るための画面です。

## 開き方

- ホーム（システム）→ **操作履歴**、または検索ボックスで `SY07`。

## 記録される操作

業務データが保存されるたびに、変更前後のスナップショット付きで自動記録されます。操作種別は次のとおりです。

- **作成** … レコードの新規作成。
- **更新** … 既存レコードの変更（変更されたフィールドの差分が要約されます）。
- **削除** … レコードの削除。
- **初期データ** / **マイグレーション** … システムによる初期投入・移行処理。

- **閲覧** / **書き出し** … 秘密・個人データにかかわる一部の「見る」操作だけを個別に記録します（共有端末の PIN・設定コードの開示、ログイン履歴の詳細、取引先ポータルでの書類閲覧 = 閲覧 / フォーム回答の書き出し・回答 PDF・QRカード台紙 = 書き出し）。

それ以外の閲覧や書類 PDF のダウンロードなど「見るだけ」の操作は対象外です。

## 一覧の見方

- **日時** … 操作が行われた日時。既定で新しい順に並び、列見出しで昇順/降順を切り替えられます（サーバー側で並べ替えられるのはこの列だけ）。
- **操作** … 作成 / 更新 / 削除 など。
- **対象** … 変更されたデータの種類。例: 見積書、価格試算、価格表、製品、取引先、アプリ管理。
- **レコード** … 業務識別子（文書番号 `QOT-…` / `EST-…`、マスタの ID など。等幅表示）。
- **ユーザー** … 操作したユーザーの表示名。システムによる処理は「システム」と表示されます。共有タブレット（キオスク端末）経由の操作には、名前の下に**端末名のバッジ**が付きます（Web からの操作にはバッジは付きません）。
- **変更内容** … 変更の要約。更新の場合は「ステータス: 下書き → 確定」のように変更フィールドごとの差分が表示されます。

一覧はページ単位（10 / 20 / 50 / 100 件、既定 20 件）で、総件数に対してページングします。以前の「最新 300 件まで」の制限はありません。

## 検索・絞り込み

- 検索ボックス（「レコード・ユーザーで検索」）はレコード（文書番号など）とユーザーの表示名を検索します。**変更内容は検索対象ではありません。**
- **開始日** / **終了日** で期間を絞り込めます（表示タイムゾーンの暦日）。
- **操作** セレクトで操作種別（作成/更新/削除 など）を絞り込めます。
- **対象** セレクトでデータの種類（見積書・製品 など）を絞り込めます。
- **ユーザー** セレクトで操作者を絞り込めます。
- **リセット** で条件を全部クリアします。

## よくある質問

- **特定の文書の履歴だけ見たい** … その文書の詳細画面を開き、「履歴」タブを確認するのが早いです。この画面では文書番号で検索してください。
- **古い履歴が出てこない** … 開始日・終了日で期間を指定するか、ページを進めてください。
- **ログインや PDF 出力の記録が無い** … ログインは [ログイン履歴](/manual/ja/operations/system/login-history/user)（SY0D）に残ります。書類 PDF の出力は記録されません（上記の「閲覧 / 書き出し」の例外を除く）。
- **「アプリ管理」という対象は何か** … [アプリ管理](/admin-manual/ja/system/app-management) でのアプリ表示 ON/OFF の切り替え記録です。
- ユーザーと権限の確認は [ユーザー管理](/admin-manual/ja/system/user-management) を参照してください。
