操作代码 **SY07**。面向管理员的应用，可跨全系统查看操作历史（审计日志）——"谁在何时、以何种方式修改了哪条数据"。

> 入口权限为 **`personal_data`（个人数据查看）**（不是 `system`）。此外，跨单据搜索（列表）和单条详情分别是特权操作 `personal_data.activity_search` / `personal_data.activity_detail`，只有在 [特权访问](/manual/zh/operations/system/privileged-access/user)（SY0G）中申请并获批准的期间内才能打开。各单据的「履歴」（历史）标签不受此批准限制。历史记录 **仅供查看**，无法在此界面编辑或删除。

## 本应用能做什么

- 跨所有应用、所有记录，查看数据的创建・更新・删除历史。
- 按记录、用户名搜索；按期间、操作类型、对象、操作人筛选（筛选・排序・分页均在服务器端进行）。
- 与各单据详情页的"历史"标签页数据源相同——本界面用于全局横向查看。

## 打开方式

- 主页（系统）→ **操作履歴（操作历史）**，或在搜索框输入 `SY07`。

## 记录哪些操作

每次保存业务数据时，系统会自动记录一条带变更前后快照的日志。操作类型如下。

- **创建** … 新建记录。
- **更新** … 修改现有记录（变更字段以差异形式摘要显示）。
- **删除** … 删除记录。
- **初始数据** / **迁移** … 系统执行的初始数据导入和迁移处理。

- **查看** / **导出** … 只单独记录与机密・个人数据有关的部分"查看"操作（显示共用终端 PIN・设置代码、打开登录记录详情、在客户门户中查看单据 = 查看 / 导出表单回答、回答 PDF、二维码卡台纸 = 导出）。

除此之外的浏览、下载单据 PDF 等"只看不改"的操作不在记录范围内。

## 列表说明

- **日期时间** … 操作发生的时间。默认从新到旧排序，点击列标题可切换升序/降序（服务器端只能按此列排序）。
- **操作** … 创建 / 更新 / 删除 等。
- **对象** … 被修改数据的种类。例如：报价单（見積書）、价格试算（価格試算）、价格表、产品、业务伙伴、应用管理。
- **记录** … 业务标识（`QOT-…` / `EST-…` 等单据编号、主数据 ID；等宽字体）。
- **用户** … 操作用户的显示名。系统自动执行的操作显示为"システム（系统）"。经由共享平板（终端设备）进行的操作，名字下方会带**设备名徽章**（来自 Web 的操作没有徽章）。
- **变更内容** … 变更摘要。更新时按字段显示差异，如"状态：草稿 → 确定"。

列表按页显示（每页 10 / 20 / 50 / 100 条，默认 20 条），对全部条数分页。以前"最多显示最新 300 条"的限制已不存在。

## 搜索与筛选

- 搜索框（「レコード・ユーザーで検索」）匹配记录（单据编号等）和用户显示名。**不搜索变更内容。**
- 用 **开始日期** / **结束日期** 筛选期间（按显示时区的日历日）。
- **操作** 下拉框按操作类型（创建/更新/删除 等）筛选。
- **对象** 下拉框按数据种类（报价单、产品 等）筛选。
- **用户** 下拉框按操作人筛选。
- 点 **重置** 清除全部条件。

## 常见问题

- **只想看某一单据的历史** … 最快的方式是打开该单据的详情页查看"历史"标签页。在本界面则可按单据编号搜索。
- **看不到较早的记录** … 请用开始日期・结束日期指定期间，或往后翻页。
- **没有登录或 PDF 下载的记录** … 登录记录在[登录历史](/manual/zh/operations/system/login-history/user)（SY0D）中。单据 PDF 的输出不会被记录（上述"查看 / 导出"的例外除外）。
- **对象"应用管理"是什么** … 指在[应用管理](/admin-manual/zh/system/app-management)中切换应用显示开关的记录。
- 用户与权限的查看请参见[用户管理](/admin-manual/zh/system/user-management)。
