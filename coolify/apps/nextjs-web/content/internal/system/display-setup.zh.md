在现场的电视上显示生产状况的步骤。**即使不熟悉电脑，按顺序做下来也能装好。**

从准备到显示大约需要 **30 分钟**，其中约 15 分钟是等待时间。

> 💡 没有复杂的设置。电视上显示什么，之后用电脑来选。这次的作业里不选。

## 这个页面能做什么

- 准备好驱动电视的小型电脑
- 连接电视并接通电源
- 用 1 台在 2 台电视上显示不同的内容
- 用画面上显示的关联码登记这块屏幕
- 遇到问题时知道怎么处理

## 用语（本页出现的词）

- **Raspberry Pi（树莓派）** … 手掌大小的小型电脑。把它连到电视上使用。
- **microSD 卡** … 放进 Raspberry Pi 里的小存储卡，相当于电脑的硬盘。
- **关联码** … 电视画面上显示的 12 位英文数字，用来告诉系统这是哪一块屏幕。
  与共用终端（平板）使用的机制相同。

## 需要准备的东西

| 物品 | 补充说明 |
|---|---|
| Raspberry Pi 5 主机 | 4GB 版本即可 |
| 专用电源适配器 | **必须使用原厂的** |
| microSD 卡 | 32GB 以上，选标有「A2」（高耐久）的 |
| HDMI 线 | Raspberry Pi 一端是较小的「micro HDMI」接口 |
| 网线 | 无线也可以，但有线更稳定 |
| USB 键盘 | 只在最开始用一次 |
| 能读 microSD 卡的电脑 | 只在准备阶段使用 |

> ⚠️ 电源**必须使用 Raspberry Pi 5 专用的**。手机充电器供电不足，会出现
> 「有时候画面会黑掉」这种最难排查的故障。

## ① 准备 microSD 卡

在电脑上操作。

1. 在电脑上安装 **Raspberry Pi Imager**（可从 `raspberrypi.com` 免费获取）。
2. 把 microSD 卡插入电脑。
3. 打开 Raspberry Pi Imager。
4. 点「选择设备」，选 **Raspberry Pi 5**。
5. 点「选择操作系统」，选 **Raspberry Pi OS (64-bit)**。
6. 点「选择存储卡」，选刚插入的 microSD 卡。
7. 点「下一步」。
8. 点「编辑设置」。

在这里加入几项设置，之后会省事。

9. 在「主机名」里填一个好认的名字（例如 `ckk-display-1`）。
10. 勾选「设置用户名和密码」，然后决定用户名和密码。**请把密码记下来。**
11. 使用无线时，勾选「配置无线局域网」，填入网络名称和密码。
12. 打开「服务」标签，勾选「启用 SSH」。
13. 点「保存」，再点「是」开始写入。

写入需要 5〜10 分钟。完成后取出卡。

> 💡 先做好第 9〜12 步，后面只需要用一次键盘。

## ② 连接到电视

1. 把 microSD 卡插到 Raspberry Pi 背面的卡槽里，插到底。
2. 用 HDMI 线连接 Raspberry Pi 和电视。Raspberry Pi 这一侧用靠近电源的那个接口。
3. 接上网线（若已设置无线则不需要）。
4. 接上 USB 键盘。
5. **最后**再接电源。
6. 把电视的信号源切换到所连接的 HDMI。

稍等片刻画面就会出现。第一次启动需要 2〜3 分钟。

## ③ 安装显示程序

需要用键盘的作业只有这一次。

1. 点画面左上角的黑色方块图标（终端）。
   找不到时，同时按键盘上的 `Ctrl`、`Alt`、`T`。
2. 黑色窗口打开后，**原样**输入下面这一行。

```bash
curl -fsSL https://ckk-kiosk.kai-lab.net/rpi/install.sh | bash
```

3. 按 `Enter` 键。
4. 中途出现要求输入密码时，输入①里决定的密码并按 `Enter`。
   **输入时画面上不会显示任何字符，但已经输入进去了。**
5. 等待约 5 分钟。会滚动很多文字，不用管它。
6. 出现「完成」后，输入下面这一行并按 `Enter`。

```bash
sudo reboot
```

Raspberry Pi 会重新启动。**此时可以拔掉键盘。**

> ⚠️ 输入有误时会出现英文的错误信息。这时再输入一次同样的行即可，
> 重复多少次都没有关系。

## ④ 登记屏幕

重启后，电视上会出现 12 位的关联码。
**从这里开始，步骤与共用终端（平板）完全相同。**

在电脑上打开 **终端管理（SY09）**，切换到「显示屏」标签。

1. 点「添加显示屏」。
2. 在「名称」里填现场的人会叫的名字（例如 `A 线 入口`）。
3. 选择「安装位置」「据点」「显示画面」，点「创建」。
   （新建的显示屏默认就是「生产状况」，之后可以更改。）
4. 点列表中新建那一行的「关联」。
5. 点「扫描显示屏的二维码」，扫描电视上的二维码。
   （扫不上时，也可以在下面的输入框里输入 12 位字符。）
6. 状态变为「待启用」后，点「启用」。

电视的显示会在几秒内切换。安装到此完成。

> 💡 第 1〜3 步可以在准备电视之前先做好。先建好的话，现场只需关联和启用。

> ⚠️ 关联码 **10 分钟**后失效。超时后请点电视画面上的「重新发行代码」，
> 或者把 Raspberry Pi 的电源重新开关一次，会出现新的代码。

## 用 1 台驱动 2 台电视

Raspberry Pi 5 有 2 个 HDMI 接口，1 台就能在 2 台电视上显示**不同的内容**。

把③的那一行加上 `--screens 2` 执行:

```bash
curl -fsSL https://ckk-kiosk.kai-lab.net/rpi/install.sh | bash -s -- --screens 2
```

> 💡 不加选项直接执行时，会自动数出连接的电视数量。只有数不对时才需要
> 用 `--screens` 指定。

重启后，**每台电视会分别显示各自的关联码**。请对每台电视各做一次④
（共 2 次）。画面上会显示「本机 2 块中的第 1 块」，可以分辨正在输入哪个码。

登记完成后，2 台电视会被当作**完全独立的显示屏**。显示画面和显示倍率都能
分别设定，停用其中一台不影响另一台。

> ⚠️ 左右显示反了时，最简单的办法是对调 HDMI 线。

## 不用 Raspberry Pi 也可以

**只是把画面映出来的话，Windows / Mac 的浏览器也能做到。** 适合演示、临时布置，
或者等 Pi 到货之前先用。

1. 在浏览器打开 `https://ckk-kiosk.kai-lab.net/display`
2. 把出现的关联码在终端管理（SY09）的「显示屏」里登记
3. 按 `F11` 全屏，看起来就和电视一样

### 用 1 台电脑出 2 个画面

**只要在第 2 个窗口打开同一个 URL 即可。** 第 2 个窗口会自动成为「2 枚目」，
可以登记成另一台显示屏（不需要改 URL）。

**每个窗口会显示各自的关联码（二维码）。** 请在终端管理里逐个登记。
代码上方会显示「这台机器的 2 个中的第 1 个」，便于区分正在登记哪个窗口。

> ⚠️ 自动判断的是**打开的顺序**，不是在哪一块显示器上。想固定「左边是第 1 个」
> 时，请按下面的写法明确指定编号。

#### 想固定编号时

编号不同就会登记成不同的显示屏，可以各显示各的。

| 窗口 | 打开的 URL |
|---|---|
| 第 1 个 | `.../display?machine=pc-1&screen=1&of=2` |
| 第 2 个 | `.../display?machine=pc-1&screen=2&of=2` |

- `machine` … 这台电脑的名字（随意，但**两个窗口要一样**）
- `screen` … 第几个画面（**从 1 开始**）
- `of` … 这台机器一共出几个画面

这样在终端管理的列表里会**合并成 1 行**，可以选「1 枚目 / 2 枚目」分别查看设置。
不加编号的话，两个窗口共用同一个登记，只能显示相同的内容。

> 💡 `machine` 和 `screen` 只用于区分画面，不参与权限或显示内容的判断。

## 之后要更改时

**不需要碰 Raspberry Pi。** 在电脑上打开 **终端管理（SY09）** 的「显示屏」标签操作。

| 想做的事 | 操作 |
|---|---|
| 更改显示的内容 | 打开该屏幕，在「显示内容」标签点「编辑」，重新选择后「保存」 |
| 修改名称或位置 | 打开该屏幕，修改后「保存」 |
| 暂时停用 | 打开该屏幕，点「暂停」 |
| 移到别处使用 | 打开该屏幕，点「解除关联」（设置会保留） |
| 不再使用 | 打开该屏幕，点「注销」 |

点「解除关联」后，名称和显示画面都会保留，只解除与屏幕的绑定 —
想用同样的设置换一台 Raspberry Pi 时很方便。
点「注销」后，该屏幕会回到显示关联码的画面。

## 常见问题

**Q. 电视上什么都没有（一片漆黑）**
A. 请确认电视的信号源是否切换到了所连接的 HDMI。若仍无显示，
把 HDMI 线换到 Raspberry Pi 的另一个接口试试。

**Q. 画面上显示「无法连接」**
A. 请确认网线有没有松脱。网络恢复后会自动回到原来的显示，不需要做任何操作。

**Q. 又回到关联码画面了**
A. 该屏幕的登记被注销或被暂停了。请在终端管理（SY09）的「显示屏」标签确认状态。
要再次使用时，用画面上显示的关联码重新登记。

**Q. 断电了，需要重新设置吗**
A. 不需要。重新通电后会自动回到原来的显示。

**Q. 显示的内容好像是旧的**
A. 显示内容会按设定的间隔自动重新读取。想立刻更新时，
把 Raspberry Pi 的电源重新开关一次。

**Q. 想再做一台一样的**
A. 请重复本页的①到④。①里做的 microSD 卡内容，对任何一块屏幕都是一样的。
要一次做很多台时，请与信息系统负责人商量
（复制步骤在 `external/rpi-display/README.md`）。
