Operation code **SY06**. Browse the files kept in file storage (SeaweedFS) — uploads and system-generated document PDFs — in a **Finder-style folder browser** to view, download, delete, and upload them.

> No special permission is needed to open this app (login only). **What you can see differs per user**, though: system administrators (`system:ADMIN`) see every file; everyone else sees only the folders allowed by **folder grants** (individual) and the generated files matching their **business-app read permissions** (e.g. read permission on `quote` shows quote PDFs). Deletion cannot be undone, so operate with care.

## What you can do here

- Walk the folder hierarchy to list and preview files (images and PDFs preview right in the right-hand pane).
- Per file: **Open** (view in a new tab), **Download**, and **Delete**.
- **Upload** files into the folder you have open (write permission on that folder required).
- Search by file name or path **across all folders**.
- System administrators can grant and revoke **folder permissions** (user × folder read/write).

## Opening it

- Home (System) → **ファイル管理 (File Management)**, or type `SY06` in the search box.

## Reading the screen

- The **breadcrumb** at the top shows where you are, starting from "すべて" (All). Click an entry to go back to that level.
- **Name** — the file name with an icon (red for PDF, blue for images, gray otherwise). Click a folder to enter it; click a file and a preview appears in the right-hand pane.
- **Size** / **Modified** — file size and last modified time.
- Files the system generated automatically carry a gray "システム" (System) badge.

There are 3 display modes, switched at the top left.

- **List** — a table of name, size, and modified time (default).
- **Icons** — a grid of larger icons.
- **Columns** — levels side by side, left to right, like the Mac Finder's column view.

The "**システムファイル**" (system files) switch next to it toggles whether **leftover files that the OS or a tool generated by itself** — `.DS_Store`, `*.tmp` and so on (decided by `lib/system-files.ts`) — are shown. Business files such as document PDFs never count as "system files" and are always shown (the toggle is a display classification only, unrelated to access control).

The **Refresh** button at the top right reloads the list. If storage is unreachable, a red warning appears at the top of the screen (`SEAWEED_FILER_URL` and the containers need checking).

## Searching

Type into the search box "ファイル名・パスで検索（全フォルダ横断）" (search by file name or path, across all folders) and every file whose name or path matches is listed, regardless of the folder you are in.

## Viewing, downloading, deleting

Select a file and the right-hand pane shows a preview (images and PDFs) along with its **path**, **size**, **modified time**, and **type**, plus these actions:

- **Open** — shows the file in a new tab.
- **Download** — downloads the file.
- **Delete** — deletes after a confirmation dialog. **This cannot be undone.** Shown only for files you have write permission on.

> Document PDFs (under `pdfs`) are referenced by business documents such as quotes and invoices. Deleting them can break the PDF link on those documents, so avoid deleting files tied to business data.

## Uploading

1. Open the folder you want to put the file in. The **Upload** button appears **only when you have write permission** on the folder you have open (administrators always see it).
2. Press **Upload** and pick a file.
3. The file is saved into **the folder you have open**, with a timestamp prefix on the file name (to avoid overwriting same-named files; pressing it at the root saves under `uploads`).
4. On completion a notification appears and the list refreshes.

## Folder permissions (system administrators only)

**フォルダ権限** (Folder permissions) at the top right manages user × folder access rights (`app.file_folder_grants`).

1. Enter the target folder into **Folder (path prefix)**. It matches by prefix, so everything underneath is covered.
2. Pick the **User**, tick **Allow writing too** (upload and delete) if needed, and press **Grant**.
3. The granted list carries "読み書き" (read and write) / "読み取り" (read only) badges; press **Delete** on a row to revoke.

Even without a folder grant, a business-app read permission lets the user read that app's generated files (the folder → permission-code map is `APP_PREFIX_PERMISSIONS` in `lib/file-access.ts`; e.g. `pdfs/quotes` → `quote`, `attachments/work_orders` → `work_order`). Writing (upload and delete) requires a folder grant with "Allow writing too" or administrator rights.

## FAQ

- **"Cannot connect to storage" is shown** — the file server (SeaweedFS) is down or misconfigured. Contact your system administrator.
- **A file that should exist is not visible** — you lack read access to its folder (a folder grant or the matching business-app read permission), or it is hidden as a leftover file. The latter can be shown with the "システムファイル" (system files) switch.
- **The Upload button does not appear** — you have no write permission on the folder you have open. Ask a system administrator for a folder grant with write allowed.
- **I deleted a file by mistake** — it cannot be restored from this screen. Ask your system administrator about restoring from backup.
- For the documents that generate these files, see their app manuals, e.g. [Quote (見積書)](/manual/en/operations/sales/quote/user) and [Invoice (請求書)](/manual/en/operations/billing/invoice/user).
