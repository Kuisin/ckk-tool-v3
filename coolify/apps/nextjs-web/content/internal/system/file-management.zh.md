操作代码 **SY06**。以 **Finder 风格的文件夹浏览器**逐层浏览文件存储（SeaweedFS）中保存的文件——上传文件以及系统生成的单据 PDF——并进行预览、下载、删除和上传。

> 打开本应用**不需要**特殊权限（仅需登录）。但**可见范围因用户而异**：系统管理员（`system:ADMIN`）可见全部文件；其他人只能看到**文件夹权限**（单独授予）允许的文件夹，以及与**业务应用查看权限**对应的生成文件（例：有 `quote` 的查看权限就能看到报价单 PDF）。删除无法撤销，请谨慎操作。

## 本应用能做什么

- 逐层浏览文件夹，列出并预览文件（图片和 PDF 可直接在右侧窗格确认）。
- 对每个文件进行 **打开**（在新标签页显示）、**下载**、**删除**。
- 向当前打开的文件夹 **上传** 文件（需要该文件夹的写入权限）。
- 按文件名・路径**跨全部文件夹搜索**。
- 系统管理员可以授予・取消 **文件夹权限**（用户 × 文件夹的查看/写入）。

## 打开方式

- 主页（系统）→ **ファイル管理（文件管理）**，或在搜索框输入 `SY06`。

## 界面说明

- 界面上部的**面包屑**从「すべて」（全部）起依次显示当前位置。点击可返回该层。
- **名称** … 带图标（PDF 为红色、图片为蓝色、其他为灰色）的文件名。点击文件夹进入其中，点击文件则在右侧窗格显示预览。
- **大小** / **更新时间** … 文件大小与最后更新时间。
- 系统自动生成的文件带有灰色的「システム」（系统）徽章。

显示形式可在左上角切换，共 3 种。

- **列表** … 名称・大小・更新时间的表格显示（默认）。
- **图标** … 以较大图标排列的网格显示。
- **分栏** … 层级从左到右排列的 Mac Finder 风分栏显示。

旁边的「**システムファイル**」（系统文件）开关，用于切换是否显示 `.DS_Store`、`*.tmp` 等 **OS・工具自动生成的残留文件**（由 `lib/system-files.ts` 判定）。单据 PDF 等业务文件不属于「系统文件」，始终显示（该开关只是显示上的分类，与访问控制无关）。

右上角的 **刷新** 按钮可重新加载列表。无法连接存储时，界面顶部会显示红色警告（需要检查 `SEAWEED_FILER_URL` 与容器运行状态）。

## 搜索

在搜索框「ファイル名・パスで検索（全フォルダ横断）」（按文件名・路径搜索，跨全部文件夹）中输入后，无论当前在哪个文件夹，名称或路径匹配的文件都会被跨文件夹列出。

## 预览・下载・删除

选中文件后，右侧窗格会显示预览（图片・PDF）以及**路径**・**大小**・**更新时间**・**类型**，并可进行以下操作。

- **打开** … 在新标签页中显示文件。
- **下载** … 下载文件。
- **删除** … 在确认对话框上删除。**此操作无法撤销**。仅对有写入权限的文件显示。

> 单据 PDF（`pdfs` 目录下）被报价单、发票等业务单据引用。删除后相关单据可能无法再打开 PDF，请避免删除与业务数据关联的文件。

## 上传

1. 打开想放入的文件夹。**上传** 按钮**仅在对当前打开的文件夹有写入权限时**显示（管理员始终显示）。
2. 点击 **上传**，选择文件。
3. 文件会保存到**当前打开的文件夹**，文件名带日期时间前缀（防止同名覆盖；在根目录点击时保存到 `uploads` 下）。
4. 完成后显示通知，列表随之更新。

## 文件夹权限（仅限系统管理员）

通过右上角的 **フォルダ権限**（文件夹权限），管理以用户 × 文件夹为单位的访问权限（`app.file_folder_grants`）。

1. 在 **文件夹（路径前缀匹配）** 中输入目标文件夹。因为是前缀匹配，其下的全部内容都会成为对象。
2. 选择 **用户**，必要时勾选 **同时允许写入**（可上传・删除），然后 **授予**。
3. 已授予列表带有「読み書き」（读写）/「読み取り」（只读）徽章，可通过行内的 **删除** 取消。

即使没有文件夹权限，只要有业务应用的查看权限，就能读取该应用生成的文件（文件夹 → 权限代码的对应关系见 `lib/file-access.ts` 的 `APP_PREFIX_PERMISSIONS`。例：`pdfs/quotes` → `quote`、`attachments/work_orders` → `work_order`）。写入（上传・删除）则只有带「同时允许写入」的文件夹权限或管理员才可以。

## 常见问题

- **显示"无法连接存储"** … 文件服务器（SeaweedFS）停止运行或配置有误，请联系系统管理员。
- **应该存在的文件看不到** … 没有该文件夹的查看权限（文件夹权限或对应业务应用的查看权限），或者它作为残留文件被隐藏了。后者可用「システムファイル」（系统文件）开关显示。
- **不显示上传按钮** … 对当前打开的文件夹没有写入权限。请向系统管理员申请文件夹权限（允许写入）。
- **误删了文件** … 无法从本界面恢复。请联系系统管理员从备份中恢复。
- 生成这些文件的单据操作请参见各应用手册，如[报价单（見積書）](/manual/zh/operations/sales/quote/user)、[发票（請求書）](/manual/zh/operations/billing/invoice/user)。
