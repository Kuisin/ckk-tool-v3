操作コード **SY08**。拠点フロアの共有タブレット（キオスク端末）にログインするための **QRカード** を発行・管理するアプリです。

> このアプリの利用には **キオスク管理権限** が必要です。すべての操作は監査ログに記録されます。

## このアプリでできること

- QRカードの **発行**（まとめて 1〜100 枚）
- カードの **ユーザーへの割当**（1 ユーザーにつき 1 枚）
- 印刷シートからの **カード印刷**（名刺サイズ）
- カードの **一時停止 / 再開 / 取り消し**
- **有効期間つき割当**（開始日・終了日を指定するテンポラリカード）
- **同時ログイン上限** の変更（1〜10 台）
- **PIN のリセット / ロック解除**

## カードの状態

- **未割当** … 発行済みで、まだ誰にも割り当てていない状態。
- **割当済** … ユーザーに割り当てられ、ログインに使える状態。
- **一時停止** … 一時的にログインを止めた状態。「再開」で戻せます。
- **取り消し** … 完全に無効化した状態。**元に戻せません**（紛失・退職時など）。

## 発行から利用開始まで

1. **カードを発行** で枚数（1〜100）を指定します。カードは「未割当」で作られます。
2. 行メニューの **ユーザーに割当** で割当先を選びます。割当できるのは有効なユーザーのみで、**1 ユーザーにつき 1 枚** です。
3. カードにチェックを付けて **選択したカードを印刷**（または行メニューの **印刷**）を押すと、印刷シートが別タブで開きます。A4 名刺用紙 10 面（エーワン等）の定位置に、名刺サイズ（91×55mm）のカードが 1 ページ 10 枚（2 列 × 5 行）並び、四隅のトンボに合わせて断裁できます。シート上部には原寸確認用の 50mm 目盛りを薄く印字しています。

**印刷はこの画面の「印刷」（ブラウザ印刷）を使うこと。** シートは CSS の `@page { size: 210mm 297mm }` で用紙サイズを**長さ**で宣言しており、これは「絶対ページボックス」＝ UA が用紙に合わせて拡大縮小してはならない指定なので、常に原寸で出ます（`size: A4` のようなキーワード指定は逆に "scalable" ＝ 縮小されうる。旧実装が縮んでいた原因）。印刷ダイアログで確認するのは用紙が A4 であることだけ。

「PDFで保存」は保存・配布用です。**PDF になった時点で CSS の絶対指定は効かず**、ビューアの「印刷可能領域に合わせる」で数 % 縮むことがあります（PDF 側もページボックスを A4 より一回り小さく取って対策していますが、ビューア依存）。名刺用紙に刷るときは PDF 経由にしないこと。
4. 印刷したカードを本人に渡します。タブレットで QR をかざし、初回に **PIN**（4〜6 桁の数字）を設定するとログインできます。

一覧のカード ID はセキュリティのため **末尾 8 文字のみ** 表示されます。フル ID は印刷シートの QR にだけ含まれます。

## PIN のしくみ

- PIN は本人がタブレットで初回ログイン時に設定します（4〜6 桁）。管理者が PIN の値を見たり設定したりすることはできません。
- 同じ端末で **48 時間以内** に使用しており、かつ最後の PIN 確認から **2 週間以内** なら、QR をかざすだけでログインできます。それ以外の場合は PIN 入力が求められます（新しい端末での初回は必ず PIN 入力）。
- PIN を **5 回連続** で間違えると **15 分間ロック** されます。一覧の PIN 列に「ロック中」と表示されます。
- **PINロック解除** … ロックだけを解除します。PIN はそのまま残ります。
- **PINリセット** … PIN を消去します。本人が PIN を忘れたときに使います。次回ログイン時に新しい PIN を設定します。

ログイン後のセッションは無操作 **5 分** で自動ログアウト、最長 **8 時間** です。

## 有効期間と同時ログイン上限

- **有効期間** … カードに **開始日・終了日** を設定できます（テンポラリカード。片側だけの指定も可、両方外すと無期限に戻ります）。開始日は当日 0:00 から、終了日は当日 23:59 まで有効です。期間外のカードはキオスクで**ログインできません**（判定はログイン時のみ — 既存セッションは 8 時間ハード期限 / 5 分アイドルで自然失効します）。一覧には期間が表示され、期間外のカードには「**期限切れ**」（赤）/「**開始前**」（黄）のバッジが付きます。
- **同時ログイン上限** … 1 枚のカードで同時にログインできる端末数です（既定 1、**1〜10** で変更可）。上限を超えてログインすると、**最終活動がいちばん古いセッションから失効**します（= いちばん古い端末がログアウトされる）。上限を下げても既存セッションは即時には切れず、次のログイン時に反映されます。

## 停止・取り消し

- **一時停止** … このカードでのログインを止めます。「再開」で元に戻せます。
- **取り消し** … カードを完全に無効化します。**元に戻せません**。実行すると、そのカードで開いているキオスクセッションも即時失効します。

割当先を変えたいときは、既存カードを **取り消し** てから、新しいカード（または未割当カード）を割り当てます。割当済カードをそのまま別のユーザーに付け替えることはできません。

## 一覧・検索

- カード ID・ユーザー名で検索、状態で絞り込みできます。
- 列: カードID / 割当ユーザー / 状態 / PIN（設定済・未設定、ロック中） / 最終使用 / 使用回数。
