会社の実績を数字とグラフでまとめて見られる分析ツール「**Metabase**」の使い方です。業務管理システム本体（このマニュアルの他のページ）とは別のツールで、そこに入っているデータをグラフや表にして見せてくれます。

> 💡 このページの画面は、説明のためのサンプルデータで撮影したものです。実際の画面には自社の実データが表示されます。Metabase 自体の画面（検索欄やメニューなど）も日本語表示です。

## このツールでできること

- 受注・生産・請求・在庫の状況を、グラフと表でまとめて見られます。
- 勤怠（労働時間・残業時間）の推移を、部署や拠点ごとに見られます。
- 期間や状態で絞り込んで見られます。
- グラフにマウスを合わせると、正確な数値が出ます。

自分で新しいグラフを作ったり、表示できる範囲を変えたりすることはできません。見られる範囲は Metabase 側の権限設定で管理されています。開けない、または見たいデータが無いときはシステム管理者にご相談ください。

## 開き方

`https://bi.ckk-tool.co.jp` を開きます。社内メールアドレスと、ふだん使っている社内共通アカウントのパスワードでサインインしてください。

サインインすると、左上のフォルダアイコンから 2 つの領域（コレクション）を開けます。

- **CKK 業務** … 受注・売上 / 生産進捗 / 請求 / 在庫 の 4 枚のダッシュボード
- **労務分析** … 勤怠（労働時間・残業時間）のダッシュボード 1 枚

## 共通の使い方

### 期間で絞り込む

どのダッシュボードにも、上部に **期間** の絞り込みがあります。開くと、今日・今週・今月・過去 N 日・日付を指定、などから選べます。選んだ期間に応じて、下のグラフや表がすべて更新されます。指定しなければ、全期間が対象です。

### 表示通貨を切り替える

「受注・売上」と「請求」には **表示通貨** の絞り込みがあります。既定は JPY（円）です。USD に切り替えると、合計金額が通貨マスタの為替レートで換算され、ドル建ての金額に置き換わります。

### 状態で絞り込む

「受注・売上」には **状態（明細）** と **状態（請書）** の 2 つの絞り込みがあります。前者は注文明細（受注 1 行ごと）の状態、後者は注文請書（受け取った注文そのもの）の状態です。別々の項目なので、別々に絞り込めます。

## 受注・売上

見積・受注の実績をまとめたダッシュボードです。

![受注・売上ダッシュボード](./assets/screenshots/analytics-sales-01.png)

- **注文請書 総数 / 注文明細 総数** … 件数です。
- **受注金額 合計** … 選んだ表示通貨での合計金額です（キャンセルは含みません）。
- **注文請書 状態別 / 注文明細 状態別** … 状態ごとの件数です。
- **受注金額 月次** … 月ごとの受注金額の推移です。
- **顧客別 受注金額 上位** … 受注金額の多い顧客の上位です。
- **最近の注文明細** … 直近の注文明細を一覧できる表です。行の注文明細番号を押すと、業務管理システム側の詳細画面が開きます。
- **営業担当別 受注金額 / 営業担当別 受注金額 月次** … 営業担当ごとの受注金額と、その月次推移です。

## 生産進捗

指示書（製造の指示）と工程の進み具合をまとめたダッシュボードです。

![生産進捗ダッシュボード](./assets/screenshots/analytics-production-01.png)

- **指示書 総数 / 進行中の指示書 / 工程 総数** … 件数です。
- **指示書 状態別 / 指示書 承認状態別 / 工程 状態別** … 状態ごとの件数です。
- **進行中・承認待ちの指示書** … いま動いている指示書の一覧です。指示書番号を押すと詳細画面が開きます。

## 請求

請求書と締日処理の状況をまとめたダッシュボードです。

![請求ダッシュボード](./assets/screenshots/analytics-billing-01.png)

- **請求書 総数 / 請求額 合計** … 件数と、選んだ表示通貨での合計金額です。
- **請求書 状態別 / 締日処理 状態別** … 状態ごとの件数です。
- **請求額 月次** … 月ごとの請求額の推移です。

## 在庫

製品・素材の在庫と、在庫予約の状況をまとめたダッシュボードです。

![在庫ダッシュボード](./assets/screenshots/analytics-inventory-01.png)

- **製品在庫 総数量 / 素材在庫 総数量** … 全拠点合計の数量です。
- **製品在庫 上位 / 素材在庫 上位** … 数量の多い製品・素材の上位です。
- **在庫予約 状態別** … 在庫予約の状態ごとの件数です。

## 労務分析

勤怠（労働時間・残業時間）の推移をまとめたダッシュボードです。

![労務分析ダッシュボード](./assets/screenshots/analytics-labor-01.png)

- **総労働時間（週次・部門別）** … 部署ごとの週間労働時間の推移です。
- **【工場別】労働時間（週次）** … 拠点（工場）ごとの週間労働時間の推移です。
- **残業時間の月次合計（今月）** … 拠点・部署ごとの、今月の残業時間の合計です。
- **残業時間の日次集計（今月）** … 部署・社員ごとの、今月の日別の残業時間です。他のグラフと違い個人名が出るため、見られる人は限られています。

このダッシュボードだけは常に「今月」の勤怠を対象にしたグラフ・表が含まれます。期間の絞り込みは、週次の 2 枚（総労働時間・工場別）にだけ効きます。
