可以用图表和表格汇总查看公司业绩的分析工具「**Metabase**」的使用方法。它与业务管理系统本体（本手册的其他页面）是不同的工具，读取的是同一份数据，只是以图表和表格的形式呈现。

> 💡 本页的截图使用示例数据拍摄，仅供说明。实际画面会显示贵公司的真实数据。Metabase 自身的界面（搜索框、菜单等内容以外的部分）为英文显示。

## 可以做什么

- 汇总查看销售、生产、请款、库存的状况（图表和表格）。
- 按部门或据点查看考勤（工作时长、加班时长）的变化趋势。
- 按期间或状态筛选查看。
- 将鼠标悬停在图表上可查看精确数值。

无法自行创建新图表，也无法更改可查看的范围——可查看范围由 Metabase 自身的权限设置管理。若无法打开，或找不到需要的数据，请联系系统管理员。

## 打开方法

打开 `https://bi.ckk-tool.co.jp`，使用公司邮箱地址和平时使用的公司统一账号密码登录。

登录后，点击左上角的文件夹图标可打开以下两个集合：

- **CKK 業務（业务）** — 4 个仪表板：受注・売上（销售）/ 生産進捗（生产进度）/ 請求（请款）/ 在庫（库存）
- **労務分析（劳务分析）** — 1 个考勤仪表板

## 通用操作

### 按期间筛选

每个仪表板顶部都有 **期間（期间）** 筛选项。点开后可选择今天、本周、本月、最近 N 天或指定日期范围。下方所有图表和表格都会随之更新。不设置则代表不限期间。

### 切换显示币种

「受注・売上（销售）」和「請求（请款）」有 **表示通貨（显示币种）** 筛选项。默认为 JPY（日元）。切换为 USD 后，会按币种主数据中的汇率换算，改为显示美元金额。

### 按状态筛选

「受注・売上（销售）」有两个独立的筛选项：**状態（明細）（明细状态）** 和 **状態（請書）（订单确认书状态）**。前者是每一行订单明细的状态，后者是订单确认书（收到的整张订单）本身的状态。二者相互独立，可分别筛选。

## 受注・売上（销售）

报价与订单业绩汇总。

![销售仪表板](./assets/screenshots/analytics-sales-01.png)

- **注文請書 総数 / 注文明細 総数（订单确认书 / 订单明细总数）** — 件数。
- **受注金額 合計（订单金额合计）** — 按所选显示币种统计的合计金额（不含已取消的订单）。
- **注文請書 状態別 / 注文明細 状態別（按状态）** — 各状态的件数。
- **受注金額 月次（订单金额月度趋势）**。
- **顧客別 受注金額 上位（按客户排名的订单金额）**。
- **最近の注文明細（最近的订单明细）** — 最近订单明细的列表。点击订单明细编号可打开业务管理系统中的详情页面。
- **営業担当別 受注金額 / 営業担当別 受注金額 月次（按销售负责人统计的订单金额及其月度趋势）**。

## 生産進捗（生产进度）

工单及其工序的进展情况。

![生产进度仪表板](./assets/screenshots/analytics-production-01.png)

- **指示書 総数 / 進行中の指示書 / 工程 総数（工单 / 进行中工单 / 工序总数）** — 件数。
- **指示書 状態別 / 指示書 承認状態別 / 工程 状態別（按状态）** — 各状态的件数。
- **進行中・承認待ちの指示書（进行中・待审批的工单）** — 当前进行中或待审批的工单列表。点击工单编号可打开详情页面。

## 請求（请款）

请款单与结算处理的状况。

![请款仪表板](./assets/screenshots/analytics-billing-01.png)

- **請求書 総数 / 請求額 合計（请款单总数 / 请款金额合计）** — 件数以及按所选显示币种统计的合计金额。
- **請求書 状態別 / 締日処理 状態別（按状态）** — 各状态的件数。
- **請求額 月次（请款金额月度趋势）**。

## 在庫（库存）

产品、材料库存及库存预留状况。

![库存仪表板](./assets/screenshots/analytics-inventory-01.png)

- **製品在庫 総数量 / 素材在庫 総数量（产品库存 / 材料库存总数量）** — 全部据点的合计数量。
- **製品在庫 上位 / 素材在庫 上位（按数量排名的产品 / 材料）**。
- **在庫予約 状態別（按预留状态）** — 各状态的件数。

## 労務分析（劳务分析）

考勤（工作时长、加班时长）变化趋势。

![劳务分析仪表板](./assets/screenshots/analytics-labor-01.png)

- **総労働時間（週次・部門別）（总工作时长，按周・按部门）** — 各部门的每周工作时长趋势。
- **【工場別】労働時間（週次）（按工厂统计的工作时长，按周）** — 各据点的每周工作时长趋势。
- **残業時間の月次合計（今月）（本月加班时长月度合计）** — 按据点、部门统计的本月加班时长合计。
- **残業時間の日次集計（今月）（本月加班时长每日汇总）** — 按部门、员工、日期统计的本月每日加班时长。与其他图表不同，此表会显示个人姓名，因此可查看的人员范围有限。

只有这个仪表板中，部分图表始终固定显示「本月」的考勤数据。期間（期间）筛选项只对两张按周统计的图表（总工作时长、按工厂）生效。
