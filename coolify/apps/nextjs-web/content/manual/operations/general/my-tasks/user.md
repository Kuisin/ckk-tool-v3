自分がやるべきことだけを 1 つの画面にまとめたアプリです。操作コードは `CM01` です。以前は「承認管理」（`PD03`）という別のアプリでしたが、作業予定と統合してこちらに移りました。

## このアプリでできること

タブに分かれた次のものを、まとめて確認できます。

- **作業予定** … 自分に割り当てられた、まだ終わっていない作業計画。
- **承認依頼中** … 自分が承認する番になっている書類（承認権限がある人にだけ出ます）。
- **未回答のフォーム** … 自分に共有されていて、まだ出していないフォーム。
- **回答済みのフォーム** … 自分が出したフォームの回答。
- **完了した申請** … 自分宛に届いた、フォームの完了通知。
- **文書のコメント** … 自分が作った・直した文書に付いた、まだ解決していないコメント。

行をクリックすると、その作業・書類・フォームの画面がそのまま開きます。

## 表示するタブを選ぶ

タブが多くて使わないものがあるときは、画面右上の「**表示するタブ**」から非表示にできます。設定は自分だけのもので、他の人の画面には影響しません。

## 作業予定

自分に割り当てられた工程（work_order_step_plans）のうち、まだ終わっていないものを計画日の順に並べます。行をクリックすると、その工程の実行画面（共有端末アプリ）へのリンクが開きます。

## 承認依頼中

自分が承認する番になっている書類だけを、種類をまたいで一覧します。承認の「受信箱」だと思ってください。**承認の権限が無い人にはこのタブ自体が出ません。**

一覧に出るのは、次の書類です。

- **指示書** … 承認設定で決めた段（[指示書](/manual/ja/operations/production/work-order/user) PD02）
- **注文請書** … 確定前の承認（[注文請書](/manual/ja/operations/sales/order-acceptance/user) SA04）
- **注文請書キャンセル** … 確定済みの注文請書をキャンセルするための依頼。行をクリックすると、その注文請書の画面が開きます
- **素材発注書** … 発注する前の承認（[素材発注書](/manual/ja/operations/purchasing/purchase-order/user) PU02）
- **購買依頼** … [購買依頼](/manual/ja/operations/purchasing/purchase-request/user) PU01
- **工程フロー変更** … 承認済み・進行中の指示書で、工程の分岐を足したり直したりする変更。行をクリックすると、その指示書の画面が開きます

### 用語（このタブで出てくる言葉）

- **承認グループ** … 承認していい人をまとめた名簿です。ここに入っている人だけが、承認・差し戻しをできます。段ごとにどのグループが承認するかは 承認設定（`MS0B`）で決まっています。
- **代理（だいり）** … 承認する人が不在のあいだ、代わりに承認できるように期間を決めて任された人のことです。
- **段階（だんかい）** … 承認の順番です。何段の承認を通るかは、書類の種類ごとに承認設定（`MS0B`）で決まっていて、書類の内容によって変わることもあります。
- **差し戻し（さしもどし）** … 内容に問題があるとき、書類を作った人に返すことです。書類は「下書き」に戻ります。

### 画面の見かた

- **種別** … 「指示書」「注文請書」「注文請書キャンセル」「素材発注書」「購買依頼」「工程フロー変更」のどれかを、色つきのバッジで表示します。
- **対象番号** … その書類の番号です。
- **段階** … 「**2/3 部門承認**」のように、**いま何段目か / 全部で何段か** と段の名前が出ます（1 段だけのときは段の名前だけです）。最後の段は色が変わり、あと 1 つで通ることが分かります。段が「全員」の設定のときは「全員 ◯/◯」も添えられます。
- **依頼者** … 承認を頼んだ人です。
- **依頼日時** … 頼まれた日時です。**古いものが上** に並びます。待たせている依頼が上に来ます。
- **備考** … 依頼のときに書かれたメモです。
- 検索欄で **対象番号・依頼者・備考** を検索できます。「**種別**」でも絞り込めます。
- 「**閲覧権限なし**」というバッジが付いた行は、承認グループには入っているものの、その書類を開く権限が無い状態です。承認は書類の画面で行うため、管理者に権限の付与を相談してください。

### 承認する

1. 一覧の行をクリックします。その書類の画面が開きます。
2. 画面の上のほうに「**手続き状況**」があり、今どの段階かが分かります。
3. 自分が承認できる番であれば、「**承認**」のボタンが出ます。
4. 内容を確認して、ボタンを押します。

何段の承認を通るかは書類ごとに決まっています。カードに「第 2/3 段「部門承認」・製造部長」のように、いま何段目かが出ます。最後の段まで終わると、次の作業（指示書なら製造の開始）に進める状態になります。

段が「**全員**」の設定になっているときは、その段の対象者全員が承認するまで次へ進みません。カードに「残り ◯ 名」と、まだ承認していない人の名前が出ます。

> 💡 承認できるのは、その段の承認グループに入っている人と、期間内の代理の人だけです。ボタンが出ないときは「◯◯ のメンバーのみ承認・差し戻しできます」と表示されます。

### 差し戻す

内容に問題があるときは、書類を作った人に返します。

1. 「**差し戻し**」を押します。
2. 「差し戻しの確認」という小さな画面が出ます。
3. 「**差し戻し理由**」に理由を書きます（必ず必要です）。
4. 「**差し戻す**」を押します。

差し戻すと、その書類は「**下書き**」に戻り、作った人の画面に理由が赤く表示されます。作った人が直したあと、もう一度承認依頼を出します。

#### 差し戻し理由 [#field-reject-reason]

差し戻すときの理由です。**依頼した人に、そのまま見えます。**「数量が注文と違う」「素材の指定が抜けている」のように、**何を直せばよいかがわかる書き方**にしてください。理由は履歴に残るので、あとから「なぜ止まったのか」をたどれます。

### 承認の記録

承認・差し戻しをすると、「手続き状況」の下に **承認記録** が残ります。誰がいつ、どの段階で、承認したのか差し戻したのか、コメントも含めて分かります。代理の人が承認したものには「（代理: 原承認者）」が付きます。

## 未回答のフォーム / 回答済みのフォーム

[フォーム](/manual/ja/operations/general/forms/user)（`CM02`）のうち、自分に共有されていて回答できるもの（締切が近い順）と、自分が出した回答を並べます。回答者を表示しない設定のフォームでも、自分の分は自分に見えます（他人には出ません）。編集期限内であれば、回答済みのタブから開いて直せます。

## 完了した申請

自分宛に届いた、フォームの**完了通知**を並べます。「完了した申請ぜんぶ」ではなく、フォームの共有設定で完了通知が付いた宛先にだけ届きます。未読の行は強調表示されます。

## 文書のコメント

自分が作った・直した文書に付いた、まだ解決していない行コメントを集めます。自分で自分に付けたコメントは出ません。指摘の見落としを防ぐための「レビュー待ち」一覧です。

## よくある質問・困ったとき

**Q. 「承認依頼中」タブが見当たりません。**
A. 承認の権限が無いためです。承認するには、対象書類の段の承認グループに入っている必要があります。管理者に相談してください。

**Q. 一覧に何も表示されません。**
A. いま該当する予定・依頼・回答が無い状態です。処理が済んだものはそれぞれの一覧から自動で消えます。

**Q. 承認のボタンが出ません。**
A. その段の承認グループに入っていないためです。管理者に、承認設定でのグループ登録を相談してください。

**Q. 行に「閲覧権限なし」というバッジが付いています。**
A. 承認グループには入っていますが、その書類を開く権限がありません。承認・差し戻しは書類の詳細画面で行うため、管理者に権限の付与を相談してください。

**Q. 差し戻しのボタンを押したら「差し戻し理由を入力してください」と出ました。**
A. 理由が空のままです。理由は必ず必要なので、内容を書いてからもう一度「差し戻す」を押してください。

**Q. さっきまであった承認依頼が一覧から消えました。**
A. ほかの承認できる人が先に処理した可能性があります。処理が済んだ依頼はこの一覧から自動で消えます。書類そのものは、それぞれのアプリから開けます。

**Q. 自分が休みのあいだ、承認が止まってしまいます。**
A. 期間を決めて代理の人を設定できます。[承認設定](/manual/ja/operations/masters/approval-setting/user)の設定になるので、管理者に相談してください。

**Q. 使わないタブを消したいです。**
A. 画面右上の「表示するタブ」から非表示にできます。あとから戻すこともできます。

## 必要な権限

この画面に特別な権限は要りません。ログインしていれば使えます。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
