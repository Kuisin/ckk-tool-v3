人が手で在庫の **入庫・出庫・移動を記録する唯一の入口** です。操作コードは `ST06` です。

> ⚠️ このアプリは今のところ **テスト用の環境だけ** で使えます。本番で使えるようになるまでに、画面や手順が変わることがあります。

> このアプリが属するフロー … [生産の流れ](/manual/ja/process/production)

## このアプリでできること

- 「入庫」「出庫」「移動」のどれかを、[移動タイプ](/manual/ja/operations/inventory/movement-types/user)（ST09）から選んで記録できます。
- 品目・数量を入れるだけで、その場で 1 件の[入出庫伝票](/manual/ja/operations/inventory/inventory-movements/user)（ST04）ができます。
- 続けて何件も登録できるように、直前に選んだ「移動タイプ」「出庫元」「入庫先」は次の入力にも残ります。

**在庫の数を人が直接直したいときは、必ずこのアプリを使います。** [在庫管理](/manual/ja/operations/inventory/inventory-management/user)（ST01）の「移動」は場所を変えるだけの専用の入口で、入庫・出庫そのものはここでしか記録できません。

## 用語（このページで出てくる言葉）

- **移動タイプ** … 「何をする移動か」の種類です。あらかじめ[移動タイプ](/manual/ja/operations/inventory/movement-types/user)（ST09）に登録されたものから選びます。「入庫」「出庫」「移動」のどの向きの動きかが決まっています。
- **出庫元 / 入庫先** … それぞれ「どこから減るか」「どこへ増えるか」です。移動タイプによって、どちらか一方だけ、両方、またはどちらも不要かが決まっています。
- **品目** … 動かす製品または素材です。

## 入力する

1. 「**移動タイプ**」を選びます。選ぶと、向き（入庫 / 出庫 / 移動）のバッジが出ます。
2. その移動タイプが必要とするなら、「**出庫元**」（拠点 → 保管場所 → 棚）を選びます。
3. その移動タイプが必要とするなら、「**入庫先**」（拠点 → 保管場所 → 棚）を選びます。
4. 「**品目**」を検索して選びます。製品か素材かのバッジが出ます。
5. 「**数量**」を入れます。製品は整数だけ、素材は小数第 3 位まで入れられます。
6. 製品を入庫するときは、必要なら「**ロット番号**」を入れます（任意）。
7. 必要なら「**備考**」を書きます。
8. 「**登録**」を押します。

入れた内容に問題があれば、その場で赤い案内が出ます（品目が未選択、数量が 0 以下、出庫元・入庫先が未入力、移動で出庫元と入庫先が同じ、など）。案内が出ているあいだは登録できません。

登録すると、その内容で[入出庫伝票](/manual/ja/operations/inventory/inventory-movements/user)（ST04、事由「手動」）が 1 枚できます。「移動」の場合は、出庫元からの出庫が先に、入庫先への入庫が後に記録されます（在庫が足りないときに、増える方だけが先に起きてしまわないようにするためです）。

登録が終わると、緑色の案内とその伝票へのリンクが出ます。**「移動タイプ」「出庫元」「入庫先」は次の入力のために残ります** — 「品目」「数量」「ロット番号」「備考」だけが空に戻ります。同じ移動タイプで何件も続けて登録するときに、選び直す手間を減らすためです。

このアプリを使うには、在庫の権限が必要です。

## よくある質問・困ったとき

**Q. 移動タイプを選んだのに、出庫元も入庫先も出てきません。**
A. その移動タイプが出庫元・入庫先のどちらも必要としない設定になっています。[移動タイプ](/manual/ja/operations/inventory/movement-types/user)（ST09）で確認・変更してください。

**Q. 登録しようとしたら、足りないという案内が出ます。**
A. 出庫元にその品目の在庫が、入れたい数量ぶん無いということです。[在庫管理](/manual/ja/operations/inventory/inventory-management/user)（ST01）や[在庫一覧](/manual/ja/operations/inventory/stock-overview/user)（ST02）で実際の在庫数を確認してください。

**Q. 登録した内容を直したいのですが。**
A. このアプリには直す操作がありません。間違えたときは、逆方向の登録をもう一度行って戻してください。

**Q. 移動タイプの選択肢を増やしたいのですが。**
A. [移動タイプ](/manual/ja/operations/inventory/movement-types/user)（ST09）で管理者が登録します。

## 必要な権限

この画面を使うには **在庫**（`inventory`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 在庫 の 閲覧 |
| 追加・変更・削除する | 在庫 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
