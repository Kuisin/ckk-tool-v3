由人**手动记录库存入库・出库・调拨的唯一入口**。操作码是 `ST06`。

> ⚠️ 本应用目前 **仅在测试环境** 中可用。在正式投入使用之前，画面和操作步骤可能会有变化。

> 本应用所属的流程……[生产流程](/manual/zh/process/production)

## 本应用可以做什么

- 从[移動タイプ](/manual/zh/operations/inventory/movement-types/user)（ST09）中选择「入库」「出库」「调拨」之一并记录。
- 只需输入品目・数量，当场即可生成一张[入出庫伝票](/manual/zh/operations/inventory/inventory-movements/user)（ST04）。
- 为方便连续登记多条，上一次选择的「移动类型」「出库源」「入库目的地」会保留到下一次输入。

**想由人手直接纠正库存数量时，请务必使用本应用。** [在庫管理](/manual/zh/operations/inventory/inventory-management/user)（ST01）的「移动」只是变更存放位置的专用入口，真正的入库・出库只能在这里记录。

## 术语（本页出现的词语）

- **移動タイプ**（移动类型）… 「这是做什么用的移动」的种类。从预先在[移動タイプ](/manual/zh/operations/inventory/movement-types/user)（ST09）中登记好的选项中选择，决定了是入库・出库・调拨中的哪一种方向。
- **出庫元 / 入庫先**（出库源 / 入库目的地）… 分别是「从哪里减少」和「增加到哪里」。根据移动类型的不同，可能只需其中一个、两个都需要，或都不需要。
- **品目**（品目）… 要移动的产品或材料。

## 输入

1. 选择「**移動タイプ**」（移动类型）。选定后会显示方向（入库 / 出库 / 调拨）的徽章。
2. 若该移动类型需要，选择「**出庫元**」（出库源：据点 → 存放位置 → 货架）。
3. 若该移动类型需要，选择「**入庫先**」（入库目的地：据点 → 存放位置 → 货架）。
4. 搜索并选择「**品目**」（品目）。会显示产品或材料的徽章。
5. 输入「**数量**」（数量）。产品只能输入整数，材料最多可输入 3 位小数。
6. 产品入库时，如有需要可输入「**ロット番号**」（批次号，选填）。
7. 如有需要，填写「**備考**」（备注）。
8. 按下「**登録**」（登记）。

若输入内容有问题，会当场显示红色提示（品目未选择、数量为 0 或以下、出库源・入库目的地未填、调拨时出库源与入库目的地相同等）。有提示显示时无法登记。

登记后，会以该内容生成一张[入出庫伝票](/manual/zh/operations/inventory/inventory-movements/user)（ST04，事由为「手動」/手动）。「调拨」的情况下，会先记录出库源的出库，再记录入库目的地的入库（这样即使库存不足，也不会只有增加的一方先发生）。

登记完成后，会出现绿色提示及指向该单据的链接。**「移动类型」「出库源」「入库目的地」会保留供下一次输入使用**——只有「品目」「数量」「批次号」「备注」会清空。这样在用同一移动类型连续登记多条时，可以省去重新选择的麻烦。

使用本应用需要库存权限。

## 常见问题・遇到困难时

**Q. 我选择了移动类型，但出库源和入库目的地都没有出现。**
A. 该移动类型的设置为不需要出库源和入库目的地中的任何一个。请在[移動タイプ](/manual/zh/operations/inventory/movement-types/user)（ST09）中确认或修改。

**Q. 我要登记时，出现了「数量不足」的提示。**
A. 表示出库源该品目的库存不足以移动您想要的数量。请在[在庫管理](/manual/zh/operations/inventory/inventory-management/user)（ST01）或[在庫一覧](/manual/zh/operations/inventory/stock-overview/user)（ST02）中确认实际的库存数量。

**Q. 我想修改已登记的内容。**
A. 本应用没有修改操作。如登记有误，请登记一次反方向的操作来还原。

**Q. 我想增加移动类型的选项。**
A. 由管理员在[移動タイプ](/manual/zh/operations/inventory/movement-types/user)（ST09）中登记。

## 所需权限

使用本画面需要 **库存**（`inventory`）权限。

| 想做的事 | 所需权限 |
| --- | --- |
| 打开画面、查看列表与明细 | 库存 — 查看 |
| 新增・变更・删除 | 库存 — 创建 / 更新 / 删除 |

仅查看有「查看」即可。画面中若有新增、变更或删除的操作，则分别需要对应的权限。

权限通过角色授予。若不足，请与管理员联系。

权限的整体说明请参见「[权限与角色](../../../permissions)」。
