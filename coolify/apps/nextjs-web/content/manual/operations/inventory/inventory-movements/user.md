在庫が動いた **1 回ごとの記録** を伝票として確認するアプリです。操作コードは `ST04` です。

> ⚠️ このアプリは今のところ **テスト用の環境だけ** で使えます。本番で使えるようになるまでに、画面や手順が変わることがあります。

> このアプリが属するフロー … [生産の流れ](/manual/ja/process/production)

## このアプリでできること

- いつ・何が理由で・どの品目が・何本動いたかを、伝票 1 枚ずつ確認できます。
- 事由（何が起こしたか）・拠点で絞り込んで探せます。
- 伝票から、その元になった書類（指示書・出荷書・素材入荷・棚卸など）へ辿れます。

**このアプリに「新規作成」はありません。** 伝票は在庫を動かした業務の処理が自動で起こすもので、人が手でここから起こすものではないためです（意図的な仕様です）。人が手で在庫を動かす唯一の入口は [手動入出庫](/manual/ja/operations/inventory/goods-movement/user)（ST06）で、そこで起こした移動もここに伝票として記録されます。

## 用語（このページで出てくる言葉）

- **伝票（でんぴょう）** … 在庫が 1 回動いたことの記録です。伝票番号が付きます。
- **事由（じゆう）** … その伝票が何によって起こされたかです。下の表を参照してください。
- **明細** … 1 枚の伝票の中の、品目ごとの動きの行です。1 枚の伝票に複数の明細が乗ることがあります。
- **元書類** … その伝票を起こした、もとの業務書類（指示書・出荷書など）です。

## 伝票を起こす事由

| 事由 | 何が起こすか |
|---|---|
| 指示書完了 | [指示書](/manual/ja/operations/production/work-order/user)の全工程が完了し、良品（・半製品）が在庫に入ったとき |
| 出荷 | [出荷書](/manual/ja/operations/shipping/delivery-order/user)で発送したとき |
| 素材入荷 | [素材入荷](/manual/ja/operations/purchasing/material-receipt/user)（PU03）で入荷を登録したとき |
| 在庫移動 | [在庫管理](/manual/ja/operations/inventory/inventory-management/user)（ST01）の「移動」で置き場所を変えたとき |
| 引当予約 | 注文明細の「在庫照合」、または指示書の承認で在庫が取り置きされたとき |
| 予約解除 | 取り置きが外れたとき |
| 棚卸調整 | [棚卸](/manual/ja/operations/inventory/stock-takes/user)（ST05）を確定して、数のずれを直したとき（ずれが無かった棚卸では伝票は起きません） |
| 手動 | [手動入出庫](/manual/ja/operations/inventory/goods-movement/user)（ST06）で、人が手で入出庫を記録したとき |
| 外注預け | 工程の外注に品物を預けたとき（預け在庫が増える） |
| 預け戻り | 外注から品物が戻ったとき（預け在庫が減る） |
| 返品 | 出荷したあとに顧客から返品があったとき（在庫が戻る。出荷書・請求は動きません） |
| 不明（移行前） | 在庫の仕組みを作り直す前からあった、事由が分からない古い記録です |

## 画面の見かた

一覧の列は次のとおりです。

- **伝票番号** … クリックすると詳細画面が開きます。
- **日時** … 伝票が起きた日時です。
- **事由** … 上の表の色つきバッジです。
- **拠点** … どの拠点で起きたかです。
- **明細数** … その伝票に乗っている明細の行数です。
- **元書類** … もとになった業務書類の参照です。

上の検索欄（伝票番号・元書類の参照で探せます）、「**事由**」、「**拠点**」で絞り込めます。件数が多すぎて **1000 件で切っている** ときは、その旨がオレンジ色で知らされます。

## 詳細画面の見かた

伝票番号をクリックすると、その伝票の詳しい画面が開きます。

上のほうに、伝票番号・日時・事由・拠点・元書類（リンク）・作成者・備考が並びます。

下は明細の表です。

- **種別** … 入庫 / 出庫 / 予約 / 予約解除 / 棚卸調整のバッジです。
- **区分** … 製品か素材かです。
- **品目名** … 動いた品目の名前です。
- **ロット** … 製品の場合のロット番号です。
- **保管場所** … その明細の保管場所です。
- **数量** … 動いた数です。
- **備考** … その明細への補足です。

**この画面には編集・キャンセルの操作がありません。** 伝票は確定した記録で、あとから内容を直すことはできません。間違いがあった場合は、もとになった業務（指示書・出荷書など）を直すか、[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)（ST06）または[棚卸](/manual/ja/operations/inventory/stock-takes/user)（ST05）で正しい状態へ調整してください。

このアプリを使うには、在庫の権限が必要です。

## よくある質問・困ったとき

**Q. 伝票を新しく作りたいのですが、ボタンがありません。**
A. このアプリには新規作成がありません。人が手で在庫を動かしたいときは [手動入出庫](/manual/ja/operations/inventory/goods-movement/user)（ST06）を使ってください。そこで起こした移動が、この一覧に「事由: 手動」の伝票として現れます。

**Q. 棚卸をしたのに伝票が出てきません。**
A. 数えた数と帳簿の数が一致していた（差異が無かった）ときは、[棚卸](/manual/ja/operations/inventory/stock-takes/user)（ST05）を確定しても伝票は作られません。ずれが無かった、という意味です。

**Q. 伝票の内容を直したいのですが。**
A. この画面から直すことはできません。もとになった業務を直すか、正しい状態へ調整する新しい伝票（手動入出庫や棚卸）を起こしてください。

**Q. 「元書類」が空の伝票があります。**
A. 在庫の仕組みを作り直す前からあった記録（事由「不明（移行前）」）には、元書類が残っていないことがあります。

## 必要な権限

この画面を使うには **在庫**（`inventory`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 在庫 の 閲覧 |
| 追加・変更・削除する | 在庫 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
