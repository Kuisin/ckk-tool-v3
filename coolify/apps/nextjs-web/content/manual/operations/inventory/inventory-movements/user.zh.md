以单据形式查看库存 **每一次变动的记录** 的应用。操作码是 `ST04`。

> ⚠️ 本应用目前 **仅在测试环境** 中可用。在正式投入使用之前，画面和操作步骤可能会有变化。

> 本应用所属的流程……[生产流程](/manual/zh/process/production)

## 本应用可以做什么

- 逐张单据确认何时・因何事由・哪个品目・变动了多少。
- 可按事由（由什么引起）・据点缩小范围查找。
- 可从单据追溯到引发它的原始文档（工单・出货单・材料到货・盘点等）。

**本应用没有「新建」功能。** 单据是由引发库存变动的业务处理自动生成的，不是由人在此手动生成的（这是有意为之的设计）。人工手动移动库存的唯一入口是[手動入出庫](/manual/zh/operations/inventory/goods-movement/user)（ST06），在那里进行的移动也会作为单据记录在此处。

## 术语（本页出现的词语）

- **伝票**（单据）… 库存发生一次变动的记录，附有单据编号。
- **事由**（事由）… 该单据由什么引起，参见下表。
- **明細**（明细）… 一张单据中，按品目区分的变动行。一张单据可以有多行明细。
- **元書類**（原始文档）… 引发该单据的原始业务文档（工单・出货单等）。

## 生成单据的事由

| 事由 | 由什么引起 |
|---|---|
| 指示書完了（工单完成） | [工单](/manual/zh/operations/production/work-order/user)的全部工序完成，良品（・半成品）入库 |
| 出荷（出货） | 通过[出货单](/manual/zh/operations/shipping/delivery-order/user)发货 |
| 素材入荷（材料到货） | 在[材料到货](/manual/zh/operations/purchasing/material-receipt/user)（PU03）登记到货 |
| 在庫移動（库存调拨） | 在[在庫管理](/manual/zh/operations/inventory/inventory-management/user)（ST01）中通过「移动」变更存放位置 |
| 引当予約（预留） | 订单明细的「库存核对」，或工单获得批准而预留库存 |
| 予約解除（解除预留） | 占用被解除 |
| 棚卸調整（盘点调整） | 确定[棚卸](/manual/zh/operations/inventory/stock-takes/user)（ST05）并纠正数量偏差时（没有偏差的盘点不会生成单据） |
| 手動（手动） | 在[手動入出庫](/manual/zh/operations/inventory/goods-movement/user)（ST06）中由人工手动记录出入库 |
| 不明（移行前）（未知・迁移前） | 库存系统重建之前遗留的旧记录，事由不明 |

## 画面的查看方式

一览的列如下：

- **伝票番号**（单据编号）… 点击可打开详情画面。
- **日時**（日期时间）… 单据发生的日期时间。
- **事由**（事由）… 上表中带颜色的徽章。
- **拠点**（据点）… 在哪个据点发生。
- **明細数**（明细数）… 该单据所含的明细行数。
- **元書類**（原始文档）… 指向原始业务文档的参照。

可用上方的搜索栏（可按单据编号或原始文档参照查找）、「**事由**」、「**拠点**」进行筛选。当行数过多、**在 1000 条处被截断** 时，会以橙色提示。

## 详情画面的查看方式

点击单据编号即可打开该单据的详情画面。

上方会显示单据编号・日期时间・事由・据点・原始文档（链接）・创建人・备注。

下方是明细表：

- **種別**（种类）… 入库 / 出库 / 预留 / 解除预留 / 盘点调整的徽章。
- **区分**（类别）… 产品还是材料。
- **品目名**（品目名称）… 发生变动的品目名称。
- **ロット**（批次）… 产品情况下的批次号。
- **保管場所**（存放位置）… 该明细的存放位置。
- **数量**（数量）… 变动的数量。
- **備考**（备注）… 该明细的补充说明。

**本画面没有编辑・取消操作。** 单据是已确定的记录，之后无法修改内容。若有错误，请修正原始业务（工单・出货单等），或通过[手動入出庫](/manual/zh/operations/inventory/goods-movement/user)（ST06）或[棚卸](/manual/zh/operations/inventory/stock-takes/user)（ST05）调整为正确状态。

使用本应用需要库存权限。

## 常见问题・遇到困难时

**Q. 我想新建一张单据，但没有相应的按钮。**
A. 本应用没有「新建」功能。想手动移动库存时，请使用[手動入出庫](/manual/zh/operations/inventory/goods-movement/user)（ST06）。在那里进行的移动会以「事由：手动」的单据出现在此一览中。

**Q. 我做了盘点，却没有出现单据。**
A. 若盘点的数量与账面数量一致（没有偏差），确定[棚卸](/manual/zh/operations/inventory/stock-takes/user)（ST05）也不会生成单据 —— 这表示没有需要纠正的地方。

**Q. 我想修改单据的内容。**
A. 无法在本画面修改。请修正原始业务，或生成一张新的单据（手动出入库或盘点）将其调整为正确状态。

**Q. 有些单据的「元書類」（原始文档）为空。**
A. 库存系统重建之前遗留的旧记录（事由为「不明（移行前）」）可能已不再保留原始文档。

## 所需权限

使用本画面需要 **库存**（`inventory`）权限。

| 想做的事 | 所需权限 |
| --- | --- |
| 打开画面、查看列表与明细 | 库存 — 查看 |
| 新增・变更・删除 | 库存 — 创建 / 更新 / 删除 |

仅查看有「查看」即可。画面中若有新增、变更或删除的操作，则分别需要对应的权限。

权限通过角色授予。若不足，请与管理员联系。

权限的整体说明请参见「[权限与角色](../../../permissions)」。
