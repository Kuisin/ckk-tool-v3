[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)で選ぶ区分を管理します。操作コードは `ST09` です。

> ⚠️ このアプリは今のところ **テスト用の環境だけ** で使えます。本番で使えるようになるまでに、画面や手順が変わることがあります。

> このアプリが属するフロー … [生産の流れ](/manual/ja/process/production)

## このアプリでできること

- 手動入出庫の選択肢（移動タイプ）を追加・編集できます。
- 出し入れの向き（入庫・出庫・移動）を決められます。
- 「出庫元」「入庫先」を必ず記録させるかどうかを決められます。
- 使わなくなったタイプを無効にできます。

## 用語（このページで出てくる言葉）

- **番号** … 手動入出庫の選択肢に出る番号です（例: 101 / 201 / 311）。
- **向き** … 「入庫」「出庫」「移動」の 3 つです。
- **出庫元要 / 入庫先要** … その場所を必ず選ばせるかどうかです。

## 追加のしかた

1. 右上の「**新規作成**」を押します。
2. 「**番号**」を入れます。手動入出庫の一覧に出る番号です。
3. 「**名称**」を入れます。現場の人が読んで分かる言葉にします。
4. 「**向き**」を選びます。
5. 必要なら「**出庫元要**」「**入庫先要**」を切り替えます。
6. 「保存」を押します。

編集も一覧の行から同じモーダルで行います（番号だけは編集できません）。

## 向きが決めていること

向きによって、**必ず要る場所** が決まっています。

| 向き | 必ず要る |
|---|---|
| 入庫 | 入庫先 |
| 出庫 | 出庫元 |
| 移動 | 出庫元と入庫先の両方 |

これより **緩くはできません**。たとえば「出庫」で「出庫元要」を外そうとすると「**この向きでは「出庫元」を必須から外せません**」と出て、保存できません。どこから出したか分からない出庫は記録になりません。

逆に、厳しくするのは自由です。入庫でも「出庫元要」を入れておけば、「どこから来たか」を必ず書かせられます。

## 使わなくなったタイプ

- 削除はできません。**無効化** に倒します。すでに登録された伝票がそのタイプを指しているためです。
- 一覧から「有効化」「無効化」をまとめて切り替えられます。
- 無効にすると、手動入出庫の選択肢から消えます。過去の伝票の表示は変わりません。

## よくある質問・困ったとき

**Q. 番号は何を入れればいいですか。**
A. 決まりはありません。現場で使っている伝票の区分番号に合わせるのが分かりやすいです（入庫は 1xx、出庫は 2xx、移動は 3xx など）。

**Q. 名前を変えたら、昔の伝票の表示も変わりますか。**
A. 変わります。タイプは 1 つの登録を共有しているためです。意味が変わる変更のときは、新しいタイプを作って古いほうを無効にしてください。

**Q. 移動タイプと「事由」は何が違いますか。**
A. 「事由」はシステムが決める大まかな区分（指示書完了・出荷・棚卸調整など）で、手動入出庫はすべて「手動入出庫」という事由になります。その中の内訳を表すのが移動タイプです。

## 必要な権限

この画面を使うには **在庫**（`inventory`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 在庫 の 閲覧 |
| 追加・変更・削除する | 在庫 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
