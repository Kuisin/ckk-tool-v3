[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)（ST06）で選ぶ **「移動の種類」を登録するマスタ** です。操作コードは `ST09` です。

> ⚠️ このアプリは今のところ **テスト用の環境だけ** で使えます。本番で使えるようになるまでに、画面や手順が変わることがあります。

> このアプリが属するフロー … [生産の流れ](/manual/ja/process/production)

## このアプリでできること

- 手動入出庫で選べる「移動タイプ」を登録・編集できます。
- 向き（入庫 / 出庫 / 移動）と、出庫元・入庫先のどちらが必須かを、種類ごとに決められます。
- 使わなくなった種類は無効化できます（削除はできません — 下の「削除できない理由」を参照）。

このアプリで登録した内容は、そのまま[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)（ST06）の「移動タイプ」の選択肢になります。ここを直すと、あちらの選択肢もすぐに変わります。

## 用語（このページで出てくる言葉）

- **向き** … その移動タイプが「入庫」「出庫」「移動」のどれであるかです。
- **出庫元要 / 入庫先要** … その移動タイプを選んだときに、出庫元・入庫先の入力を必須にするかです。

## 一覧の見かた

- **番号** … 移動タイプのコードです。
- **名称** … 移動タイプの名前です。
- **向き** … 入庫 / 出庫 / 移動のバッジです。
- **出庫元要 / 入庫先要** … 必須なら✓、不要なら✗のアイコンです（列を隠すこともできます）。
- **表示順** … 手動入出庫の選択肢に出る順番です（列を隠すこともできます）。
- **状態** … 有効 / 無効です。

検索欄・「**向き**」・「**状態**」で絞り込めます。複数行を選んで「**一括有効化**」「**一括無効化**」もできます（一括削除はありません）。

行をクリック、または行の「**編集**」から、内容を直せます。「**新規**」から新しく登録できます。

## 新しく登録する / 内容を直す

「**新規**」または行の「**編集**」を押すと、入力画面が開きます。

| 項目 | 必須 | 何を入れるか |
|------|------|-------------|
| [番号](#field-code) | 必須 | 移動タイプのコード |
| [名称](#field-name) | 必須 | 移動タイプの名前 |
| [向き](#field-direction) | 必須 | 入庫 / 出庫 / 移動 |
| [出庫元要](#field-requires-from) | 任意 | 出庫元の入力を必須にするか |
| [入庫先要](#field-requires-to) | 任意 | 入庫先の入力を必須にするか |
| [表示順](#field-sort-order) | 任意 | 選択肢に出る順番 |
| [有効/無効](#field-is-active) | 任意 | 使える状態かどうか |
| [備考](#field-notes) | 任意 | 補足 |

### 番号 [#field-code]

移動タイプのコードです。**新規作成のときだけ入力でき、あとから変更できません** — 手動入出庫の記録がこの番号を指しているためです。

### 名称 [#field-name]

移動タイプの名前です。日本語は必須、ほかの言語は「多言語」から入れられます。

### 向き [#field-direction]

「入庫」「出庫」「移動」のどれかです。手動入出庫の画面に、選んだ向きに合わせたバッジが出ます。

### 出庫元要 [#field-requires-from]

オンにすると、この移動タイプを選んだときに出庫元の入力が必須になります。**向きが「出庫」「移動」なのにオフにすると、保存時に止められます**（出庫元が必要な向きでは、この設定を外せません）。

### 入庫先要 [#field-requires-to]

オンにすると、この移動タイプを選んだときに入庫先の入力が必須になります。**向きが「入庫」「移動」なのにオフにすると、保存時に止められます**（入庫先が必要な向きでは、この設定を外せません）。

### 表示順 [#field-sort-order]

手動入出庫の選択肢に出る順番です。小さい数字ほど上に出ます。

### 有効/無効 [#field-is-active]

無効にすると、手動入出庫の選択肢からは消えますが、これまでの記録には影響しません。

### 備考 [#field-notes]

この移動タイプについての補足です。

## 削除できない理由

**移動タイプには削除がありません。** 一度でも使われた移動タイプは、その記録（入出庫伝票）がこの移動タイプを指しているため、消すとその記録の意味が分からなくなってしまいます。使わなくなったら「**無効**」にしてください。無効にしても、過去に登録された記録はそのまま残ります。

このアプリを使うには、在庫の権限が必要です。

## よくある質問・困ったとき

**Q. 番号を直したいのですが、欄が押せません。**
A. 番号は作成後に変更できません。手動入出庫の記録が番号で結びついているためです。別の番号にしたいときは、新しく登録して古い方を無効にしてください。

**Q. 出庫元要をオフにしたら、保存できませんでした。**
A. その移動タイプの向き（出庫・移動）では、出庫元の入力が必ず必要です。オフにはできません。

**Q. 無効にした移動タイプが、手動入出庫の選択肢に出たままです。**
A. 出ないはずです。手動入出庫の画面を開き直して（再読み込みして）確認してください。

**Q. 移動タイプを削除したいのですが、ボタンがありません。**
A. 移動タイプには削除がありません。上の「削除できない理由」を参照し、「無効」にしてください。

## 必要な権限

この画面を使うには **在庫**（`inventory`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 在庫 の 閲覧 |
| 追加・変更・削除する | 在庫 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
