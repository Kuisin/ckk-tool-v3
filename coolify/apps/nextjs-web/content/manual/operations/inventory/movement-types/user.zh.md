[手動入出庫](/manual/zh/operations/inventory/goods-movement/user)（ST06）中所选**「移动种类」的主数据**。操作码是 `ST09`。

> ⚠️ 本应用目前 **仅在测试环境** 中可用。在正式投入使用之前，画面和操作步骤可能会有变化。

> 本应用所属的流程……[生产流程](/manual/zh/process/production)

## 本应用可以做什么

- 登记・编辑手动出入库中可选的「移动类型」。
- 按类型分别决定方向（入库 / 出库 / 移动），以及出库源・入库目的地哪个是必填项。
- 不再使用的类型可以停用（无法删除 —— 参见下方「为什么无法删除」）。

在此登记的内容会直接成为[手動入出庫](/manual/zh/operations/inventory/goods-movement/user)（ST06）中「移动类型」的选项。在此修改后，那边的选项会立即随之变化。

## 术语（本页出现的词语）

- **向き**（方向）… 该移动类型是「入库」「出库」「移动」中的哪一种。
- **出庫元要 / 入庫先要**（需出库源 / 需入库目的地）… 选择该移动类型时，是否要求必须填写出库源・入库目的地。

## 一览的查看方式

- **番号**（编号）… 移动类型的编号。
- **名称**（名称）… 移动类型的名称。
- **向き**（方向）… 入库 / 出库 / 移动的徽章。
- **出庫元要 / 入庫先要**（需出库源 / 需入库目的地）… 必填显示✓、不需要显示✗的图标（这些列可以隐藏）。
- **表示順**（显示顺序）… 在手动出入库选项中出现的顺序（此列可以隐藏）。
- **状態**（状态）… 启用 / 停用。

可用搜索栏、「**向き**」（方向）、「**状態**」（状态）进行筛选。可勾选多行进行「**一括有効化**」（批量启用）「**一括無効化**」（批量停用）（没有批量删除）。

点击行，或使用行的「**編集**」（编辑）操作即可修改内容。通过「**新規**」（新建）可以新增登记。

## 新建 / 修改内容

按下「**新規**」（新建）或行的「**編集**」（编辑）会打开输入画面。

| 项目 | 必填 | 填什么 |
|------|------|--------|
| [编号](#field-code) | 必填 | 移动类型的编号 |
| [名称](#field-name) | 必填 | 移动类型的名称 |
| [方向](#field-direction) | 必填 | 入库 / 出库 / 移动 |
| [需出库源](#field-requires-from) | 选填 | 是否要求必须填写出库源 |
| [需入库目的地](#field-requires-to) | 选填 | 是否要求必须填写入库目的地 |
| [显示顺序](#field-sort-order) | 选填 | 在选项中出现的顺序 |
| [启用/停用](#field-is-active) | 选填 | 是否处于可用状态 |
| [备注](#field-notes) | 选填 | 补充说明 |

### 编号 [#field-code]

移动类型的编号。**只有在新建时才能输入，之后无法修改** —— 因为手动出入库的记录会指向这个编号。

### 名称 [#field-name]

移动类型的名称。日语为必填，其他语言可通过「多语言」输入。

### 方向 [#field-direction]

「入库」「出库」「移动」三者之一。手动出入库画面会显示与所选方向对应的徽章。

### 需出库源 [#field-requires-from]

开启后，选择该移动类型时必须填写出库源。**若方向为「出库」「移动」却将其关闭，保存时会被阻止**（这些方向下无法取消此设置）。

### 需入库目的地 [#field-requires-to]

开启后，选择该移动类型时必须填写入库目的地。**若方向为「入库」「移动」却将其关闭，保存时会被阻止**（这些方向下无法取消此设置）。

### 显示顺序 [#field-sort-order]

在手动出入库选项中出现的顺序。数字越小，排位越靠前。

### 启用/停用 [#field-is-active]

停用后会从手动出入库的选项中消失，但不影响以往的记录。

### 备注 [#field-notes]

关于该移动类型的补充说明。

## 为什么无法删除

**移动类型没有删除操作。** 只要曾被使用过的移动类型，其记录（入出库单）会指向该类型，删除会导致这些记录失去意义。不再使用时，请将其设为「**無効**」（停用）。停用后，以往登记的记录不受影响、原样保留。

使用本应用需要库存权限。

## 常见问题・遇到困难时

**Q. 我想修改编号，但栏位无法点击。**
A. 编号创建后无法修改，因为手动出入库的记录通过编号相互关联。想使用别的编号时，请新建一个并停用旧的。

**Q. 我关闭了「需出库源」，结果无法保存。**
A. 该移动类型的方向（出库・移动）必然需要出库源，无法关闭。

**Q. 我停用的移动类型仍出现在手动出入库的选项中。**
A. 不应如此。请重新打开（刷新）手动出入库画面确认。

**Q. 我想删除移动类型，但没有相应的按钮。**
A. 移动类型没有删除操作。请参考上方「为什么无法删除」，改为将其停用。

权限通过角色授予。若不足，请与管理员联系。
