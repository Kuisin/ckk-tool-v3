どの場所に何がどれだけあるかを、**製品・素材まとめて 1 本の表**で見るアプリです。操作コードは `ST02` です。

> ⚠️ このアプリは今のところ **テスト用の環境だけ** で使えます。本番で使えるようになるまでに、画面や手順が変わることがあります。

> このアプリが属するフロー … [生産の流れ](/manual/ja/process/production)

## このアプリでできること

- 拠点・保管場所・棚を絞り込んで、その場所に何があるかを一覧で確認できます。
- 製品と素材を分けずに、同じ表で見比べられます。
- 在庫ゼロの行を隠して、実際にあるものだけに絞れます。
- 品目名・品目コードで探すこともできます。

このアプリは**「どの場所に何があるか」を場所の側から見る画面**です。「この品目は足りているか」を品目の側から見たいときは、[在庫・所要量](/manual/ja/operations/inventory/stock-requirements/user)（ST03）を使います。詳しく在庫を動かしたり、製品・仕掛品・ロケーションを分けて見たいときは、[在庫管理](/manual/ja/operations/inventory/inventory-management/user)（ST01）を使います。この 3 つは同じ在庫を見ていますが、それぞれ見る向きが違う別のアプリです。

## 用語（このページで出てくる言葉）

- **品目（ひんもく）** … 製品または素材のことです。表の行には、どちらであるかを示すバッジが付きます。
- **拠点** … 工場や倉庫など、大きな場所の単位です。
- **保管場所 / 棚** … 拠点の中の置き場所です。
- **ロット** … まとめて作った製品のかたまりに付く番号です。
- **手持ち** … 実際にある数量です。
- **予約** … 特定の注文・指示書のために確保されている分です。
- **利用可能** … 手持ちのうち、まだ予約されていない分です。

## 画面の見かた

- **品目** … 品目の名前です。「製品」か「素材」かのバッジが付きます。
- **コード** … 品目コードです。
- **拠点** … どの拠点にあるかです。
- **保管場所・棚** … 「場所名 / 棚コード」の形で出ます。決まっていないものは「**未割当**」と出ます。
- **ロット** … 製品の場合のロット番号です。
- **手持ち** … 実際にある数量です。**赤いマイナスの数字**は、台帳にある数より多く出荷したという印です（[出荷書](/manual/ja/operations/shipping/delivery-order/user)は在庫が足りなくても止まりません）。
- **予約** … そのうち予約されている数量です（列を隠すこともできます）。
- **利用可能** … 手持ちから予約を除いた、実際に使える数量です。
- **単位** … 数量の単位です（列を隠すこともできます）。
- **更新日** … その行の在庫が最後に動いた日です。

一覧の上には、絞り込みの検索欄・「**拠点**」・「**保管場所**」（拠点を選ぶと、その拠点の保管場所だけに絞られます）・「**品目種別**」（製品 / 素材）があります。

「**在庫ゼロを隠す**」のスイッチは既定で **オン** です。オフにすると、手持ちが 0 の場所も表に出ます — 「あるはずの場所に何も無い」ことを確かめたいときに使います。

一覧の下に、表示している行数・品目数・拠点数の要約が出ます。件数が多すぎて表示を **1000 行で切っている** ときは、その旨がオレンジ色で知らされます。絞り込みを増やして件数を減らしてください。

このアプリには詳細画面も新規作成画面もありません。**見るための一覧だけ**のアプリです。在庫を動かしたいときは[在庫管理](/manual/ja/operations/inventory/inventory-management/user)（ST01）または[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)（ST06）を使ってください。

このアプリを使うには、在庫の権限が必要です。

## よくある質問・困ったとき

**Q. 探している品目が一覧に出てきません。**
A. 「在庫ゼロを隠す」がオンだと、手持ちが 0 の場所は表に出ません。オフにして確認してください。それでも出ないときは、絞り込み（拠点・保管場所・品目種別）が合っているか確認してください。

**Q. 一覧が 1000 行で切れています。**
A. 絞り込み（拠点・保管場所・品目種別・検索）を増やして、件数を減らしてください。この一覧はページ送りをせず、常に絞り込みで件数を減らす作りになっています。

**Q. 手持ちが赤いマイナスになっています。**
A. 台帳にある数より多く出荷するとこうなります。出荷そのものは記録されていて、足りなかった分は[入出庫伝票](/manual/ja/operations/inventory/inventory-movements/user)（ST04）に「在庫不足のまま出庫」として残ります。[棚卸](/manual/ja/operations/inventory/stock-takes/user)（ST05）で数え直すか、入れ忘れていた入庫を[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)（ST06）で記録すると 0 以上に戻ります。

**Q. ここから在庫を移動したいのですが。**
A. このアプリからは移動できません。[在庫管理](/manual/ja/operations/inventory/inventory-management/user)（ST01）の該当する行、または[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)（ST06）を使ってください。

**Q. 同じ在庫が[在庫管理](/manual/ja/operations/inventory/inventory-management/user)（ST01）にも出ています。どちらが正しいのですか。**
A. どちらも正しく、同じ在庫を別の向きから見ているだけです。場所を横断してざっと数えたいときはこのアプリ、製品・素材・仕掛品を分けて詳しく見たいときは ST01 を使ってください。

## 必要な権限

この画面を使うには **在庫**（`inventory`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 在庫 の 閲覧 |
| 追加・変更・削除する | 在庫 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
