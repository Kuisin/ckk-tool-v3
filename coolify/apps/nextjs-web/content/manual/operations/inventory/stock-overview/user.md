「**この棚に何があるか**」を場所の側から見るアプリです。操作コードは `ST02` です。

> ⚠️ このアプリは今のところ **テスト用の環境だけ** で使えます。本番で使えるようになるまでに、画面や手順が変わることがあります。

> このアプリが属するフロー … [生産の流れ](/manual/ja/process/production)

## このアプリでできること

- 拠点・保管場所・棚の順に、いまある在庫を一覧で確認できます。
- 製品と素材を **同じ一覧** で確認できます（分かれていません）。
- 取り置き（予約）されている分と、まだ使える分を分けて確認できます。
- 外注先に預けている分を、預け先ごとに確認できます。
- 棚卸の前に「この棚には何があることになっているか」を確認するときに使います。

> 💡 品目 1 つを選んで「これから増えるぶん・減るぶん」を時間の順に見たいときは、[在庫・所要量](/manual/ja/operations/inventory/stock-requirements/user)のほうが向いています。この一覧は **場所から見る** 画面です。

## 用語（このページで出てくる言葉）

- **品目（ひんもく）** … 製品と素材をまとめた呼び方です。この一覧では両方が並びます。
- **拠点（きょてん）** … 工場や倉庫など、大きな場所の単位です。
- **保管場所 / 棚** … 拠点の中の置き場所です。「第一倉庫」の「A-1」棚、のように 2 段階で管理します。
- **未割当（みわりあて）** … 棚がまだ決まっていない在庫です。入庫したばかりのものはここに入ります。
- **ロット** … まとめて作った製品のかたまりに付く番号です。指示書の番号がそのまま入ります。
- **予約（取り置き）** … 特定の注文のために確保されている分です。ほかの注文には使えません。
- **預け先（あずけさき）** … その在庫を預かっている外注先です。自社の手元にはありません。

## 画面の見かた

1 行が「品目 × 拠点 × 保管場所 × 棚 × ロット」の 1 つのかたまりです。同じ製品でもロットや棚が違えば別の行になります。

- **品目** … 「製品」か「素材」かのバッジと、名前が出ます。
- **コード** … 製品コード・素材コードです。
- **拠点** … どの拠点にあるかです。外注に預けている分には「**〇〇 が保管**」というオレンジのバッジが付きます。
- **保管場所** … 「場所名 / 棚コード」の形で出ます。棚が決まっていないものは「**未割当**」と出ます。
- **ロット** … 製品のロット番号です。素材には付きません。
- **手持ち** … 台帳にある本数です。**赤いマイナスの数字**は、在庫が足りないまま出荷した分です（[出荷書](/manual/ja/operations/shipping/delivery-order/user)は在庫が無くても止まりません）。数え直して直します。
- **予約** … そのうち取り置きされている本数です。
- **利用可能** … 手持ちから予約を引いた、いま使える本数です。
- **更新日** … その行が最後に動いた日です。

画面の上に「**{行数} 行 / {品目数} 品目 / {拠点数} 拠点**」という要約が出ます。絞り込むと、この数も一緒に変わります。

## 探しかた・絞り込みかた

1. 上の検索欄に品目名か品目コードを入れます。
2. 「**拠点**」を選ぶと、その拠点だけになります。
3. 「**保管場所**」を選ぶと、さらにその場所だけになります（拠点を選ぶと、その拠点の場所だけが選べるようになります）。
4. 「**品目種別**」で「製品」だけ・「素材」だけにできます。
5. 「**在庫ゼロを隠す**」は最初から入っています。0 本の行も見たいときは外します。

> 💡 絞り込んだ状態は画面のアドレス（URL）に残ります。そのまま同僚に送れば、同じ絞り込みの画面が開きます。

## 外注に預けている分を見る

外注先に預けている在庫がある場合だけ、「**自社**」と書かれた選択欄が出ます。

1. 選択欄を開きます。
2. 見たい外注先を選びます。
3. その外注先が預かっている分だけが表示されます。

自社の在庫に戻すには、選択欄の「×」を押します（何も選んでいない状態が「自社」です）。

> ⚠️ **預けている分は手持ちには入りません。** 出荷にも引当にも使えず、棚卸の対象にもなりません。何も選んでいない状態の一覧と、それぞれの外注先の一覧は、別々の数えものです。

預けている分は、工程の画面で外注の「依頼日」を入れたときに増え、「入荷日」を入れたとき（または指示書が完了したとき）に減ります。この一覧から直接動かすことはできません。

## 件数が多いと出るお知らせ

「**件数が多いため、一部のみ表示しています。絞り込んでください。**」と出ることがあります。在庫のかたまりは品目・棚・ロットの組み合わせで増えるので、全社ぶんを一度には出しません。拠点や品目で絞り込んでください。

## よくある質問・困ったとき

**Q. 手持ちが赤いマイナスになっています。**
A. 台帳にある本数より多く出荷したときにこうなります。出荷そのものは記録されていて、足りなかった分は[入出庫伝票](/manual/ja/operations/inventory/movements/user)に「在庫不足のまま出庫」として残っています。[棚卸](/manual/ja/operations/inventory/stock-takes/user)で数え直すか、入れ忘れていた入庫を[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)で記録すると 0 以上に戻ります。

**Q. 数が合いません。この画面で直せますか。**
A. 直せません。数は日々の操作（指示書の完了・出荷・入荷など）にあわせて自動で動きます。数え直して合わせるときは[棚卸](/manual/ja/operations/inventory/stock-takes/user)、理由のある出し入れを手で記録するときは[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)を使います。

**Q. 「利用可能」が 0 なのに「手持ち」があります。**
A. すべて取り置き（予約）されています。どの注文のための予約かは、注文明細の画面で確認できます。

**Q. 棚が「未割当」のままです。**
A. 入庫した直後はどの棚に置くか決まっていない扱いになります。棚を決めたら[手動入出庫](/manual/ja/operations/inventory/goods-movement/user)で移すと、この一覧にも反映されます。

**Q. 外注に預けた分が「自社」の一覧に出てきません。**
A. そのとおりの動きです。預けている分は手元にないので、自社の在庫には数えません。上の「預け先」の選択欄から見てください。

## 必要な権限

この画面を使うには **在庫**（`inventory`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 在庫 の 閲覧 |
| 追加・変更・削除する | 在庫 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
