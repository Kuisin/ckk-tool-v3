以**产品和材料放在同一张表**中，查看每个场所有什么、有多少的应用。操作码是 `ST02`。

> ⚠️ 本应用目前 **仅在测试环境** 中可用。在正式投入使用之前，画面和操作步骤可能会有变化。

> 本应用所属的流程……[生产流程](/manual/zh/process/production)

## 本应用可以做什么

- 缩小到据点・存放位置・货架的范围，一览查看该场所有什么。
- 不区分产品和材料，在同一张表中比较查看。
- 可以隐藏库存为零的行，只看实际存在的部分。
- 也可以按品目名・品目编号查找。

本应用是**从「场所」的角度查看「哪里有什么」的画面**。想从「品目」的角度查看「这个品目是否够用」时，请使用[在庫・所要量](/manual/zh/operations/inventory/stock-requirements/user)（ST03）。想详细移动库存，或分开查看产品・在制品・位置时，请使用[在庫管理](/manual/zh/operations/inventory/inventory-management/user)（ST01）。这三个应用查看的是同样的库存，只是方向不同。

## 术语（本页出现的词语）

- **品目**（品目）… 产品或材料。表格行上会标出是哪一种的徽章。
- **拠点**（据点）… 工厂或仓库等大范围的场所单位。
- **保管場所 / 棚**（存放位置 / 货架）… 据点内的存放位置。
- **ロット**（批次）… 一批集中制作的产品所带的编号。
- **手持ち**（手持）… 实际拥有的数量。
- **予約**（预留）… 为特定订单・工单保留的部分。
- **利用可能**（可用）… 手持库存中尚未被预留的部分。

## 画面的查看方式

- **品目**（品目）… 品目的名称，附带「製品」（产品）或「素材」（材料）的徽章。
- **コード**（编号）… 品目编号。
- **拠点**（据点）… 位于哪个据点。
- **保管場所・棚**（存放位置・货架）… 以「场所名 / 货架编号」的形式显示。尚未确定的显示为「**未割当**」（未分配）。
- **ロット**（批次）… 产品情况下的批次号。
- **手持ち**（手持）… 实际拥有的数量。
- **予約**（预留）… 其中被预留的数量（此列可以隐藏）。
- **利用可能**（可用）… 手持数量扣除预留后，实际可用的数量。
- **単位**（单位）… 数量的单位（此列可以隐藏）。
- **更新日**（更新日）… 该行库存最后一次变动的日期。

一览上方有搜索栏、「**拠点**」（据点）、「**保管場所**」（存放位置 — 选择据点后会缩小到该据点内的存放位置）、「**品目種別**」（品目类别 — 产品 / 材料）。

「**在庫ゼロを隠す**」（隐藏零库存）开关默认为 **开启**。关闭后，手持为 0 的场所也会显示出来 —— 用于确认「本该有东西的场所是否真的什么都没有」。

一览下方会显示所展示的行数・品目数・据点数的摘要。当行数过多、**在 1000 行处被截断** 时，会以橙色提示，此时请增加筛选条件以减少行数。

本应用没有详情画面，也没有新建画面 —— 是**纯粹用于查看的一览**。想移动库存时，请使用[在庫管理](/manual/zh/operations/inventory/inventory-management/user)（ST01）或[手動入出庫](/manual/zh/operations/inventory/goods-movement/user)（ST06）。

使用本应用需要库存权限。

## 常见问题・遇到困难时

**Q. 我要找的品目没有出现在一览中。**
A. 若「在庫ゼロを隠す」（隐藏零库存）为开启状态，手持为 0 的场所不会显示，请关闭后确认。若仍未显示，请检查筛选条件（据点・存放位置・品目类别）是否设置正确。

**Q. 一览在 1000 行处被截断了。**
A. 请增加筛选条件（据点・存放位置・品目类别・搜索）以减少行数。此一览没有分页，设计上始终依靠筛选来减少行数。

**Q. 我想从这里移动库存。**
A. 本应用无法移动库存。请使用[在庫管理](/manual/zh/operations/inventory/inventory-management/user)（ST01）中对应的行，或[手動入出庫](/manual/zh/operations/inventory/goods-movement/user)（ST06）。

**Q. 同样的库存也出现在[在庫管理](/manual/zh/operations/inventory/inventory-management/user)（ST01）中，哪个才是对的？**
A. 两者都是对的，只是从不同方向查看同一份库存。想跨场所快速清点时使用本应用，想分别详细查看产品・材料・在制品时使用 ST01。

## 所需权限

使用本画面需要 **库存**（`inventory`）权限。

| 想做的事 | 所需权限 |
| --- | --- |
| 打开画面、查看列表与明细 | 库存 — 查看 |
| 新增・变更・删除 | 库存 — 创建 / 更新 / 删除 |

仅查看有「查看」即可。画面中若有新增、变更或删除的操作，则分别需要对应的权限。

权限通过角色授予。若不足，请与管理员联系。

权限的整体说明请参见「[权限与角色](../../../permissions)」。
