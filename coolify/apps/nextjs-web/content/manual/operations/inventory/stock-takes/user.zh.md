按据点・存放位置 **重新盘点实物**，若与账面数量不符则加以纠正的应用。操作码是 `ST05`。

> ⚠️ 本应用目前 **仅在测试环境** 中可用。在正式投入使用之前，画面和操作步骤可能会有变化。

> 本应用所属的流程……[生产流程](/manual/zh/process/production)

## 本应用可以做什么

- 只需选择据点（如需要，还可选存放位置），该处的所有库存会自动作为盘点对象加入。
- 可以填写盘点结果，并当场确认与账面数量的差异。
- 若审批设置（MS0B）中有流程，则经过审批；没有的话直接确定。
- 确定后，只有存在差异的品目会自动作为「棚卸調整」（盘点调整）反映到[入出庫伝票](/manual/zh/operations/inventory/inventory-movements/user)（ST04）。没有差异的品目不会发生任何变化。

## 术语（本页出现的词语）

- **棚卸**（盘点）… 数清实物、核对是否与账面库存数一致的作业。
- **帳簿数**（账面数）… 开始盘点时系统中记录的数量。
- **記入数**（填写数）… 实际数出的数量。
- **差異**（差异）… 填写数减去账面数。这里只是填写时的参考值，实际生效的是确定时点的数量差（参见下方「确定后会发生什么」）。
- **下書き / 記入中 / 確定 / キャンセル**（草稿 / 填写中 / 已确定 / 已取消）… 盘点本身的状态。
- **承認依頼中 / 承認済 / 差し戻し**（审批中 / 已批准 / 已退回）… 需要审批时的状态。

## 开始盘点

1. 在一览中按下「**新規作成**」（新建）。
2. 选择「**拠点**」（据点，必填）。
3. 若想把盘点范围缩小到某一个存放位置，也可选择「**保管場所**」（存放位置，选填。留空则以整个据点为对象）。
4. 如有需要，填写「**備考**」（备注）。
5. 按下「**作成**」（创建）。

创建后，该时点该据点（・存放位置）内的**所有库存单元**会自动作为盘点对象加入行中。**库存为 0 的场所、存放位置未分配的库存也会包含在内**——这样才能同时发现「本该有实物却没有」和「本不该有实物却有」两种情况。若完全没有对象（该据点没有任何库存），则无法创建。

## 填写盘点结果

在详情画面的填写表格中输入实际数出的数量。

- **種別**（种类）… 产品或材料的徽章。
- **品目名**（品目名称）… 要盘点的品目。
- **保管場所**（存放位置）… 该库存的存放位置。
- **ロット**（批次）… 产品情况下的批次号。
- **帳簿数**（账面数）… 开始盘点时记录的数量（无法修改）。
- **記入数**（填写数）… 输入实际数出的数量。
- **差異**（差异）… 填写数与账面数之差。偏多显示为蓝色，偏少显示为橙色，尚未盘点的行显示为「**未カウント**」（未记录）。
- **備考**（备注）… 该行的补充说明。

上方会显示「已数 ◯ / ◯ 件」「差异 ◯ 件」等摘要。

按下「**保存**」（保存）即可保留目前的填写内容。**首次保存会将盘点的状态从「下書き」（草稿）变为「記入中」（填写中）。** 保存次数不限，无需一次数完。

## 提交

只要有 1 行填写了，即可按下「**提出**」（提交）。

- 若审批设置（MS0B）的「棚卸」流程中有 **1 级以上**，会变为审批申请。盘点状态仍为「記入中」（填写中），审批状态变为「**承認依頼中**」（审批中）。
- 若 **没有任何一级**，提交后会直接确定。

提交后，在等待审批期间无法继续填写（审批期间填写表格将变为不可编辑）。

## 审批

拥有审批权限的人，可以从详情画面上方的卡片进行「**承認**」（批准）或「**差し戻し**」（退回）。退回后会回到提交前的状态，可重新填写并再次提交。所有级别都审批通过后，即进入确定阶段。

## 确定后会发生什么

在确定的那一刻，系统会**重新以最新数值读取各场所实物的数量**（因为从开始盘点到确定之间，出货或到货可能会使数量发生变动）。差异由「填写的数量」与「该最新数量」之间的差决定。

- 没有差异的行……不会发生任何变化。
- 有差异的行……会为该品目・该场所生成一张[入出庫伝票](/manual/zh/operations/inventory/inventory-movements/user)（ST04，事由为「棚卸調整」/盘点调整），并按该差异纠正库存数量。
- 若一行差异都没有……不会生成任何单据（表示没有需要纠正的地方）。
- 未盘点的行，以及盘点开始后该场所库存本身已消失的情况，都会从确定对象中排除。

确定后，详情画面上方会出现指向实际生成单据的链接（若未生成单据则不会出现）。

## 取消

在「下書き」（草稿）或「記入中」（填写中）状态下，可以从详情画面按「**キャンセル**」（取消）。若在审批中取消，该审批申请也会一并撤回，并从[未処理一覧](/manual/zh/operations/general/my-tasks/user)（CM01）中消失。

**已确定的盘点无法取消。** 确定是实际纠正库存数量的操作，若要撤销，需要进行反方向的盘点（重新数一遍再改回去）。

## 一览的查看方式

- **棚卸番号**（盘点编号）… 点击可打开详情画面。
- **拠点 / 保管場所**（据点 / 存放位置）… 盘点对象所在的场所。
- **明細数**（明细数）… 需盘点的行数。
- **状態**（状态）… 草稿 / 填写中 / 已确定 / 已取消。
- **承認状態**（审批状态）… 不需要审批的盘点显示为「—」（横线）。
- **更新日**（更新日）… 最后一次发生变化的日期。

可用搜索栏和「**状態**」（状态）进行筛选。

使用本应用需要库存权限。

## 常见问题・遇到困难时

**Q. 我数了，但那个品目不在盘点对象里。**
A. 创建盘点那一刻没有库存的场所不会包含在对象内。之后无法追加对象，请重新创建一次新的盘点。

**Q. 提交后填写表格无法修改了。**
A. 审批期间无法填写。若被退回，或因审批设置没有流程而自动确定，那时填写就已经结束了。

**Q. 确定了却没有生成单据。**
A. 这表示没有差异——填写的数量与确定时点的实际数量一致。这是正常结果，无需进一步处理。

**Q. 我填写的差异与确定后实际纠正的数量不一致。**
A. 确定时比较的是**确定那一刻**的实际数量，而不是填写时的数量。若盘点过程中发生了出货或到货，填写时的差异与确定时的差异可能会不同。

**Q. 我想撤销已确定的盘点。**
A. 无法撤销。请创建一张反方向重新盘点的新单据。

**Q. 取消后审批申请会怎样？**
A. 若在审批中取消，该审批申请也会一并撤回，并从审批人的[未処理一覧](/manual/zh/operations/general/my-tasks/user)（CM01）中消失。

## 所需权限

使用本画面需要 **库存**（`inventory`）权限。

| 想做的事 | 所需权限 |
| --- | --- |
| 打开画面、查看列表与明细 | 库存 — 查看 |

仅查看有「查看」即可。画面中若有新增、变更或删除的操作，则分别需要对应的权限。

权限通过角色授予。若不足，请与管理员联系。
