タブレットの「**工程実行**」で、自分に割り当てられた作業を確認し、開始・完了を記録します。

## このアプリでできること

- 今日やる作業（工程）の一覧を確認できます。
- 作業の **開始・一時停止・再開・完了** を記録できます。
- 何本受け取ったかと、不良が出た分を入力できます（良品数は自動で計算されます）。
- 不良が出たときは、種類・本数・詳細を残せます。
- 検査工程では、測った値と合否を記録できます。

## 用語（このページで出てくる言葉）

- **指示書（しじしょ）** … 「どの製品を何本作るか」の作業指示です。`#9001` のような番号が付きます。
- **受入数（うけいれすう）** … その工程に入ってきた本数です。
- **良品数（りょうひんすう）** … 問題なく次の工程へ渡せる本数です。
- **前工程待ち** … 前の作業が終わっていないため、まだ始められない状態です。

## 画面の見かた

作業は 3 つのまとまりに分かれて表示されます。

![今日の作業一覧](../../../assets/screenshots/kiosk-steps-01.png)

- **遅延** … 予定日を過ぎている作業です。まずここから片付けます。
- **本日** … 今日の予定です。
- **予定** … 先の日付の作業です。

各カードには、指示書の番号・拠点・工程名・製品名・割り当て本数が並びます。右上のラベルは今の状態です。

- **開始可** … すぐ始められます。
- **前工程待ち** … 前の作業がまだ終わっていません。始められません。
- **作業中** … いま作業している最中です。
- **一時停止中** … 中断しています。「再開」で続きから始められます。
- **◯◯ さんが作業中** … ほかの人がその工程を進めている最中です。その人が完了か一時停止するまで操作できません。
- **完了** … 終わった作業です。
- **キャンセル** … 取りやめになった作業です。

> 💡 完了した作業は「**完了した工程を隠す**」で一覧から隠せます。表示件数が多いときに使ってください。

## 作業を始める

1. 一覧から、始めたい作業のカードを押します。
2. 画面下の「**工程開始**」を押します。
3. 「工程を開始」の画面で **受入数**（その工程に入ってきた本数）を確認します。前の工程から引き継いだ数が最初から入っています。
4. 実際の数と違う場合は数字を直します。
5. 「**ロット/伝票コード**」の欄が出る工程では、素材ロットや伝票のコードを入れます（「必須」の工程では入れないと始められません。「任意」なら空のままでもかまいません）。入れたコードは、工程のカードに「ロット ◯◯」と表示されます。
6. 「**開始する**」を押します。

![工程の画面](../../../assets/screenshots/kiosk-step-detail-01.png)

開始すると状態が「作業中」に変わり、作業時間の計測が始まります。

> 💡 複数の工程を同時に進めることもできます。同時に進めている間の実働時間は、**同時に作業している数で割って**それぞれの工程に記録されます（例: 2 つ同時なら、その間の時間は半分ずつ）。

## 途中でやめる・再開する

- 昼休みなどで中断するときは「**一時停止**」を押します。作業時間の計測が止まります。
- 続きを始めるときは「**再開**」を押します。

一時停止しても、それまでの作業時間は残ります。何回でも止めたり再開したりできます。

## 作業場所の記録

工程の画面には「**作業場所**」の欄があり、**どの機械・区画で作業したか** が実績に記録されます。

![作業場所の欄と読み取りボタン](../../../assets/screenshots/kiosk-step-location-01.png)

- ふだんは何もしなくて大丈夫です。**開始・再開すると、このタブレットに設定された既定の作業場所が自動で記録されます**
- 別の機械で作業するときは「**作業場所を読み取り**」を押し、機械に貼ってある **作業場所の QR ラベル** をカメラで読み取ってください。いまの作業の場所が読み取った場所に変わります
- 開始する前に読み取っておくと、開始と同時にその場所が記録されます

> ⚠️ 「**この工程では使用できない作業場所です**」と出たときは、その工程で使ってよい場所が決められています（管理者が工程マスタで設定）。貼ってある QR の機械がその工程の対象か確認してください。
>
> ⚠️ 「**この端末の作業場所ではこの工程を実行できません**」と出たときは、このタブレットの場所ではその工程を実行できない設定です。画面に表示される **実行できる作業場所**（とそこにある端末）を確認し、その端末から作業してください。

## 作業を終える

1. 画面下の「**工程完了**」を押します。
2. 「工程を完了」の画面で **良品数**（次に渡せる本数）を確認します。良品数は、受入数から不良の合計を引いた数が **自動で計算** されます（「自動計算」と表示されます）。入力するのは不良だけです。
3. 不良が出たときは「**不良を追加**」を押し、1 行ごとに次を入れます。
   - **種別** … 半製品・廃棄・工程分岐（手直しなど、別の工程へ回す分）のどれか
   - **不良種類**（必須） … あらかじめ登録された不良の種類から選びます
   - **本数**
   - **詳細**（必須） … どんな不良だったかを文章で書きます
4. 「**完了する**」を押します。

> ⚠️ 不良の合計が受入数より多いときは「**不良の合計（n）が受入数（n）を超えています**」と表示され、完了できません。本数を見直してください。また、不良の行に種類か詳細が入っていないと「**不良の各行に種類と詳細を入力してください**」と表示されます。全部の行を埋めてから完了してください。

## 検査の工程

検査の工程では、完了する前に検査記録を入力します。

1. 「**検査記録**」の欄に、「**検査数**」と「**合格数**」を入れます。
2. 項目ごとに **実測値** を入力します。合格・不合格は、決められた範囲に入っていれば **自動で判定** されます。
3. 自動で判定できない項目は、自分で「合格」「不合格」を選びます。
4. 「**検査記録を保存**」を押します。

## 入力項目

工程の種類によって、聞かれる数量が変わります。数量を記録しない工程では、開始と完了だけです。

| 項目 | 必須 | 何を入れるか |
|------|------|-------------|
| [受入数 / 検査数](#field-input) | 必須 | 手元に届いた本数 |
| [ロット/伝票コード](#field-lot) | 条件付き | 素材ロット・伝票のコード |
| [良品数 / 合格数](#field-success) | 自動計算 | 次の工程へ渡せる本数（入力しません） |
| [不良内訳](#field-defects) | 条件付き | 不良 1 件ごとの種別・不良種類・本数・詳細 |
| [不良理由](#field-reasons) | 条件付き | 不良の行ごとの不良種類と詳細 |
| [検査記録](#field-inspection) | 条件付き | 検査表の実測値 |

### 受入数 / 検査数 [#field-input]

工程を**開始するとき**に入れる、手元に届いた本数です。前の工程の良品数が初めから入っています。実際に届いた数が違うときは、**届いた数に直してください**。

### ロット/伝票コード [#field-lot]

工程を**開始するとき**に入れる、素材ロットや伝票のコードです。工程ごとに「必須」「任意」「なし」が決められていて、必須の工程では入れないと始められません。入れたコードは工程のカードに「ロット ◯◯」と表示されます。

### 良品数 / 合格数 [#field-success]

次の工程へ渡せる本数です。**自分では入力しません** — 受入数から不良の合計を引いた数が自動で計算されて表示されます。

### 不良内訳 [#field-defects]

良品にならなかった分を、1 件ごとに 1 行で入れるリストです。各行に **種別**・**不良種類**（必須）・**本数**・**詳細**（必須）を入れます。種別は次の 3 つです。

- **半製品** — 製品にはならないが、在庫として置いておく分
- **廃棄** — 捨てる分
- **工程分岐** — 手直しなど、別の工程へ回す分

種別ごとの合計と在庫への反映は、このリストから自動で計算されます。**不良の合計が受入数を超えない**ことだけが条件で、超えると画面に警告が出ます（良品数は受入数から不良の合計を引いた数になります）。

### 不良理由 [#field-reasons]

不良の各行に入れる **不良種類** と **詳細** のことです。以前は別の欄でしたが、いまは不良内訳のリストにまとまっています。どの行も、不良種類を選んで詳細を書かないと工程を完了できません。あとで原因を振り返るときの手がかりになります。

### 検査記録 [#field-inspection]

検査工程では、検査表の項目ごとに実測値を入れます。**許容範囲から外れると自動で不合格**になります。抜取検査の場合は、必要なサンプル数が画面に出ます。

---

一時停止すると、そこまでの作業時間が記録され、他の人がその工程を引き取れる状態になります。再開すると、また自分の作業として続きが記録されます。

## よくある質問・困ったとき

**Q. 一覧に何も出ません。**
A.「**本日の担当工程はありません**」と表示されている場合、今日あなたに割り当てられた作業がありません。割り当ては事務所（指示書の担当者）が行います。

**Q.「前工程待ち」で始められません。**
A. 前の工程がまだ完了していません。前の作業をしている人が終わらせると始められるようになります。

**Q. 受入数が実際と違います。**
A. 開始のときに数字を直してください。前の工程から引き継いだ数が初期値として入っているだけなので、実際に受け取った本数に合わせて問題ありません。

**Q. 間違えて完了してしまいました。**
A. タブレットからは取り消せません。事務所の担当者に連絡してください（パソコン側で対応します）。

**Q. 途中で画面が閉じてしまいました。**
A. 記録は残っています。もう一度ログインして同じ工程を開けば、「作業中」のまま続きから操作できます。

## 必要な権限

この画面を使うには **指示書**（`work_order`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 指示書 の 閲覧 |
| 追加・変更・削除する | 指示書 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
