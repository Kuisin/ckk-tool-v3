这是用于登记工厂中所做 **作业种类** 的应用，例如「切断」（切断）、「円筒加工」（圆筒加工）、「製作検査」（制作检查）。操作代码是 `MS08`。

[指示书](/manual/zh/operations/production/work-order/user)上的工序，都是从这里登记的内容中挑选并排列的。这里没有登记的作业，在指示书上也无法选择。

> ⚠️ 本应用处于试用公开阶段。根据您使用的环境，可能还看不到它。

## 本应用可以做什么

- 可以登记工厂中所做的工序。
- 可以为每道工序设定它属于哪类作业（材料准备、加工、涂层、检查等）。
- 可以设定该工序 **是在公司内部做，还是可以委托外部公司**。
- 可以设定执行该工序时 **让现场人员输入哪些数量**（接收数、良品数等）。
- 可以登记「做这道工序之前，那道工序必须先完成」这样的 **顺序规则**。

## 本页出现的词语

- **工序** … 指「切断」（切断）、「センタレス」（无心磨）、「製作検査」（制作检查）这样一项一项的作业。
- **类别** … 工序的大分类。共有 6 种：材料准备 / 加工 / 涂层 / 检查 / 检查审批 / 出货。
- **实施场所** … 该工序是只在公司内部进行，还是也可以委托外部公司的区分。
- **可并行** … 指可以与其他工序同时推进、并一起记录的工序。
- **数量管理** … 执行工序时，让现场人员输入哪些数量的设定。
- **使用依赖 / 执行依赖** … 工序之间的规则。详情请见「[登记工序的顺序规则](#登记工序的顺序规则)」。

## 开始之前

- 使用本应用需要 **主数据权限**。按钮按不了时，请咨询拥有权限的同事。
- 常用的工序一开始就已经登记好了。请先查看列表，确认是否已经有相同的工序。

## 界面的看法

打开应用后，会显示已登记工序的列表。

![工序主数据的列表界面](../../../assets/screenshots/master-process-step-list-01.png)

- 列表按 **コード**（代码）/ **名称**（名称）/ **カテゴリ**（类别）/ **実施場所**（实施场所）/ **同期可**（可并行）/ **検査**（检查）/ **承認**（审批）/ **数量管理**（数量管理）/ **表示順**（显示顺序）/ **状態**（状态）的顺序排列。
- 平时按「**表示順**」（显示顺序）数字从小到大排列。
- 在上方「**コード・名称で検索**」（按代码・名称搜索）栏中输入文字，就只显示您要找的工序。
- 也可以用「**カテゴリ**」（类别）和「**状態**」（状态）筛选。状态有「有効」（有效，可使用）和「無効」（无效，不再使用）两种。
- 点击行，就会打开该工序的详细界面。

## 登记工序

1. 点击列表界面右上角的「**新規作成**」（新建）。
2. 在「**工程コード**」（工序代码）中输入代表该工序的文字（例 `CYLINDER_MACHINING`）。只能使用大写字母、数字和下划线。
3. 在「**名称**」（名称）的日语栏中输入现场使用的名称（例 円筒加工）。英语栏留空也可以保存。
4. 选择「**カテゴリ**」（类别）。
5. 选择「**実施場所**」（实施场所）。有可能委托外部公司的工序，请选择「**社内・外注**」（公司内・外协）。
6. 选择「**数量管理**」（数量管理）。请见下面的说明。
7. 选择「**ロット入力（既定）**」（批次输入・默认）。这是决定开始工序时是否要求现场人员输入材料批次或单据编码的设定（必填 / 选填 / 无）。
8. 如有需要，在「**既定作業時間**」（默认作业时间）中输入通常需要的时间（单位为小时）。
9. 在「**表示順**」（显示顺序）中输入数字。数字越小，在列表中越靠上。
10. 点击「**保存**」（保存）。

![工序主数据的新建表单](../../../assets/screenshots/master-process-step-new-01.png)

> 💡 「**工程コード**」（工序代码）保存之后无法更改。名称和显示顺序以后可以修改。

### 数量管理的选择方法

这里决定现场人员执行工序时输入哪些数量。

- **なし（記録しない）**（无，不记录）… 不输入数量。上一道工序传来的数量原样传给下一道工序。
- **数量管理（受入・良品・不良）**（数量管理：接收・良品・不良）… 输入接收数、良品数、不良数。普通的加工工序请选这个。
- **検査（検査数・合格・不合格）**（检查：检查数・合格・不合格）… 输入检查数、合格数、不合格数。检查工序请选这个。

打开「**検査工程**」（检查工序）开关后，「数量管理」（数量管理）会自动切换为「検査」（检查）。如果不合适，可以重新选择。

### 各开关的含义

- **同期可**（可并行）… 该工序可以与其他工序同时进行时打开。
- **検査工程**（检查工序）… 该工序进行检查时打开。
- **検査承認工程**（检查审批工序）… 该工序由上级确认检查结果时打开。打开后会出现「**承認必要役職**」（所需审批职位）栏，请填写「係長以上」（股长以上）之类的内容。
- **有効**（有效）… 关闭后，在指示书等处就无法选择该工序。

## 登记工序的顺序规则

工序可以登记两种规则。在表单下方的「**使用依存**」（使用依赖）和「**実行依存**」（执行依赖）中设定。

- **使用依存**（使用依赖）… 「**在什么情况下可以把这道工序放进指示书**」的规则。例如放入「円筒加工」（圆筒加工）时，必须同时放入「円筒加工検査」（圆筒加工检查）。
- **実行依存**（执行依赖）… 「**在什么情况下可以开始这道工序**」的规则。例如「円筒加工検査」（圆筒加工检查）要等「円筒加工」（圆筒加工）结束后才能开始。

两者的登记方法相同。

1. 点击「**依存を追加**」（添加依赖）。
2. 在「**依存先の工程を検索**」（搜索被依赖的工序）栏中输入工序名，选择对方工序。
3. 在其右侧选择规则的连接方式。
   - 「**AND（すべて）**」（AND，全部）… 所选工序必须全部具备。
   - 「**OR（いずれか）**」（OR，任一）… 其中任意一个即可。
4. 想留备注时，请填写右侧的「**備考**」（备注）栏。
5. 点击「**保存**」（保存）。

![输入工序依赖的界面](../../../assets/screenshots/master-process-step-deps-01.png)

只有「使用依存」（使用依赖）的行上有「**排他**」（排他）开关。打开后含义相反，变成「只有在 **没有** 那道工序时才可以使用」的规则。用于像「溝」（沟）和「刃裏」（刃背）这种不会同时放入的工序。

想删除某一行时，请点击该行右端的红色按钮。

> ⚠️ 不能把自己选为对方。也不能在两行中填入同一个对方。保存后，界面上排列的行就原样成为登记内容（删掉的行会消失）。

## 确认已登记的工序

在列表中点击行，就会打开该工序的详细界面。

![工序主数据的详细界面](../../../assets/screenshots/master-process-step-detail-01.png)

上方会集中显示工序代码、名称、类别、实施场所、数量管理、默认作业时间、显示顺序等。下方有 3 个标签页。

- **概要**（概要）… 显示允许的作业场所（无限制时为「制限なし」（无限制），有限制时为类型・场所的一览），以及备注中填写的内容。
- **依存関係**（依赖关系）… 分别以表格显示使用依赖和执行依赖。点击行会跳转到对方工序的界面。
- **履歴**（历史）… 何时由谁做了修改的记录。

![工序主数据的依赖关系标签页](../../../assets/screenshots/master-process-step-dependencies-01.png)

一条规则都没有时，会显示「**使用依存はありません（単独でワークフローに含められます）**」（没有使用依赖，可单独纳入工作流）和「**実行依存はありません（先行工程なしで開始できます）**」（没有执行依赖，无前置工序也可开始）。两者都表示「没有限制」。

## 停用不再使用的工序

不再使用的工序，建议不要删除，而是 **停用**（设为无效）。停用后，以往的记录仍然保留。

1. 点击详细界面右上角的「**…**」（三个点的按钮）。
2. 选择「**無効化**」（停用）。
3. 会弹出确认小窗口，点击「**無効化する**」（确认停用）。

也可以在列表中勾选多行，用「**一括無効化**」（批量停用）一起停用。

## 输入项

工序主数据登记画面的输入项一览。此处登记的工序，即为指示书工作流中排列的「部件」。

| 项目 | 必填 | 填什么 |

| [工序编码 / 名称](#field-code) | 必填 | 工序的管理编号与名称 |
| [类别](#field-category) | 必填 | 材料准备・加工・检查 等区分 |
| [实施地点](#field-execution) | 必填 | 仅社内或可委外 |
| [允许的作业场所](#field-allowed-locations) | 选填 | 限制该工序可使用的作业场所 |
| [数量管理](#field-quantity-tracking) | 必填 | 该工序如何处理数量 |
| [批次输入（默认）](#field-lot-input-mode) | 必填 | 开始时是否要求输入批次・单据编码 |
| [默认作业时间](#field-default-time) | 选填 | 每次的大致时间 |
| [可并行](#field-sync) | — | 是否可与其他工序并行 |
| [检查工序 / 检查审批工序](#field-inspection) | — | 是否为检查相关工序 |
| [审批所需职位](#field-approval-rank) | 选填 | 审批所需的职位 |
| [显示顺序](#field-sort-order) | 选填 | 列表中的排序 |
| [有效 / 备注](#field-active) | — | 是否显示・补充说明 |

### 工序编码 / 名称 [#field-code]

工序的管理编号与名称。指示书中排列的即为该名称。

### 类别 [#field-category]

材料准备・加工・涂层・检查・检查审批・发货的区分。

### 允许的作业场所 [#field-allowed-locations]

![编辑画面的允许作业场所栏目](../../../assets/screenshots/master-process-step-locations-01.png)

限制该工序的**计划・实绩**中可使用的作业场所。可按类型（机械／区域等）批量指定，也可逐个指定场所（可并用，允许其并集）。**两者都留空则不限制**（可使用所有作业场所）。

- 在指示单工序中添加计划・实绩时，选项只会显示允许的场所
- 现场平板（Kiosk）也适用同样的限制：扫描不允许的作业场所二维码会被拒绝；终端默认作业场所不在允许列表内时，不会记录到实绩
- 开启「作业场所限制」开关的 Kiosk 终端，只能开始允许列表中包含其默认作业场所的工序

### 实施地点 [#field-execution]

**仅社内** 或 **社内・委外皆可**。允许委外后，可在指示书中选择外协厂商。

### 数量管理 [#field-quantity-tracking]

该工序如何处理数量。可选 **传递（沿用数量）/ 作为检查计数 / 不计数**，工序执行画面的输入栏会随之变化。

### 批次输入（默认） [#field-lot-input-mode]

决定开始工序时是否要求现场人员输入材料的**批次或单据编码**的设定。设为「**必須**」（必填）时，不输入编码就无法开始工序。「**任意**」（选填）则输不输入都可以开始，「**なし**」（无）则不显示输入栏。此处只是默认值 — 在产品的工序列表或指示书一侧**可以按工序修改**。

### 默认作业时间 [#field-default-time]

每次的大致时间，作为制作指示书时的初始值。

### 可并行 [#field-sync]

是否可与其他工序并行推进。

### 检查工序 / 检查审批工序 [#field-inspection]

是执行检查的工序，还是审批检查结果的工序。**设为检查工序后，可在工序执行画面记录检查表。**

### 审批所需职位 [#field-approval-rank]

审批该工序所需的职位。

### 显示顺序 [#field-sort-order]

列表与选项中的排列顺序。数值越小越靠前。**把工序选入工序列表或指示书时，最初的排列顺序也由这个数字决定**（材料出库・交接的工序无论数字大小都排在最前，发货前检查排在最后）。已经创建的工序列表・指示书的排列，事后修改数字也不会改变。

### 有效 / 备注 [#field-active]

取消后工序选项中将不再显示。备注为补充说明。

## 常见问题・遇到麻烦时

**Q. 出现「他の工程がこの工程に依存しているため削除できません。無効化を検討してください。」（因为其他工序依赖该工序，无法删除。请考虑停用）。**
A. 其他工序把这道工序作为「顺序规则」的对象。请不要删除，改为「停用」。如果一定要删除，请先从对方工序中删掉那条规则行。

**Q. 出现「この工程に関連する検査表テンプレートが存在するため削除できません。無効化を検討してください。」（因为存在与该工序相关的检查表模板，无法删除。请考虑停用）。**
A. [检查表模板](/manual/zh/operations/masters/inspection-template/user)把这道工序指定为「相关工序」。请不要删除，改为「停用」。

**Q. 出现「同じ工程コードの工程が既に存在します」（已存在相同工序代码的工序），无法保存。**
A. 该代码已被使用。请在列表搜索中查找该代码，确认是否已有相同工序。如果是不同的工序，请另取一个代码。

**Q. 出现「工程コードは英大文字はじまりの英大文字・数字・アンダースコアで入力してください」（工序代码请以大写字母开头，使用大写字母、数字和下划线输入）。**
A. 代码只能使用大写字母、数字和下划线（ `_` ）。第一个字符必须是大写字母。不能使用中日文字和小写字母。

**Q. 工序代码填错了，可以修改吗？**
A. 保存之后无法修改。请用正确的代码重新登记一个，并把填错的那个「停用」。

**Q. 我想改变列表的排列顺序。**
A. 请修改各工序的「**表示順**」（显示顺序）数字。数字越小越靠上。像 10、20、30 这样留出间隔，以后更方便在中间插入。

**Q. 「表示順」（显示顺序）和「実行依存」（执行依赖），到底哪个决定作业的顺序？**
A. 决定排列顺序的是「**表示順**」（显示顺序）。把工序放进工序列表或指示书时，会按这个数字从小到大排列（已经创建的指示书的排列，事后修改数字也不会改变）。「**実行依存**」（执行依赖）并不是顺序本身，而是决定「前一道工序结束之前，这道工序不能开始」这样的 **可以开始的条件**。
