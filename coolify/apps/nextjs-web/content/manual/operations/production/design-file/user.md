製品の図面を **版（バージョン）ごと** に登録し、**受注元ごとに分けて** 管理するアプリです。操作コードは `PD06` です。

> ⚠️ このアプリはまだ試験公開中です。画面や手順が今後変わることがあります。

## このアプリでできること

- 製品の図面を **版として登録** できます。1 回の登録が 1 つの版になります。
- 1 つの版に **2D 原図・3D 原図・プレビュー用（STL など）・参考資料** を載せられます。どれも任意です。
- 版は **受注元ごとに分けて** 持てます。同じ製品でも、お客様ごとに別々の図面を育てられます。
- 製品の **仕様**（材種・直径・全長・製品項目）と **図面情報**（品名・材質・刃数 …）を版ごとに持てます。
- **図脳RAPID の SXF（.sfc）** を選ぶと、表題欄と寸法を読んで仕様を自動で埋めます。
- 版は **下書き → (承認) → 確定** の順に進みます。確定するまでは何度でも直せます。
- 登録した版を画面で開いて確かめられます（PDF・画像はそのまま、STL などの 3D モデルは回して見られます）。
- [設計依頼書](/manual/ja/operations/sales/design-request/user)の成果物として登録すると、その依頼を完了できるようになります。

**図面と仕様を登録・編集できるのはこのアプリだけです。** [製品マスタ](/manual/ja/operations/masters/product/user)と[設計依頼書](/manual/ja/operations/sales/design-request/user)にも表示されますが、そちらは見るだけです。書き込む場所を 1 つにしておかないと、版の番号の付け方や仕様が画面ごとにずれてしまうためです。

## 版と系列（このアプリの考え方）

### 1 回の登録 = 1 つの版

2D 原図・3D 原図・プレビュー用・参考資料を同時に上げても、**すべて同じ版番号** になります。版は「図面の改訂世代」であって、ファイルの通し番号ではありません。ファイルを 1 枚も載せない **仕様だけの版** も作れます。

### 版は「製品 × 受注元」ごとに数えます

同じ製品でも、お客様ごとに図面が別々に育ちます。この **製品と受注元の組み合わせ** を系列と呼びます。

- A 社の v3 と B 社の v1 が、同じ製品に同居します。
- 受注元を空のままにした系列は **汎用** です。そのお客様専用の図面が無いときに使われます。
- **他のお客様の系列は決して使われません。** B 社の指示書に A 社の図面が出ることはありません（気づかないまま違う物を作ってしまうためです）。

指示書がどの図面を見るかは「受注元が一致する系列 → 無ければ汎用」の順で決まります。**使われるのは確定した版だけ** です。

### 版の状態（下書き → 承認 → 確定）

| 状態 | 意味 | 直せるか |
|------|------|---------|
| **下書き** | 登録したばかりの版。指示書・製品マスタからはまだ見えません | 直せる |
| **承認依頼中** | 承認を待っている版 | 直せない |
| **差し戻し** | 承認者が差し戻した版。直してもう一度出せます | 直せる |
| **確定** | 使える版。指示書・製品マスタはこの版を読みます | 直せない |

**承認は任意です。** [承認設定](/manual/ja/operations/masters/approval-setting/user)（MS0B）の「**設計図の版**」に段を組んだときだけ承認を通ります。段が無ければ「**確定**」ボタン 1 つで確定します。

**系列ごとに確定前の版は 1 つだけ** です。下書きがあるうちは、同じ系列に次の版を作れません（どちらが次の版なのか分からなくなるため）。先に確定するか、下書きを削除してください。

## 画面の見かた

一覧には **1 行 = 1 系列** で並びます。版を 1 行ずつ並べると同じ製品が何行も出てしまい、探している系列が埋もれるためです。

| 列 | 内容 |
|----|------|
| 製品 | 図面の対象製品 |
| 受注元 | お客様。空の系列は「汎用」と出ます |
| 最新版 | いちばん新しい版の番号と状態。下書きのときは確定済みの版も併記します |
| 役割 | 最新版に載っているファイルの種類 |
| 出どころ | 設計依頼から出た版があれば「依頼」、無ければ「手動」 |
| 更新日 | いちばん新しい版を更新した日 |

行をクリックすると、その製品の設計図が **その行の系列に絞った状態** で開きます。上の「**受注元**」のドロップダウンで別の系列に切り替えたり、空にして **全系列** を受注元ごとに並べたりできます。系列ごとに確定済みの最新版のサムネイルと、版の一覧（状態・仕様の要約・ファイル）が出ます。版を押すと、その版の画面が開きます。受注元で絞っているときの「**版を登録**」は、その受注元を選んだ状態で登録画面が開きます。

## 図面を登録する

1. 一覧の右上「**設計図を登録**」を押します。
2. **製品** を選びます（必須）。
3. **受注元** を選びます。空のままなら「汎用」になります。
4. **ファイル** を選びます（どれも任意）。
5. **図面情報** と **仕様** を確かめます（SXF を選んだときは自動で入っています）。
6. 「**下書きを保存**」を押します。

保存すると下書きの版ができ、その版の画面が開きます。版番号は自動で決まります（その系列の最新版 + 1）。**この時点ではまだ指示書から使われません** — 版の画面で確定してください。

![設計図の登録画面。役割ごとにファイルを選ぶ](../../../assets/screenshots/design-file-new-01.png)

### ファイルの役割

| 役割 | 何を入れるか |
|------|-------------|
| **2D 原図** | 図脳 SXF（.sfc）・DXF・DWG などの 2D の元図。製品の「最新図面」はこれを指します |
| **3D 原図** | STEP・IGES・CIM3D などの 3D の元データ |
| **プレビュー用** | 画面で形を確かめるためのファイル（STL など）。回して見られます |
| **参考資料** | 部品図・寸法表など。何枚でも、1 枚ずつ説明を付けられます |

原図・プレビュー用は 1 枚ずつ、参考資料は何枚でも載せられます。

**プレビュー用と原図を別に選ぶ** のは、用途が違うからです。同じ形でも STL は「見るため」、原図は「作るため」のもので、片方で代わりになりません。

### 図脳 SXF から仕様を読み取る

2D 原図に **図脳RAPID で「SXF形式」で書き出した .sfc** を選ぶと、その場で図面を読み、次の欄を埋めます。

- **図面情報** … 表題欄に書かれた 品名・図面番号・工具番号・材質・表面処理・刃数・ネジレ・刻印・作成年月日
- **直径・全長** … 図面の寸法のうち、いちばん太い φ の寸法を直径、いちばん長い長さ寸法を全長として読みます
- **製品項目** … [製品項目](/manual/ja/operations/system/product-type/settings)（SY03）の名前が表題欄の言葉と同じ項目（例：「図番」← 図面番号）
- **受注元** … 表題欄の「お得意先名」が受注元の 1 社に決まるときだけ選びます。決まらないときは手で選んでください

読み取った値は **保存する前に必ず確認してください**。図面に書かれていない項目は変わりません。材種は図面の「材質」（超微粒子超硬 など）からは決められないので、手で選びます。

**図面から読んだ欄は読み取り専用です**（欄の上に「**図面**」と出ます）。図面と違う値にしたいときは、その欄の「**手入力**」を押して上書きします。上書きしても **図面の値は欄の上に「図面: …」として残る** ので、どこが図面と違うのかが後から分かります。「**図面の値に戻す**」で読み取り専用に戻ります。版の画面の閲覧でも、値の横に「図面」「手入力」の印が付きます。

読み取った値を使わないときは、上の青い枠の「**読み取りを外す**」を押すと、すべての欄が普通に入力できるようになります（入っている値はそのまま）。

> 💡 読めるのは図脳RAPID の「SXF形式」で書き出した .sfc だけです。DXF や画像では読み取りは動きません（ファイルとしては載せられます）。表題欄の枠が社内の仕様図と違う図面では、拾えない項目が出ます。

### 対応しているファイル

形式の制限はありません（1 件 20MB まで）。ただし **画面で開けるのは** PDF・画像・一部の 3D モデル（STL・OBJ・PLY・GLB・3MF など）だけです。SXF・STEP・IGES・DXF・DWG・CIM3D はダウンロードしてお使いのソフトでご覧ください。

## 版を直す・確定する

版の画面は、確定前（下書き・差し戻し）のあいだ直せます。

- **仕様** … 「**編集**」を押すと図面情報・材種・直径・全長・製品項目・メモを直せます。「**保存**」で閲覧に戻ります。
- **ファイル** … 「**ファイルを追加**」で足せます（SXF を足すと仕様へ反映されます）。行の「**削除**」で外せます。
- **確定** … 承認の段が無いときは「**確定**」、段があるときは「**承認依頼**」を押します。
- **版を削除** … 下書きのうちは版ごと消せます。

**確定した版は直せません。** 図面を変えるということは新しい版を作るということで、過去の版を書き換えると「何を見て作ったか」が追えなくなるためです。

## 製品の仕様はここで決まります

製品の **材種・直径・全長・製品項目** は、製品マスタではなく **設計図の確定した版** が持ちます。改訂やお客様ごとに図面と一緒に変わるためです。

製品マスタ・指示書の素材候補・製品検索では、確定した版から次の順で 1 つ選んで使います。

1. 指示書が図面を固定していれば、その版
2. 受注元が一致する系列の最新版
3. 汎用系列の最新版
4. それも無ければ、最後に確定した版

## 設計依頼の成果物として登録する

[設計依頼書](/manual/ja/operations/sales/design-request/user)の詳細画面から「**設計図に登録**」を押すと、**製品と受注元が依頼のものに固定された状態** で登録画面が開きます。この 2 つは依頼が決めているので変更できません。

版を登録すると（下書きのままでも）、依頼の画面で「**完了**」を押せるようになります。**依頼は成果物が 1 件以上ないと完了できません。** 版の確定は設計図の側で行います。

## ファイルにメモを書く

版の画面のファイル一覧で、行の「**メモ**」を押すと、**そのファイルだけのメモ** が開きます。

- 文字は **太字・斜体・箇条書き・見出し・リンク** などを付けられます。
- **確定した版でも書けます。** 凍結されるのは図面の中身であって、注記ではありません。
- **メモは社内限定です。** 帳票（PDF）には出ません。

## よくある質問・困ったとき

**Q. 同じ製品なのに版が v1 に戻っています**
受注元が違う系列を見ています。版は「製品 × 受注元」ごとに数えるので、新しいお客様向けの図面は v1 から始まります。

**Q. 登録した図面が指示書に出てきません**
版がまだ下書き（または承認依頼中）です。版の画面で確定してください。確定した版が無い場合は、汎用（受注元を空）で 1 版確定すると、どのお客様の指示書からも使えるようになります。

**Q. 「この系列には確定前の版があります」と出て登録できません**
同じ系列に下書き（または承認依頼中・差し戻し）の版があります。その版を確定するか削除してから登録してください。

**Q. SXF を選んだのに何も入りません**
「SXF として読めませんでした」と出ている場合は、図脳RAPID の「SXF形式」で書き出した .sfc ではありません。AutoCAD 形式（DXF）などでは読み取れません。

**Q. 製品マスタで材種や寸法を直したい**
製品マスタでは直せません。設計図で新しい版を作り、仕様を直して確定してください。

**Q. 「設計図を登録」が出てきません**
図面を登録する権限がありません。管理者にご相談ください（閲覧はほとんどの方ができます）。

## 必要な権限

この画面を使うには **設計図**（`design_file`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 設計図 の 閲覧 |
| 追加・変更・削除する | 設計図 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
