製品の図面を **版（バージョン）ごと** に登録し、**受注元ごとに分けて** 管理するアプリです。操作コードは `PD06` です。

> ⚠️ このアプリはまだ試験公開中です。画面や手順が今後変わることがあります。

## このアプリでできること

- 製品の図面を **版として登録** できます。1 回の登録が 1 つの版になります。
- 版を **受注元ごとに分けて** 持てます。同じ製品でも、お客様ごとに別々の図面を育てられます。
- 登録した版を画面で開いて確かめられます（PDF・画像はそのまま、STL などの 3D モデルは回して見られます）。
- [設計依頼書](/manual/ja/operations/sales/design-request/user)の成果物として登録すると、その依頼を完了できるようになります。
- 依頼を通さずに登録することもできます（図面だけ先に出来ている、既存の図面を取り込む、など）。
- 版ごとに **メモ** を残せます（この版で何が変わったか）。

**図面を登録・編集・削除できるのはこのアプリだけです。** [製品マスタ](/manual/ja/operations/masters/product/user)と[設計依頼書](/manual/ja/operations/sales/design-request/user)にも図面は表示されますが、そちらは見るだけです。書き込む場所を 1 つにしておかないと、版の番号の付け方が画面ごとにずれてしまうためです。

## 版と系列（このアプリの考え方）

### 1 回の登録 = 1 つの版

図面データ・プレビュー用・参考資料を同時に上げても、**すべて同じ版番号** になります。版は「図面の改訂世代」であって、ファイルの通し番号ではありません。組図と部品図を一緒に出しても版番号がばらばらにならないので、「v3 にしてください」が何を指すか迷いません。

### 版は「製品 × 受注元」ごとに数えます

同じ製品でも、お客様ごとに図面が別々に育ちます。この **製品と受注元の組み合わせ** を系列と呼びます。

- A 社の v3 と B 社の v1 が、同じ製品に同居します。
- 受注元を空のままにした系列は **汎用** です。そのお客様専用の図面が無いときに使われます。
- **他のお客様の系列は決して使われません。** B 社の指示書に A 社の図面が出ることはありません（気づかないまま違う物を作ってしまうためです）。

指示書がどの図面を見るかは「受注元が一致する系列 → 無ければ汎用」の順で決まります。

## 画面の見かた

一覧には **1 行 = 1 系列** で並びます。版を 1 行ずつ並べると同じ製品が何行も出てしまい、探している系列が埋もれるためです。

| 列 | 内容 |
|----|------|
| 製品 | 図面の対象製品 |
| 受注元 | お客様。空の系列は「汎用」と出ます |
| 最新版 | いちばん新しい版の番号（全何版かも出ます） |
| 役割 | 最新版に揃っているファイルの種類 |
| 出どころ | 設計依頼から出た版があれば「依頼」、無ければ「手動」 |
| 更新日 | いちばん新しい版を登録した日 |

行をクリックすると、**その製品の全系列** が受注元ごとに分かれて表示されます。系列ごとに最新版のサムネイルと、版の一覧が出ます。

## 図面を登録する

1. 一覧の右上「**設計図を登録**」を押します。
2. **製品** を選びます（必須）。
3. **受注元** を選びます。空のままなら「汎用」になります。
4. **図面データ** を選びます（必須・1 枚）。これがその系列の最新図面になります。
5. 必要なら **プレビュー用**（任意・1 枚）と **参考資料**（任意・何枚でも）を足します。
6. 必要なら **メモ** を書きます。
7. 「**保存**」を押します。

版番号は自動で決まります（その系列の最新版 + 1）。

![設計図の登録画面。役割ごとにファイルを選ぶ](../../../assets/screenshots/design-file-new-01.png)

### 3 つの役割

| 役割 | 何を入れるか |
|------|-------------|
| **図面データ** | 加工プログラムを起こす元になるファイル（CAD など）。**必須**で、製品の「最新図面」はこれを指します |
| **プレビュー用** | 画面で形を確かめるためのファイル（STL など）。回して見られます |
| **参考資料** | 部品図・寸法表など。1 枚ずつ説明を付けられます |

**プレビュー用と図面データを別に選ぶ** のは、用途が違うからです。同じ形でも STL は「見るため」、CAD は「作るため」のもので、片方で代わりになりません。

### 対応しているファイル

形式の制限はありません（1 件 20MB まで）。ただし **画面で開けるのは** PDF・画像・一部の 3D モデル（STL・OBJ・PLY・GLB・3MF など）だけです。STEP・IGES・DXF・DWG はダウンロードしてお使いのソフトでご覧ください。

## 設計依頼の成果物として登録する

[設計依頼書](/manual/ja/operations/sales/design-request/user)の詳細画面から「**設計図に登録**」を押すと、**製品と受注元が依頼のものに固定された状態** で登録画面が開きます。この 2 つは依頼が決めているので変更できません。

登録すると依頼の画面に戻り、そこで「**完了**」を押せるようになります。**依頼は成果物が 1 件以上ないと完了できません** — 完了が状態を進めるだけの操作になってしまうと、依頼を出した側から見て何が出来たのか判らないためです。

## メモを直す・版を消す

版の一覧で、行の右にあるボタンから操作します。

| 操作 | できる条件 |
|------|-----------|
| メモの編集 | 指示書で使われていない版 |
| 削除 | 指示書で使われておらず、かつ設計依頼を経ていない（手動登録の）版 |

**図面そのものは差し替えられません。** 図面を変えるということは新しい版を作るということで、過去の版を書き換えると「何を見て作ったか」が追えなくなるためです。

**指示書で使われている版は動かせません。** その図面で物を作った（あるいはこれから作る）という記録なので、あとから中身や番号が変わっては困ります。設計依頼から出た版を消せないのは別の理由で、それは完了した依頼の成果物そのものだからです（メモは直せます）。

## よくある質問・困ったとき

**Q. 同じ製品なのに版が v1 に戻っています**
受注元が違う系列を見ています。版は「製品 × 受注元」ごとに数えるので、新しいお客様向けの図面は v1 から始まります。

**Q. 指示書に図面が出てきません**
その注文の受注元向けの系列も、汎用の系列も無い状態です。汎用（受注元を空）で 1 版登録すると、どのお客様の指示書からも使えるようになります。

**Q. 「設計図を登録」が出てきません**
図面を登録する権限がありません。管理者にご相談ください（閲覧はほとんどの方ができます）。

**Q. 依頼の「完了」が押せません**
その依頼の成果物がまだ登録されていません。依頼の画面に出ている「設計図に登録」から登録してください。

**Q. 間違った製品に登録してしまいました**
その版を削除して、正しい製品で登録し直してください（手動登録で、まだ指示書に使われていなければ削除できます）。

## 必要な権限

この画面を使うには **設計図**（`design_file`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 設計図 の 閲覧 |
| 追加・変更・削除する | 設計図 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
