按 **版本** 登记产品图纸，并 **按接单方分别管理**。操作代码为 `PD06`。

> ⚠️ 本应用仍处于试用发布阶段，界面和步骤今后可能会调整。

## 本应用可以做什么

- 将产品图纸登记为 **一个版本**。一次登记就是一个版本。
- 版本 **按接单方分开**。同一产品可以为每个客户维护不同的图纸。
- 在界面上打开已登记的版本（PDF 和图片直接显示，STL 等 3D 模型可以旋转查看）。
- 作为[设计委托单](/manual/zh/operations/sales/design-request/user)的成果登记，登记后该委托单才能完成。
- 也可以不经委托单直接登记（图纸已经先做好，或导入既有图纸）。
- 每个版本都可以写 **备注**（这一版改了什么）。

**只有本应用能登记、编辑和删除图纸。**[产品主数据](/manual/zh/operations/masters/product/user)和[设计委托单](/manual/zh/operations/sales/design-request/user)中也会显示图纸，但那些界面只能查看。写入口保持唯一，版本编号的规则才不会因界面而异。

## 版本与系列

### 一次登记 = 一个版本

即使同时上传图纸文件、预览和参考资料，它们 **共用同一个版本号**。版本指图纸的修订代次，而不是文件的流水号。装配图和零件图一起发布时版本号不会错开，因此「改成 v3」指的是什么不会含糊。

### 版本按「产品 × 接单方」计数

同一产品会为每个客户分别演进图纸。这个 **产品与接单方的组合** 称为系列。

- A 公司的 v3 和 B 公司的 v1 可以并存于同一产品。
- 接单方留空的系列是 **通用** 系列，在客户没有专用图纸时使用。
- **绝不会使用其他客户的系列。** A 公司的图纸不会出现在 B 公司的工单上，否则会在无人察觉的情况下做错东西。

工单按「接单方一致的系列 → 通用系列」的顺序选择图纸。

## 界面说明

列表中 **一行 = 一个系列**，而不是一个版本。如果逐版本列出，同一产品会重复很多行，要找的系列反而被淹没。

| 列 | 内容 |
|----|------|
| 产品 | 图纸对应的产品 |
| 接单方 | 留空的系列显示为「通用」 |
| 最新版本 | 最新的版本号（同时显示共有几版） |
| 角色 | 最新版本已具备的文件类型 |
| 来源 | 有来自设计委托单的版本时显示「委托」，否则显示「手动」 |
| 更新日期 | 登记最新版本的日期 |

点击行会显示 **该产品的全部系列**，按接单方分节，每节都有最新版本的缩略图和版本列表。

## 登记图纸

1. 点击列表右上角的「**登记图纸**」。
2. 选择 **产品**（必填）。
3. 选择 **接单方**。留空即为「通用」。
4. 选择 **图纸文件**（必填，1 个）。它将成为该系列的最新图纸。
5. 如有需要，添加 **预览**（可选，1 个）和 **参考资料**（可选，任意数量）。
6. 如有需要，填写 **备注**。
7. 点击「**保存**」。

版本号自动确定（该系列的最新版本加 1）。

![图纸登记界面，按角色分别选择文件](../../../assets/screenshots/design-file-new-01.png)

### 三种角色

| 角色 | 放什么 |
|------|--------|
| **图纸文件** | 编写加工程序所依据的源数据（CAD）。**必填**，产品的「最新图纸」指的就是它 |
| **预览** | 用于在界面上确认形状的文件（STL 等），可以旋转查看 |
| **参考资料** | 零件图、尺寸表等，每个都可以单独写说明 |

**预览和图纸文件分开选择**，是因为用途不同。即使形状相同，STL 用于查看、CAD 用于制造，两者不能互相替代。

### 支持的文件

格式不受限制（每个文件 20MB 以内）。但 **能在界面上打开的** 只有 PDF、图片和部分 3D 模型（STL、OBJ、PLY、GLB、3MF 等）。STEP、IGES、DXF、DWG 请下载后用自己的软件查看。

## 作为设计委托单的成果登记

在[设计委托单](/manual/zh/operations/sales/design-request/user)详情页点击「**登记图纸**」，登记界面会以 **该委托单的产品和接单方为固定值** 打开。这两项由委托单决定，不能更改。

登记后会回到委托单页面，此时才能点击「**完成**」。**没有成果的委托单无法完成** — 否则完成只是推进状态，提出委托的一方看不出究竟做出了什么。

## 给版本写备忘

在版本列表中点击行上的「**メモ**」（备忘），会打开 **仅属于该版本** 的备忘，用来记录「这一版改了什么」「使用时要注意什么」。

- 文字可以使用 **粗体、斜体、项目符号、标题、链接** 等。
- **每个版本只有一个共享栏**，能登记或编辑图纸的人都可以改写（这里放的是关于该版本的当前事实，而不是谁说了什么的记录）。
- **即使是工单正在使用的版本也可以写。** 冻结的是图纸内容，不是关于它的注记。
- **备忘仅限内部。** 不会出现在单据（PDF）上。

这与列表「**備考**」列中的短句是两回事：备注是登记时写的一行，备忘是之后逐步补充的文字。

## 编辑备注与删除版本

在版本列表中，通过每行右侧的按钮操作。

| 操作 | 允许条件 |
|------|----------|
| 备忘 | 随时（只读用户也能打开） |
| 编辑备注 | 该版本未被工单使用 |
| 删除 | 该版本未被工单使用，且不是来自设计委托单的版本 |

**图纸文件本身不能替换。** 更改图纸意味着新建一个版本；改写既往版本会导致无法追溯「照着什么做的」。

**工单正在使用的版本不能改动。** 它记录着已经或即将照此制造的事实。来自设计委托单的版本不能删除则是另一个原因：它是已完成委托单的成果本身（备注和备忘仍可编辑）。

## 常见问题

**Q. 同一产品的版本怎么回到 v1 了**
您看的是另一个系列。版本按「产品 × 接单方」计数，因此面向新客户的图纸从 v1 开始。

**Q. 工单上没有出现图纸**
该订单接单方的系列和通用系列都不存在。将接单方留空登记一个版本，任何客户的工单都能使用。

**Q. 找不到「登记图纸」**
您没有登记图纸的权限，请咨询管理员（查看权限几乎所有人都有）。

**Q. 委托单的「完成」点不了**
该委托单尚未登记成果。请通过委托单页面上的「登记图纸」进行登记。

**Q. 登记到错误的产品上了**
删除该版本后重新登记到正确的产品（手动登记且尚未被工单使用的版本可以删除）。

## 所需权限

使用本画面需要 **图纸**（`design_file`）权限。

| 想做的事 | 所需权限 |
| --- | --- |
| 打开画面、查看列表与明细 | 图纸 — 查看 |
| 新增・变更・删除 | 图纸 — 创建 / 更新 / 删除 |

仅查看有「查看」即可。画面中若有新增、变更或删除的操作，则分别需要对应的权限。

权限通过角色授予。若不足，请与管理员联系。

权限的整体说明请参见「[权限与角色](../../../permissions)」。
