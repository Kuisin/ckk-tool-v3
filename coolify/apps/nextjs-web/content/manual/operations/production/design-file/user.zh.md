**按版本** 登记产品图纸，并 **按订货方分别** 管理。操作代码为 `PD06`。

> ⚠️ 本应用仍处于试用发布阶段，界面和步骤今后可能会调整。

## 本应用可以做什么

- 将产品图纸 **登记为版本**。一次登记就是一个版本。
- 一个版本可以放 **2D 图纸、3D 模型、预览（STL 等）、参考资料**，均为可选。
- 版本 **按订货方分开** 持有。同一产品可以为每个客户分别维护不同的图纸。
- 每个版本都可以持有产品的 **规格**（材料类别、直径、全长、产品项目）和 **图纸标题栏**（品名、材质、刃数 …）。
- 选择 **图脑 RAPID 的 SXF（.sfc）** 文件时，会读取标题栏和尺寸，自动填入规格。
- 版本按 **草稿 →（审批）→ 已确定** 的顺序推进。确定之前可以随时修改。
- 在界面上打开已登记的版本（PDF 和图片直接显示，STL 等 3D 模型可以旋转查看）。
- 作为[设计委托单](/manual/zh/operations/sales/design-request/user)的成果登记后，该委托单才能完成。

**只有本应用能登记和编辑图纸与规格。**[产品主数据](/manual/zh/operations/masters/product/user)和[设计委托单](/manual/zh/operations/sales/design-request/user)中也会显示，但那些界面只能查看。写入口若不唯一，版本编号的方式和规格就会因界面而出现偏差。

## 版本与系列（本应用的思路）

### 一次登记 = 一个版本

即使同时上传 2D 图纸、3D 模型、预览和参考资料，它们 **共用同一个版本号**。版本指图纸的修订代次，而不是文件的流水号。也可以创建一个文件都不放的 **仅含规格的版本**。

### 版本号在产品内连续编号，图纸按「产品 × 订货方」的系列演进

同一产品会为每个客户分别演进图纸。这个 **产品与订货方的组合** 称为系列。

- **版本号是每个产品一条连续的编号。** 通用 v1，为 A 公司做的是 v2，再修改通用图纸是 v3 — 无论在哪个系列中创建，编号都会增加，因此「v2」在产品内只对应一个版本。
- 因此系列内的编号可能会跳号（通用为 v1、v3，A 公司为 v2 等）。
- 订货方留空的系列是 **通用** 系列，在客户没有专用图纸时使用。
- **绝不会使用其他客户的系列。** A 公司的图纸不会出现在 B 公司的工单上（否则会在无人察觉的情况下做错东西）。

工单按「订货方一致的系列 → 没有则用通用系列」的顺序选择图纸。**只使用已确定的版本。**

### 版本的状态（草稿 → 审批 → 已确定）

| 状态 | 含义 | 能否修改 |
|------|------|---------|
| **草稿** | 刚登记的版本。工单和产品主数据还看不到它 | 可以 |
| **审批中** | 正在等待审批的版本 | 不可以 |
| **已退回** | 被审批人退回的版本。修改后可以再次提交 | 可以 |
| **已确定** | 可以使用的版本。工单和产品主数据读取这个版本 | 不可以 |

**审批是可选的。** 只有在[审批设置](/manual/zh/operations/masters/approval-setting/user)（MS0B）的「**图纸版本**」中设置了审批级别时才会经过审批。没有级别时，点一下「**确定**」按钮即可确定。

**每个系列同时只能有一个未确定的版本。** 存在草稿时，无法在同一系列中创建下一个版本（否则分不清哪个才是下一版）。请先确定，或删除草稿。

## 界面说明

列表中 **一行 = 一个系列**。如果逐版本列出，同一产品会重复很多行，要找的系列反而被淹没。

| 列 | 内容 |
|----|------|
| 产品 | 图纸对应的产品 |
| 订货方 | 客户。留空的系列显示为「通用」 |
| 最新版本 | 最新版本的版本号和状态。是草稿时，同时显示已确定的版本 |
| 角色 | 最新版本中文件的种类 |
| 来源 | 有来自设计委托单的版本时显示「委托」，否则显示「手动」 |
| 更新日期 | 最新版本的更新日期 |

点击行会以 **筛选为该行系列的状态** 打开该产品的图纸。可以用上方的「**订货方**」下拉框切换到其他系列，或清空后按订货方列出 **全部系列**。每个系列显示已确定的最新版本的缩略图，以及版本列表（状态、规格摘要、文件）。点击版本即可打开该版本的画面。按订货方筛选时点击「**登记版本**」，会以已选择该订货方的状态打开登记画面。

## 登记图纸

1. 点击列表右上角的「**登记图纸**」。
2. 选择 **产品**（必填）。
3. 选择 **订货方**。留空即为「通用」。
4. 选择 **文件**（均为可选）。
5. 确认 **图纸标题栏** 和 **规格**（选择 SXF 时会自动填入）。
6. 点击「**保存草稿**」。

保存后会生成草稿版本，并打开该版本的画面。版本号自动确定（该产品最新的版本号加 1）。**此时工单还不会使用它** — 请在版本画面中确定。

![图纸登记界面，按角色分别选择文件](../../../assets/screenshots/design-file-new-01.png)

### 文件的角色

| 角色 | 放什么 |
|------|--------|
| **2D 图纸** | 图脑 SXF（.sfc）、DXF、DWG 等 2D 原始图纸。产品的「最新图纸」指的就是它 |
| **3D 模型** | STEP、IGES、CIM3D 等 3D 原始数据 |
| **预览** | 用于在界面上确认形状的文件（STL 等），可以旋转查看 |
| **参考资料** | 零件图、尺寸表等。数量不限，每个都可以单独写说明 |

原始图纸和预览各放 1 个，参考资料可以放任意数量。

**预览和原始图纸分开选择**，是因为用途不同。即使形状相同，STL 用于「查看」，原始图纸用于「制造」，两者不能互相替代。

### 从图脑 SXF 读取规格

在 2D 图纸中选择 **用图脑 RAPID 以「SXF 格式」导出的 .sfc** 文件时，会当场读取图纸并填入以下栏位。

- **图纸标题栏** … 标题栏中写的品名、图纸编号、刀具编号、材质、表面处理、刃数、螺旋角、刻印、绘制日期
- **直径・全长** … 在图纸尺寸中，把最粗的 φ 尺寸读作直径，最长的长度尺寸读作全长
- **产品项目** … [产品项目](/manual/zh/operations/system/product-type/settings)（SY03）中名称与标题栏用语相同的项目（例：「図番」← 图纸编号）
- **订货方** … 仅当标题栏的「お得意先名」（客户名称）能确定为唯一一个订货方时才自动选择。无法确定时请手动选择

**保存前请务必确认读取到的值。** 图纸上没有写的项目不会改变。材料类别无法根据图纸上的「材质」（超细颗粒硬质合金等）确定，请手动选择。

**从图纸读取的栏位为只读**（栏位上方显示「**图纸**」）。如需使用与图纸不同的值，请点击该栏位的「**手动输入**」进行覆盖。覆盖后，**图纸的值仍会以「图纸：…」的形式显示在栏位上方**，之后可以看出哪里与图纸不同。点击「**恢复为图纸的值**」即可恢复为只读。版本画面的浏览模式中，也会在值旁边标注「图纸」「手动输入」。

不使用读取的值时，点击上方蓝色框中的「**解除读取**」，所有栏位即可正常输入（已填入的值保持不变）。

> 💡 只能读取用图脑 RAPID 以「SXF 格式」导出的 .sfc 文件。DXF 或图片不会被读取（但可以作为文件附加）。标题栏框线与公司内部规格图不同的图纸，会有读取不到的项目。

### 支持的文件

格式不受限制（每个文件 20MB 以内）。但 **能在界面上打开的** 只有 PDF、图片和部分 3D 模型（STL、OBJ、PLY、GLB、3MF 等）。SXF、STEP、IGES、DXF、DWG、CIM3D 请下载后用自己的软件查看。

## 修改・确定版本

版本在确定之前（草稿・已退回）都可以在其画面中修改。

- **规格** … 点击「**编辑**」可以修改图纸标题栏、材料类别、直径、全长、产品项目和备忘。点击「**保存**」回到查看状态。
- **文件** … 用「**添加文件**」追加（追加 SXF 时会反映到规格中）。用行上的「**删除**」移除。
- **确定** … 没有审批级别时点击「**确定**」，有级别时点击「**审批申请**」。
- **删除版本** … 草稿阶段可以整个版本删除。

**已确定的版本无法修改。** 更改图纸意味着新建一个版本；改写既往版本会导致无法追溯「照着什么做的」。

## 产品的规格在这里决定

产品的 **材料类别、直径、全长、产品项目** 不由产品主数据持有，而由 **图纸已确定的版本** 持有，因为它们会随改版或不同客户与图纸一起变化。

产品主数据、工单的材料候选和产品搜索，会按以下顺序从已确定的版本中选出一个使用。

1. 如果工单固定了图纸，则用该版本
2. 订货方一致的系列的最新版本
3. 通用系列的最新版本
4. 以上都没有时，最后确定的版本

## 作为设计委托单的成果登记

在[设计委托单](/manual/zh/operations/sales/design-request/user)详情页点击「**登记为图纸**」，登记界面会以 **产品和订货方固定为该委托单的值** 打开。这两项由委托单决定，不能更改。

登记版本后（即使仍是草稿），委托单画面上的「**已完成**」即可点击。**委托单没有至少 1 件成果就无法完成。** 版本的确定在图纸一侧进行。

## 给文件写备忘

在版本画面的文件列表中点击行上的「**备忘**」，会打开 **仅属于该文件** 的备忘。

- 文字可以使用 **粗体、斜体、项目符号、标题、链接** 等。
- **已确定的版本也可以写。** 冻结的是图纸内容，不是关于它的注记。
- **备忘仅限内部。** 不会出现在单据（PDF）上。

## 常见问题

**Q. 系列内的版本号跳号了（v1 之后是 v3）**
版本号在整个产品内连续编号，中间的编号被其他订货方的系列使用了。请在同一产品的图纸画面中查看其他系列。

**Q. 登记的图纸没有出现在工单上**
该版本仍是草稿（或审批中）。请在版本画面中确定。如果没有已确定的版本，将订货方留空确定一个通用版本，任何客户的工单都能使用。

**Q. 出现「该系列已有未确定的版本」，无法登记**
同一系列中存在草稿（或审批中・已退回）的版本。请先确定或删除该版本后再登记。

**Q. 选择了 SXF 却什么都没有填入**
如果显示「无法作为 SXF 读取」，说明该文件不是用图脑 RAPID 以「SXF 格式」导出的 .sfc。AutoCAD 格式（DXF）等无法读取。

**Q. 想在产品主数据中修改材料类别或尺寸**
产品主数据中无法修改。请在图纸中创建新版本，修改规格后确定。

**Q. 找不到「登记图纸」**
您没有登记图纸的权限，请咨询管理员（查看权限几乎所有人都有）。

## 所需权限

使用本画面需要 **图纸**（`design_file`）权限。

| 想做的事 | 所需权限 |
| --- | --- |
| 打开画面、查看列表与明细 | 图纸 — 查看 |
| 新增・变更・删除 | 图纸 — 创建 / 更新 / 删除 |

仅查看有「查看」即可。画面中若有新增、变更或删除的操作，则分别需要对应的权限。

权限通过角色授予。若不足，请与管理员联系。

权限的整体说明请参见「[权限与角色](../../../permissions)」。
