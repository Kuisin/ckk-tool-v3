できあがった製品をお客様へ送るときに、**何をいくつ送ったか** を記録する **出荷書** を作るアプリです。操作コードは `SH01` です。

> ⚠️ このアプリはまだ準備中です。正式に使えるようになるまでに、画面や手順が変わることがあります。

> このアプリが属するフロー … [出荷の流れ](/manual/ja/process/shipping)

## このアプリでできること

- 送る製品と本数をまとめた出荷書をつくれます。
- 注文請書を選ぶだけで、**まだ出荷していない分の明細が自動で入ります**（手で打ち直す必要はありません）。
- 出荷した記録を残すと、**在庫が自動で減ります**。
- 出荷書を**確定すると**、[納品書](/manual/ja/operations/shipping/delivery-note/user)が**自動で作られます**（手で作る必要はありません）。
- 送らずに社内で預かる分（予備でつくった分など）も記録できます。

出荷書は、あとで[請求書](/manual/ja/operations/billing/invoice/user)をつくるときの元になる大事な書類です。

## 用語（このページで出てくる言葉）

- **注文請書（ちゅうもんうけしょ）** … 「どのお客様に、どの製品を何本、いつまでに」を受けたかをまとめた書類です。出荷書はこれを選んで作ります。
- **注文明細（ちゅうもんめいさい）** … 注文請書の中の受注 1 行のことです。出荷書の明細はこの単位でまとまります。
- **指示書（しじしょ）** … 工場に「この製品をこれだけ作ってください」と出す書類です。作り終わった指示書の分を出荷します。
- **ロット** … 一度にまとめて作った製品のかたまりにつく番号です。指示書の番号がそのままロット番号になります。
- **発送 / 在庫保管** … 「発送」はお客様へ送る分、「在庫保管」は送らずに社内で保管しておく分です。
- **明細（めいさい）** … 出荷書の中の 1 行のこと。「どの製品を何本」を書きます。

## はじめる前に

- 出荷したい分の **注文請書** が先に確定（展開済み）になっている必要があります。
- 製品ができ上がっていること（[指示書](/manual/ja/operations/production/work-order/user)が完了していること）を確認してください。完了した指示書の分が、明細に自動で入ります。
- 出荷書を作ったり出荷したりするには、出荷の権限が必要です。使えないときは管理者にご相談ください。

## 画面の見かた

アプリを開くと、これまでに作った出荷書の一覧が出ます。

![出荷書の一覧画面](../../../assets/screenshots/delivery-order-list-01.png)

- **出荷書番号** … `DOR-` で始まる番号です。システムが自動で付けます。
- **種別** … 青い「発送」はお客様へ送る分、灰色の「在庫保管」は社内で預かる分です。
- **状態** … 灰色は「下書き」、青は「確定」、緑は「出荷済」です。
- 上の検索欄には、出荷書番号・注文明細番号・お客様の名前を入れて絞り込めます。この検索欄は **すでに作った出荷書を探すため** のもので、新規作成のときに注文明細を選ぶ欄とは別ものです。
- 一覧に出るのは、**自分が所属している拠点から送る出荷書** です。
- 行をクリックすると、その出荷書の詳しい画面が開きます。

## 出荷書をつくる

出荷書は 4 つの入口から作れます。どこから始めても、開くのは同じフォームです。

| 始める場所 | 何が入った状態で開くか |
|---|---|
| 出荷書の一覧「**新規作成**」 | 空。注文請書を自分で選ぶ |

**一覧から作る以外は、「注文請書」の欄も入った状態で開きます** — 入った明細の親の注文請書がそのまま欄に入ります。
| [注文請書](/manual/ja/operations/sales/order-acceptance/user)の「**出荷書を作成**」 | その注文請書の出荷できる明細すべて |
| [注文明細](/manual/ja/operations/sales/order-line/user)・[未処理出荷書](/manual/ja/operations/shipping/pending-shipment/user)の「**出荷書を作成**」 | その注文明細 1 件 |
| [指示書](/manual/ja/operations/production/work-order/user)の「**出荷書を作成**」 | その指示書の注文明細。**同じ注文請書に他にも出せる明細があれば「まとめますか」と聞かれます** |

1. 一覧画面の右上にある「**新規作成**」を押します。
2. 「**注文請書**」の欄をクリックして、出荷したい注文請書を選びます。この欄の中では、**お客様の名前・製品名・お客様の注文書番号** で探します。
3. その注文請書の出荷できる注文明細ごとに、**まだ出荷していない本数が明細に自動で入ります**。数量のもとになるのは**指示書の完成数**（その注文明細のためにでき上がった本数）で、ロット（指示書）へ番号順に、現物在庫の範囲で割り振られます（必要な本数までしか入りません）。
4. 「**種別**」で「**発送**」か「**在庫保管**」を選びます。ふつうはそのまま「発送」です。
5. 「**出荷元拠点**」で、どこから送るかを選びます。
6. 明細の「**数量**」を、実際に送る本数に直します。**受注の残り（受注数 − 出荷済）を超える本数は入れられません** — 超えると赤い警告が出て保存できません。
7. 行を増やしたいときは「**行を追加**」、消したいときは行の右にあるゴミ箱の印を押します。
8. 「**保存**」を押します。出荷数が受注の残りに足りないときや、完成品が受注の残りに足りないときは、**「一部出荷の確認」**の画面が出ます。内容を確かめて「**一部出荷として保存**」を押すと保存されます（残りは後から別の出荷書で出せます）。

![出荷書の新規作成フォーム](../../../assets/screenshots/delivery-order-new-01.png)

保存すると「**下書き**」として登録され、詳しい画面が開きます。

> 💡 注文請書を選ぶと、注文明細ごとのまとまりに、その受注の内容（番号・お客様・製品・出荷先・ユーザー直送かどうか・**受注した本数・出荷済みの本数・完成した本数**）が表示されます。「完成」は、つながっている指示書ができ上がった本数のうち、この明細に割り当てられた分です。合っているか確認してから進めてください。

> ⚠️ 注文明細は、保存したあとで変えられません。間違えたときは、その出荷書をキャンセルして作り直してください。

## 内容を確認する

![出荷書の詳しい画面](../../../assets/screenshots/delivery-order-detail-01.png)

上のほうに、出荷書番号・注文明細番号・お客様・製品・種別・出荷元拠点・数量・出荷日が並びます。

- **数量合計** … 「30 / 受注 50」のように、送る本数と注文された本数を並べて表示します。
- 下の「明細」には、製品・ロット・数量・備考が並びます。
- タブは 4 つあります。**概要** は備考、**納品書** はこの出荷書から作った納品書の一覧、**メモ** は社内向けの共有メモ、**履歴** はいつ誰が変更したかの記録です。

## 出荷までの 3 段階

出荷書は「下書き → 確定 → 出荷済」と 3 段階で進みます。操作は画面右上の「**…**」（点が 3 つのボタン）から行います。

![詳しい画面の「…」メニュー](../../../assets/screenshots/delivery-order-menu-01.png)

### 1. 内容を固める（確定）

1. 出荷書の画面で右上の「**…**」を押します。
2. 「**確定**」を選びます。
3. 「確定の確認」という小さな画面が出るので、内容を読んで「**確定**」を押します。

![確定の確認画面](../../../assets/screenshots/delivery-order-confirm-01.png)

確定すると **編集ができなくなります**。発送（発送分）の出荷書は、確定と同時に**納品書が自動で作られます** — ユーザー直送は、価格記載なし（最終需要家へ渡す分）と価格記載あり（お客様宛）の **2 通**になります。在庫保管は納品書を作りません。

確認画面には、**これから作られる納品書の宛先と価格記載の有無**が並びます。押す前にここで確かめてください。

### 2. 実際に送ったら（出荷）

1. 右上の「**…**」を押します。
2. 「**出荷**」を選びます。
3. 「出荷の確認」が出るので「**出荷する**」を押します。

出荷すると、その日の日付が **出荷日** として記録され、状態が「**出荷済**」になります。同時に、送った分だけ[製品在庫](/manual/ja/operations/production/product-inventory/user)が減り、注文明細のほうも「一部出荷」または「出荷済」に自動で変わります。

### まちがえたとき（キャンセル）

「下書き」のあいだだけ、右上の「**…**」から「**キャンセル**」で消せます。確定したあとは消せません。

## 送らずに社内で保管する（在庫保管）

予備で多めに作った分など、お客様へ送らずに社内で保管するときは、「**種別**」で「**在庫保管**」を選びます。

- 「在庫保管」で出荷すると、製品は保管先の在庫として **増えます**。
- 請求の対象にはなりません。注文明細の状態も変わりません。

種別で「在庫保管」を選ぶと、画面にその説明が出ます。

## 納品書ができるまで

納品書は**手で作りません**。発送（発送分）の出荷書を**確定した瞬間に自動で作られます**。

- 通常配送は、価格記載ありの納品書が **1 通**。
- ユーザー直送は、**2 通**（価格記載なしを最終需要家へ、価格記載ありをお客様へ）。**価格記載ありの納品書を最終需要家へ渡さないよう注意してください**（[納品書](/manual/ja/operations/shipping/delivery-note/user)側にも開くときの警告があります）。
- 在庫保管の出荷書は納品書を作りません。

出荷書の画面の「**納品書**」タブに、この出荷書から作られた納品書の一覧（納品番号・納品先・方法・状態・納品日）が並びます。

![納品書タブ](../../../assets/screenshots/delivery-order-delivery-notes-01.png)

## 入力項目

出荷書の画面で入力する項目の一覧です。アプリの入力欄の横にある「?」からも、その項目の説明へ直接来られます。

| 項目 | 必須 | 何を入れるか |
|------|------|-------------|
| [注文請書](#field-order-line) | 必須 | どの受注に対する出荷か |
| [種別](#field-type) | 必須 | 発送か、在庫保管か |
| [出荷元拠点](#field-plant) | 必須 | どの拠点から出すか |
| [備考](#field-notes) | 任意 | 出荷書全体への補足 |
| [製品](#field-product) | 必須 | 出す製品 |
| [ロット（在庫）](#field-lot) | 必須 | どの製造分から出すか |
| [数量](#field-quantity) | 必須 | 出す本数 |

### 注文請書 [#field-order-line]

どの受注に対する出荷かを注文請書で選びます。選ぶと、その注文請書の出荷できる明細が自動で入ります。数量のもとは**指示書の完成数**で、現物在庫と受注の残りの範囲までしか入りません。

複数の注文請書を 1 つの出荷書にまとめられるのは、**同じお客様・同じ出荷先・同じ配送方法（通常配送 / ユーザー直送）**のものだけです。違うものを追加しようとすると、その場で理由が表示されます。

この欄には、**いま明細に載っている注文請書がそのまま入ります**。注文明細・指示書・注文請書のどれから作りはじめても、その明細の親の注文請書が最初から入っているので、自分で選び直す必要はありません。

欄は 1 つしか値を持てないので、**2 つ以上の注文請書をまとめたときだけ**、欄の下に「**対象の注文請書**」として全部の番号が並びます。注文請書を外したいときは、その注文請書の明細の行を（行の右のゴミ箱の印で）消してください — 欄を空にする操作はありません。

### 種別 [#field-type]

出荷の種類です。**発送だけが納品書・請求へ進みます。**

- **発送** … お客様へ送るもの。納品書・請求へ進みます
- **在庫保管** … 予備に作った分を社内に置いておくもの。**請求には進みません**

### 出荷元拠点 [#field-plant]

どの拠点から出すかです。書類や記録のうえで「どこから出したか」を残すための項目なので、実際に荷物を出す拠点を選んでください。種別が「在庫保管」のときは、**この拠点の在庫として保管されます**。なお「発送」で減る在庫は、拠点ではなく明細で選んだロットの在庫です。

### 備考 [#field-notes]

出荷書全体への補足です。明細ごとの補足は、各行の備考に書きます。

### 製品 [#field-product]

出す製品です。注文請書を選ぶと、その受注の製品が自動で入ります。欄をクリックすれば、すべての製品から検索して選び直すこともできます。

### ロット（在庫）[#field-lot]

どの製造分（ロット）から出すかを選びます。**ロット番号は指示書の番号と同じ**で、これによって「どの製造分をどのお客様へ出したか」が後から追えます。選べるのは、その注文明細のためにでき上がった（完了した）指示書のロットのうち、在庫が残っているものです。

### 数量 [#field-quantity]

出す本数です。ロットの在庫数と、**受注の残り（受注数 − 出荷済）**を超えては出せません。受注の残りに足りない本数で保存するときは「一部出荷の確認」が出ます。分けて出す場合は、出荷書を分けて作ります。

## よくある質問・困ったとき

**Q. 新規作成の「注文請書」の欄で、出荷したい注文請書が検索しても出てきません。**
A. この欄には **お客様の名前・製品名・お客様の注文書番号** を入れてください。それでも出ないときは、その注文請書がまだ展開（確定）されていないか、明細がすべて「出荷済」またはキャンセルになっている可能性があります。

**Q. 注文請書を選んだのに、明細があまり入りません。**
A. 数量は指示書の完成数（現物在庫の範囲）から自動で入るため、まだ完了した指示書がない注文明細には、数量だけ入った行が 1 行入ります（見出しの「完成 0」で分かります）。製品ができ上がってから作り直すか、ロットを手で選んでください。すでに受注数量まで出荷済みの明細はスキップされます。

**Q.「受注数を超えています」と出て、保存できません。**
A. 同じ注文明細で、注文された本数より多く送ろうとしています（見出しに赤く「受注残 N を超えています」と出ます）。この出荷書の数量を減らすか、これまでの出荷分を確認してください。

**Q.「在庫が不足」と出て、出荷できません。**
A. 選んだロットに、送る本数ぶんの在庫が残っていません。[製品在庫](/manual/ja/operations/production/product-inventory/user)で数を確かめてから、もう一度お試しください。

**Q. 内容をまちがえたので直したいのですが、「編集」が出てきません。**
A. 編集できるのは「下書き」のあいだだけです。確定したあとは直せないので、その出荷書はそのままにして、正しい内容で新しく作り直してください。

**Q. 出荷したのに、注文明細が「出荷済」になりません。**
A. 種別が「在庫保管」になっていないか確認してください。「在庫保管」は社内で預かる記録なので、注文明細の状態は変わりません。また、注文された本数の一部だけを送った場合は「一部出荷」になります。

## 必要な権限

この画面を使うには **出荷書**（`delivery_order`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 出荷書 の 閲覧 |
| 追加・変更・削除する | 出荷書 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
