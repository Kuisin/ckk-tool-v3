「できあがったのに、まだ出荷書を作っていない注文」と「作ったけれど、まだ出ていない出荷書」をまとめて確認する **未処理出荷書** のアプリです。操作コードは `SH03` です。

> このアプリが属するフロー … [出荷の流れ](/manual/ja/process/shipping)

## このアプリでできること

- 製造が完了した注文明細のうち、完成分がまだ出荷書に載りきっていないものを一覧で見られます。
- その注文明細が選ばれた状態で、[出荷書](/manual/ja/operations/shipping/delivery-order/user)の新規作成へ直行できます。
- 作成済みで、まだ出荷していない出荷書（下書き・確定）を確認できます。
- 「今日どの注文の出荷書を作るか」を納期の近い順に決めるときに便利です。

## 用語（このページで出てくる言葉）

- **注文明細（ちゅうもんめいさい）** … 注文請書の 1 行分です。「この製品を何本」という受注の単位です。
- **出荷書（しゅっかしょ）** … 「どの製品を何本出すか」を決める出荷の書類です。
- **完成数（かんせいすう）** … 完了した指示書で実際にできあがった良品の本数です。不良で減った分は入りません。
- **未手配（みてはい）** … 完成した本数のうち、まだ出荷書に載っていない本数です。**未手配 = 完成数 − 出荷手配済** で計算されます。

## 開き方

ホーム画面の「出荷」の中にある **未処理出荷書** を押します。または、画面上の検索欄に `SH03` と入れます。閲覧には出荷書の権限が必要です。

## 画面の見かた

画面にはタブが 2 枚あります。どちらも「まだ処理が終わっていないもの」だけが並ぶ作業キューです。

- **未手配** … 完成分が出荷書に載りきっていない注文明細です。件数がオレンジ色で表示されます。
- **出荷準備中** … 作成済みで、まだ出荷済みになっていない出荷書です。

上の検索欄と「**状態**」（出荷準備中タブでは「**種別**」も）で絞り込めます。条件を消すときは「**リセット**」を押します。

### 未手配タブ

完了した指示書が 1 件以上ある注文明細のうち、完成分がまだ出荷書に載りきっていないものが、**納期の早い順** に並びます。

- **注文明細番号** … クリックすると[注文明細](/manual/ja/operations/sales/order-line/user)の詳細が開きます。
- **顧客 / 製品** … 誰から受けた、どの製品の注文かです。
- **完了ロット** … 完了した指示書のロット番号です（`#123` のように表示されます）。
- **完成数** … 完了した指示書で実際にできあがった本数です。予定数量ではなく実際の出来高なので、不良で減った分はここに入りません。
- **出荷手配済** … すでに出荷書に載せた本数の合計です。下書きの出荷書に載せた分も「手配済み」として数えます。
- **未手配** … 完成数 − 出荷手配済。オレンジ色のバッジで表示されます。
- **納期 / 状態** … 納入予定日と、明細の状態（確定・製造中・一部出荷）です。

### 出荷準備中タブ

まだ出荷済みになっていない出荷書（下書き・確定）が並びます。行をクリックすると[出荷書](/manual/ja/operations/shipping/delivery-order/user)の詳細が開きます。

- **出荷書番号 / 顧客・注文明細** … どの出荷書で、どの注文の分かです。
- **種別** … 「発送」か「在庫保管」かです。
- **数量合計 / 状態** … 出荷書に載っている本数の合計と、出荷書の状態（下書き・確定）です。

出荷済みの出荷書はこの画面には出ません。[出荷書](/manual/ja/operations/shipping/delivery-order/user)の一覧（`SH01`）で確認してください。

## 未手配の注文から出荷書を作る

1. 「**未手配**」タブで、出荷書を作りたい行を探します。
2. 行の右端にある「**出荷書作成**」を押します。
3. 出荷書の新規作成画面が開きます。その注文明細が選ばれた状態で始まるので、完了ロットから出す本数を組み立てます。
4. 内容を確認して保存します。以降の手順は[出荷書](/manual/ja/operations/shipping/delivery-order/user)のマニュアルをご覧ください。

保存すると、その分だけ「出荷手配済」が増えます。未手配が 0 本になった明細は、このタブから消えます。

## よくある質問・困ったとき

**Q. 製造が終わったはずの注文が、未手配タブに出てきません。**
A. 完了した指示書がまだ 1 件も無いか、完成分がすべて出荷書に載っているかのどちらかです。指示書の完了は[指示書](/manual/ja/operations/production/work-order/user)の画面で確認してください。

**Q. 完成数が受注数より少なく表示されます。**
A. 完成数は指示書の実際の出来高です。不良が出て良品が減った場合や、指示書がまだ一部しか完了していない場合は、受注数より少なくなります。

**Q. 出荷書を下書きのまま置いていたら、未手配の数が減りました。**
A. 正しい動きです。下書きの出荷書に載せた本数も「出荷手配済」として数えるので、同じ完成分を二重に手配しないようになっています。

**Q. 出荷済みの出荷書はどこで見られますか？**
A. この画面は作業キューなので、出荷済みの出荷書は出ません。出荷書の一覧（`SH01`）で確認してください。

**Q. 未手配タブに「出荷書待ちの注文明細はありません」と表示されます。**
A. 出荷書の手配が必要な注文明細が今は無い、という意味です。指示書が完了して完成分ができると、ここに出てきます。

## 必要な権限

この画面を使うには **出荷書**（`delivery_order`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | 出荷書 の 閲覧 |
| 追加・変更・削除する | 出荷書 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
