把「做好了但还没做出货单的订单」和「做好了但还没发出去的出货单」放在一起确认的 **未处理出货单**（未処理出荷書）应用。操作代码是 `SH03`。

## 这个应用能做什么

- 可以在一览里看到：制造已完成、但完成量还没有全部写进出货单的订单明细。
- 可以在已经选好那条订单明细的状态下，直接去新建[出货单](/manual/zh/operations/shipping/delivery-order/user)。
- 可以确认已经做好、但还没发货的出货单（草稿・确定）。
- 按交期从近到远排列，方便决定「今天要给哪些订单做出货单」。

## 本页出现的词

- **订单明细（注文明細）** … 订单回执里的一行。是「这个产品多少支」这样的受订单位。
- **出货单（出荷書）** … 决定「发什么产品、发多少支」的发货单据。
- **完成数（完成数）** … 已完成的指示书实际做出来的良品支数。因不良而减少的部分不算在内。
- **未手配（未安排）** … 完成的支数里，还没有写进出货单的部分。计算方式是 **未安排 = 完成数 − 已安排发货**。

## 打开方法

按主页「出荷」（出货）分类里的 **未処理出荷書**。或者在界面上方的搜索框里输入 `SH03`。查看需要出货单的权限。

## 界面的看法

界面上有 2 个页签。两个都是只列出「还没处理完的东西」的作业队列。

- **未手配（未安排）** … 完成量还没有全部写进出货单的订单明细。件数以橙色显示。
- **出荷準備中（备货中）** … 已经做好、但还没变成已发货的出货单。

可以用上方的搜索框和「**状態**」（状态，在备货中页签还有「**種別**」＝类别）来筛选。要清除条件时按「**リセット**」（重置）。

### 未安排页签

在至少有 1 张已完成指示书的订单明细中，完成量还没有全部写进出货单的，按 **交期从早到晚** 排列。

- **订单明细号** … 点击可以打开[订单明细](/manual/zh/operations/sales/order-line/user)的详细界面。
- **客户 / 产品** … 从谁那里接的、哪个产品的订单。
- **完了ロット（已完成批次）** … 已完成指示书的批次号（显示成 `#123` 这样）。
- **完成数** … 已完成指示书实际做出来的支数。这是实际产出而不是预定数量，所以因不良减少的部分不在里面。
- **出荷手配済（已安排发货）** … 已经写进出货单的支数合计。写进草稿状态出货单的部分也算「已安排」。
- **未手配（未安排）** … 完成数 − 已安排发货。以橙色徽章显示。
- **交期 / 状态** … 预定交货日，以及明细的状态（确定・制造中・部分发货）。

### 备货中页签

列出还没有变成已发货的出货单（草稿・确定）。点一行就能打开[出货单](/manual/zh/operations/shipping/delivery-order/user)的详细界面。

- **出货单号 / 客户・订单明细** … 是哪张出货单、哪个订单的部分。
- **種別（类别）** … 「発送」（发送）还是「在庫保管」（库存保管）。
- **数量合计 / 状态** … 出货单上的支数合计，以及出货单的状态（草稿・确定）。

已发货的出货单不会出现在这个界面上。请到[出货单](/manual/zh/operations/shipping/delivery-order/user)的一览（`SH01`）确认。

## 从未安排的订单做出货单

1. 在「**未手配**」页签里找到想做出货单的那一行。
2. 按行最右边的「**出荷書作成**」（新建出货单）。
3. 出货单的新建界面会打开。那条订单明细已经被选好，接下来从已完成批次里组合要发的支数。
4. 确认内容后保存。之后的步骤请看[出货单](/manual/zh/operations/shipping/delivery-order/user)的手册。

保存以后，「已安排发货」就会增加相应的支数。未安排变成 0 支的明细会从这个页签消失。

## 常见问题・遇到麻烦时

**Q. 制造应该已经做完了，但订单没有出现在未安排页签里。**
A. 要么是还没有一张已完成的指示书，要么是完成量已经全部写进出货单了。指示书是否完成请在[指示书](/manual/zh/operations/production/work-order/user)的界面确认。

**Q. 完成数显示得比受订数少。**
A. 完成数是指示书的实际产出。出了不良导致良品减少，或者指示书只完成了一部分时，就会比受订数少。

**Q. 出货单一直放着当草稿，未安排的数量却减少了。**
A. 这是正常的。写进草稿状态出货单的支数也算「已安排发货」，这样同一批完成量就不会被重复安排。

**Q. 已发货的出货单在哪里看？**
A. 这个界面是作业队列，所以不显示已发货的出货单。请在出货单的一览（`SH01`）确认。

**Q. 未安排页签显示「等待出货单的订单明细没有」。**
A. 意思是现在没有需要安排出货单的订单明细。指示书完成、产生完成量以后，就会出现在这里。

## 所需权限

使用本画面需要 **出货单**（`delivery_order`）权限。

| 想做的事 | 所需权限 |
| --- | --- |
| 打开画面、查看列表与明细 | 出货单 — 查看 |
| 新增・变更・删除 | 出货单 — 创建 / 更新 / 删除 |

仅查看有「查看」即可。画面中若有新增、变更或删除的操作，则分别需要对应的权限。

权限通过角色授予。若不足，请与管理员联系。

权限的整体说明请参见「[权限与角色](../../../permissions)」。
