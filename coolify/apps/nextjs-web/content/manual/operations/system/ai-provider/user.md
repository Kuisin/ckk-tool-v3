注文書の読み取りや、マスタのキーワード候補づくりで使う **AI の接続先** を決める設定です。操作コードは `SY0E` です。

> ⚠️ このアプリは今のところ **テスト用の環境だけ** で使えます。本番で使えるようになるまでに、画面や手順が変わることがあります。

> ⚠️ この画面はシステム管理者向けです。外部のサービスを選ぶと、**注文書の画像と読み取り結果が社外へ送られます**。

## このアプリでできること

- AI の接続先を、社内の GPU と外部サービスのあいだで切り替えられます。
- 使うモデル（画像読み取り用・文章の組み立て用）を指定できます。
- API トークンを登録できます。
- 保存する前に「接続テスト」で実際に 1 回ずつ呼び出して確かめられます。

## 用語（このページで出てくる言葉）

- **プロバイダ** … AI の提供元です。社内（Ollama）か、外部サービスかを選びます。
- **画像読み取りモデル** … 注文書の画像を読むモデルです。
- **構造化モデル** … 読み取った内容を項目ごとに整えるモデルです。
- **API トークン** … 外部サービスを使うための合言葉です。

## 既定では社内で動いています

設定を触らなければ、**社内の GPU（Ollama）** で動きます。この状態では書類が社外に出ません。画面には「**現在は既定（社内 GPU の Ollama）です**」と出ます。

> 💡 **文字の読み取り（OCR）は、どの設定でも必ず社内で行います。** 外部サービスを選んでも、OCR の部分だけは社外に出ません。

## 接続先を変える

1. 「**プロバイダ**」を選びます（ローカル (Ollama) / OpenAI 互換 / Anthropic (Claude) / Google Gemini）。
2. 必要なら「ベース URL」を入れます（空欄ならそのプロバイダの既定）。
3. 「**画像読み取りモデル**」にモデル名を入れます。
4. 「**構造化モデル**」を入れます。空欄なら画像読み取りモデルと同じものを使います。
5. 外部サービスなら「**API トークン**」を貼り付けます。
6. 「**接続テスト**」を押して、両方に応答があることを確かめます。
7. 「保存」を押します。

外部サービスを選ぶと、画面に「**外部の AI サービスを使用します。注文書の画像と読み取り結果が社外へ送信されます。**」と出ます。

> ⚠️ トークンは保存すると **下 4 桁だけ** が表示されます。全体をもう一度見ることはできません。

## 社内に戻すとき

「**既定に戻す**」を押すと社内の Ollama に戻ります。**保存すると、登録済みのトークンも削除されます。**

## 接続テストで分かること

「構造化」と「画像読み取り」を 1 回ずつ呼びます。保存前の入力でも試せます。うまくいけば「**構造化・画像読み取りの両方に応答がありました**」と出ます。

## よくある質問・困ったとき

**Q. 「AI プロバイダに API トークンを拒否されました」と出ます。**
A. トークンが違うか、期限が切れています。入れ直してから接続テストを押してください。

**Q. 「AI プロバイダに指定のモデルがありません」と出ます。**
A. モデル名の間違いです。Anthropic では **日付を付けません**（`claude-opus-5` のように）。

**Q. 「指定のモデルは画像を読み取れません」と出ます。**
A. 画像を読めないモデルを「画像読み取りモデル」に指定しています。画像に対応したモデル名に変えてください。

**Q. 「暗号鍵が更新されています」と出ます。**
A. トークンを守るための鍵が変わっています。設定を保存し直すと、新しい鍵で保存されます。

**Q. 設定を変えたら、いつから効きますか。**
A. 保存した直後から、すべての AI の呼び出しがこの設定を使います。

## 必要な権限

この画面を使うには **システム管理**（`system`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | システム管理 の 閲覧 |
| 追加・変更・削除する | システム管理 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
