「**誰が・いつ・どこから・どの端末でログインしたか**」と、**うまくいかなかった試み**をまとめて調べられるアプリです。操作コードは `SY0D` です。

パソコン（Web）からのログインと、現場の共有タブレット（共有端末）からのログインの両方が、同じ画面に並びます。

見るだけのアプリです。この画面から記録を直したり消したりすることはできません。

## このアプリでできること

- ログインの **成功と失敗の両方** を、新しい順に見られます。
- 「同じ人が何回も失敗している」「知らない場所から試されている」といった動きに気づけます。
- 1 件を選ぶと、そのときの **接続元・端末の情報** を詳しく確認できます。
- IP アドレスの範囲（例: 社内ネットワーク全体）で絞り込めます。

## 用語（このページで出てくる言葉）

- **試み（こころみ）** … ログインしようとした 1 回のことです。成功でも失敗でも 1 件として記録されます。
- **IP アドレス** … 接続してきた場所を表す番号です。社内から接続したか、社外から接続したかの手がかりになります。
- **端末シグネチャ** … ブラウザの特徴を集めて作った目印です。**「いつもと同じパソコンか」を見分ける目安**であり、端末を特定するものではありません。
- **端末区分** … その端末が会社のものか、そうでないかの自動判定です。次の節で詳しく説明します。

## はじめる前に

- このアプリを開くには **システム管理の権限** が必要です。開けない場合は、システム管理者にご相談ください。
- 記録には接続元やパソコンの構成といった情報が含まれます。**必要があるときに調べるためのもの**で、日常的に人の行動を眺めるためのものではありません。
- 記録は自動で消えます。**成功は 180 日、失敗は 400 日** で消えます。

## 開き方

ホーム画面の「システム」の中にある **ログイン履歴** を押します。または、画面上の検索欄に `SY0D` と入れます。

## 端末区分（会社の端末か、そうでないか）

一覧と詳細に「**端末区分**」が出ます。これはシステムが自動で判定したもので、**判定の確かさが 4 段階**あります。バッジにマウスを重ねると、判定の理由が出ます。

| 表示 | 意味 | 確かさ |
|------|------|--------|
| **会社（管理端末）** | 端末が持っている鍵の署名で確認できた | 確実 |
| **会社（社内NW）** | 接続元が社内ネットワークの範囲内だった | 状況からの推測 |
| **未管理** | 会社の端末だという証拠がなかった | 断定ではない |
| **未判定** | 判定する材料がなかった | — |

いちばん大事な注意点です。

> ⚠️ 「**会社（社内NW）**」は「**社内から接続している**」という意味であって、「**会社が配った端末である**」という意味ではありません。私物のパソコンを社内に持ち込んでも、VPN でつないでも、同じ表示になります。
>
> はっきり「会社の端末」と言えるのは「**会社（管理端末）**」だけです。これは現場の共有タブレット（専用アプリ入り）が、端末の中に保管された鍵で署名して申告したときに付きます。

この判定は表示のためのものです。**この判定によってログインが拒否されることはありません。**

## 画面の見かた

アプリを開くと、上に直近 24 時間のまとめ、下に記録の一覧が並びます。

### 上のまとめ

- **24時間の失敗** … 失敗した試みの件数です。ふだんより多いときは下の一覧を確認してください。
- **24時間の成功** … 成功した件数です。
- **失敗の多い IP（24h）** … 失敗が集中している接続元です。
- **失敗の多い相手（24h）** … 失敗が集中しているユーザーです。存在しないユーザー名で試されている場合は「**(未解決)**」と、目印の記号で表示されます。

### 一覧

- **日時** … その試みがあった日時です。
- **結果** … 成功（緑）か失敗（赤）かです。
- **アプリ** … Web（パソコン）か、共有端末（共有タブレット）かです。
- **方式** … どうやってログインしようとしたかです（パスワード / シングルサインオン / QRカード + PIN など）。
- **ユーザー** … 誰の試みかです。存在しないユーザー名だった場合は「**未解決**」と目印だけが出ます（**入力された文字はわざと保存していません**）。
- **理由** … 失敗の理由です（パスワード不一致、カードが無効、PIN 不一致 など）。
- **IP** … 接続元です。
- **端末区分** … 上で説明した自動判定です。
- **端末** … 共有タブレットならその端末名、パソコンなら「Chrome / Windows 11」のような目印です。

## 探す・絞り込む

上の絞り込みで、見たい範囲を狭められます。

1. **期間** … 24 時間 / 7 日 / 30 日 / 90 日 / 全期間。はじめは 7 日です。
2. **結果** … 失敗だけ、成功だけに絞れます。調べものではまず「失敗」を選ぶと見やすくなります。
3. **アプリ** … Web だけ、共有端末だけに絞れます。
4. **端末区分** … 「未管理」だけを見る、といった絞り込みができます。
5. **検索欄（IP / CIDR）** … IP アドレスをそのまま入れるか、**範囲でまとめて指定**できます。たとえば `192.168.50.0/24` と入れると、`192.168.50.1` から `192.168.50.254` までがまとめて対象になります。
6. 条件を全部消したいときは「**リセット**」を押します。

## 1 件を詳しく見る

一覧の行をクリックすると、右側にその 1 件の詳細が開きます。

- **注意すべき兆候** … 気になる点があるときだけ、いちばん上に橙色で出ます。たとえば「自動操作フラグが立っている（人ではなくプログラムからの接続かもしれない）」「端末の時計が大きくずれている」といった内容です。
- **日時・方式・理由・ユーザー** … 一覧と同じ内容です。
- **送信元 IP** と **プロキシチェーン** … 接続元と、そこに至るまでの経路です。
- **判定理由** … 端末区分をそう判定した根拠です（`wrapper:device-owner`、`cidr:inside` など）。英字のままですが、システム管理者が原因を追うときに使います。
- **端末シグネチャ** … ブラウザの特徴から作った目印です。同じ人の別の記録と見くらべると、いつもと同じパソコンかどうかの参考になります。
- **収集シグネチャ** … 判断の材料にした情報の一覧です。ふだんは見る必要はありません。

> 💡 詳細を開くと、その操作が[操作履歴](/manual/ja/operations/system/activity-log/user)に記録されます（誰が中身を見たかを残すためです）。一覧を眺めるだけでは記録されません。

## 記録されないこと

安全のため、**わざと保存していない情報**があります。

- **パスワードと PIN** … 一切保存しません。
- **存在しないユーザー名** … 入力された文字は保存しません（打ち間違えたパスワードが混ざる可能性があるためです）。同じ相手が繰り返しているかどうかだけが分かる目印を残します。
- **QRカードの中身** … 読み取った値は保存しません。「カードの QR だったか、指示書の QR だったか」という**種類だけ**を残します。

## 入力項目

ログイン履歴は**記録を見るだけの画面**です。入力する項目はなく、絞り込みの条件を選ぶだけです。

| 絞り込み | 何が変わるか |
|----------|-------------|
| [期間](#field-days) | 何日ぶんの記録を見るか |
| [結果](#field-outcome) | 成功だけ・失敗だけに絞る |
| [アプリ](#field-app) | Web だけ・共有端末だけに絞る |
| [端末区分](#field-ownership) | 会社の端末かどうかの判定で絞る |
| [IP / CIDR](#field-ip) | 接続元で絞る（範囲指定もできる） |

### 期間 [#field-days]

何日ぶんの記録を見るかです。はじめは 7 日です。古い記録を探すときは広げてください。

### 結果 [#field-outcome]

成功だけ、失敗だけに絞り込みます。調べものではまず「失敗」を選ぶと見やすくなります。

### アプリ [#field-app]

パソコン（Web）からのログインか、現場の共有タブレット（共有端末）からのログインかで絞り込みます。

### 端末区分 [#field-ownership]

会社の端末かどうかの自動判定で絞り込みます。判定の意味と確かさは「端末区分」の節を参照してください。

### IP / CIDR [#field-ip]

接続元で絞り込みます。`192.168.50.10` のように 1 つを指定するほか、`192.168.50.0/24` のように**範囲でまとめて**指定できます。

## よくある質問・困ったとき

**Q. 失敗が急に増えました。どうすればよいですか。**
A. 「結果」を「失敗」にして、上の「失敗の多い IP」「失敗の多い相手」を見てください。同じ相手が繰り返しているなら、本人の打ち間違いかどうかを確認します。心当たりのない接続元が並ぶ場合は、システム管理者にご相談ください。

**Q. ユーザー欄が「未解決」になっています。誰ですか。**
A. 存在しないユーザー名でログインしようとした記録です。入力された文字は**わざと保存していません**。横の目印が同じなら、同じ文字が繰り返し使われていることが分かります。

**Q. 端末シグネチャが「—」になっています。異常ですか。**
A. 異常ではありません。ログイン画面を通らない経路（外部の認証画面から直接戻ってきた場合など）では集まりません。

**Q. 自分のパソコンなのに「未管理」と出ます。**
A. 「未管理」は「会社の端末だという証拠がない」という意味で、「私物である」と断定しているわけではありません。社外や別のネットワークから接続するとこの表示になります。

**Q. 誰かがログインしたあと何をしたかを知りたいです。**
A. この画面ではログインまでしか分かりません。その後の操作は[操作履歴](/manual/ja/operations/system/activity-log/user)（`SY07`）で調べてください。

**Q. 共有タブレットの記録だけを見たいです。**
A. 「アプリ」を「共有端末」に絞ってください。特定の 1 台だけを見たいときは、[端末管理](/manual/ja/operations/system/kiosk-device/user)（`SY09`）の端末詳細に「認証エラー」の一覧があります。

**Q. 古い記録が出てきません。**
A. 記録は自動で消えます（成功 180 日 / 失敗 400 日）。それより前のことを調べる必要があるときは、システム管理者にご相談ください。
