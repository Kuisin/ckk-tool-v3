システムを使う人の一覧を見て、**その人が何をできるか** を確認するアプリです。操作コードは `SY01` です。

ここから人を追加したり、名前やメールを変えたりすることはできません（それらは社内の共通ログインのしくみから取り込まれます）。この画面で変えられるのは **ロール** と **所属拠点** の 2 つだけです。

## このアプリでできること

- システムに登録されている人を、一覧で見られます。
- 名前やメールアドレスで、探している人を絞り込めます。
- ひとりを選ぶと、その人に与えられている **役割** と、**できること** の一覧を確認できます。
- その人の **役割（ロール）** と **所属拠点** を変えられます（権限が要ります）。
- 「この人はなぜこの画面を開けないのか」を調べるときに使います。

## 用語（このページで出てくる言葉）

- **ロール** … その人の役割のことです。「営業」「工場担当」のようにまとめて登録され、ロールごとに使える画面が決まっています。
- **権限（けんげん）** … 「その画面を見てよい」「保存してよい」という許可のことです。ロールについてきます。
- **拠点（きょてん）** … 工場や事業所のことです。人によっては「自分の拠点のデータだけ見られる」といった決まりがあります。
- **区分（くぶん）** … その人の種類です。**社員** / **ゲスト** / **システム**（人ではなく、システム自身が行う処理）の 3 つがあります。

## はじめる前に

- このアプリを開くには **システム管理の権限** が必要です。開けない場合は、画面に「この操作の権限がありません（system:READ）」と表示されます。システム管理者にご相談ください。
- 人の追加・削除・氏名の変更は、このアプリではできません。社内の共通ログインのしくみ側で管理されています。

## 開き方

ホーム画面の「システム」の中にある **ユーザー管理** を押します。または、画面上の検索欄に `SY01` と入れます。

## 画面の見かた

アプリを開くと、登録されている人の一覧が表示されます。

![ユーザー管理の一覧画面](../../../assets/screenshots/settings-users-list-01.png)

- **ユーザー名** … ログインに使う ID です。
- **表示名** … 画面に出る氏名です。
- **メール** … 登録されているメールアドレスです。無いときは「—」と出ます。
- **区分** … **システム** / **社員** / **ゲスト** のいずれかです。
- **ロール** … その人に与えられている役割です。複数付いていることもあります。
- **状態** … いまログインできる人は「**有効**」、止められている人は「**無効**」です。
- **最終ログイン** … 最後にログインした日時です。一度もログインしていない人は「—」です。

上の検索欄「**ユーザー名 / 表示名 / メール / ロール...**」に文字を入れると、その文字を含む人だけが残ります。「**区分**」「**状態**」で絞り込むこともできます。条件を全部消したいときは「**リセット**」を押します。

行をクリックすると、その人の詳しい画面が開きます。

## ひとりの内容を確認する

一覧で行をクリックすると、その人の画面が開きます。上のほうに基本の情報が並びます。

![ユーザーの詳細画面](../../../assets/screenshots/settings-users-detail-01.png)

- **ユーザー名** / **区分** / **メール** / **最終ログイン** / **社員 ID** … 一覧と同じ内容です。
- **ログイン方式** … 「**パスワード + SSO**」はこのシステムのパスワードでも社内共通ログインでも入れる人、「**SSO のみ**」は社内共通ログインだけで入る人です。

その下に、3 つの表が並びます。

### ロール割当（どんな役割を持っているか）

![ロール割当の表](../../../assets/screenshots/settings-users-roles-01.png)

- 「**ロール**」に役割の名前、「**状態**」にいま有効かどうかが出ます。
- 過去に外した役割も記録として残ります。「**解除日時**」に日付が入っている行は、いまは効いていません。
- 何も無いときは「**ロールが割り当てられていません**」と表示されます。この人はまだ何もできない状態です。
- 権限のある人には「**編集**」ボタンが出ます。やりかたは「[ロールを変える](#ロールを変える)」を参照してください。

### 所属拠点（どの拠点の人か）

![所属拠点のカード](../../../assets/screenshots/settings-users-plants-01.png)

- その人が所属する拠点（工場・事業所）です。
- 「自分の拠点のぶんだけ見られる」という決まりの権限は、ここが空だと **見られるデータがゼロ** になります。権限を付けたのに何も見えない、というときはここを確認してください。
- 何も無いときは「**所属拠点がありません**」と表示されます。

### 実効権限（結局なにができるのか）

![実効権限の表](../../../assets/screenshots/settings-users-permissions-01.png)

その人がいま実際にできることの一覧です。役割をいくつも持っていても **1 つの許可につき 1 行**にまとめ、その許可でできること（アクション）と、届く**いちばん広い範囲**を並べて出します。

表の読みかたは次のとおりです。

- 「**権限コード**」… どのアプリの話かを表します（`quote` は見積書、`master` はマスタ、`system` はシステム管理、など）。
- 「**アクション**」… 何をしてよいかです。1 つの許可で複数できる場合は、その分だけ並びます。**閲覧**（見るだけ）・**作成**・**更新**（直す）・**削除**・**書き出し**・**管理**（管理者としての操作）があります。なお、書類を**承認できるかどうか**はここでは決まりません。承認できる人は、[承認設定](/manual/ja/operations/masters/approval-setting/user)（MS0B）の承認グループで決まります。
- 「**スコープ**」… その許可がどこまで届くかです。**全社**（会社全体）・**拠点**（自分の拠点だけ）・**地域**（自分の地域だけ）・**自分の担当**（自分が担当するデータだけ）などがあります。拠点・地域の場合は、対象がかっこ書きで続きます。

何も無いときは「**権限がありません**」と表示されます。

## ロールを変える

その人の役割（ロール）を付けたり外したりします。**ロールを変えると、その人にできることがそのまま変わります**。

「**ユーザー管理の変更**」の権限を持っている人にだけ、「**ロール割当**」の右上に「**編集**」ボタンが出ます。

1. 変えたい人の詳細画面を開きます。
2. 「**ロール割当**」の「**編集**」を押します。
3. 選択欄をクリックして、一覧からロールを選びます。複数選べます。
4. 外したいロールは、もう一度クリックして選択を外します。
5. 「**保存**」（承認が要る場合は「**承認を依頼**」）を押します。

システム管理者はその場で変更が反映されます。**それ以外の方は、そのままは変わりません** — 「**変更の理由**」を書いて申請すると[特権アクセス](/manual/ja/operations/system/privileged-access/user)（SY0G）に承認依頼が出て、**別の人が承認した時点で変更が反映されます**。自分で申請して自分で承認することはできません。

> ⚠️ ロールをすべて外すと、その人は何も操作できなくなります。外す前に、その人が使っている画面を確認してください。

> ⚠️ 管理者が 1 人しか居ないときに、その人から管理者のロールを外すことはできません。誰も管理者に戻せなくなるためです。「**最後の管理者から管理者ロールを外すことはできません**」と表示されます。

> 💡 自分のロールは自分では変えられません。他の方にご依頼ください。

外したロールは記録として残ります。表の「**解除日時**」に日付が入り、いつ外れたのかが後から読めます。

## 所属拠点を変える

「**ユーザー管理の変更**」の権限を持っている人にだけ、「**所属拠点**」の右上に「**編集**」ボタンが出ます。

1. 変えたい人の詳細画面を開きます。
2. 「**所属拠点**」の「**編集**」を押します。
3. 一覧から拠点を選びます。複数選べます。
4. 外したい拠点は、もう一度クリックして選択を外します。
5. 「**保存**」（承認が要る場合は「**承認を依頼**」）を押します。

「**保存しました**」「**所属拠点を更新しました**」と表示されれば完了です。ロールと同じく、システム管理者以外は理由を書いて申請し、承認された時点で変更が反映されます。

> ⚠️ 所属拠点を外すと、その人が見られるデータが減ります。「自分の拠点のぶんだけ」という決まりの画面が、空になることがあります。

> 💡 選択欄に「（無効）」と付いた拠点が出ることがあります。すでに使われなくなった拠点ですが、この人には割り当てられたままなので表示されています。

## 入力項目

ユーザーの名前やメールは **Active Directory から取り込まれる**ため、この画面では変えられません。ここで入力するのはロールと所属拠点だけです。

| 項目 | 必須 | 何を入れるか |
|------|------|-------------|
| [ロール](#field-roles) | 任意 | そのユーザーに与える役割 |
| [所属拠点](#field-plants) | 任意 | そのユーザーが扱える拠点 |

### ロール [#field-roles]

そのユーザーに与える役割です。複数選べます。

**その人にできることは、選んだロールすべてを合わせたもの**になります。結果は同じ画面の「実効権限」で確認できます。ロールをすべて外すと、その人は何も操作できません。

編集できるのは「ユーザー管理の変更」の権限を持つ人だけで、システム管理者以外は承認が要ります。自分のロールは変えられません。

### 所属拠点 [#field-plants]

そのユーザーが担当する拠点です。複数選べます。

権限の「拠点」範囲は、**ここで選んだ拠点との重なりで決まります**。たとえば「拠点内のみ閲覧できる」権限を持つ人は、ここに入っている拠点のデータだけが見えます。ここが空だと、拠点範囲の権限は何も見えない状態になります。

編集できるのは「ユーザー管理の変更」の権限を持つ人だけで、システム管理者以外は承認が要ります。権限が無い人には、現在の所属がバッジで表示されます。

## よくある質問・困ったとき

**Q. 新しく入った人を追加したいのですが、追加ボタンがありません。**
A. このアプリからは人を追加できません。人の情報は社内の共通ログインのしくみから取り込まれます。システム管理者にご依頼ください。

**Q. ある人の役割（ロール）を変えたいです。**
A. 詳細画面の「**ロール割当**」で「**編集**」を押してください（「[ロールを変える](#ロールを変える)」）。ボタンが出ないときは権限がありません。システム管理者にご依頼ください。

**Q. ロールを保存したのに、その人の権限が変わっていません。**
A. システム管理者以外の変更は、**承認されるまで反映されません**。[特権アクセス](/manual/ja/operations/system/privileged-access/user)（SY0G）で、出した依頼がまだ承認依頼中でないかを確認してください。

**Q. 「編集」ボタンが出ません。**
A. ロールと所属拠点を変えるには「ユーザー管理の変更」の権限が要ります。それ以外の方は表示のみになります。システム管理者にご依頼ください。

**Q. ロールを付けてもらったのに、その人が画面を開けないと言っています。**
A. その人の詳細画面で「**実効権限**」に該当の行があるかを見てください。行はあるのにデータが空、という場合は「**所属拠点**」が空でないかも確認してください。

**Q. 役割を 2 つ持っている人の「実効権限」に、同じ権限コードが 1 行しか出ていません。**
A. 正常です。同じ許可は**アクションが違っても 1 行**にまとめます。範囲が全部同じならまとめて 1 つ、アクションによって違うときだけアクションごとに書き分けます。両方の役割から同じ許可が来ているときは、**広いほうの範囲**で出します（片方が「自分の担当だけ」、もう片方が「全社」なら「全社」）。

**Q. 誰がいつこの人のロールや所属拠点を変えたのか知りたいです。**
A. [操作履歴](/manual/ja/operations/system/activity-log/user)で確認できます。変更はすべて記録されています。

## 必要な権限

この画面を使うには **ユーザー・権限の変更**（`user_admin`）の権限が要ります。

| したいこと | 必要な権限 |
| --- | --- |
| 画面を開く・一覧や詳細を見る | ユーザー・権限の変更 の 閲覧 |
| 追加・変更・削除する | ユーザー・権限の変更 の 作成 / 更新 / 削除 |

見るだけなら「閲覧」で足ります。追加・変更・削除の操作がある画面では、その操作にあたる権限がそれぞれ必要です。

権限は役割（ロール）を通して付きます。足りないときは管理者に相談してください。

権限の全体像は「[権限とロール](../../../permissions)」を参照してください。
