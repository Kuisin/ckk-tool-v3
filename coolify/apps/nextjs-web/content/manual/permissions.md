アプリごとに「使うために必要な権限」が決まっています。各アプリのマニュアルの末尾にも「必要な権限」を載せているので、まずはそちらを見てください。このページは全体像です。

## 権限は 3 つの組み合わせで決まります

「見積書を、自分の担当ぶんだけ、見られる」のように、3 つが揃って 1 つの権限になります。

| | 意味 | 例 |
| --- | --- | --- |
| 権限 | 何についての権限か | 見積書 |
| アクション | その中で何ができるか | 閲覧 / 作成 / 更新 |
| 範囲 | どこまでが対象か | 全社 / 拠点 / 自分の担当 |

### アクション

| アクション | 意味 |
| --- | --- |
| 閲覧 | 一覧や詳細を見る |
| 作成 | 新しく作る |
| 更新 | 内容を変える |
| 削除 | 消す |
| 書き出し | CSV などに書き出す |

### 範囲（スコープ）

同じ「閲覧」でも、範囲によって見える件数が変わります。拠点で絞られている場合、自分が所属する拠点のデータだけが出ます。

| 範囲 | 意味 |
| --- | --- |
| 全社 | 会社全体。拠点による絞り込みはありません |
| 地域 | 自分の所属拠点がある地域の、すべての拠点 |
| 拠点 | 自分が所属している拠点だけ |
| 自分の担当 | 自分が作った / 自分が担当のものだけ |

## 承認できるかどうかは、権限では決まりません

書類を承認できる人は、**承認設定（MS0B）の承認グループに入っているかどうか**で決まります。権限の側で必要なのは、その書類を見られる（閲覧）か直せる（更新）ことだけです。

承認する人を増やしたいときは、権限ではなく承認グループのメンバーを見てください。

## 特権操作 — 権限だけでは行えないもの

端末の PIN を見る、QR カードを発行する、ログイン履歴の中身を開く——こうした操作は、権限を持っていても**そのままでは行えません**。特権アクセス（`SY0G`）で理由を書いて申請し、別の人の承認を受けた期間だけ行えます。

持ち時間は承認された時点ではなく、**最初にその操作をした時点から**減りはじめます。詳しくは「[特権アクセス](operations/system/privileged-access/user)」を参照してください。

## 権限の一覧

### 業務

| 権限 | コード | できること |
| --- | --- | --- |
| 価格表 | `price_list` | 試算と価格表を扱えます。顧客ごとの単価を決める権限です。 |
| 見積書 | `quote` | 見積書を扱えます。 |
| 注文請書・注文明細 | `order_acceptance` | 注文請書と、その明細（注文明細）を扱えます。 |
| 設計依頼 | `design_request` | 設計依頼書を扱えます。 |
| 素材発注・購買依頼 | `purchase_order` | 購買依頼と素材発注書を扱えます。 |
| 素材入荷 | `material_receipt` | 素材の入荷を記録できます。 |
| 外注依頼 | `outsource_order` | 外注依頼を扱えます。 |
| 指示書 | `work_order` | 指示書と工程の実行を扱えます。現場のタブレット（キオスク）の工程実行もこの権限です。 |
| 在庫 | `inventory` | 製品・素材・仕掛の在庫を見て、移動や調整ができます。 |
| 出荷書 | `delivery_order` | 出荷書を扱えます。 |
| 納品書 | `delivery_note` | 納品書を扱えます。 |
| 請求書 | `invoice` | 請求書を扱えます。 |
| 締日処理 | `billing_closing` | 締日処理と、会計へ渡す書き出しができます。 |
| 承認管理 | `approve` | 承認待ちの一覧（承認・予定）を見られます。**押せるかどうかは別** — 承認できる人は承認設定 (MS0B) の承認グループ所属が決めます。 |
| フォーム | `form` | フォームの作成・編集と、全回答の閲覧ができます。誰が回答できるかはフォームごとの共有設定が決めます。 |
| 社内文書 | `internal_page` | 社内文書アプリを使えます。個々の文書が見えるかは文書ごとの共有設定が決めます。 |

### マスタ・設定

| 権限 | コード | できること |
| --- | --- | --- |
| マスタ管理 | `master` | 取引先・製品・材種・素材・工程・検査表・承認設定・拠点などのマスタを扱えます。 |
| 管理マニュアル | `admin_manual` | 端末セットアップなど、管理者向けの手順書を読めます（公開マニュアルとは別の権限です）。 |

### 管理

| 権限 | コード | できること |
| --- | --- | --- |
| システム管理 | `system` | アプリ設定・試算計算・リンク管理・注文書取込・AI プロバイダ・通知メールなど、システム側の設定を扱えます。 |
| キオスク管理 | `kiosk` | 共有端末の一覧・詳細を見て、名称や設置場所を直せます。**秘密の開示や端末の登録・失効は別の権限**（下の特権操作）です。 |

### 特権操作（申請と承認が要る）

| 権限 | コード | できること |
| --- | --- | --- |
| キオスク端末の秘密 | `kiosk_secret` | メンテナンス退出 PIN・PIN 履歴・端末設定コードの開示と再生成、端末鍵のリセット。 |
| 端末アクセスの付与 | `kiosk_device` | 端末プロファイルの作成・リンク・有効化・停止・失効。端末を入れることはアクセスを与えることです。 |
| QRカードの発行・PIN | `kiosk_card` | QRカードの一覧を見られます。発行・割当・失効・PIN のリセット・台紙の印刷は承認が要ります。 |
| 個人データの閲覧 | `personal_data` | ログイン履歴と操作履歴を開けます。詳細（IP・端末シグネチャ）と横断検索は承認が要ります。書類ごとの履歴タブはこの権限では制限しません。 |
| ユーザー・権限の変更 | `user_admin` | ユーザー管理を開けます。利用停止・復帰・所属拠点の変更は、1 件ずつ変更依頼を出して承認を受けます。 |
