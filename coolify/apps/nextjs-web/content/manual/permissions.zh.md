「能否登录」与「能否操作」是分开决定的。本页说明其中的机制。各应用手册的末尾都有「所需权限」一节，若只想了解眼前的画面，看那里更快。

## 认证与授权 — 两个阶段

系统分两个阶段。

1. **认证** … 确认你是谁的阶段，也就是登录。通过之后，系统便知道是谁在使用。
2. **授权** … 决定允许这个人做什么的阶段，这里用到的就是**权限**。

已经登录却打不开画面，正是因为两者是分开的：认证通过了，但授权不足。

| 从哪里使用 | 如何确认本人 | 步骤 |
| --- | --- | --- |
| 电脑（Web） | 公司账号登录，或用户名与密码 | [开始使用](start) |
| 车间共享平板 | 二维码卡与 PIN | [自助终端入门](operations/kiosk/start/user) |

## 授权 — 权限由三者组合而成

如「只能查看本人负责的报价单」，三个部分合起来构成一项权限。

| | 含义 | 例 |
| --- | --- | --- |
| 权限 | 针对什么的权限 | 报价单 |
| 动作 | 在其中可以做什么 | 查看 / 创建 / 更新 |
| 范围 | 涉及到哪里 | 全公司 / 基地 / 本人负责的记录 |

### 动作

| 动作 | 含义 |
| --- | --- |
| 查看 | 查看列表与明细 |
| 创建 | 新建记录 |
| 更新 | 修改内容 |
| 删除 | 删除 |
| 导出 | 导出为 CSV 等 |

### 范围

同样是「查看」，范围不同可见的条数也不同。若限定为基地，则只显示本人所属基地的数据。

| 范围 | 含义 |
| --- | --- |
| 全公司 | 全公司，不按基地过滤 |
| 地区 | 本人所属基地所在地区的全部基地 |
| 基地 | 仅本人所属的基地 |
| 本人负责的记录 | 仅本人创建或负责的记录 |

## 能否审批不由权限决定

谁可以审批单据由**审批设置（MS0B）**决定，而非权限。其机制与设置方法请参见「[审批设置](operations/masters/approval-setting/user)」。

## 特权操作 — 仅有权限还不够

查看终端 PIN、发放二维码卡、打开登录记录的明细——即使拥有权限也**不能直接执行**。需在特权访问（`SY0G`）中写明理由提出申请，并只在他人批准的时间段内执行。

时间不是从批准时开始，而是从**第一次执行该操作时**开始减少。详见「[特权访问](operations/system/privileged-access/user)」。

## 权限的种类

权限按性质分为四类。想确认自己持有哪些，请打开「[我的权限](/profile/permissions)」。

**业务** — 日常工作使用的权限，按所处理的单据划分——报价单、订单确认书、作业指示书、出货单。大多数人只持有这一类。

**主数据与设置** — 整理全员共用的「基础数据」的权限。修改客户或产品会影响此后创建的所有单据，因此通常只由少数人持有。

**管理** — 更改系统本身设置的权限，涉及画面行为与外部对接等机制层面，而非业务数据。

**特权操作（需申请与批准）** — 仅持有还不能执行的权限。终端 PIN、卡片发放、个人数据查看等影响大且难以回退的操作属于此类。每次使用都需申请，并只在他人批准的时间段内执行。

## 权限一览

### 业务

| 权限 | 代码 | 可以做什么 |
| --- | --- | --- |
| 价格表 | `price_list` | 处理试算与价格表，即各客户的单价。 |
| 报价单 | `quote` | 处理报价单。 |
| 订单确认书・订单明细 | `order_acceptance` | 处理订单确认书及其明细。 |
| 设计委托 | `design_request` | 处理设计委托单。 |
| 材料订购・采购申请 | `purchase_order` | 处理采购申请与材料订购单。 |
| 材料入库 | `material_receipt` | 登记材料入库。 |
| 外协委托 | `outsource_order` | 处理外协委托。 |
| 作业指示书 | `work_order` | 处理作业指示书与工序执行，包括车间平板（自助终端）。 |
| 库存 | `inventory` | 查看产品・材料・在制品库存，并进行移动或调整。 |
| 出货单 | `delivery_order` | 处理出货单。 |
| 送货单 | `delivery_note` | 处理送货单。 |
| 请款单 | `invoice` | 处理请款单。 |
| 结账处理 | `billing_closing` | 执行结账处理并导出至会计。 |
| 审批管理 | `approve` | 查看待审批列表。能否实际审批由审批设置（MS0B）决定，而非此权限。 |
| 表单 | `form` | 创建、编辑表单并查看全部回答。谁可以回答由各表单的共享设置决定。 |
| 内部文档 | `internal_page` | 使用内部文档应用。各文档是否可见由该文档的共享设置决定。 |

### 主数据与设置

| 权限 | 代码 | 可以做什么 |
| --- | --- | --- |
| 主数据管理 | `master` | 处理主数据：客户、产品、材种、材料、工序、检验表、审批设置、基地等。 |
| 管理手册 | `admin_manual` | 阅读面向管理员的操作手册，如终端设置（与公开手册是不同的权限）。 |

### 管理

| 权限 | 代码 | 可以做什么 |
| --- | --- | --- |
| 系统管理 | `system` | 更改系统侧设置：应用管理、试算计算、链接管理、订单导入、AI 提供方、通知邮件。 |
| 自助终端管理 | `kiosk` | 查看共享终端并修改名称与位置。**查看机密、注册或注销终端属于另外的权限**（见特权操作）。 |

### 特权操作（需申请与批准）

| 权限 | 代码 | 可以做什么 |
| --- | --- | --- |
| 自助终端机密 | `kiosk_secret` | 查看维护退出 PIN、PIN 历史与终端设置码，重新生成设置码并重置终端密钥。 |
| 终端访问授予 | `kiosk_device` | 创建、绑定、启用、停用与注销终端配置。加入终端即等于授予访问权限。 |
| 二维码卡发放・PIN | `kiosk_card` | 查看卡片列表。发放、分配、注销、重置 PIN 与打印卡纸需要批准。 |
| 个人数据查看 | `personal_data` | 打开登录历史与操作历史。明细（IP、终端签名）与跨单据检索需要批准。各单据的历史页签不受此限制。 |
| 用户・权限变更 | `user_admin` | 打开用户管理。停用、恢复与变更所属基地需逐项提交变更申请并获批准。 |
