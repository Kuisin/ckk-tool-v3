本页整理了从确定单价到接单、再交给制造为止的流程。在这里确认「现在处于哪个阶段、接下来该谁做什么」，以及价格差异・退回等**分支**、各**单据状态**。基本操作步骤由[标准流程](/manual/zh/process/default-flow)负责。

## 整体流程

![销售流程整体图（含价格差异循环・审批退回的泳道图）](../assets/diagrams/process-sales.svg)

对于没有图纸的产品，需要**与本流程并行**起草**设计委托单**。既可以在报价阶段、也可以在接单之后起草，也可以不关联任何单据**单独**起草。

## 各阶段的负责人与应用

| 阶段 | 做什么 | 负责人 | 使用的应用 |
|------|--------|--------|------------|
| 1. 计算单价 | 根据材料费、加工费计算该产品的报价单价 | 内部销售 | [价格试算](/manual/zh/operations/sales/trial-estimate/user)（`SA01`） |
| 2. 按客户确定价格 | 按客户与产品的组合制作价格表。数量越多越便宜的设定也在这里确定 | 内部销售 | [价格表](/manual/zh/operations/sales/price-list/user)（`SA02`） |
| 3. 出具报价单 | 按价格表的单价制作报价单，将 PDF 提交给客户 | 内部销售 | [报价单](/manual/zh/operations/sales/quote/user)（`SA03`） |
| 4. 接收订单 | 导入客户发来的订单文件，确认内容并获得审批 | 内部销售助理 | [订单确认书](/manual/zh/operations/sales/order-acceptance/user)（`SA04`） |
| 5. 确定接单 | 确定已批准的订单确认书，按明细生成订单明细 | 内部销售助理 | 订单明细（`SA05`） |
| 6. 下达制造指示 | 分为库存分与制造分制作工单 | 内部销售助理 | [工单](/manual/zh/operations/production/work-order/user)（`PD02`） |
| （并行）没有图纸时 | 起草设计委托单，经审批后由制造制作图纸 | 内部销售 / 内部销售助理 → 制造 | [设计委托单](/manual/zh/operations/sales/design-request/user)（`SA06`） |

## 各阶段发生的事

### 1. 计算单价（价格试算）

计算出的价格试算以「下書き」（草稿）保存，内容确定后设为「確定」（确定）。**只有已确定的价格试算才能用作价格表单价的基础。** 已在价格表中使用过的价格试算会变为「価格表登録済」（已登记价格表），无法直接编辑 —— 要重做时需要复制（操作步骤……[标准流程 §1](/manual/zh/process/default-flow#stage-1)）。

![草稿价格试算的操作菜单。确定以红框强调](../assets/screenshots/flow-trial-estimate-01.png)

### 2. 按客户确定价格（价格表）

按客户与产品的组合制作 1 张价格表。可以按订单类别（正式・测试・样品・其他）分别设定价格，也可以按数量区间改变单价（操作步骤……[标准流程 §2](/manual/zh/process/default-flow#stage-2)）。

![价格表新建画面。保存按钮以红框强调](../assets/screenshots/flow-price-list-01.png)

### 3. 出具报价单（报价单）

选择客户与产品后，会自动从价格表带入单价。**不在价格表中的产品无法带入单价，会显示警告** —— 此时需要先制作价格试算和价格表。发行后会保存 PDF，变为可以提交给客户的状态（操作步骤……[标准流程 §3](/manual/zh/process/default-flow#stage-3)）。

![报价单发行弹窗。发行按钮以红框强调](../assets/screenshots/flow-quote-issue-01.png)

### 4. 接收订单（订单确认书）

导入客户发来的订单文件（传真・PDF）后会自动进行识别。在画面上确认并修正识别结果。配送方式（常规配送・直送最终用户）与最终用户也在这里确定 —— **若是直送最终用户但最终用户未指定，则既无法申请审批也无法确定**（操作步骤……[标准流程 §4](/manual/zh/process/default-flow#stage-4)）。这里确定的配送方式还会**决定下游送货单的生成方式** —— 直送最终用户的出货单，确定时会自动生成不记载价格（寄给最终用户）与记载价格（寄给客户）的 2 份送货单（[出货流程](/manual/zh/process/shipping)）。若客户会自备送货单（例如印有条码），在这里附上「顧客提供の納品書」（客户自备送货单），就能让准备出货的负责人知悉。

**价格差异分支** —— 明细的单价会**自动从价格表带入**，无法直接编辑。若客户订单文件上写的是别的单价等原因，需要以不同的单价接单时，在该行填入「**単価を上書き**」（单价上覆）自行决定 —— 这是有意为之的单价，因此不算价格差异，也不会卡住审批申请（审批人画面会显示为「单价上覆 N 处」）。

剩下的**价格差异**只是「未上覆却与价格表不一致」的行，多出现在保存后价格表发生变化等情况。需要先在「回到报价单调整价格 / 修改价格表 / 作为上覆接受」三者中选择一项，才能继续（带着差异申请审批需要一次确认）。

![显示价格差异的订单确认书详情画面。差异显示以红框强调](../assets/screenshots/flow-order-acceptance-diff-01.png)

**审批分支** —— 内容确定后申请审批。申请中无法编辑。若被退回，需要修改内容后重新申请。要经过几级审批，由[审批设置](/manual/zh/operations/masters/approval-setting/user)的条件规则决定，级数的构成可能因单据内容（合计金额・配送方式・负责据点等）而变化。

![审批中的订单确认书。批准操作以红框强调](../assets/screenshots/flow-order-acceptance-01.png)

### 5～6. 确定接单与下达制造指示（订单明细・工单）

确定订单确认书后，会按明细生成**订单明细**。接着，针对该订单明细制作**工单**。库存分・制造分的划分方式与库存分的固定构成，请参见[生产流程](/manual/zh/process/production)。从已确定的订单确认书，也可以直接进入**制作出货单**（操作步骤……[标准流程 §5](/manual/zh/process/default-flow#stage-5)・[§6](/manual/zh/process/default-flow#stage-6)）。

![确定确认弹窗。展开按钮以红框强调](../assets/screenshots/flow-order-deploy-01.png)

![由订单明细制作的工单新建画面。保存按钮以红框强调](../assets/screenshots/flow-work-order-new-01.png)

### （并行）设计委托

对于没有图纸的产品，会在报价阶段、接单之后其中之一，或不关联任何单据**单独**起草设计委托单。**只有通过审批才能开工**（级数的构成由[审批设置](/manual/zh/operations/masters/approval-setting/user)决定，可按触发方式・委托区分・优先级而变化）。由制造制作图纸，完成后会替换产品的最新图纸（操作步骤……[标准流程（并行）设计委托](/manual/zh/process/default-flow#design-request)）。

产品已有图纸时会自动判定为**修订**，没有则判定为**新规**（新增），修订时需要填写变更理由。

**图纸本身由[图纸](/manual/zh/operations/production/design-file/user)（PD06）负责。** 委托是「请做这个」的起草，做好的图纸会作为版本登记到图纸中（预览用・图纸数据・参考资料汇总为 1 个版本）。版本按「产品 × 订货客户」分别计数。委托要等成果物登记 1 件以上后才能完成。

![尚未开工的设计委托。开工按钮以红框强调](../assets/screenshots/flow-design-request-01.png)

## 单据状态

| 单据 | 状态变化 |
|------|----------|
| 价格试算 | 草稿 → 确定 → 已登记价格表 |
| 报价单 | 草稿 → 已发行（超过有效期限后自动显示为「已过期」；是否已接单由是否存在订单确认书判断） |
| 订单确认书 | 导入中 → 草稿 → 审批中 → 已批准 → 已确定 → 已归档 / 已取消（取消需经申请 → 审批） |
| 订单明细 | 草稿 → 确定 → 生产中 → 部分出货 → 已出货（只能通过按订单确认书发起的申请取消） |
| 工单 | 草稿 → 审批中 → 已批准 → 进行中 → 已完成 |
| 设计委托单 | 草稿 → 审批中 → 未开工 → 进行中 → 已完成（审批不通过则退回；完成前可以取消） |

## 容易卡住的地方

**报价单无法带入单价**
价格表中没有该客户・产品的行。按「价格试算 → 价格表」的顺序制作后，再重新制作报价单。

**想修改价格试算却无法编辑**
在价格表中使用过的价格试算会变为「価格表登録済」（已登记价格表），无法编辑。请复制后作为新的价格试算重做。这是为了防止过去报价单的金额事后被改动而设计的机制。

**订单的价格与报价单不一致**
在订单确认书画面能看到差异。回到报价单调整价格后，再修改订单确认书的内容。

**订单确认书无法继续推进**
确认审批申请是否已完成，或审批人是否已完成审批。配送方式为直送最终用户却未指定最终用户时，也无法申请审批・无法确定 —— 请先指定最终用户再继续。批准后即可进入订单明细・工单。

**设计委托的「申请审批」无法通过**
[审批设置](/manual/zh/operations/masters/approval-setting/user)中一个「设计委托单」的审批级都没有登记。请先登记级数再发起申请。

**无法完成设计委托**
该委托的图纸还没有登记到[图纸](/manual/zh/operations/production/design-file/user)。请从委托画面上的「設計図に登録」（登记到图纸）进行登记（产品・订货客户会带入委托的信息）。
