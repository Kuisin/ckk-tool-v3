操作コード **DC01**。この「マニュアル」アプリ自体の使い方を説明します。全ユーザーが利用できます（権限は不要です）。

## このアプリでできること

システム内のすべてのアプリの操作マニュアルを、アプリを離れずに読めます。マニュアルは **日本語・English・中文** の 3 言語で用意されています。

- 左のサイドバーは **操作方法**（画面ごとの操作手順と入力欄の意味。カテゴリ別）と **プロセス**（業務の流れと、その段階で使うアプリ）の 2 つに分かれています。
- 初めての方は [スタートマニュアル](/manual/ja/start) から読み始めてください。

## 開き方

- ホームまたはランチャーの **マニュアル**、または検索で `DC01`（右上の検索ボックスはパソコンのみ。スマートフォンではランチャーの中の検索を使います）。
- 入力欄の横に「?」が付いている場合は、そこから説明を読めます。「もっと読む」を押すと、その項目の詳しい説明までまっすぐ開きます。

## 言語の切り替え

- サイドバー上部（モバイルではページ上部のバー）の **日本語 / English / 中文** をクリックすると、表示言語が切り替わります。
- 言語はページ間を移動しても保持されます。マニュアル内のリンクも同じ言語のページへつながります。

## 検索

- サイドバーの **検索** ボタン、またはキーボードの **⌘K**（Windows は Ctrl+K）で検索ウィンドウが開きます。
- キーワードを入力すると、全マニュアルの本文から一致する箇所を探します。結果をクリックするとそのページへ移動します。
- 検索は現在の表示言語のマニュアルが対象です。

## 画像を拡大する

- 本文の画面写真を押すと、画面いっぱいに開きます。
- マウスのホイール・指でのピンチ・ダブルクリックで拡大でき、ドラッグで動かせます。画像の右上の「拡大」「縮小」「元のサイズに戻す」のボタンも使えます。
- 閉じるときは右上の × か、キーボードの Esc を押します。

## 動画で見る

- 一部のページ（プロセスの流れなど）には、実際の操作を録画した動画があります。動画の下に「**手順**」の一覧が出ていて、押すとその場面へ移動します。
- 動画が用意されていない環境では、動画の枠そのものが出ません。写真と文章だけで読めるように書いてあります。

## アプリへ戻る

- サイドバー（モバイルではメニュー）の「**アプリへ戻る**」を押すと、業務アプリのホーム画面へ戻ります。

## よくある質問

- **マニュアルに書いてある画面が見当たらない** … アプリによっては、環境（本番 / 開発）によって公開されていないことがあります。また、権限がないアプリはホームに表示されません。
- **内容が実際の画面と違う** … システムの更新でマニュアルより先に画面が変わることがあります。気づいた点は管理者へ連絡してください。
