操作コード **SY06**。ファイルストレージ（SeaweedFS）に保存されているファイル — アップロードファイルや、システムが生成した帳票 PDF — を **Finder 風のフォルダブラウザ**でたどって表示・ダウンロード・削除・アップロードできるアプリです。

> このアプリを開くのに特別な権限は**不要**です（ログインのみ）。ただし**見える範囲はユーザーごとに異なります**: システム管理者（`system:ADMIN`）は全ファイル、それ以外は **フォルダ権限**（個別付与）で許可されたフォルダと、**業務アプリの閲覧権限**に対応する生成ファイル（例: `quote` の閲覧権限があれば見積書 PDF）だけが表示されます。削除は取り消せないため、操作は慎重に行ってください。

## このアプリでできること

- フォルダ階層をたどってファイルを一覧・プレビューできます（画像・PDF は右ペインでそのまま確認）。
- ファイルごとに **開く**（新しいタブで表示）・**ダウンロード**・**削除** ができます。
- いま開いているフォルダに、ファイルを **アップロード** できます（そのフォルダへの書き込み権限が必要）。
- ファイル名・パスで、**全フォルダを横断して検索**できます。
- システム管理者は **フォルダ権限**（ユーザー × フォルダの閲覧/書き込み）を付与・取消できます。

## 開き方

- ホーム（システム）→ **ファイル管理**、または検索ボックスで `SY06`。

## 画面の見方

- 画面上部の**パンくず**に現在位置が「すべて」から順に並びます。クリックでその階層へ戻れます。
- **名前** … アイコン（PDF は赤、画像は青、その他はグレー）付きのファイル名。フォルダをクリックすると中に入り、ファイルをクリックすると右ペインにプレビューが出ます。
- **サイズ** / **更新日時** … ファイルサイズと最終更新日時。
- システムが自動生成したファイルには「システム」の灰色バッジが付きます。

表示形式は左上の切り替えで 3 種類あります。

- **リスト** … 名前・サイズ・更新日時のテーブル表示（既定）。
- **アイコン** … 大きめのアイコンで並べるグリッド表示。
- **カラム** … 階層を左から右へ並べる Mac の Finder 風カラム表示。

その隣の「**システムファイル**」スイッチは、`.DS_Store` や `*.tmp` など **OS・ツールが自動生成した残骸ファイル**（`lib/system-files.ts` の判定）を表示するかどうかの切り替えです。帳票 PDF などの業務ファイルは「システムファイル」には含まれず、常に表示されます（このトグルは表示上の分類であり、アクセス制御とは無関係です）。

右上の **更新** ボタンで一覧を再読み込みできます。ストレージに接続できない場合は画面上部に赤い警告が表示されます（`SEAWEED_FILER_URL` とコンテナ稼働の確認が必要です）。

## 検索

検索ボックス「ファイル名・パスで検索（全フォルダ横断）」に入力すると、現在のフォルダに関係なく、名前またはパスが一致するファイルが横断的に一覧されます。

## 表示・ダウンロード・削除

ファイルを選ぶと右ペインにプレビュー（画像・PDF）と **パス**・**サイズ**・**更新日時**・**種類** が表示され、次の操作ができます。

- **開く** … ファイルを新しいタブで表示します。
- **ダウンロード** … ファイルをダウンロードします。
- **削除** … 確認ダイアログの上で削除します。**この操作は取り消せません**。書き込み権限のあるファイルにだけ表示されます。

> 帳票 PDF（`pdfs` 配下）は見積書・請求書などの文書から参照されています。削除すると該当文書から PDF が開けなくなる場合があるため、業務データに紐づくファイルの削除は避けてください。

## アップロード

1. 入れたいフォルダを開きます。**アップロード** ボタンは、いま開いているフォルダへの**書き込み権限がある場合のみ**表示されます（管理者は常時）。
2. **アップロード** を押してファイルを選択します。
3. ファイルは**いま開いているフォルダ**に、日時の接頭辞付きのファイル名で保存されます（同名ファイルの上書きを防ぐため。ルートで押した場合は `uploads` 配下）。
4. 完了すると通知が表示され、一覧に反映されます。

## フォルダ権限（システム管理者のみ）

右上の **フォルダ権限** から、ユーザー × フォルダ単位のアクセス権（`app.file_folder_grants`）を管理します。

1. **フォルダ（パス前方一致）** に対象フォルダを入力します。前方一致なので、配下のすべてが対象になります。
2. **ユーザー** を選び、必要なら **書き込みも許可**（アップロード・削除まで可）を入れて **付与** します。
3. 付与済み一覧には「読み書き」/「読み取り」のバッジが付き、行の **削除** で取り消せます。

フォルダ権限が無くても、業務アプリの閲覧権限があれば、そのアプリの生成ファイルは読み取りできます（フォルダ → 権限コードの対応は `lib/file-access.ts` の `APP_PREFIX_PERMISSIONS`。例: `pdfs/quotes` → `quote`、`attachments/work_orders` → `work_order`）。書き込み（アップロード・削除）はフォルダ権限の「書き込みも許可」か管理者だけです。

## よくある質問

- **「ストレージに接続できません」と表示される** … ファイルサーバー（SeaweedFS）が停止しているか、接続設定に問題があります。システム管理者に連絡してください。
- **あるはずのファイルが見えない** … そのフォルダの閲覧権限（フォルダ権限 or 対応する業務アプリの閲覧権限）が無いか、残骸ファイルとして隠れています。後者は「システムファイル」スイッチで表示できます。
- **アップロードボタンが出ない** … いま開いているフォルダへの書き込み権限がありません。システム管理者にフォルダ権限（書き込み許可）を依頼してください。
- **誤って削除してしまった** … この画面からは復元できません。システム管理者にバックアップからの復旧を相談してください。
- ファイルの生成元となる文書の操作は各アプリのマニュアル（例: [見積書](/manual/ja/operations/sales/quote/user)、[請求書](/manual/ja/operations/billing/invoice/user)）を参照してください。
