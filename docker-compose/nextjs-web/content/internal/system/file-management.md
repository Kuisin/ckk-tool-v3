操作コード **SY06**。ファイルストレージ（SeaweedFS）に保存されているファイル — 取り込んだアップロードファイルや、システムが生成した帳票 PDF — を一覧・表示・ダウンロード・削除・アップロードできる管理者向けアプリです。

> このアプリは **システム権限** が必要です（ストレージ操作は管理アクション）。削除は取り消せないため、操作は慎重に行ってください。

## このアプリでできること

- ストレージ上の全ファイルを一覧で確認できます（ファイル名・保存キー・サイズ・更新日時）。
- ファイルごとに **表示**（ブラウザで開く）・**DL**（ダウンロード）・**削除** ができます。
- 任意のファイルを **アップロード** できます。
- ファイル名/パスでの検索と、区分（トップフォルダ）での絞り込みができます。

## 開き方

- ホーム（システム）→ **ファイル管理**、または検索ボックスで `SY06`。

## 一覧の見方

- **ファイル名** … アイコン（PDF は赤、画像は青、その他はグレー）付きのファイル名。下段に保存キー（ストレージ上のフルパス）が等幅で表示されます。
- **区分** … 保存キーの先頭フォルダのバッジ。例: `pdfs`（生成された帳票 PDF）、`uploads`（この画面からのアップロード）。フォルダが無いものは「(ルート)」。
- **サイズ** … ファイルサイズ（B / KB / MB / GB）。
- **更新日時** … 最終更新日時。既定でこの列の新しい順に並びます（1 ページ 20 件）。

右上の **更新** ボタンで一覧を再読み込みできます。ストレージに接続できない場合は画面上部に赤い警告が表示されます（サーバー側の設定・コンテナ稼働の確認が必要です）。

## アップロード

1. 右上の **アップロード** を押してファイルを選択します。
2. ファイルは `uploads` フォルダに、日時の接頭辞付きのファイル名で保存されます（同名ファイルの上書きを防ぐため）。
3. 完了すると通知が表示され、一覧に反映されます。

## 表示・ダウンロード

- **表示** … ファイルを新しいタブで開きます（PDF や画像はそのままプレビューできます）。
- **DL** … ファイルをダウンロードします。

## 削除

各行の **削除** を押すと確認ダイアログが表示されます。**この操作は取り消せません**。

> 帳票 PDF（`pdfs` 配下）は見積書・請求書などの文書から参照されています。削除すると該当文書から PDF が開けなくなる場合があるため、業務データに紐づくファイルの削除は避けてください。

## よくある質問

- **「ストレージに接続できません」と表示される** … ファイルサーバー（SeaweedFS）が停止しているか、接続設定に問題があります。システム管理者に連絡してください。
- **どのファイルが何の帳票か知りたい** … 保存キー（ファイル名の下の等幅表示）にフォルダと生成元が含まれます。区分での絞り込みも活用してください。
- **誤って削除してしまった** … この画面からは復元できません。システム管理者にバックアップからの復旧を相談してください。
- ファイルの生成元となる文書の操作は各アプリのマニュアル（例: [見積書](/manual/ja/apps/quote/user)、[請求書](/manual/ja/apps/invoice/user)）を参照してください。
