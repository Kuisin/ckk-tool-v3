操作代码 **SY08**。用于签发和管理登录工厂现场共享平板（kiosk 终端）所用的 **QR 卡片**。

> 使用此应用需要**kiosk 管理权限**。所有操作都会记录到审计日志中。

## 此应用可以做什么

- **签发** QR 卡片（一次 1〜100 张）
- 将卡片**分配给用户**（每人 1 张）
- 通过打印页**打印卡片**（名片尺寸）
- 卡片的**暂停 / 恢复 / 作废**
- **限期分配**（指定开始日・结束日的临时卡）
- 更改**同时登录上限**（1〜10 台）
- **重置 PIN / 解除 PIN 锁定**

## 卡片状态

- **未割当（未分配）** … 已签发但尚未分配给任何人。
- **割当済（已分配）** … 已分配给用户，可用于登录。
- **一時停止（暂停）** … 暂时禁止登录。可通过「再開」（恢复）还原。
- **取り消し（作废）** … 已彻底停用。**无法撤销**（用于卡片丢失、员工离职等）。

## 从签发到开始使用

1. 点击 **カードを発行**（签发卡片），输入张数（1〜100）。卡片以「未分配」状态创建。
2. 在行菜单中选择 **ユーザーに割当**（分配给用户）。只能选择有效用户，且**每位用户只能持有 1 张卡**。
3. 勾选卡片后点击 **選択したカードを印刷**（打印所选卡片），或使用行菜单中的 **印刷**（打印）。打印页会在新标签页打开：A4 纵向每页排列 10 张（2 列 × 5 行）名片尺寸（91×55mm）的卡片，位置对应 A4 名片专用纸（10 面），可沿四角裁切标记裁切。页面上方印有浅色的 50mm 刻度，用于确认原尺寸。

**请使用该画面的「印刷」（浏览器打印）。** 该页以**长度**声明纸张尺寸 `@page { size: 210mm 297mm }`，这属于「绝对页面盒」—— UA 不得为适配纸张而缩放，因此必定按原尺寸输出（而 `size: A4` 这类关键字是 "scalable"，可被缩小，正是旧实现变小的原因）。打印对话框中只需确认纸张为 A4。

「PDFで保存」（保存为 PDF）用于保存与分发。**一旦变成 PDF，CSS 的绝对尺寸即失效**，查看器的「适合可打印区域」可能使其缩小百分之几（PDF 侧也将页面盒取得略小于 A4 以作对策，但仍取决于查看器）。用名片专用纸打印时请勿经由 PDF。
4. 将打印好的卡片交给本人。在平板上扫描 QR，首次登录时设置 **PIN**（4〜6 位数字）后即可使用。

出于安全考虑，列表中只显示卡片 ID 的**末尾 8 位**。完整 ID 只包含在打印页的 QR 中。

## PIN 的机制

- PIN 由本人在平板上首次登录时自行设置（4〜6 位）。管理员无法查看或设置 PIN 的内容。
- 如果在**同一台终端上 48 小时内**使用过该卡，且距离上次 PIN 验证**不超过 2 周**，则只需扫描 QR 即可登录。否则会要求输入 PIN（在新终端上的首次登录必定要求输入 PIN）。
- PIN **连续输错 5 次**会被**锁定 15 分钟**。此时列表的 PIN 列会显示「ロック中」（锁定中）。
- **PINロック解除**（解除 PIN 锁定） … 只解除锁定，PIN 本身保留。
- **PINリセット**（重置 PIN） … 清除 PIN。用于本人忘记 PIN 的情况；下次登录时重新设置新 PIN。

登录后的会话在**无操作 5 分钟**后自动登出，最长 **8 小时**。

## 有效期与同时登录上限

- **有效期** … 可以为卡片设置**开始日・结束日**（临时卡。也可只指定一侧，两侧都取消则恢复为无限期）。开始日从当天 0:00 起、结束日到当天 23:59 为止有效。有效期外的卡片在 kiosk 上**无法登录**（判定只在登录时进行 — 既有会话会按 8 小时硬性期限 / 5 分钟空闲自然失效）。列表中会显示有效期，期外的卡片会带「**期限切れ**」（已过期，红色）/「**開始前**」（未开始，黄色）徽章。
- **同时登录上限** … 一张卡可同时登录的终端数（默认 1，可在 **1〜10** 之间更改）。登录超过上限时，**最后活动最早的会话最先失效**（= 最旧的终端被登出）。调低上限不会立即切断既有会话，会在下次登录时生效。

## 暂停与作废

- **一時停止**（暂停） … 禁止使用该卡登录。可通过「再開」（恢复）还原。
- **取り消し**（作废） … 彻底停用该卡。**无法撤销**。执行后，该卡当前打开的 kiosk 会话也会立即失效。

若要更换持卡人，请先**作废**现有卡片，再分配一张新卡（或未分配的卡）。已分配的卡片不能直接转给其他用户。

## 列表与搜索

- 可按卡片 ID、用户名搜索，并按状态筛选。
- 列：卡片ID / 分配用户 / 状态 / PIN（已设置・未设置、锁定中） / 最后使用 / 使用次数。
