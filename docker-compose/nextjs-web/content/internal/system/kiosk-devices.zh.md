操作代码 **SY09**。用于注册和管理工厂现场的共享平板（kiosk 终端）：链接、启用、楼层平面图布置以及使用记录的查看。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

> 使用此应用需要**kiosk 管理权限**。所有操作都会记录到审计日志中。

## 此应用可以做什么

- 创建终端档案，并对平板进行**链接**和**启用**
- 编辑终端信息（名称・工厂・位置），停用 / 重新启用、解除链接、作废
- 在**楼层平面图**上放置终端图钉，并实时显示在线状态
- 查看使用记录（登录 / 登出、上线 / 离线）

## 终端状态

- **リンク待ち（待链接）** … 仅创建了档案，尚未链接平板。
- **有効化待ち（待启用）** … 已与平板链接，等待启用。
- **有効（有效）** … 可作为 kiosk 使用。
- **無効（停用）** … 暂时停止。可通过「再有効化」（重新启用）还原。
- **取り消し（作废）** … 已彻底停用。**无法撤销**。

## 注册终端（链接 → 启用）

注册采用「档案先行」方式。平板本体的准备（安装专用应用等）请参见 [Kiosk 终端设置](/internal-docs/zh/system/kiosk-device-setup)。

1. 点击 **端末プロファイル作成**（创建终端档案），输入终端名称、工厂和位置（可选）。状态变为「待链接」。
2. 平板的设置界面会显示 **12 位链接码**（附 QR，**10 分钟内有效**）。
3. 在列表的行菜单中选择 **端末をリンク**（链接终端），输入该码，或**用摄像头扫描 QR**（任何浏览器均可扫描，包括手机）。成功后状态变为「待启用」。
4. 点击 **有効化**（启用）。状态变为「有效」，平板会自动检测并切换到登录界面。

如果链接码过期，请在平板侧重新显示后再试。只有「待链接」状态的档案才能链接。

## 列表说明

- **在线** … 用绿 / 灰圆点显示有效终端的连接状态。通常通过 WebSocket 实时更新；无法连接时回退为每 30 秒自动刷新，或根据最近 5 分钟内的活动判定。
- **利用者（使用者）** … 当前在该终端上登录的用户。
- 终端名称下方带 🔑 显示的是终端应用的**认证密钥**（指纹）。
- 点击行可打开**终端详情**页，查看最近的使用者和使用记录。行菜单中的 **利用履歴**（使用记录）也可打开同样的记录。

## 编辑与终端设置码

- 通过**編集**（编辑）可修改终端名称、工厂和位置。**更改工厂时，楼层平面图上的图钉会被解除**（平面图按工厂划分）。
- **终端设置码**（6 位）和**维护 PIN**（所有设备通用，每天 4:00 自动更新）在**设备详情页的「PIN・設定コード」**中查看。查看前需确认，**查看操作会记录到审计日志**（60 秒后自动隐藏）。设置码也可在同一位置**重新生成**。

## 更换与停止终端

- **リンク解除**（解除链接） … 将平板从档案中分离，状态回到「待链接」。名称、工厂、位置和平面图图钉保留；会话、设备令牌和认证密钥被销毁。用于更换或维修终端，然后将新平板重新链接到同一档案。
- **鍵リセット**（密钥重置） … 只清除认证密钥。该终端的应用下次连接时会绑定新密钥（用于终端被初始化等情况）。
- **無効化 / 再有効化**（停用 / 重新启用） … 暂时停止 / 恢复使用。停用期间不能作为 kiosk 使用。
- **取り消し**（作废） … 彻底停用终端。**无法撤销**。设备令牌被销毁，打开中的会话失效；若要再次使用，需要通过新档案重新注册。
- **削除**（删除） … 只有从未链接过（「待链接」）的档案可以删除。

## GPS 位置

设备每 **5 分钟**自动上报一次 GPS 位置并保存为历史记录（保留 90 天）。设备详情页的「GPS 位置（最新）」显示最新坐标，可通过链接在 Google 地图中打开。显示「未取得」时，说明平板未授予位置权限或无法获取 GPS 信号。专用应用（v0.5.0 及以上）首次使用时会弹出位置权限对话框。

## 楼层平面图

通过列表右上角的 **フロアマップ**（楼层平面图）打开。选择工厂后，各楼层（楼 / 区域）标签页会显示对应平面图和终端图钉。图钉颜色与在线状态联动，并显示登录中的用户名。

在编辑模式（开关）下可以：

- **拖拽**图钉移动位置（位置自动保存）。
- 点击侧栏中未布置的终端，将其放置到中央，再拖拽调整。
- 通过已布置终端的**解除**（取消布置）移除图钉。
- **添加、重命名、删除**楼层（已布置终端的楼层无法删除）。
- 上传或替换**平面图图片**（PNG / JPG / WEBP / SVG，最大 10MB）。
