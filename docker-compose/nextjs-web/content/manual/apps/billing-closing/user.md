操作コード **BL02**。顧客ごとの締日で未請求の出荷を集計し、請求書を生成する月次の処理です。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

月に一度の「締め」を行うアプリです。対象月の未請求出荷（**出荷済み × 発送** の[出荷書](/manual/ja/apps/shipping-order/user)）を顧客ごとに集計して締めの行を作り、そこから[請求書](/manual/ja/apps/invoice/user)（下書き）を生成します。

- 種別が「在庫保管」の出荷は請求フロー外のため、集計に含まれません。
- 既に請求書の明細になっている出荷は「未請求」から外れるので、二重請求にはなりません。
- 操作には締日処理の権限（billing_closing）が必要です。

## 締日の決まり方

- 顧客ごとの締日は[顧客](/manual/ja/masters/customer/user)マスタの **締日** 設定から決まります（未設定の場合は月末）。
- 締日より後に出荷された分は、その月の締めには含めず翌月の扱いになります。

## 締日処理の実行

1. 一覧右上の **締日処理を実行** を押します。
2. 対象の **年・月** を選んで「実行」します。
3. 対象月の未請求出荷が顧客ごとに集計され、**未処理（PENDING）** の行が作成・更新されます（作成 / 更新 / 処理済みスキップの件数が表示されます）。
4. 何度実行しても安全です。処理済みの行はスキップされ、未処理の行は金額が最新に更新されます。
5. サーバーの設定によっては、当月分が毎朝自動で実行されることもあります。

## 請求書の生成

1. 一覧から締めの行を開くと、対象出荷の一覧（出荷書番号・出荷日・数量・金額）を確認できます。
2. **請求書を生成** を押すと、対象出荷の明細から請求書（下書き）が作成され、行は **処理済（PROCESSED）** になります。そのまま生成された請求書の詳細へ移動します。
3. 消費税と支払期限は、顧客マスタの税区分・支払サイトから自動計算されます。
4. 以降の発行・送付・入金の記録と弥生会計 CSV の出力は[請求書](/manual/ja/apps/invoice/user)アプリで行います。

## 状態

- **未処理（PENDING）**：締めの行が作成された状態。請求書を生成できます。
- **処理済（PROCESSED）**：請求書を生成済み。詳細の「生成請求書」から請求書へ移動できます。
- 弥生会計 CSV のエクスポート状況は請求書側（弥生エクスポート日時）に記録されます。

## 一覧・検索

- 顧客名で検索でき、状態で絞り込めます。行をクリックすると詳細画面へ移動します。
