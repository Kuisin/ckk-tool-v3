操作代码 **SH02**。从出货单创建送货单（納品書，DRN-YYYYMM-NNNNN），管理开具与送达，并输出 PDF。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

创建随出货产品附上或寄送的**送货单（納品書）**。选择[出货单](/manual/zh/apps/shipping-order/user)（已确认或已出货的）后，收货方与明细会自动填入。

- 收货方由出货单 → 订单回执的[客户](/manual/zh/masters/customer/user)（含分店）自动确定（不可更改）。
- 可选择送货方式（普通送货 / 直送用户）以及是否记载价格。
- 可输出送货单 PDF 用于随货同封或寄送。
- 操作本应用需要送货单权限（delivery_note）。

![送货单列表（含送货方式、状态徽章）](../../assets/screenshots/delivery-note-list-01.png)

## 送货方式与价格记载

- **普通送货（通常納品）**：向下单客户随货同封送货单的常规方式。价格记载默认为"有"。
- **直送用户（ユーザー直送）**：直接送达[最终需求方](/manual/zh/masters/end-user/user)的方式。必须选择**收件方（最终需求方）**，价格记载默认为"无"。
- 价格记载设为"无"时，不保存单价和金额，画面和 PDF 上也不会显示。

## 创建方法

1. 在列表页点击**新規作成**（新建）（也可从出货单详情页的**納品書を作成**进入 — 此时出货单已预先选好）。
2. 选择**出货单**。明细（产品、数量、单价 = 订单回执的接单单价）会自动填入。
3. 设置**送货方式**和**价格记载**。直送用户时需选择**收件方（最终需求方）**。
4. 明细可以修改，但不能登记出货单中不存在的产品，也不能超过出货数量。
5. 保存后成为**草稿**。创建后无法更改出货单和收货方。

## 状态与操作

操作在详情页右上角的菜单中进行。

- **草稿（下書き / DRAFT）**：可以编辑。内容确定后点击**発行**（开具）——开具后不可再编辑。
- **已开具（発行済 / ISSUED）**：货物送达客户后点击**納品済みにする**（标记已送达）。送达日期记录为当天。
- **已送达（納品済 / DELIVERED）**：完成状态。

- 通过 **PDF** 按钮可随时输出送货单 PDF。
- 送货单没有删除（取消）操作。已创建的送货单无法删除，请在草稿阶段确认好内容。

## 与开票的关系

- 送货单编号会作为"来源"链接显示在[发票](/manual/zh/apps/invoice/user)的明细中（发票本身由[结算日处理](/manual/zh/apps/billing-closing/user)从出货单生成）。

## 列表与搜索

- 可按送货单号、出货单号、收货方搜索，并按送货方式、状态筛选。
- 列表显示出货工厂为自己所属[工厂](/manual/zh/masters/plant/user)的送货单，以及自己创建的送货单。
- 点击行即可进入详情页。
