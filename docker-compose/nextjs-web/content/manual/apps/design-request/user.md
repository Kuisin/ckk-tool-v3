操作コード **SA05**。見積時・受注時に設計部門へ設計を依頼し、完成した設計ファイルをバージョン管理して製品マスタに登録するアプリです。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 依頼のきっかけ（**トリガー**）を **見積時** / **受注時** から選び、[見積書](/manual/ja/apps/quote/user) または注文請書に紐付けて設計依頼を登録します。
- 依頼番号 **DSG-YYYYMM-NNNNN** が保存時に自動採番されます。
- 依頼の進み具合を **未着手 → 進行中 → 完了** の状態で管理します。
- 完了時に添付した設計ファイルが **バージョン（v1, v2, …）** として登録され、製品を指定していれば [製品マスタ](/manual/ja/masters/product/user) の最新設計として反映されます。
- 利用には設計依頼権限（design_request）が必要です。

![設計依頼書一覧](../../assets/screenshots/design-request-list-01.png)

## 作成方法

1. 一覧の **新規作成** を開きます。
2. **トリガー** を選びます：**見積時**（見積と並行して設計する場合）または **受注時**（受注後に設計する場合）。
3. トリガーに応じて参照元を選びます（どちらも任意）：見積時は **見積書**（直近の見積から選択）、受注時は **注文請書**（検索して選択）。
4. **製品**（任意）と **依頼内容** を入力し、**保存** します。保存すると依頼番号が採番され、詳細ページへ移動します。

![設計依頼書の新規作成フォーム](../../assets/screenshots/design-request-new-01.png)

**注意**：トリガーと参照元（見積書 / 注文請書）は **作成後に変更できません**。間違えた場合は新しい依頼を作り直してください。

## 進め方（状態の流れ）

- **未着手**（PENDING）— 作成直後。詳細画面の **着手** ボタンで進行中にします。
- **進行中**（IN_PROGRESS）— 設計作業中。**ファイル** タブに設計ファイルをアップロードします。
- **完了**（IN_PROGRESS → COMPLETED）— アクションメニューの **完了** で確定します。**設計ファイルの添付が 1 件以上必須** で、最新の添付が新しいバージョンとして登録されます。完了日時も記録されます。
- **差し戻し**（COMPLETED → 進行中）— 完了後に修正が必要になったら、アクションメニューの **差し戻し** で進行中に戻せます（完了日時はクリアされます）。

## 編集

- **編集** できるのは **未着手・進行中** のときだけで、変更できるのは **製品** と **依頼内容** のみです。
- 完了済みの依頼は編集・ファイル追加ともにできません。修正するにはまず **差し戻し** してください。

## ファイル（バージョン管理）

- 詳細の **ファイル** タブで設計ファイルをアップロード・削除できます（完了前のみ）。
- **完了** のたびに、その時点の最新添付ファイルが v1, v2, … と版を上げて登録され、最新版には **最新** バッジが付きます。
- 製品を指定した依頼では、完了時にその製品の最新設計も新しい版に切り替わります。

![ファイルタブ（バージョン一覧と最新バッジ）](../../assets/screenshots/design-request-files-01.png)

## 一覧・検索

- 列：依頼番号 / トリガー / 製品 / 状態 / 更新日。
- 番号・製品・依頼内容で検索、トリガーと状態で絞り込みできます。行クリックで詳細へ。

## よくある質問

- **完了ボタンでエラーになる** —「設計ファイルを添付してから完了してください」の場合、**ファイル** タブから設計ファイルをアップロードしてから完了してください。
- **見積書・注文請書の指定は必須？** — どちらも任意です。紐付けなしでも依頼を作成できます。
- **受注請書との関係は？** — 受注の取込・展開は [受注請書](/manual/ja/apps/order-acceptance/user)（SA04）で行い、そこで生成された注文請書を本アプリの「受注時」トリガーの参照元に指定できます。
