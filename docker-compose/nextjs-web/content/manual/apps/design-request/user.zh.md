操作代码 **SA04**。在报价或接单阶段向设计部门委托设计，对完成的设计文件进行版本管理，并登记到产品主数据。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

- 选择委托的**触发时点**——**見積時**（报价时）或 **受注時**（接单时），并将设计委托书（設計依頼書）关联到[报价单](/manual/zh/apps/quote/user)或注文请书（注文請書）。
- 委托编号 **DSG-YYYYMM-NNNNN** 在保存时自动编号。
- 通过 **未着手（未开始）→ 進行中（进行中）→ 完了（已完成）** 的状态管理进度。
- 完成时，附加的设计文件会作为**版本（v1、v2、…）**登记；如果指定了产品，还会成为[产品主数据](/manual/zh/masters/product/user)的最新设计。
- 使用本应用需要设计委托权限（design_request）。

## 创建方法

1. 从列表打开 **新規作成**（新建）。
2. 选择**触发时点**：**見積時**（与报价并行设计）或 **受注時**（接单后设计）。
3. 根据触发时点选择来源单据（均为可选）：报价时选择**报价单**（从最近的报价中选取）；接单时选择**注文请书**（搜索选择）。
4. 输入**产品**（可选）和**委托内容**，然后**保存**。保存后会分配委托编号并跳转到详情页。

**注意**：触发时点和来源单据（报价单 / 注文请书）**创建后不可更改**。选错时请重新创建新的委托。

## 推进方式（状态流程）

- **未着手**（未开始，PENDING）— 刚创建。在详情画面点击 **着手**（开始）进入进行中。
- **進行中**（进行中，IN_PROGRESS）— 设计作业中。在**ファイル**（文件）标签页上传设计文件。
- **完了**（完成，IN_PROGRESS → COMPLETED）— 通过操作菜单的 **完了** 确定。**必须至少附加 1 个设计文件**，最新的附件会登记为新版本，并记录完成时间。
- **差し戻し**（退回，COMPLETED → 进行中）— 完成后需要修改时，通过操作菜单的 **差し戻し** 退回到进行中（完成时间会被清除）。

## 编辑

- 只有在**未开始・进行中**时才能**编辑**，且只能修改**产品**和**委托内容**。
- 已完成的委托不能编辑，也不能追加文件。需要修改时请先**退回**。

## 文件（版本管理）

- 在详情的**ファイル**（文件）标签页可以上传、删除设计文件（仅限完成前）。
- 每次**完成**时，当时最新的附件会以 v1、v2、… 递增登记版本，最新版会带有 **最新** 徽章。
- 指定了产品的委托，完成时该产品的最新设计也会切换为新版本。

## 列表与搜索

- 列：委托编号 / 触发时点 / 产品 / 状态 / 更新日期。
- 可按编号、产品、委托内容搜索，并按触发时点和状态筛选。点击行进入详情。

## 常见问题

- **点击完成按钮报错** — 如果提示需要先附加设计文件，请先在**ファイル**标签页上传设计文件再执行完成。
- **必须指定报价单或注文请书吗？** — 都是可选的。不关联单据也可以创建委托。
- **与受注请书的关系？** — 订单的导入与展开在[受注请书](/manual/zh/apps/order-acceptance/user)（SA03）中进行；在那里生成的注文请书可以作为本应用「受注時」（接单时）触发的来源单据。
