操作代码 **BL01**。管理由结算日处理生成的发票（請求書，INV-YYYYMM-NNNNN）的开具、寄送与收款，并输出 PDF 和弥生会计 CSV。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

管理开给客户的**发票（請求書）**。发票不在此画面手工新建，而是由**[结算日处理](/manual/zh/apps/billing-closing/user)（BL02）的"請求書を生成"（生成发票）**自动创建。明细由已出货的[出货单](/manual/zh/apps/shipping-order/user)生成。

- 每条明细都会以链接显示来源的出货单号和[送货单](/manual/zh/apps/delivery-note/user)号，可直接跳转到原始单据。
- 消费税根据[客户](/manual/zh/masters/customer/user)主数据的税区分自动计算（应税 10% / 轻减税率 8% / 免税 0%）。
- 付款期限自动设为"结算日 + 客户的付款账期（未设置时为 30 天）"。
- 操作本应用需要发票权限（invoice）。

## 详情页说明

- 上部显示发票编号、客户（含分店）、账单期间、小计、消费税、合计金额（含税）、付款期限、开具日期以及弥生导出时间。
- 明细表列出摘要（产品名 + 批次）、数量、单价、金额，以及来源出货单 / 送货单的链接。
- 在**履歴**（历史）标签页可查看操作记录。
- 画面上消费税栏的标签固定显示为「消費税（10%）」，但实际税额是按客户主数据的税区分（10% / 8% / 0%）计算出的金额。

![发票详情（明细与来源链接）](../../assets/screenshots/invoice-detail-01.png)

## 状态与操作

操作在详情页右上角的菜单中进行。状态按顺序推进，没有编辑画面。

- **草稿（下書き / DRAFT）**：生成后的初始状态。确认内容后点击**発行**（开具）——开具日期记录为当天。
- **已开具（発行済 / ISSUED）**：寄送给客户后点击**送付済みにする**（标记已寄送）。
- **已寄送（送付済 / SENT）**：确认收款后点击**入金済みにする**（标记已收款）。
- **已收款（支払済 / PAID）**：完成状态。

## PDF 与弥生会计 CSV

- 通过 **PDF** 按钮输出发票 PDF。
- 菜单中的**弥生会計CSV**可下载可导入弥生会计 Next 的记账凭证 CSV（借方：应收账款 / 贷方：销售收入与暂收消费税，UTF-8 带 BOM）。
- 导出后会记录导出时间，显示在详情页的"弥生エクスポート"栏中。
- CSV 导出需要结算日处理的导出权限（billing_closing 的 EXPORT）。

## 列表与搜索

- 可按发票编号、客户搜索，并按状态筛选。
- 点击行即可进入详情页。
