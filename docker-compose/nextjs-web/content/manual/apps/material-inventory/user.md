[在庫管理](/manual/ja/apps/product-inventory/user)（操作コード **PD04**）の **素材** タブ・**仕掛品** タブの見かたです。素材の在庫数・予約数と、入荷予定を含めた「いつ・どれだけ使えるか」（ATP）を確認します。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このページで説明する範囲

旧 素材在庫（PD05）は **在庫管理** アプリに統合されました — 旧一覧 URL は自動で在庫管理の素材タブへリダイレクトされます。数量をここで直接編集することはありません — 在庫は業務の操作に連動して自動的に動きます（唯一の書き込み操作は [在庫移動](/manual/ja/apps/product-inventory/user)）。

- **入庫** … [素材入荷](/manual/ja/apps/material-receipt/user)（PU03）で入荷を登録すると、入荷先拠点の在庫に入庫されます。
- **予約** … 製造分の [指示書](/manual/ja/apps/work-order/user) が承認されると、使用素材が予定数量ぶん予約されます。
- **消費（出庫）** … 指示書の全工程が完了すると、予約されていた素材が消費されます。
- **入荷予定** … 発注済みの [素材発注書](/manual/ja/apps/purchase-order/user) の明細から、次回入荷日と入荷予定量が表示されます。

## 素材タブ

- 列は **素材**（素材コード + 名称）、**拠点**、**保管場所**、**在庫数**（単位付き）、**利用可能**、**次回入荷**（発注済み明細の直近の入荷予定日）、**更新日**、行アクションの **移動** です。
- 素材コード・素材名で検索でき、**拠点** で絞り込めます。
- 行をクリックすると素材在庫の詳細画面が開きます。**移動** ボタンからは在庫移動のモーダルが開きます（[在庫移動の手順](/manual/ja/apps/product-inventory/user)参照）。

![在庫管理 素材タブ — 次回入荷列と保管場所](../../assets/screenshots/inventory-materials-01.png)

## 仕掛品タブ

進行中の指示書から工程ごとに計算した「いま工程に乗っている数」です（在庫レコードはありません — 実在庫は全工程完了時にのみ動きます）。

- 製品ごとのグループ行（計 n）の下に、**指示書番号・工程・仕掛数** が並びます。
- 指示書番号をクリックすると指示書詳細へ移動します。
- 進行中の指示書がなければ「進行中の仕掛品はありません」と表示されます。

![在庫管理 仕掛品タブ — 指示書 × 工程ごとの仕掛数](../../assets/screenshots/inventory-wip-01.png)

## 素材在庫の詳細画面

サマリには素材・拠点・在庫数・予約数・利用可能・次回入荷・保管場所・備考が表示されます。

**ATP タイムライン** タブ … 「現時点の利用可能数」から始まり、入荷予定日ごとに利用可能数がどう積み上がるかを時系列で表示します。

- 列は **時点**、**入荷量**、**利用可能**（累積）、**参照**（発注番号）。
- 利用可能がマイナスの時点は赤字で表示されます — 予約（製造コミット）が手持ち + 入荷予定を上回っている状態で、発注判断のシグナルです。

**取引履歴** タブ … 在庫が動いた記録です。種別は **入庫 / 出庫 / 予約 / 解除 / 調整** で、日時・数量・参照・備考が残ります。

## よくある質問

**Q. 予約数が在庫数より多いのですが。** — 異常ではありません。指示書の承認時は在庫が足りなくても予約されます（不足 = 発注が必要というシグナル）。ATP タイムラインで入荷後に足りるかを確認してください。

**Q. 在庫数を手で直したい。** — この画面からできるのは在庫移動（場所の変更）だけです。数量のずれは棚卸調整として管理者側の対応が必要です。

このアプリの利用には在庫（inventory）権限が必要です。製品タブ・ロケーションタブ・在庫移動の手順は [在庫管理](/manual/ja/apps/product-inventory/user) を参照してください。
