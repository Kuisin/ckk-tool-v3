操作代码 **PD05**。用于查看素材的库存数・预约数，以及包含到货计划在内的"何时・可用多少"（ATP）的台账。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

素材库存是**只读**画面。不能在这里直接修改数量 — 库存会随业务操作自动变动。

- **入库** … 在[素材到货（素材入荷）](/manual/zh/apps/material-receipt/user)（PU01）登记到货后，入库到到货工厂的库存。
- **预约** … 生产供货（製造分）的[制造指示单（指示書）](/manual/zh/apps/work-order/user)审批通过后，所用素材按计划数量被预约。
- **消耗（出库）** … 指示書的全部工序完成后，已预约的素材被消耗。
- **到货计划** … 已下单（状态为"発注済"）的[素材订购单（素材発注書）](/manual/zh/apps/purchase-order/user)明细提供下次到货日和到货数量。

## 列表说明

一行 = 素材 × 工厂。

- 列包括：**素材**（素材代码 + 名称）、**工厂**、**库存数**（带单位）、**预约数**、**可用数**（库存数 − 预约数）、**下次到货**（已下单明细中最近的预计到货日）、**更新日**。
- 可按素材代码・名称搜索，并按**工厂**筛选。
- 点击行可打开详情页。

## 详情页

摘要中显示素材・工厂・库存数・预约数・可用数・下次到货・保管位置。

**ATP 时间线**标签页 … 从"当前可用数"开始，按每个预计到货日展示可用数如何累积。

- 列包括：**时点**（当前 → 各预计到货日；未填日期的订单显示"未定"）、**到货量**、**可用数**（累计）、**参照**（订购单编号）。
- 可用数为负的时点以红色显示 — 表示预约（生产承诺）超过了现有库存 + 预计到货，是需要采购的信号。

**交易记录**标签页 … 库存变动的记录。类别为 **入庫（入库）/ 出庫（出库）/ 予約（预约）/ 解除 / 調整（调整）**，包含时间・数量・参照（指示单编号・到货等）・备注。

## 常见问题

**Q. 预约数比库存数还多。** — 这不是异常。指示書审批时即使库存不足也会进行预约（不足 = 需要采购的信号）。请在 ATP 时间线中确认到货后是否足够。

**Q. 想手动修正库存数。** — 无法在此画面编辑。数量差异需由管理员通过盘点调整处理。

使用此应用需要库存（inventory）权限。产品库存请在[产品库存](/manual/zh/apps/product-inventory/user)（PD04）中查看。
