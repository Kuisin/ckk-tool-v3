操作码 **PU01**。记录素材到达工厂，并将其计入素材库存的应用。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

素材入库（素材入荷）记录的台账。入库分为两种。

- **采购单入库** — 由[素材采购单（素材発注書，PU03）](/manual/zh/apps/purchase-order/user)的「入库完成」操作**自动**登记的入库。列表中会显示采购单号（PO-…）的链接。
- **直接采购** — 不经过采购单而采购的素材入库。通过本应用的「新建登记」手动录入。

无论哪种情况，登记的同时都会将素材计入入库工厂的素材库存（[库存管理 PD04](/manual/zh/apps/material-inventory/user)）（数量增加）。登记需要素材入库权限。

![素材入库列表（含采购单号链接的行与「直接采购」徽章的行，以及入库类型筛选）](../../assets/screenshots/material-receipt-list-01.png)

## 新建登记（直接采购）

1. 打开列表右上角的「新建登记」。
2. 搜索并选择 **素材**（必填）——从[素材主数据](/manual/zh/masters/material/user)中已登记的素材里选择。
3. **供应商** 与 **入库工厂** 为可选项。选择工厂后，素材会计入该工厂的素材库存。
4. 输入 **入库日**（默认今天）以及 **数量・单位**。
5. 如有需要，可选择 **凭证**（送货单副本、验收单等。PDF / PNG / JPG / WEBP / HEIC / XLSX / CSV，每个不超过 20MB），然后点击「登记」。凭证会在登记完成后上传。

保存后会跳转到详情页。

## 详情页

- 可查看素材、供应商、入库工厂、数量、入库日、采购明细（采购单入库时显示到素材采购单的链接，直接采购时显示徽章）。
- 入库是已计入库存的**确定记录**，不可编辑或删除。
- **凭证** 可随时添加或删除。

![素材入库详情（采购单入库 — 到素材采购单的链接与入库内容摘要）](../../assets/screenshots/material-receipt-detail-01.png)

## 列表与检索

- 列：素材（代码＋名称）/ 供应商 / 入库工厂 / 数量 / 入库日 / 采购明细（采购单号 或 直接采购）。
- 可用搜索框（素材代码・名称、供应商、采购单号）和 **入库类型**（采购单入库 / 直接采购）筛选。
- 点击行跳转到详情页。

## 常见问题

**采购的素材也在这里登记入库吗？** — 不是。采购单入库由素材采购单（PU03）的「入库完成」自动登记。本应用手动录入的仅限直接采购。

**想分批（部分）入库怎么办？** — 采购单的「入库完成」会一次性入库剩余数量。分批到货的部分请在本应用中直接登记补充。

**登记内容填错了** — 入库记录没有修改功能。因为会影响库存数量，请在登记前仔细核对数量与工厂。
