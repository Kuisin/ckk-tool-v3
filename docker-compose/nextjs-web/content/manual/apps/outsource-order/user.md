操作コード **PU04**。指示書の外注工程（センタレス・コーティングなど）を横断して確認する一覧アプリです。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

[指示書（PD02）](/manual/ja/apps/work-order/user)の工程のうち、実施場所が **外注** の工程だけを集めた一覧です。「いまどの加工がどの外注先に出ていて、いつ戻る予定か」をひと目で確認できます。

- このアプリは **閲覧専用** です。外注依頼という独立した伝票はなく、指示書の外注工程がそのまま表示されます。
- 依頼日・入荷予定日・入荷日の入力・変更は **工程実行画面**（指示書詳細の該当工程）で行います。一覧の行をクリックすると、直接その画面へ移動します。
- 閲覧には外注依頼の権限が必要です。

![外注依頼一覧（指示書番号・製品・工程名・外注先・依頼日・入荷予定日・状態の列と外注先/状態フィルタ）](../../assets/screenshots/outsource-order-list-01.png)

## 一覧の見かた

- 列：指示書番号（クリックで指示書詳細へ）/ 製品 / 工程名 / 外注先 / 依頼日 / 入荷予定日 / 入荷日 / 状態。
- **状態** は工程の進行状態です：未着手 / 進行中 / 完了 / キャンセル。
- 検索（指示書番号・製品・工程・外注先）に加えて、**外注先** と **状態** で絞り込めます。外注先の選択肢は一覧に登場する外注先から自動で作られます。

## 外注工程をこの一覧に載せるには

このアプリからは追加できません。指示書の工程で実施場所に **外注** を選び、外注先を指定すると、この一覧に表示されます。外注先の企業は[外注企業マスタ](/manual/ja/masters/supplier/user)で管理します。

## よくある質問

**一覧が空です** — 外注工程を持つ指示書がまだありません。指示書の工程で外注を選ぶと表示されます。

**日付を修正したい** — この画面では編集できません。行をクリックして工程実行画面を開き、そこで依頼日・入荷予定日・入荷日を変更してください。

**素材の発注はここで行いますか？** — いいえ。素材の発注は[素材発注書（PU02）](/manual/ja/apps/purchase-order/user)で行います。このアプリは製造工程の外部委託（加工の外注）の一覧です。
