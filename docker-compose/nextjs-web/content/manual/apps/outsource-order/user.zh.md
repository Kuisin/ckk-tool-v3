操作码 **PU02**。跨指示单查看外协工序（无心磨、涂层等）的列表应用。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

汇总[指示单（指示書，PD02）](/manual/zh/apps/work-order/user)中执行地点为 **外协** 的工序的列表。可以一目了然地确认「哪道加工正在哪家外协厂、预计何时返回」。

- 本应用为 **只读**。没有独立的外协委托（外注依頼）单据——直接显示指示单的外协工序。
- 委托日、预计到货日、到货日的录入与修改在 **工序执行画面**（指示单详情中的对应工序）进行。点击列表中的行可直接跳转到该画面。
- 查看需要外协委托权限。

![外协委托列表（指示单号、产品、工序名、外协厂、委托日、预计到货日、状态列与外协厂/状态筛选）](../../assets/screenshots/outsource-order-list-01.png)

## 列表说明

- 列：指示单号（点击打开指示单详情）/ 产品 / 工序名 / 外协厂 / 委托日 / 预计到货日 / 到货日 / 状态。
- **状态** 表示工序的进度：未开始 / 进行中 / 完成 / 取消。
- 除搜索框（指示单号、产品、工序、外协厂）外，还可按 **外协厂** 与 **状态** 筛选。外协厂选项由列表中出现的外协厂自动生成。

## 如何让外协工序出现在此列表

无法从本应用添加。在指示单的工序中将执行地点选为 **外协** 并指定外协厂后，该工序即显示在此列表中。外协企业在[外协企业主数据](/manual/zh/masters/supplier/user)中管理。

## 常见问题

**列表是空的** — 还没有包含外协工序的指示单。在指示单的工序中选择外协后即会显示。

**想修改日期** — 此画面无法编辑。请点击行打开工序执行画面，在那里修改委托日、预计到货日、到货日。

**素材的采购在这里进行吗？** — 不是。素材采购请使用[素材采购单（素材発注書，PU03）](/manual/zh/apps/purchase-order/user)。本应用仅列出制造工序的外部委托（加工外协）。
