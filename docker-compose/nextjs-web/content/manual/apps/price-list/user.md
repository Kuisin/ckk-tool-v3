操作コード **SA02**。顧客ごとの製品単価を管理します。見積書の単価はここから自動解決されます。

## このアプリでできること

[顧客](/manual/ja/masters/customer/user)ごとに「この[製品](/manual/ja/masters/product/user)はいくら」という **販売単価** を登録しておく台帳です。登録しておくと、[見積書](/manual/ja/apps/quote/user)を作るときに単価と値引きが自動で入ります（見積書側での手入力はありません）。

- 基準単価は多くの場合、製品にリンクした **確定済みの試算（SA01）** から取り込みます（手動設定も可 — 確認あり）。
- 1 つの価格表（顧客×製品）の中に、**注文種別ごとの価格** と、数量が多いほど安くする **数量段階（数量範囲 → 倍率）** を設定できます。
- **値引きルール**（期間・数量条件）を登録しておくと、見積書作成時に自動適用されます。
- **有効期間** はバリアント（注文種別）単位で設定します。テスト・サンプルは終了日必須です。

![価格表一覧](../../assets/screenshots/price-list-list-01.png)

## 価格表エントリ

1 エントリ = **顧客 + 製品**（作成後は変更不可・同じ組み合わせは 1 件だけ）。注文種別（本番 / テスト / サンプル / その他）ごとの価格はエントリ内の **バリアント** として持ちます。

- バリアントごとに **基準単価**・**有効期間**・有効/無効・試算リンク（価格ソース）を持ちます。
- **数量段階**：数量範囲ごとの倍率（例：1〜49 本 = ×1.05、50〜99 本 = ×1.00、100 本〜 = ×0.95）。段階の単価 = 基準単価 × 倍率。段階ごとに手動の固定単価へ上書きすることもできます（確認あり — 採用単価に「手動」表示）。

![価格表詳細（価格設定タブ）](../../assets/screenshots/price-list-detail-01.png)

## 作成方法

1. 一覧の「新規作成」から **顧客と製品** を選びます。同じ顧客×製品の価格表が既にあると警告が表示されます（既存を編集してください。保存時も「同一の顧客・製品の価格表が既に存在します」エラーになります）。
2. 注文種別ごとに価格を設定します。選んだ製品に **リンク済みの確定試算（SA01）** があれば **価格ソース（試算）** として選択でき、その見積単価が基準単価に入ります（推奨）。
3. 試算が無い場合や別の単価にしたい場合は「**カスタム単価を使用**」にチェックして基準単価を手動設定します（確認あり）。
4. **有効開始日** を設定します。テスト・サンプルは **有効終了日も必須** です。
5. 「注文種別を追加」で別の種別の価格を同じエントリに追加できます。
6. 試算をソースに保存すると、その試算は **価格表登録済（REGISTERED）** としてロックされます。

## 編集・値引きルール

- 詳細画面 →「編集」で、注文種別の追加・削除、基準単価（カスタム時のみ）・有効期間・数量段階を変更できます。保存済みバリアントの注文種別と価格ソースは変更できません。

![価格表編集フォーム](../../assets/screenshots/price-list-edit-01.png)

- **値引きルール** は詳細画面の「値引き設定」タブで注文種別ごとに登録します。名称・値引き種別（率 % / 金額 ¥/本）・数量条件・有効期間を設定でき、条件を満たすルールが見積書作成時に自動適用されます（複数該当時は値引き額が最大のもの）。

![値引き設定タブ](../../assets/screenshots/price-list-discounts-01.png)

## 一覧・検索・その他の操作

- 顧客・製品で検索、顧客・製品・注文種別で絞り込みできます。1 行 = 顧客×製品（注文種別はバッジ、単価は範囲表示、試算元・値引き件数・有効期間も列表示）。
- 行メニューから「**見積書を作成**」（この価格表を使った見積書の下書きを作成）・「**有効期間を変えて複製**」・「**別の顧客・製品へコピー**」（試算リンクは外れて手動扱い）・「**削除**」が実行できます。
- 行を選択して **有効化 / 無効化 / 一括削除** の一括操作もできます。
- 詳細の「関連」タブには試算元と、この価格表から作成した見積書の一覧が表示されます。
