操作コード **PD04**。製品・素材・仕掛品・ロケーションを 1 つの画面で確認し、保管場所間の在庫移動を記録します。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

旧 製品在庫（PD04）と素材在庫（PD05）は 1 つの **在庫管理** アプリに統合されました（旧一覧 URL は自動でこのアプリへリダイレクトされます）。画面は 4 つのタブに分かれます。

- **製品** … 完成品・半製品の在庫台帳（このページで説明）。
- **素材** / **仕掛品** … 素材在庫（ATP）と製造中の仕掛数。→ [在庫管理（素材・仕掛品）](/manual/ja/apps/material-inventory/user)
- **ロケーション** … 拠点 → 保管場所 → 棚の階層で「どこに何があるか」を見る画面（このページで説明）。

数量をここで直接編集することはありません — 在庫は業務の操作に連動して自動的に動き、この画面からの唯一の書き込み操作は **在庫移動** です。

- **入庫** … [指示書](/manual/ja/apps/work-order/user) の全工程が完了すると、良品がロット番号付きで入庫されます。半製品に振り分けた分は半製品在庫として入庫されます。
- **予約** … 注文請書の在庫照合を実行すると、利用可能な在庫がその注文に引当予約されます。
- **出庫・解除** … [出荷書](/manual/ja/apps/shipping-order/user) の出荷で出庫され、予約が解除されます。

## 製品タブ

- 列は **製品**（名称 + 製品コード）、**拠点**、**保管場所**（「場所名 / 棚コード」。割り当てがなければ「未割当」）、**ロット**、**在庫数**、**利用可能**（利用可能数 + 予約がある場合は「予約 n」バッジ）、**区分**（完成品 / 半製品）、**更新日**、行アクションの **移動** です。
- 製品名・製品コードで検索でき、**拠点** と **区分**（完成品 / 半製品）で絞り込めます。
- 行をクリックすると製品在庫の詳細画面が開きます。

![在庫管理 製品タブ — 保管場所・予約バッジ・区分](../../assets/screenshots/inventory-products-01.png)

## 在庫移動

各行の **移動** ボタン（ロケーションタブの在庫チップにもあります）から在庫移動のモーダルを開きます。

1. 移動元（現在の場所）が表示されます。
2. 移動先を **拠点 → 保管場所 → 棚** の順に選びます。
3. **数量**（上限は利用可能数。製品は整数のみ）と必要なら **備考** を入力します。

移動は出庫・入庫の取引ペアとして記録され、取引履歴タブに残ります。**予約分は移動できません。**

## ロケーションタブ

拠点を選ぶと、その拠点の **保管場所カード**（名称 + コード）が並び、カード内に **棚のグリッド**（棚コード・空き・在庫チップ: 品目 + 数量 + 移動ボタン）が表示されます。保管場所内で棚が未指定の在庫は「棚未割当」枠に、保管場所自体が未割当の在庫は「未割当（保管場所なし）」枠にまとまります。

拠点にフロアマップと配置済みの保管場所ピンがあれば **フロアマップ** も表示されます。ピンには「場所名（コード）｜在庫 n 件」と出て、クリックするとその保管場所のカードへスクロール・ハイライトされます。

保管場所と棚の登録は 保管場所マスタ（MS0E）で行います。

![在庫管理 ロケーションタブ — 保管場所カードと棚グリッド](../../assets/screenshots/inventory-locations-01.png)

## 製品在庫の詳細画面

- サマリ … 製品・拠点・ロット番号・区分・在庫数・予約数・利用可能・保管場所。半製品の場合は **発生工程**（どの指示書のどの工程から出たか）も表示されます。
- **予約** タブ … この在庫行への引当予約の一覧です。状態は **予約中** → **確定**（全工程完了時）→ **解除**（出荷・キャンセル時）と進みます。関連する注文請書番号・指示書番号も確認できます。
- **取引履歴** タブ … 在庫が動いた記録です。種別は **入庫 / 出庫 / 予約 / 解除 / 調整** で、在庫移動は出庫・入庫のペアとして残ります。

## よくある質問

**Q. 在庫数を手で直したい。** — この画面からできるのは在庫移動（場所の変更）だけです。数量のずれは棚卸調整として管理者側の対応が必要です。

**Q. 利用可能が 0 なのに在庫数はある。** — その分は他の注文に予約済みです。予約タブでどの注文請書に引き当てられているか確認できます。

このアプリの利用には在庫（inventory）権限が必要です。素材タブ・仕掛品タブの見かたは [在庫管理（素材・仕掛品）](/manual/ja/apps/material-inventory/user) を参照してください。
