操作コード **PD04**。完成品・半製品の在庫と、製造中の仕掛品の数を確認する台帳です。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

製品在庫は **照会専用** の画面です。数量をここで直接編集することはありません — 在庫は業務の操作に連動して自動的に動きます。

- **入庫** … [指示書](/manual/ja/apps/work-order/user) の全工程が完了すると、良品がロット番号付きで入庫されます。半製品に振り分けた分は半製品在庫として入庫されます。
- **予約** … 注文請書の在庫照合を実行すると、利用可能な在庫がその注文に引当予約されます。
- **出庫・解除** … [出荷書](/manual/ja/apps/shipping-order/user) の出荷で出庫され、予約が解除されます。

## 一覧の見かた

一覧上部の切り替えで **製品在庫** と **仕掛品** の 2 つの表示を切り替えられます。

**製品在庫** … 在庫 1 行 = 製品 × 拠点 × ロットです。

- 列は **製品**（名称 + 製品コード）、**拠点**、**ロット**、**在庫数**、**予約数**、**利用可能**（在庫数 − 予約数）、**区分**（完成品 / 半製品）、**更新日**。
- 製品名・製品コードで検索でき、**拠点** と **区分** で絞り込めます。
- 行をクリックすると詳細画面が開きます。

**仕掛品** … 進行中の指示書から計算した「いま工程に乗っている数」です（在庫レコードはありません — 実在庫は全工程完了時にのみ動きます）。

- 製品ごとにまとめて、**指示書番号・工程・仕掛数** を表示します。
- 指示書番号をクリックすると指示書詳細へ移動します。

## 詳細画面

- サマリ … 製品・拠点・ロット・区分・在庫数・予約数・利用可能・保管場所。半製品の場合は **発生工程**（どの指示書のどの工程から出たか）も表示されます。
- **予約** タブ … この在庫行への引当予約の一覧です。状態は **予約中**（製造中・照合済み）→ **確定**（全工程完了時）→ **解除**（出荷・キャンセル時）と進みます。関連する注文請書番号・指示書番号も確認できます。
- **取引履歴** タブ … 在庫が動いた記録です。種別は **入庫 / 出庫 / 予約 / 解除 / 調整** で、日時・数量・参照（出荷番号や指示書番号）・備考が残ります。

## よくある質問

**Q. 在庫数を手で直したい。** — この画面からは編集できません。数量のずれは棚卸調整として管理者側の対応が必要です。

**Q. 利用可能が 0 なのに在庫数はある。** — その分は他の注文に予約済みです。予約タブでどの注文請書に引き当てられているか確認できます。

このアプリの利用には在庫（inventory）権限が必要です。素材の在庫は [素材在庫](/manual/ja/apps/material-inventory/user)（PD05）で確認します。
