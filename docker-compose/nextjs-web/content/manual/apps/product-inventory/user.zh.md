操作代码 **PD04**。在一个画面中查看产品・素材・在制品・位置，并记录保管位置之间的库存移动。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

原有的产品库存（PD04）和素材库存（PD05）已统合为一个**库存管理**应用（旧的列表 URL 会自动重定向到这里）。画面分为 4 个标签页。

- **製品（产品）** … 成品・半成品的库存台账（本页说明）。
- **素材** / **仕掛品（在制品）** … 素材库存（ATP）和生产中的在制数量。→ [库存管理（素材・在制品）](/manual/zh/apps/material-inventory/user)
- **ロケーション（位置）** … 按 工厂 → 保管位置 → 货架 层级查看"什么东西在哪里"的画面（本页说明）。

不能在这里直接修改数量 — 库存会随业务操作自动变动，此画面唯一的写入操作是**库存移动**。

- **入库** … [制造指示单（指示書）](/manual/zh/apps/work-order/user)的全部工序完成后，良品带批次编号入库。划分为半成品的数量作为半成品库存入库。
- **预约** … 对订单回执（注文請書）执行库存核对后，可用库存会被预约分配给该订单。
- **出库・解除** … 通过[发货单（出荷書）](/manual/zh/apps/shipping-order/user)发货时出库，同时解除预约。

## 产品标签页

- 列包括：**产品**（名称 + 产品代码）、**工厂**、**保管位置**（"位置名 / 货架代码"，未分配时显示"未割当"）、**批次**、**库存数**、**可用数**（可用数量 + 若有预约则显示"予約 n"徽章）、**区分**（成品 / 半成品）、**更新日**，以及行操作**移動（移动）**。
- 可按产品名称・产品代码搜索，并按**工厂**和**区分**（成品 / 半成品）筛选。
- 点击行可打开产品库存详情页。

## 库存移动

通过各行的**移動（移动）**按钮（位置标签页的库存条目上也有）打开库存移动弹窗。

1. 显示移动源（当前位置）。
2. 按 **工厂 → 保管位置 → 货架** 的顺序选择移动目的地。
3. 输入**数量**（上限为可用数；产品只能输入整数），如有需要再填**备注**。

移动会以出库・入库的交易对形式记录，保留在交易记录标签页中。**已预约的部分无法移动。**

## 位置标签页

选择工厂后，会显示该工厂的**保管位置卡片**（名称 + 代码），卡片内为**货架网格**（货架代码・空位・库存条目：品目 + 数量 + 移动按钮）。保管位置内未指定货架的库存归入"棚未割当"（货架未分配）栏，完全没有保管位置的库存归入"未割当（保管場所なし）"（未分配）栏。

若该工厂有平面图并已放置保管位置图钉，还会显示**平面图**。图钉标注"位置名（代码）｜库存 n 件"，点击后会滚动并高亮对应的保管位置卡片。

保管位置和货架在保管位置主数据（MS0E）中登记。

![库存管理 位置标签页 — 保管位置卡片与货架网格](../../assets/screenshots/inventory-locations-01.png)

## 产品库存详情页

- 摘要 … 产品・工厂・批次编号・区分・库存数・预约数・可用数・保管位置。若为半成品，还会显示**产生工序**（来自哪张指示書的哪道工序）。
- **预约**标签页 … 针对该库存行的预约分配一览。状态依次为 **予約中（预约中）** → **確定（确定）**（全部工序完成时）→ **解除**（发货・取消时）。同时显示相关的注文請書编号・指示单编号。
- **交易记录**标签页 … 库存变动的记录。类别为 **入庫（入库）/ 出庫（出库）/ 予約（预约）/ 解除 / 調整（调整）**；库存移动以出库・入库成对记录。

## 常见问题

**Q. 想手动修正库存数。** — 此画面能做的只有库存移动（更改位置）。数量差异需由管理员通过盘点调整处理。

**Q. 可用数为 0 但库存数不为 0。** — 该部分已被其他订单预约。可在预约标签页中查看被分配给了哪些注文請書。

使用此应用需要库存（inventory）权限。素材标签页・在制品标签页的用法请参阅[库存管理（素材・在制品）](/manual/zh/apps/material-inventory/user)。
