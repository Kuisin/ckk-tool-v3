操作代码 **PD04**。用于查看成品・半成品库存以及生产中在制品数量的台账。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

产品库存是**只读**画面。不能在这里直接修改数量 — 库存会随业务操作自动变动。

- **入库** … [制造指示单（指示書）](/manual/zh/apps/work-order/user)的全部工序完成后，良品带批次编号入库。划分为半成品的数量作为半成品库存入库。
- **预约** … 对订单回执（注文請書）执行库存核对后，可用库存会被预约分配给该订单。
- **出库・解除** … 通过[发货单（出荷書）](/manual/zh/apps/shipping-order/user)发货时出库，同时解除预约。

## 列表说明

列表上方的切换按钮可在**产品库存**和**在制品（仕掛品）**两个视图之间切换。

**产品库存** … 一行 = 产品 × 工厂 × 批次。

- 列包括：**产品**（名称 + 产品代码）、**工厂**、**批次**、**库存数**、**预约数**、**可用数**（库存数 − 预约数）、**区分**（成品 / 半成品）、**更新日**。
- 可按产品名称・产品代码搜索，并按**工厂**和**区分**筛选。
- 点击行可打开详情页。

**在制品** … 根据进行中的指示書计算出的"当前在工序上的数量"（没有库存记录 — 实际库存只在全部工序完成时变动）。

- 按产品分组显示**指示单编号・工序・在制数量**。
- 点击指示单编号可跳转到指示書详情。

## 详情页

- 摘要 … 产品・工厂・批次・区分・库存数・预约数・可用数・保管位置。若为半成品，还会显示**产生工序**（来自哪张指示書的哪道工序）。
- **预约**标签页 … 针对该库存行的预约分配一览。状态依次为 **予約中（预约中）**（生产中・核对完成）→ **確定（确定）**（全部工序完成时）→ **解除**（发货・取消时）。同时显示相关的注文請書编号・指示单编号。
- **交易记录**标签页 … 库存变动的记录。类别为 **入庫（入库）/ 出庫（出库）/ 予約（预约）/ 解除 / 調整（调整）**，包含时间・数量・参照（发货编号或指示单编号）・备注。

## 常见问题

**Q. 想手动修正库存数。** — 无法在此画面编辑。数量差异需由管理员通过盘点调整处理。

**Q. 可用数为 0 但库存数不为 0。** — 该部分已被其他订单预约。可在预约标签页中查看被分配给了哪些注文請書。

使用此应用需要库存（inventory）权限。素材库存请在[素材库存](/manual/zh/apps/material-inventory/user)（PD05）中查看。
