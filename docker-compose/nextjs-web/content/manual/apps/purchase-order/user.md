操作コード **PU03**。仕入先への素材の発注を、依頼 → 承認 → 発注 → 入荷 の流れで管理します。発注番号は **PO-YYYYMM-NNNNN** です。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 仕入先ごとの素材発注書を作成し、承認フローを経て発注します。作成・編集・発注には購買（発注）の権限が必要です。
- 発注済になった明細は[素材在庫（PD05）](/manual/ja/apps/material-inventory/user)の **入荷予定** に自動反映されます。
- 「入荷完了」で明細ごとに[素材入荷（PU01）](/manual/ja/apps/material-receipt/user)の記録が自動作成され、入荷先拠点の素材在庫へ入庫されます。
- [購買依頼（PU04）](/manual/ja/apps/purchase-request/user)から変換して作成することもできます。

## 状態と流れ

- **下書き** — 作成直後。編集・キャンセルできる唯一の状態です。「承認依頼」ボタンで承認フローへ。
- **承認依頼中** — 第一承認グループのメンバー（または代理）のみ「承認」「差し戻し」できます。差し戻し（理由必須）は下書きに戻ります。承認依頼は[承認管理（PD03）](/manual/ja/apps/approval/user)にも表示されます。
- **承認済** — 「発注」ボタンで発注済にできます。発注前ならキャンセル（理由必須）も可能です。
- **発注済** — 明細が素材在庫の入荷予定（ATP）に反映されます。明細には累計の入荷済数量が表示されます。
- **入荷完了** — 「入荷完了」ボタンで未入荷の残数量を全量入荷として素材入荷を登録し、在庫へ入庫した状態。依頼者・作成者へ通知が届きます。
- **キャンセル** — 発注前（下書き・承認依頼中・承認済）のみ、理由付きで可能です。

## 作成方法

作成には 2 つの方法があります。

- **新規作成** — 一覧の「新規作成」から。**仕入先**（必須）と発注日・備考を入力し、明細（素材 × 入荷先拠点 × 数量・単位 × 単価 × 入荷予定日）を 1 件以上追加します。金額（数量 × 単価）と合計はサーバー側で自動計算されます。
- **購買依頼から変換** — 承認済の購買依頼の「発注書へ変換」から。明細は単価 0 円で引き継がれるため、下書きのうちに編集画面で単価を入力してください。

保存後は詳細画面へ移動します。編集できるのは下書きのみです。

## 証憑

承認後（承認済・発注済・入荷完了）は、詳細画面の「証憑」タブから注文書控え・納品書控えなどのファイルを添付できます。承認前は添付できません。

## 一覧・検索 / 詳細画面

- 一覧の列：発注番号 / 仕入先 / 明細数 / 合計金額 / 状態 / 発注日。検索（発注番号・仕入先）と状態で絞り込めます。
- 詳細画面には 依頼 → 承認 → 発注 → 入荷完了 のステップ表示、承認記録（代理承認は「（代理: 原承認者）」付き）、遷移履歴、タブ（明細 / 証憑 / 概要 / 履歴）があります。購買依頼から作成した場合は変換元へのリンクも表示されます。

## よくある質問

**分納（部分入荷）できますか？** — 「入荷完了」は未入荷の残数量をまとめて入荷にします。分けて届いた分は[素材入荷（PU01）](/manual/ja/apps/material-receipt/user)から直接登録してください。

**発注日を入れ忘れました** — 発注日が未設定のまま「発注」すると、発注を実行した日が自動で発注日になります。

**発注済をキャンセルしたい** — 発注済・入荷完了はキャンセルできません。キャンセルできるのは発注前のみです。
