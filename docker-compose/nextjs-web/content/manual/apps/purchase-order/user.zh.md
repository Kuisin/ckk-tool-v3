操作码 **PU03**。以 申请 → 审批 → 下单 → 入库 的流程管理向供应商的素材采购。采购单号为 **PO-YYYYMM-NNNNN**。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- 按供应商创建素材采购单（素材発注書），经审批流程后下单。创建・编辑・下单需要采购（下单）权限。
- 已下单的明细会自动反映到[素材库存（素材在庫，PD05）](/manual/zh/apps/material-inventory/user)的 **预计入库** 中。
- 「入库完成」会按明细自动创建[素材入库（素材入荷，PU01）](/manual/zh/apps/material-receipt/user)记录，并计入入库工厂的素材库存。
- 也可以由[采购申请（購買依頼，PU04）](/manual/zh/apps/purchase-request/user)转换生成。

## 状态与流程

- **草稿（下書き）** — 刚创建的状态。唯一可以编辑・取消的状态。点击「申请审批」进入审批流程。
- **审批中（承認依頼中）** — 仅第一审批组成员（或代理人）可以「批准」「退回」。退回（必须填写理由）会使采购单回到草稿。审批请求同时显示在[审批管理（承認管理，PD03）](/manual/zh/apps/approval/user)中。
- **已批准（承認済）** — 点击「下单」按钮转为已下单。下单前也可以取消（必须填写理由）。
- **已下单（発注済）** — 明细反映到素材库存的预计入库（ATP）。每条明细会显示累计已入库数量。
- **入库完成（入荷完了）** — 点击「入库完成」按钮，将未入库的剩余数量一次性登记为素材入库并计入库存的状态。申请人・创建人会收到通知。
- **取消（キャンセル）** — 仅限下单前（草稿・审批中・已批准），需填写理由。

## 创建方式

有两种方式。

- **新建** — 从列表的「新建」进入。输入 **供应商**（必填）、下单日与备注，并添加至少一条明细（素材 × 入库工厂 × 数量・单位 × 单价 × 预计到货日）。金额（数量 × 单价）与合计由服务器端自动计算。
- **由采购申请转换** — 通过已批准采购申请的「转换为采购单」创建。明细以单价 0 日元继承，请在草稿状态下于编辑页面输入单价。

保存后跳转到详情页。仅草稿状态可编辑。

## 凭证

审批之后（已批准・已下单・入库完成），可在详情页的「凭证」标签中附加订单副本、送货单副本等文件。审批前无法附加。

## 列表与检索 / 详情页

- 列表列：采购单号 / 供应商 / 明细数 / 合计金额 / 状态 / 下单日。可用搜索框（采购单号、供应商）与状态筛选。
- 详情页包含 申请 → 审批 → 下单 → 入库完成 的步骤显示、审批记录（代理审批标注「（代理: 原审批人）」）、流转历史，以及标签页（明细 / 凭证 / 概要 / 历史）。由采购申请创建时还会显示到源申请的链接。

## 常见问题

**可以分批（部分）入库吗？** — 「入库完成」会一次性入库未入库的剩余数量。分批到货的部分请在[素材入库（PU01）](/manual/zh/apps/material-receipt/user)中直接登记。

**忘记填下单日了** — 若下单日为空时点击「下单」，执行下单的当天会自动成为下单日。

**想取消已下单的采购单** — 已下单・入库完成的采购单无法取消。仅下单前可以取消。
