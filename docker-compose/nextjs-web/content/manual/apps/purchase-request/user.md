操作コード **PU04**。素材発注書の前段となる「この素材を買ってほしい」という社内依頼を、依頼 → 承認 → 発注書へ変換 の流れで管理します。依頼番号は **PRQ-YYYYMM-NNNNN** です。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

素材の購買を承認付きで依頼するアプリです。依頼の段階では **仕入先と単価を決めません** — 何を・どの拠点へ・いくつ・いつまでに、だけを書いて承認に回します。

- 承認された依頼は「発注書へ変換」で[素材発注書（PU03）](/manual/ja/apps/purchase-order/user)（下書き）になります。仕入先は変換時に指定し、単価は発注書側で入力します。
- 承認依頼は[承認管理（PD03）](/manual/ja/apps/approval/user)にも横断表示され、承認グループのメンバー（または代理）が処理できます。
- 作成・編集には購買（発注）の権限が必要です。

![購買依頼一覧（依頼番号・依頼者・主要素材・状態の列と状態フィルタ）](../../assets/screenshots/purchase-request-list-01.png)

## 状態と流れ

- **下書き** — 作成直後。編集・キャンセルできます。「承認依頼」ボタンで承認フローへ。
- **承認依頼中** — 第一承認グループのメンバー（または代理）のみ「承認」「差し戻し」できます。
- **承認済** — 「発注書へ変換」できます。変換前ならキャンセルも可能です。
- **差し戻し** — 理由付きで差し戻された状態。詳細画面に理由が表示され、内容を編集して再度承認依頼できます。
- **発注済** — 発注書へ変換済み。詳細画面に変換先の素材発注書へのリンクが表示されます。
- **キャンセル** — 変換前の依頼（下書き・承認依頼中・承認済・差し戻し）を取り下げた状態。

キャンセルと差し戻しは、いずれも **理由の入力が必須** です。

## 作成方法

1. 一覧の「新規作成」を開き、**依頼理由**（任意）と **備考** を入力します。
2. 明細を追加します。1 行 = [素材](/manual/ja/masters/material/user) × 入荷先拠点 × 数量・単位（既定は「本」）× 希望納期（任意）。行ごとの備考も入力できます。単価の欄はありません。
3. 保存すると下書きになります。内容を確認して「承認依頼」を押すと承認フローが始まります。

編集できるのは下書き・差し戻しのときだけです。

## 発注書へ変換

1. 承認済の依頼の詳細画面で「発注書へ変換」を押します。
2. **仕入先** を選んで「変換する」を押すと、明細を引き継いだ素材発注書（下書き）が作成され、その画面へ移動します。
3. 単価は 0 円で複写されるため、発注書の編集画面で単価を入力してから発注の承認依頼を行ってください。

![購買依頼詳細（承認済 — 依頼→承認→発注書へ変換のステップ表示と「発注書へ変換」ボタン）](../../assets/screenshots/purchase-request-detail-01.png)

## 一覧・検索 / 詳細画面

- 一覧の列：依頼番号 / 依頼者 / 素材（先頭明細＋他 N 件）/ 明細数 / 状態 / 希望納期 / 更新日。検索（依頼番号・依頼者・素材）と状態で絞り込めます。
- 詳細画面には 依頼 → 承認 → 発注書へ変換 のステップ表示、承認記録（代理承認は「（代理: 原承認者）」付き）、遷移履歴、タブ（明細 / 概要 / 履歴）があります。

## よくある質問

**承認ボタンが出ません** — 承認・差し戻しできるのは第一承認グループのメンバー（または有効期間内の代理）だけです。グループは承認グループマスタで管理します。

**差し戻された依頼はどうなりますか？** — 状態が「差し戻し」になり、編集して再度「承認依頼」できます。作り直す必要はありません。
