操作码 **SA03**。创建并发行提交给[客户](/manual/zh/masters/customer/user)的报价单。单价与折扣会自动从价格表解析。

## 本应用能做什么

制作提交给客户的 **报价单** 并以 PDF 发行。在明细中输入[产品](/manual/zh/masters/product/user)・订单类型・数量后，单价与折扣会从 **价格表（SA02）** 自动填入。

- 单价按 客户 × 产品 × 订单类型 × 数量 从价格表的数量阶梯解析（基准单价 × 倍率，若阶梯有手动覆盖则用该值）。**报价单侧不能手动输入单价** — 要改价请在价格表侧设置。
- 价格表的 **折扣规则**（期间・数量条件）也会自动适用（多条符合时采用折扣额最大的规则）。
- 交期可按明细行设置。底部显示 小计・消费税（10%）・合计（含税）。

## 新建报价单

1. 点击列表的"新建"。
2. 选择 **客户**（必填。若有分店也可选择 **分店**）和 **有效期**（可选）。
3. 添加 **明细**。每行输入 **产品・订单类型・数量** 后，单价（价格表）・折扣（自动）・金额会自动显示。如有需要再输入 **交期**。
4. 该客户 × 产品没有价格表的行会显示"**无价格表**"且无法保存 — 请先登记[价格表](/manual/zh/apps/price-list/user)。
5. "保存"后以草稿（DRAFT）登记并进入详情页。

更换客户后，现有明细的单价・折扣会按新客户的价格表重新解析。保存时服务器侧也会重新解析并确定价格。

## 发行

- 在详情页菜单执行"**发行**"。在弹窗中确认有效期后点击"发行"，状态变为 **已发行（ISSUED）**，并 **生成・保存报价单 PDF**（可在 PDF 标签页查看・下载・重新生成）。
- 发行后要记录 **已接受（ACCEPTED）** / **已拒绝（REJECTED）** / **已过期（EXPIRED）**，请打开"编辑"更改"状态"栏后保存。若在[订单回执（SA04）](/manual/zh/apps/order-acceptance/user)的单据展开中指定了报价单编号，该报价单会自动变为已接受。
- "复制"可创建相同内容的草稿（保存时重新编号）。

![报价单详情（明细标签页）](../../assets/screenshots/quote-detail-01.png)

## 有效期

- 报价单可设置有效期（创建时・编辑时・发行弹窗中均可修改）。超过有效期后状态不会自动改变 — 如有需要请通过编辑改为 **已过期**。

## 列表与检索

- 列表显示 报价编号（QOT-YYYYMM-NNNNN）/ 客户 / 有效期 / 合计金额 / 状态 / 更新日。可按编号・客户搜索，按客户・状态筛选。
- 详情的"关联"标签页可查看适用价格表与试算来源的链接。"历史"标签页保留变更记录。
