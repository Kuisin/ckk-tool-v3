操作コード **SH01**。注文請書にもとづいて製品の出荷を記録する出荷書（SHP-YYYYMM-NNNNN）を作成・管理します。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

製造が完了した製品を出荷するときの **出荷書** を作る台帳です。出荷書は請求の起点になる書類で、ここから[納品書](/manual/ja/apps/delivery-note/user)を作成し、出荷済みの発送分は[締日処理](/manual/ja/apps/billing-closing/user)で請求書にまとまります。

- 注文請書を選ぶと、完了した[指示書](/manual/ja/apps/work-order/user)（ロット）から明細が自動で作られます。
- 出荷すると[製品在庫](/manual/ja/apps/product-inventory/user)から出庫され、注文請書の出荷状態（一部出荷 / 出荷済）も自動で更新されます。
- 操作には出荷書の権限（shipping_order）が必要です。

## 種別（発送と在庫保管）

- **発送**：顧客へ発送する通常の出荷です。出荷すると在庫から出庫され、請求の対象になります。
- **在庫保管**：予備製作分などを出荷せず在庫として保管する記録です。請求フロー外のため、注文請書の出荷状態は変わりません。出荷（確定処理）すると保管先の在庫へ入庫されます。

## 作成方法

1. 一覧の「新規作成」を押します。
2. **注文請書** を検索して選びます。完了済みの指示書（ロット）1 件につき明細 1 行（ロット = 指示書番号、数量 = 最終工程の良品数）が自動で入ります。
3. **種別**（発送 / 在庫保管）と **出荷元拠点** を選びます。
4. 明細（製品・ロット・数量・備考）は行の追加・削除・修正ができます。
5. 保存すると **下書き** として登録されます。注文請書は作成後に変更できません。

## 状態と操作

操作は詳細画面右上のメニューから行います。状態は 3 段階で進みます。

- **下書き（DRAFT）**：編集と **キャンセル**（削除）ができます。内容が固まったら **確定** します。
- **確定（CONFIRMED）**：編集できなくなり、納品書を作成できるようになります。実際に出荷したら **出荷** を押します。
- **出荷済（SHIPPED）**：出荷日が記録され、在庫の出庫と注文請書の出荷状態（一部出荷 / 出荷済）の更新が行われます。

- 発送の累計出荷数量が受注数量を超える出荷はエラーになります（過出荷ガード）。
- 出荷元の在庫が不足している場合も出荷できません。先に在庫をご確認ください。

## 納品書との連携

- 詳細画面の「納品書」タブで、この出荷書から作った納品書の一覧を確認できます。
- 確定後は同じタブの「納品書を作成」から[納品書](/manual/ja/apps/delivery-note/user)を作成できます。

## 一覧・検索

- 出荷書番号・注文請書番号・顧客・製品で検索でき、種別・状態で絞り込めます。
- 行をクリックすると詳細画面へ移動します。
