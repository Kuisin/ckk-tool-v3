操作コード **SY02**（試算計算）。試算アプリの計算ロジックを管理者が設定する専用アプリです。**system 権限** が必要です。

## メイン画面（ハブ）

メイン画面には 5 つのカードが並び、各セクションを選ぶと編集ページが開きます。

- **計算基準** … 見積単価を構成する基準の一覧・編集。
- **工具種管理** … 工具種の追加・削除と、種ごとの適用基準・見積単価の設定。
- **材料参照価格ポリシー** … 仕入実績の算出方法・参照期間・既定材料単価。
- **カスタム入力項目** … 見積入力とグローバル固定係数の定義。
- **ルックアップ表** … 径×全長マトリクスなど、式から参照する表。

![試算計算メイン画面（ハブ）](../../assets/screenshots/trial-pricing-hub-01.png)

## 計算基準

見積単価は **計算基準（criteria）の合計** で決まります。各基準は入力変数を使った JavaScript 式です。

「計算基準」を開くと、左に基準の一覧、右に選んだ基準の編集画面が並びます（モバイルでは一覧のみ）。一覧は **「計算基準（加算・中間）」** と **「見積単価（工具種ごとに設定）」** の 2 つに分かれ、基準名・ID で絞り込みできます。

- **基準を追加** … 一覧上部の「基準を追加」から新規作成ページを開きます。
- **並び替え** … 「並び替え」を押すとモーダルが開き、上下ボタンで順序を変えて「並び順を保存」します。基準は上から順に評価されます（加算基準の合計 → 見積単価）。
- **有効/無効・削除** … 一覧ではなく、各基準の編集画面で行います（「有効」スイッチ / 「削除」ボタン。削除は取り消せません）。

各基準の編集画面では次を設定します。

- **基準** … ID・基準名・役割・有効・適用工具種。役割は **加算（合計に足す）** / **中間（合計に含めず `r.<id>` で参照）** / **見積単価（最終。合計を見積単価に変換）** の 3 つです。
- **式** … 入力項目・カスタム入力・`quantity`・`subtotal`・`r.<id>` のほか、`round()`・`lookup()`・`lookupMatrix()` などのヘルパーが使えます。使える変数はエディタ横の一覧から確認・挿入できます。
- **テスト実行** … 「テスト工具種」を選んで「テスト実行」を押すと、その場で計算結果の表を確認できます。

![計算基準の編集](../../assets/screenshots/trial-pricing-criteria-01.png)

## 適用工具種

- 各基準に **適用工具種** を指定できます。
- **未選択 = どの工具種にも適用されません。** 全てに適用するには全て選択してください（既定は全選択）。

## 工具種管理

- **工具種の追加・削除** は「工具種管理」ページで行います。組み込み 3 種（丸棒 / 円筒 / OH付）は削除できません。
- 「工具種を追加」では **値**（英大文字・数字・`_`。例 `BALL_END`。作成後変更不可）と **表示名** を入力します。「全工具種」対象の基準は、追加した種にも自動で適用されます。
- カスタム工具種は **試算で未使用の場合のみ削除** できます（一覧に「計算基準 N 件 · 試算 M 件」の使用数が表示されます）。削除すると、すべての基準の適用対象からも外れます。
- 各工具種の編集画面では、その種に **適用する計算基準**（チェックした基準がその工具種の試算で評価されます）と **使用する見積単価**（final 基準。工具種ごとにちょうど 1 つ必要）を設定します。ここでの設定は各基準の「適用工具種」と同じデータの別ビューです。
- 追加した工具種は試算フォームで選択できます。計算入力は丸棒系（参照単価ベース）です。

## 材料参照価格ポリシー

試算の材料原価が参照する価格の決め方を設定します。

- **算出方法** … 最高単価（期間内）/ 最新単価 / 平均単価（期間内）から選びます。
- **参照期間（ヶ月）** … 仕入実績を参照する月数（1〜36）。
- **既定材料単価（¥/1000mm）** … 参照できる価格が無いときに使う既定の材料単価。0 にすると既定なし。既定値が使われた試算では「既定価格」と表示されます。

## カスタム入力項目

- 各項目で **キー（変数名）**・**ラベル**・**型**（数値 / ON/OFF / 文字列 / 選択）・**スコープ**・**既定値**（選択型は選択肢を `,` 区切りで指定）を設定します。「項目を追加」で増やせます。
- **スコープ** … **見積入力（フォームに表示）** は試算フォームに入力欄として表示されます。**グローバル定数（固定係数）** はフォームには出ない全社共通の固定値です。
- キーは計算基準の式で **変数** として使えます。予約語・重複キーは保存時に弾かれます。
- 従来の「既定値・係数」（補正値・LDチャージ・加工単価（¥/10分）・予備形状本数）は、グローバル定数の固定項目としてここに統合されました。これらはキー・型・スコープが固定で削除できず、値とラベルのみ変更できます。

## ルックアップ表

- 径×全長マトリクスのような参照表を定義し、計算基準の式から `lookup()` / `lookupMatrix()` で参照できます。
- 「表を追加」から作成し、各表で **表名・戻り値型・既定値（一致なし時）・キー列（一致 / 以上 / 以下）・行データ** を設定します。
- **CSV（Excel 互換）の取込・出力** に対応しています。
