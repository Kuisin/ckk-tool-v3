操作码 **SY02**（试算计算）。管理员配置试算应用计算逻辑的专用应用，需要 **`system` 权限**。

## 主界面（汇总页）

主界面显示 5 张卡片，选择板块即打开对应的编辑页面。

- **计算基准** … 构成报价单价的各基准的列表与编辑。
- **工具种类管理** … 工具种类的添加/删除，以及每种的适用基准与报价单价设置。
- **材料参考价格策略** … 采购实绩的计算方式、参考期间、默认材料单价。
- **自定义输入项目** … 试算输入项与全局固定系数的定义。
- **查找表** … 直径×全长矩阵等可在表达式中引用的表。

![试算计算主界面（汇总页）](../../assets/screenshots/trial-pricing-hub-01.png)

## 计算基准

报价单价由 **各计算基准（criteria）之和** 决定。每个基准是使用输入变量的 JavaScript 表达式。

打开“计算基准”后，左侧为基准列表，右侧为所选基准的编辑界面（移动端仅显示列表）。列表分为 **“计算基准（加算・中间）”** 与 **“报价单价（按工具种类设置）”** 两组，可按基准名・ID 筛选。

- **添加基准** … 通过列表上方的“添加基准”打开新建页面。
- **排序** … 点击“排序”打开弹窗，用上下按钮调整顺序后点“保存排序”。基准按从上到下的顺序求值（加算基准之和 → 报价单价）。
- **启用/停用・删除** … 不在列表上操作，而是在各基准的编辑界面进行（“启用”开关 / “删除”按钮。删除不可撤销）。

在基准编辑界面可设置：

- **基准** … ID・基准名・角色・启用・适用工具种类。角色分三种：**加算（计入合计）** / **中间（不计入合计，可用 `r.<id>` 引用）** / **报价单价（最终。将合计转换为单价）**。
- **表达式** … 可使用输入项、自定义输入、`quantity`、`subtotal`、`r.<id>`，以及 `round()`、`lookup()`、`lookupMatrix()` 等辅助函数。可用变量可在编辑器旁的列表中查看并插入。
- **测试运行** … 选择“测试工具种类”并点击“测试运行”，即可当场查看计算结果表。

![编辑计算基准](../../assets/screenshots/trial-pricing-criteria-01.png)

## 适用工具种类

- 每个基准可指定 **适用工具种类**。
- **未选择 = 不适用于任何工具种类。** 若要适用全部，请全选（默认全选）。

## 工具种类管理

- **工具种类的添加与删除** 在“工具种类管理”页面进行。内置 3 种（圆棒 / 圆筒 / 带OH）不可删除。
- “添加工具种类”需输入 **值**（大写字母・数字・`_`，如 `BALL_END`，创建后不可更改）与 **显示名**。以“全部工具种类”为对象的基准会自动适用于新添加的种类。
- 自定义工具种类 **仅在未被任何试算使用时可删除**（列表显示“计算基准 N 件 · 试算 M 件”的使用数）。删除后也会从所有基准的适用对象中移除。
- 在每个工具种类的编辑界面中，可设置该种类 **适用的计算基准**（勾选的基准会在该种类的试算中求值）与 **使用的报价单价**（final 基准，每个工具种类恰好需要 1 个）。此设置与各基准的“适用工具种类”为同一数据的不同视图。
- 添加的工具种类可在试算表单中选择，其计算输入采用圆棒方式（基于参考单价）。

## 材料参考价格策略

设置试算的材料成本如何确定参考价格。

- **计算方式** … 从 最高单价（期间内）/ 最新单价 / 平均单价（期间内）中选择。
- **参考期间（月）** … 参考采购实绩的月数（1〜36）。
- **默认材料单价（¥/1000mm）** … 没有可参考价格时使用的默认材料单价。设为 0 表示无默认。使用了默认值的试算会显示“默认价格”。

## 自定义输入项目

- 每个项目设置 **键（变量名）**・**标签**・**类型**（数值 / ON/OFF / 文本 / 选择）・**范围（scope）**・**默认值**（选择型以 `,` 分隔列出选项）。可用“添加项目”增加。
- **范围** … **试算输入（显示在表单上）** 会作为输入栏显示在试算表单中；**全局常量（固定系数）** 是不显示在表单上的全公司通用固定值。
- 键可作为 **变量** 在计算基准表达式中使用。保留字或重复键在保存时会被拒绝。
- 原“默认值与系数”（修正值、LD 费用、加工单价（¥/10分）、备用成型数量）已作为全局常量固定项目并入此处。它们的键・类型・范围固定且不可删除，只能修改值与标签。

## 查找表

- 可定义直径×全长矩阵等参考表，并在计算基准表达式中通过 `lookup()` / `lookupMatrix()` 引用。
- 通过“添加表”创建，并为每张表设置 **表名・返回值类型・默认值（无匹配时）・键列（一致 / 以上 / 以下）・行数据**。
- 支持 **CSV（Excel 兼容）导入・导出**。
