操作码 **SA01**。根据成本计算报价单价，并作为价格表基准单价来源的应用。

## 本应用能做什么

根据材料费、加工费、涂层费等 **成本**，自动计算"这个[产品](/manual/zh/masters/product/user)卖多少钱"。试算可按需关联到产品（1 个产品可有多条），**已确定的试算** 会成为创建价格表（客户×产品）时的 **基准单价来源**。

- **材料费** 会根据"**材种 × 直径 × 黑皮/研磨**"组合的采购实绩（参考单价，¥/1000mm）自动填入。没有采购实绩时，使用材种上登记的 **默认单价（¥/1000mm）**。
- 输入尺寸和加工条件后，画面下方的 **试算结果**（成本明细与报价单价）会即时重新计算。
- 数量阶梯的价格缩放不在试算中处理 — 试算只计算 **1 个基准单价**，数量阶梯在[价格表](/manual/zh/apps/price-list/user)侧用倍率设置。

![试算列表](../../assets/screenshots/trial-estimate-list-01.png)

## 新建试算

1. 点击列表右上角的"新建"。
2. 选择 **工具种**（内置 3 种：圆棒 / 圆筒 / OH；管理员在[试算计算（SY02）](/manual/zh/apps/trial-estimate/settings)中添加的工具种也会出现在这里）。输入项目随工具种变化。
3. 选择 **报价对象**（客户）和 **产品**（可选）。关联产品并确定后，创建价格表时即可选择此试算作为基准单价来源。
4. 选择材料的 **材种、直径、黑皮/研磨**。三项齐全后，会根据该组合的采购实绩（没有则用材种默认单价 — 显示"默认价格"徽标）自动填入 **参考单价（¥/1000mm）**。仅圆筒类型手动输入材料价格。
5. 输入尺寸与加工条件（最大径、全长、台阶加工、颈下加工、涂层、研磨处理、检验报告、LD、加工时间等）。如有管理员添加的 **自定义项目** 也一并输入。
6. 输入 **基准数量**（默认 100 支。仅用于分摊出形/备用形状费用）。
7. 最后输入 **试算名**（必填），点击"保存"。

![试算新建表单（基本・材料部分）](../../assets/screenshots/trial-estimate-new-01.png)

下方的 **试算结果**（每支成本明细、最低单价、报价单价（基准））会随输入即时重算。

## 覆盖参考单价

- 默认使用根据材种组合采购实绩计算的参考单价。没有采购实绩时填入材种默认单价（¥/1000mm），并显示 **默认价格** 徽标。
- 要手动修改单价，点击"**编辑单价**"。确认后输入框变为可编辑，该试算会记录为"**自定义**"（列表・详情显示徽标）。可随时通过"恢复策略值"还原为自动值。
- 在"**材料价格走势**"标签页可通过图表查看采购实绩走势，也可点击图表上的点采用该时点的单价（同样视为自定义）。

## 保存・确定・在价格表中使用

- **保存** 后登记为草稿（DRAFT），并将当时的价格记录为快照（之后更改计算设置也不会影响此试算）。保存后不能再编辑 — 修改内容请使用"**复制并重新试算**"。
- 在详情页菜单中 **确定** 后，创建・编辑价格表（SA02）时即可将其选为 **基准单价来源**（**前提是已关联产品**。也可通过详情菜单的"关联产品"设置）。
- 首次被价格表使用后锁定为 **已登记价格表（REGISTERED）**，产品关联也不能再更改（重新试算请用"复制并重新试算"）。已登记的试算仍可继续被其他客户的价格表选为来源。

![试算详情（已登记价格表）](../../assets/screenshots/trial-estimate-detail-01.png)

## 列表与检索

- 列表显示 试算编号 / 名称 / 客户 / 工具种 / 材种 / 代表报价单价 / 状态 / 更新日。可按编号・名称・客户搜索，按状态・工具种筛选。
- 点击行可查看详情（试算结果・材料价格走势・关联・历史）。行菜单可执行"复制并重新试算"。
- 状态为 **草稿**（灰）→ **已确定**（蓝）→ **已登记价格表**（绿）三种。
