操作コード **PD02**。製造現場への作業指示（指示書）を作成し、承認から工程の実行・完了までを管理します。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

指示書は「この注文請書の製品を、この工程の並びで、何本作るか」を決める文書です。指示書番号は通し連番で、そのまま **ロット番号** になります。

- 注文請書を選び、製品の **工程リスト**（工程ルート）をもとに工程の並びを組み立てて作成します。
- 作成後に **承認依頼** を出し、第一承認 → 第二承認を経て製造を開始できます。
- 各工程は **工程実行画面** で開始・数量入力・完了を記録します。工程ごとに **作業計画・実績**（担当者・日付・時刻・数量・作業場所）も記録できます。
- 全工程が完了すると、良品がロット番号付きで入庫されます。在庫は [在庫管理](/manual/ja/apps/product-inventory/user)（PD04）で確認でき、製造中の数量は同アプリの **仕掛品** タブに表示されます。

指示書のもとになる **注文請書** は `/production/sales-orders` で管理します（[受注請書](/manual/ja/apps/order-acceptance/user) の取込画面から開けます）。注文請書の詳細では、確定・在庫照合（在庫の引当予約）・キャンセルができ、在庫が足りない分はそのまま指示書の作成に進めます。

![指示書一覧 — 種別・承認状態・状態のバッジが並ぶ](../../assets/screenshots/work-order-list-01.png)

## 作成方法

1. 一覧の「新規作成」を開きます（注文請書詳細からも、その注文請書を選択済みの状態で開けます）。
2. **注文請書** を検索して選びます（注文請書番号・製品・顧客で検索）。選択すると顧客・製品・受注数量が表示されます。
3. **種別**（在庫分 / 製造分）と **予定数量** を入力します。予定数量には「最低 n（不良予備分は上乗せ可）」の最低ライン（在庫フロア）が表示され、充足・不足がその場で分かります。
4. 製造分の場合は **使用素材** を選びます。素材の充足状況（ATP）が表示され、不足時は次回入荷予定、入荷予定もない場合は「素材発注を検討してください」と警告されます — いずれも警告のみで、保存はブロックされません。
5. **検査表** を必要に応じて選びます（工程を追加すると関連する検査表が自動で選択されます）。
6. **工程リスト** を選びます（下記参照）。
7. 社内・外注どちらも可能な工程は、**実施場所**（社内 → 拠点 / 外注 → 外注先）と作業時間を指定します。
8. 保存すると **下書き** の指示書ができ、詳細画面へ移動します。編集できるのは下書きの間だけです。

![指示書 新規作成 — 基本情報と工程リスト](../../assets/screenshots/work-order-new-01.png)

### 工程リスト（製品の工程ルート）

工程の並びは製品ごとに **工程リスト** として登録・バージョン管理されます。

- 注文請書を選ぶと工程リストのセクションが表示され、その製品に工程リストがあれば **先頭のリストの最新バージョンが自動で選択され、工程がプリフィル** されます。リストと **バージョン**（`vN（登録日）`、既定は最新）は選び直せます。
- 工程リストが未登録の製品では「この製品の工程リストは未登録です（下で新規作成）」と表示されるので、**新しい工程リスト名**（例: 標準工程）を入力します — 保存時に v1 として登録されます。
- 選んだバージョンから工程構成を変更すると「保存時に新バージョン v{n+1} として保存されます」という案内が出ます。指示書の詳細には使用した工程ルート（「ルート名 vN」）が表示され、製品マスタの工程リストへリンクします。

工程はカタログのカテゴリ別チェックリストから選択します。前提工程が足りない組み合わせは赤い警告（ブロッカー）が出て保存できません（「工程構成にエラーがあります」）。必須の随伴工程は自動的に追加されます。

## 状態と承認フロー

指示書の状態は **下書き → 承認待ち → 承認済 → 進行中 → 完了**（またはキャンセル）と進みます。

- **承認依頼** … 下書きの詳細画面から実行します。承認待ちになり、対象の注文請書は編集ロックされます。
- **第一承認**（工場長・部長クラス）→ **第二承認**（部長クラス） … 各承認グループのメンバー（または期間内の代理者）だけが承認・差し戻しできます。メンバーでない場合はその旨のメッセージが表示されます。承認状況は詳細画面のステッパーで確認できます。
- 第二承認が済むと指示書は **承認済** になり、工程を開始できます。製造分は使用素材が自動で **予約** されます。
- **差し戻し** … 理由の入力が必須です。指示書には差し戻し理由が赤い警告で表示され、下書きに戻って修正後に「再承認依頼」できます。
- 承認状況パネルの下部には **承認記録**（段階・承認 / 差し戻し・承認者・日時・コメント）が残ります。代理で承認した記録には「（代理: 原承認者）」が付きます。

承認操作は [承認管理](/manual/ja/apps/approval/user)（PD03）の一覧からも対象を開いて行えます。

## 工程の実行

詳細画面の「工程ワークフロー」に工程が並びます。指示書が承認済・進行中のときは「**工程実行ビューを開く**」から実行画面（左に工程ナビ、右に実行画面のスプリットビュー）を開けます。承認前は「工程実行は指示書の承認後に可能になります」と表示されます。

1. **工程開始** … 前の工程が完了していれば押せます。開始できない理由（依存工程が未完了、指示書が未承認など）は画面に表示されます。開始すると自分の **セッションロック** がかかり、他のユーザーには「完了または中断されるまで操作できません」と表示されます。
2. **数量の入力** … 入力欄は工程の **数量管理モード** で変わります。
   - **通常の工程** … **受入数**（前工程の良品数が自動で入ります）、**良品数**、不良の内訳（**半製品** / **廃棄** / **手直し**）を入力します。
   - **検査工程** … **検査数**・**合格数**・不合格の内訳（半製品 / 廃棄 / 手直し）として入力します。
   - **数量記録なしの工程** … 数量入力はなく、「この工程は数量記録なしで完了します（通過数 n）」と表示されてそのまま完了できます。
   - いずれも「良品（合格）+ 不良の合計 = 受入数（検査数）」が合わないと保存できません。
3. **検査工程** では検査表の項目ごとに実測値を記録します。合否は項目の型に応じて自動判定され、抜取検査ではサンプル数の規則が適用されます。検査承認工程では、合格した検査記録を承認できます。
4. **不良記録** … 不良種類と内容を任意で記録できます（[不良種類](/manual/ja/masters/defect-type/user) から選択）。
5. **作業計画・実績** … 工程ごとに担当者・日付・時刻・数量・作業場所を計画として登録し、実績を記録できます。
6. **工程完了** … 数量を確定して次の工程に進めます。

外注工程では **依頼日・入荷予定日・入荷日・外注費** を記録できます。

- **中断（巻き戻し）** … 進行中の工程を理由付きで未着手に戻します。
- **巻き戻し** … 完了済みの工程を未着手に戻します。後続工程が着手済みの場合や、在庫計上済みの場合は巻き戻せません。

## 分岐（手直し・再投入）

完了した工程からは **分岐追加** ができます。追加する工程の系列・流す数量・合流先（未着手の工程）を指定すると、手直し分などを別系列で流せます。分岐がある指示書は、工程ワークフローの上部に分岐図（DAG）が表示されます。

## 完了と在庫

全工程が完了すると指示書は自動的に **完了** になり、最終工程の良品がロット番号付きで製品在庫に入庫されます。半製品に振り分けた分は半製品在庫として入庫されます。予約していた素材は消費（出庫）されます。

## 一覧・検索・その他の操作

- 一覧は 指示書番号 / 注文請書番号 / 製品 / 種別（製造分・在庫分バッジ）/ 予定数量 / 承認状態 / 状態 / 更新日 を表示します。指示書番号・注文請書番号・製品で検索でき、種別・状態で絞り込めます。
- **編集** … 下書きのみ。**キャンセル** … 下書き・承認待ちのみ。
- **コピー** … 対象の注文請書を選んで、工程・実施場所・検査表を引き継いだ下書きを作成します。コピー元は詳細に記録され、より新しい版がある場合は「最新版のコピーを検討してください」と警告が出ます。
- 詳細のタブは **概要**（工程ワークフロー + 備考）/ **関連**（注文請書・コピー関係）/ **履歴**（変更履歴）です。

このアプリの利用には指示書（work_order）の権限が必要です。
