操作代码 **PD02**。创建面向生产现场的作业指示（指示書），并管理从审批到工序执行、完成的全过程。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

指示書用来规定"针对这份订单回执（注文請書）的产品，按什么工序顺序、生产多少支"。指示单编号为全局连续编号，同时就是**批次（Lot）编号**。

- 选择注文請書，基于产品的**工序清单**（工序路线）组装工序顺序后创建。
- 创建后提交**审批申请**，经第一审批 → 第二审批后即可开始生产。
- 每道工序在**工序执行画面**中进行开始、数量录入和完成操作。每道工序还可记录**作业计划・实绩**（负责人・日期・时间・数量・作业场所）。
- 全部工序完成后，良品带批次编号入库。库存在[库存管理](/manual/zh/apps/product-inventory/user)（PD04）中查看，生产中的数量显示在该应用的**在制品**标签页。

作为指示書来源的**注文請書**在 `/production/sales-orders` 中管理（可从[订单受理（受注請書）](/manual/zh/apps/order-acceptance/user)的导入画面打开）。在注文請書详情页可以执行确认、库存核对（对可用产品库存做预约分配）、取消等操作，库存不足的部分可直接转入指示書的创建。

## 创建方法

1. 从列表点击"新規作成"（新建）打开（也可从注文請書详情页打开，此时该注文請書已预先选中）。
2. 搜索并选择**注文請書**（可按注文請書编号・产品・客户搜索）。选中后会显示客户・产品・订单数量。
3. 输入**类别**（在庫分 库存供货 / 製造分 生产供货）和**计划数量**。计划数量栏会显示"最低 n（不良预备可上浮）"的最低线（库存底线），并即时提示是否充足。
4. 选择製造分时需选择**使用素材**。素材的可用状况（ATP）会即时显示 — 不足时显示下次到货计划，若没有到货计划则提示"请考虑订购素材"。这些都只是警告，不会阻止保存。
5. 按需选择**检查表**（添加工序时会自动选中相关检查表）。
6. 选择**工序清单**（见下文）。
7. 对既可内制也可外协的工序，指定**实施地点**（内制 → 工厂 / 外协 → 外协厂商）和作业时间。
8. 保存后生成**草稿**状态的指示書并进入详情页。只有草稿状态可以编辑。

### 工序清单（产品的工序路线）

工序顺序按产品以**工序清单**的形式登记并进行版本管理。

- 选中注文請書后会显示工序清单栏。若该产品已有工序清单，**会自动选中第一个清单的最新版本并预填工序**。清单和**版本**（`vN（登记日）`，默认最新）都可以重新选择。
- 若该产品尚无工序清单，会显示"该产品的工序清单未登记（在下方新建）"，此时输入**新工序清单名称**（例：標準工程），保存时将登记为 v1。
- 若在所选版本的基础上更改了工序构成，会提示"保存时将另存为新版本 v{n+1}"。指示書详情会显示所用的工序路线（"清单名 vN"），并链接到产品主数据的工序清单。

工序从按类别分组的目录清单中勾选。缺少前置工序的组合会显示红色警告（阻断项）且无法保存（"工序构成存在错误"）。必需的随附工序会自动添加。

## 状态与审批流程

指示書的状态依次为 **下書き（草稿）→ 承認待ち（待审批）→ 承認済（已审批）→ 進行中（进行中）→ 完了（完成）**，或 キャンセル（取消）。

- **承認依頼（提交审批）** … 在草稿的详情页执行。指示書进入待审批状态，对应的注文請書会被锁定、禁止编辑。
- **第一承認**（厂长・部长级）→ **第二承認**（部长级）… 只有各审批组的成员（或有效期内的代理人）才能审批或驳回。非成员会看到相应提示。审批进度可在详情页的步骤条中查看。
- 第二审批通过后指示書变为**已审批**，即可开始工序。製造分会自动**预约**所需素材。
- **差し戻し（驳回）** … 必须填写理由。驳回理由会以红色警告显示，指示書退回草稿，修改后可"再承認依頼"（重新提交审批）。
- 审批状态面板下方保留**审批记录**（阶段・审批/驳回・审批人・时间・备注）。代理审批的记录会标注"（代理: 原审批人）"。

审批操作也可以在[审批管理](/manual/zh/apps/approval/user)（PD03）的列表中打开对象后进行。

## 工序执行

详情页的"工程ワークフロー"（工序工作流）面板列出各工序。指示書处于已审批・进行中状态时，可通过"打开工序执行视图"进入执行画面（左侧工序导航、右侧执行画面的分栏视图）。审批前会提示"工序执行需在指示書审批后进行"。

1. **工程開始（开始工序）** … 前置工序完成后即可点击。无法开始时会显示原因（如依赖工序未完成、指示書尚未审批等）。开始后会获得本人的**会话锁**，其他用户会看到"在完成或中断之前无法操作"的警告。
2. **数量录入** … 输入项随工序的**数量管理模式**而变化。
   - **普通工序** … 输入**接收数**（自动带入上一工序的良品数）、**良品数**，以及不良明细（**半成品** / **报废** / **返工**）。
   - **检查工序** … 以**检查数**・**合格数**・不合格明细（半成品 / 报废 / 返工）的形式录入。
   - **不记录数量的工序** … 无数量输入，画面显示"此工序不记录数量即可完成（通过数 n）"，可直接完成。
   - 无论哪种模式，"良品（合格）+ 不良合计 = 接收数（检查数）"不平衡时无法保存。
3. **检查工序**中按检查表逐项记录实测值。合格与否按项目类型自动判定，抽检时按抽样规则确定样本数。检查审批工序中可对合格的检查记录进行审批。
4. **不良记录** … 可随时记录不良类别和内容（从[不良类别](/manual/zh/masters/defect-type/user)中选择）。
5. **作业计划・实绩** … 每道工序可登记计划的负责人・日期・时间・数量・作业场所，并记录实绩。
6. **工程完了（完成工序）** … 确定数量并交接到下一工序。

外协工序可记录**委托日、预计到货日、到货日、外协费用**。

- **中断（回退）** … 将进行中的工序连同必填理由退回未开始状态。
- **巻き戻し（回退已完成工序）** … 将已完成的工序退回未开始状态。若后续工序已开始，或库存已入账，则无法回退。

## 分支（返工・再投入）

在已完成的工序上可以**添加分支**：指定要追加的工序系列、流转数量、汇合目标（未开始的工序），即可让返工件等走另一条支线。含分支的指示書会在工序工作流上方显示分支图（DAG）。

## 完成与库存

全部工序完成后，指示書自动变为**完成**：末端工序的良品带批次编号入库到产品库存，划分为半成品的数量作为半成品库存入库，已预约的素材被消耗（出库）。

## 列表・搜索・其他操作

- 列表显示 指示单编号 / 注文請書编号 / 产品 / 类别（生产供货・库存供货徽章）/ 计划数量 / 审批状态 / 状态 / 更新日。可按指示单编号、注文請書编号、产品搜索，并可按类别、状态筛选。
- **编辑** … 仅限草稿。**取消** … 仅限草稿・待审批。
- **复制** … 选择目标注文請書，创建一份继承工序・实施地点・检查表的草稿。复制来源会被记录，若已存在更新的版本会提示"建议复制最新版本"。
- 详情的标签页为 **概要**（工序工作流 + 备注）/ **关联**（注文請書・复制关系）/ **历史**（变更记录）。

使用此应用需要指示書（work_order）权限。
