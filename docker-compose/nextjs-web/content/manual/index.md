CKK 業務管理システムの使い方をまとめた公開マニュアルです。左のサイドバー、または検索（サイドバーの検索ボタン / ⌘K。アプリ名・操作コードで検索できます）からページを開いてください。

## はじめての方へ

- [スタートマニュアル](/manual/ja/start) — ログインから最初の業務までの入門ガイド
- [マニュアルの使い方](/manual/ja/using-docs) — このマニュアル自体の読み方・検索のコツ
- [ユーザー設定](/manual/ja/user-settings) — プロフィール・通知・ホーム画面のカスタマイズ

## 内容

- **操作方法** — 画面ごとの操作手順と、入力欄の意味。販売・購買・生産・出荷・請求・マスタ・システム・現場タブレットのカテゴリ別に並んでいます
- **プロセス** — 受注から出荷までの業務の流れと、その各段階でどのアプリを使うか。一つの注文を試算から請求まで通しで追う [標準フロー](/manual/ja/process/default-flow) から読み始められます
