タブレットの「**工程実行**」で、自分に割り当てられた作業を確認し、開始・完了を記録します。

## このアプリでできること

- 今日やる作業（工程）の一覧を確認できます。
- 作業の **開始・一時停止・再開・完了** を記録できます。
- 何本受け取って、何本良品になったかを入力できます。
- 不良が出たときは、種類と本数を残せます。
- 検査工程では、測った値と合否を記録できます。

## 用語（このページで出てくる言葉）

- **指示書（しじしょ）** … 「どの製品を何本作るか」の作業指示です。`#9001` のような番号が付きます。
- **受入数（うけいれすう）** … その工程に入ってきた本数です。
- **良品数（りょうひんすう）** … 問題なく次の工程へ渡せる本数です。
- **前工程待ち** … 前の作業が終わっていないため、まだ始められない状態です。

## 画面の見かた

作業は 3 つのまとまりに分かれて表示されます。

![今日の作業一覧](../../assets/screenshots/kiosk-steps-01.png)

- **遅延** … 予定日を過ぎている作業です。まずここから片付けます。
- **本日** … 今日の予定です。
- **予定** … 先の日付の作業です。

各カードには、指示書の番号・拠点・工程名・製品名・割り当て本数が並びます。右上のラベルは今の状態です。

- **開始可** … すぐ始められます。
- **前工程待ち** … 前の作業がまだ終わっていません。始められません。
- **作業中** … いま作業している最中です。
- **一時停止中** … 中断しています。「再開」で続きから始められます。
- **完了** … 終わった作業です。

> 💡 完了した作業は「**完了した工程を隠す**」で一覧から隠せます。表示件数が多いときに使ってください。

## 作業を始める

1. 一覧から、始めたい作業のカードを押します。
2. 画面下の「**工程開始**」を押します。
3. 「工程を開始」の画面で **受入数**（その工程に入ってきた本数）を確認します。前の工程から引き継いだ数が最初から入っています。
4. 実際の数と違う場合は数字を直します。
5. 「**開始する**」を押します。

![工程の画面](../../assets/screenshots/kiosk-step-detail-01.png)

開始すると状態が「作業中」に変わり、作業時間の計測が始まります。

> ⚠️ 同時に作業できる工程は **1 つだけ** です。ほかの工程を始めたいときは、今の工程を「一時停止」か「完了」にしてください。画面に「他工程を作業中」と出ているときは、「**作業中の工程へ**」で戻れます。

## 途中でやめる・再開する

- 昼休みなどで中断するときは「**一時停止**」を押します。作業時間の計測が止まります。
- 続きを始めるときは「**再開**」を押します。

一時停止しても、それまでの作業時間は残ります。何回でも止めたり再開したりできます。

## 作業を終える

1. 画面下の「**工程完了**」を押します。
2. 「工程を完了」の画面で **良品数**（次に渡せる本数）を確認します。
3. 不良が出たときは「**不良を追加**」を押し、**種別**（半製品・廃棄・手直し）と **本数** を入れます。必要なら理由も選べます。
4. 「**完了する**」を押します。

良品数は、受入数から不良の合計を引いた数が **自動で計算** されます（「自動計算」と表示されます）。

> ⚠️ 不良の合計が受入数より多いときは「**不良の合計（n）が受入数（n）を超えています**」と表示され、完了できません。本数を見直してください。

## 検査の工程

検査の工程では、完了する前に検査記録を入力します。

1. 「**検査記録**」の欄に、「**検査数**」と「**合格数**」を入れます。
2. 項目ごとに **実測値** を入力します。合格・不合格は、決められた範囲に入っていれば **自動で判定** されます。
3. 自動で判定できない項目は、自分で「合格」「不合格」を選びます。
4. 「**検査記録を保存**」を押します。

## よくある質問・困ったとき

**Q. 一覧に何も出ません。**
A.「**本日の担当工程はありません**」と表示されている場合、今日あなたに割り当てられた作業がありません。割り当ては事務所（指示書の担当者）が行います。

**Q.「前工程待ち」で始められません。**
A. 前の工程がまだ完了していません。前の作業をしている人が終わらせると始められるようになります。

**Q. 「工程開始」のボタンが押せません。**
A. ほかの工程を作業中の可能性があります。画面上部の「他工程を作業中」を確認し、先にその工程を一時停止か完了にしてください。

**Q. 受入数が実際と違います。**
A. 開始のときに数字を直してください。前の工程から引き継いだ数が初期値として入っているだけなので、実際に受け取った本数に合わせて問題ありません。

**Q. 間違えて完了してしまいました。**
A. タブレットからは取り消せません。事務所の担当者に連絡してください（パソコン側で対応します）。

**Q. 途中で画面が閉じてしまいました。**
A. 記録は残っています。もう一度ログインして同じ工程を開けば、「作業中」のまま続きから操作できます。
