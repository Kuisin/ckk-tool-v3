操作コード **MS09**。製造中に発生した不良を記録するときの分類（キズ・欠け・寸法不良など）を登録・管理する小さなマスタです。ここで登録した種類は、[指示書](/manual/ja/apps/work-order/user) の工程実行画面の不良記録で選択肢になります。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 不良種類（コード・名称・表示順）を登録します。
- コードと名称と表示順だけのシンプルなマスタのため、**詳細ページはありません**。編集は一覧のモーダル（小窓）で行います。

利用には **マスタ権限** が必要です。

## 一覧を見る

- 一覧の列は **コード / 名称 / 表示順 / 状態** です。既定では **表示順** で並びます。
- 行をクリックすると **編集モーダル** が開きます（詳細ページには移動しません）。
- 上部の検索ボックスに **コード・名称** を入れて絞り込めます。**状態**（有効 / 無効）でも絞り込めます。
- 行を選択すると **一括有効化 / 一括無効化 / 一括削除** ができます。

## 新規作成

一覧右上の「新規作成」から登録します。

- **コード** … 不良種類を識別する一意のコード（例 `SCRATCH`）。**作成後は変更できません**。
- **名称**（日本語は必須、英語は任意）。
- **表示順** … 0 以上の整数。一覧と、工程実行画面の不良入力での並び順です。
- **有効** … オフにすると選択肢に出なくなります。

保存すると一覧に戻ります。

## 編集

- 一覧の行クリック、または行メニューの **編集** でモーダルが開きます。名称・表示順・有効を変更できます（コードは変更不可）。
- 行メニューから **無効化 / 有効化**、**削除** もできます。

## 削除と無効化

- 使わなくなった種類は削除ではなく **無効化** をおすすめします（選択肢に出なくなり、過去の記録は残ります）。不良記録から参照されている種類は削除できないことがあります。

## 用語

- **不良種類** … 不良を分類するためのラベル。工程での不良記録に使います。
- **表示順** … 選択肢・一覧での並び順。小さい数字ほど上に表示されます。
