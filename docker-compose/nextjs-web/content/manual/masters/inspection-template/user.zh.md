操作代码 **MS09**。登记和管理检查工序中使用的检查项目模板。将模板关联到[作业指示书（指示書）](/manual/zh/apps/work-order/user)后，即可按其检查项目记录检查结果。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

- 登记检查表模板（代码、名称、关联工序、检查对象、记录方式）。
- 为每个模板登记**检查项目**。项目有**输入种别**（是非 / 数值 / 单选 / 多选），并可设置**合格标准**和**目标**。检查项目在详情页面的「检查项目」标签页中直接添加、编辑、删除（项目没有单独页面）。
- 模板受**版本管理**。被作业指示书或检查记录使用中的版本会被锁定，需通过「创建新版本」进行修订。
- 可输出用于手写记录的**空白检查表 PDF**。

使用此应用需要**主数据权限**。

![检查表模板列表](../../assets/screenshots/master-inspection-template-list-01.png)

## 查看列表

- 列表的列为**代码 / Ver / 名称 / 关联工序 / 项目数 / 状态**。**Ver** 列显示最新版本（例 `v2`），存在多个版本时还会併记「全N」。点击行可打开详情页面。
- 在顶部搜索框输入**代码、名称或关联工序**即可筛选。也可按**状态**（有效 / 无效）筛选。
- 勾选行后可进行**批量启用 / 批量停用 / 批量删除**。

## 新建

从列表右上角的「新建」进行登记。

- **代码** … 由字母、数字、连字符和下划线组成（例 `INSP-DIM-01`）。代码唯一，**创建后不可更改**。
- **名称**（日语必填，英语可选）。
- **关联工序** … 默认使用此模板的检查工序（可选）。可在[工序主数据（工程マスタ）](/manual/zh/masters/process-step/user)中按代码、名称搜索选择。
- **检查对象** … 此检查表要检查的产品数量，从「**全数**」「**比例(%)**」「**支数**」中选择。全数为检查整个批次，比例、支数为抽取一部分检查（比例 0〜100%，支数 1 以上）。
- **记录方式** … 「**实测值（按产品）**」为按产品逐页记录全部项目；「**仅合格数**」为按项目只记录检查数和合格数。
- **有效** … 关闭后将不再出现在选择项中。

检查项目不在此表单中输入。保存后在详情页面的「检查项目」标签页中添加。

## 登记检查项目

在详情页面的**检查项目**标签页点击「添加项目」进行登记。已有项目通过行内的编辑、删除图标操作。项目列表的列为**项目名 / 种别 / 合格标准 / 目标 / 必填 / 显示顺序**。

![检查表模板详情（检查项目标签页）](../../assets/screenshots/master-inspection-template-items-01.png)

每个项目需设置**项目名**（日语必填，英语可选）和**输入种别**。各种别的设置如下。

- **数值** … **单位**（例 mm）和**合格范围**（下限、上限。也可只指定一侧，上限不得低于下限）。**目标值**为期望值，不影响合格与否的判定。
- **是非（是/否）** … **判为合格的回答**（是 / 否）和**目标回答**（可选）。
- **单选 / 多选** … **选择项**（以日语、英语登记显示名）和**判为合格的选择项**（未设置时需手动判定合格与否），以及**目标**（可选）。

通用设置如下。

- **允许手动覆盖合格判定** … 关闭后仅按合格标准自动判定（未设置标准的项目始终为手动判定）。关闭覆盖的项目在列表中会显示「不可覆盖」徽章。
- **显示顺序** … 在检查表中的排列顺序。添加时默认值为「现有最大值 + 10」。
- **必填 / 可选** … 记录检查时是否必须输入。

## 版本管理

- 模板的某个版本一旦被作业指示书或检查记录使用，该版本即被**锁定**、无法更改（详情页面会显示锁定提示，「编辑」也会隐藏）。
- 需要修改内容时，从菜单执行「**创建新版本**」。系统会复制检查项目生成新版本（v2、v3、…），已有的作业指示书、检查记录仍停留在旧版本上。
- **版本**标签页显示全部版本的列表（版本 / 项目数 / 使用状况（使用中 / 未使用）/ 状态 / 更新时间）。当前显示的版本会标注「（显示中）」。

## 空白检查表 PDF

通过详情页面的「**空白检查表**」按钮，可输出按该模板的检查项目排版、供手写记录用的 PDF。

## 详情页面

- 顶部摘要显示代码、版本（例 `v2（最新）`）、名称、关联工序、检查对象、记录方式、检查项目数和状态。
- 标签页为**模板信息**（名称、关联工序）/ **检查项目**（项目子表）/ **版本**（版本列表）/ **历史**（变更记录；项目的添加、修改、删除也会记录在此）。
- 右上角有**编辑**（锁定时隐藏）和**空白检查表**按钮，菜单中有**创建新版本** / **停用** / **删除**。

## 删除与停用

- 存在引用该版本的作业指示书、检查记录时无法删除。不再使用的模板建议**停用**而非删除。
- 删除模板时，其检查项目也会一并删除。

## 术语

- **检查表模板（検査表テンプレート）** … 检查项目的模板，关联到作业指示书用于检查记录。
- **版本** … 模板的修订单位。使用中的版本会被锁定，修订以新版本进行。
- **检查对象** … 此检查表要检查的产品数量（全数 / 比例 / 支数抽检）。
- **记录方式** … 按产品记录实测值，或仅记录合格数。
- **合格标准** … 自动判定合格的条件（数值的合格范围、是非的合格回答、选择式的合格选择项）。
- **目标** … 期望值、期望回答。不影响合格与否的判定。
