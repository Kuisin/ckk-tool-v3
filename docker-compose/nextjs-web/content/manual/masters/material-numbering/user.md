操作コード **MS0C**。[材種](/manual/ja/masters/material-type/user) コードと [素材](/manual/ja/masters/material/user) コードを組み立てる「部品」（構成要素）を管理する画面です。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

材種コードは `[メーカー][メーカー材種2桁][形状][種類4桁]`、素材コードは `[材種]-[黒皮研磨][径×10 3桁]-[全長3桁]` という決まりで組み立てられます。この画面では、その部品となる 7 つの区分をタブで一覧・追加・有効/無効切替します。

- **メーカー** … 材料メーカー（英大文字1文字。例 `B` = AFC）。
- **メーカー材種** … メーカー内のグレード（メーカーごとに数字2桁。例 `01` = K10UF）。
- **形状** … 通常 / OH / 円筒 など（英大文字1文字）。
- **種類** … 形状ごとの種類（英数字2桁。例 OH 形状の `B5` = CH）。
- **黒皮・研磨** … 素材表面の区分（英大文字1文字。例 `A` = 黒皮、`B` = 研磨）。
- **直径** … 直径 mm から自動導出される3桁コード（径 × 10。例 φ8.3 → `083`）。
- **全長** … 全長 mm の3桁コード（例 330mm → `330`）。カスタム識別を付けられます。

![採番構成（メーカータブ）](../../assets/screenshots/master-material-numbering-01.png)

## 一覧を見る

- タブで区分を切り替えます。各タブの列は **コード / 名称 / 状態 / 更新日** です（メーカー材種には **メーカー** 列、種類には **形状** 列、直径・全長には **mm** 列が付きます）。
- 行メニューから **有効化 / 無効化** を切り替えられます。

## 追加する

右上の「◯◯を追加」ボタン（表示中のタブに合わせて変わります）から追加します。

- メーカー / 形状 / 黒皮・研磨 … **コード**（英大文字1文字）と **名称**（日本語は必須、英語は任意）。
- メーカー材種 … **メーカー** を選び、**コード**（数字2桁）と **名称**。
- 種類 … **形状** を選び、**コード**（英数字2桁）と **名称**。
- 直径 … **直径 (mm)**（0.1〜99.9）。コードは自動で導出され、入力欄の下に表示されます。
- 全長 … **全長 (mm)**（1〜999）と **カスタム識別**（任意。例「特注 330L」）。

同じコードが既にあると追加できません。

## 削除できない理由と無効化

- コードは材種・素材のコードに **埋め込まれる** ため、**削除はできません**（無効化のみ）。
- 無効化すると、新しい材種・素材の作成で選べなくなります。**既存の材種・素材コードには影響しません。**
- 直径・全長は、[素材](/manual/ja/masters/material/user) の新規作成時にも未登録なら自動で登録されます。ここで手動追加するのは、あらかじめ選択肢を用意したい場合や名称を整えたい場合です。

## 用語

- **材種コード** … メーカー＋メーカー材種＋形状＋種類の 8 文字（例 `B01B0001`）。
- **素材コード** … 材種コードに黒皮研磨・直径・全長を付けた形（例 `B01B0001-A083-330`）。
- **構成要素** … コードを組み立てる部品となる区分の値。

このアプリの利用には **マスタ権限** が必要です。初めての方は [スタートマニュアル](/manual/ja/start) もあわせてご覧ください。
