操作コード **MS04**。素材の種類（材種）を登録・管理する台帳です。[製品](/manual/ja/masters/product/user) の素材仕様や [素材](/manual/ja/masters/material/user) の登録、[試算](/manual/ja/apps/trial-estimate/user) の材料原価計算は、ここで登録した材種を使います。

## このアプリでできること

「どのメーカーの、どのグレードの、どんな形の材料か」を **材種コード** で管理します。

- 材種を登録すると、製品・素材・試算で選べるようになります。
- 材種ごとに **既定単価**（試算のフォールバック材料単価）を設定できます。

## 材種コードのしくみ

材種コードは 4 つの部品を並べた 8 文字です（例 `B01B0001`）。

- **メーカー**（1文字目、英大文字1文字）… 材料メーカー。例 `B` = AFC。
- **メーカー材種**（2〜3文字目、数字2桁）… メーカー内のグレード。例 `01` = K10UF。
- **形状**（4文字目、英大文字1文字）… 例 `A` = 通常、`B` = OH、`C` = 円筒。
- **種類**（5〜8文字目、数字4桁）… 同じメーカー×材種×形状の中の連番。**保存時に自動採番** されます。

メーカー・形状などの選択肢そのものは [採番構成](/manual/ja/masters/material-numbering/user) で管理します。

## 一覧を見る

- 列は **材種コード / 名称 / メーカー / 形状 / 状態 / 更新日** です。行をクリックすると詳細画面が開きます。
- 検索ボックスに **材種コード・名称** を入れて絞り込めます。
- **変換状態**（変換済 / 未変換）と **状態**（有効 / 無効）でも絞り込めます。
- 行を選択すると **一括有効化 / 一括無効化 / 一括削除** ができます。

「未変換」は旧システムから取り込んだ、コード構成がまだ付いていない材種です。名称などは編集できますが、素材の親には選べません。

## 新規作成

一覧右上の「新規作成」から登録します。

1. **メーカー** を選びます。
2. **メーカー材種** を選びます（選んだメーカーのものだけが表示されます）。
3. **形状** を選びます。画面に材種コードのプレビューが表示されます（`####` の部分＝種類は保存時に自動採番）。
4. **名称**（日本語は必須、英語は任意）と **説明**、**有効** を入力して保存します。

## 詳細画面

- **概要** … 説明（日本語・英語）。
- **既定単価** … 直径 × 黒皮/研磨 ごとの既定材料単価（¥/1000mm）を表形式で入力します。「直径を追加」で直径の行を追加し、単価を入力して「既定単価を保存」で保存します（不要な行は「行を削除」）。仕入実績が無いとき、[試算](/manual/ja/apps/trial-estimate/user) の材料原価はこの単価を使います。空欄は「価格なし」です。
- **関連** … この材種に紐づく素材の一覧。クリックで素材の詳細へ移動します。
- **履歴** … 変更の記録（いつ・誰が更新したか）。

右上のメニューから **編集** / **無効化** / **削除** ができます。

## 編集・削除のルール

- **コード構成（メーカー・メーカー材種・形状・種類）は作成後変更できません。** 編集できるのは名称・説明・有効のみです。
- この材種に紐づく素材があると **削除できません**。その場合は無効化してください。
- 無効化すると新しい選択肢に出なくなりますが、過去のデータはそのまま残ります。

このアプリの利用には **マスタ権限** が必要です。初めての方は [スタートマニュアル](/manual/ja/start) もあわせてご覧ください。
