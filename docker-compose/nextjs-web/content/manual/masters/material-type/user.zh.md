操作代码 **MS05**。用于登记和管理材料种类（材种，材種）的台账。[产品](/manual/zh/masters/product/user) 的素材规格、[素材](/manual/zh/masters/material/user) 的登记，以及 [试算](/manual/zh/apps/trial-estimate/user) 的材料成本计算都使用在这里登记的材种。

## 本应用能做什么

通过 **材种代码** 管理"哪家厂商、哪个牌号、什么形状的材料"。

- 登记材种后，即可在产品、素材、试算中选择。
- 每个材种可设置 **默认单价**（试算的备用材料单价）。

## 材种代码的构成

材种代码由 4 个部分组成，共 8 个字符（例 `B01B0001`）。

- **厂商**（第 1 位，大写字母 1 位）… 材料厂商。例 `B` = AFC。
- **厂商牌号**（第 2〜3 位，数字 2 位）… 厂商内的牌号。例 `01` = K10UF。
- **形状**（第 4 位，大写字母 1 位）… 例 `A` = 通常、`B` = OH、`C` = 圆筒。
- **种类**（第 5〜8 位，数字 4 位）… 同一厂商×牌号×形状内的流水号。**保存时自动编号。**

厂商、形状等选项本身在 [编号构成（採番構成）](/manual/zh/masters/material-numbering/user) 中管理。

## 查看列表

- 列为 **材种代码 / 名称 / 厂商 / 形状 / 状态 / 更新日期**。点击行可打开详情页。
- 在搜索框中输入 **材种代码・名称** 进行筛选。
- 也可按 **转换状态**（已转换 / 未转换）和 **状态**（有效 / 无效）筛选。
- 选中行后可执行 **批量启用 / 批量停用 / 批量删除**。

"未转换"是指从旧系统导入、尚未附带代码构成的材种。名称等可以编辑，但不能作为素材的上级。

## 新建

从列表右上角的「新規作成」（新建）进行登记。

1. 选择 **厂商**。
2. 选择 **厂商牌号**（只显示所选厂商的牌号）。
3. 选择 **形状**。画面上会显示材种代码的预览（`####` 部分＝种类，保存时自动编号）。
4. 输入 **名称**（日语必填、英语可选）、**说明**、**有效** 开关，然后保存。

## 详情页

- **概要** … 说明（日语・英语）。
- **既定単価（默认单价）** … 以表格形式输入按 直径 × 黑皮/研磨 划分的默认材料单价（¥/1000mm）。通过「直径を追加」（添加直径）增加直径行，输入单价后用「既定単価を保存」（保存默认单价）保存；不需要的行可用「行を削除」（删除行）移除。没有采购记录时，[试算](/manual/zh/apps/trial-estimate/user) 的材料成本使用该单价。空白表示"无价格"。
- **関連（相关）** … 属于该材种的素材列表。点击可跳转到素材详情。
- **履歴（历史）** … 变更记录（何时、由谁更新）。

从右上角菜单可进行 **编辑** / **停用** / **删除**。

## 编辑・删除规则

- **代码构成（厂商・厂商牌号・形状・种类）创建后不可更改。** 可编辑的只有名称、说明、有效开关。
- 若有素材关联该材种，则 **无法删除**。此时请改为停用。
- 停用后不会出现在新的选项中，但过去的数据会保留。

使用本应用需要 **主数据权限（マスタ権限）**。初次使用请同时参阅 [入门手册](/manual/zh/start)。
