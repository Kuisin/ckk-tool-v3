操作コード **MS05**。仕入れて在庫する材料（素材）を登録・管理する台帳です。素材は [材種](/manual/ja/masters/material-type/user) に「黒皮・研磨」「直径」「全長」を組み合わせた実物の棒材で、[素材在庫](/manual/ja/apps/material-inventory/user) や素材の発注・入荷で使います。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 素材を登録すると、在庫管理や素材発注で選べるようになります。
- 素材コードは構成から **自動で組み立てられます**。手入力は不要です。

なお [製品](/manual/ja/masters/product/user) は「材種 + 直径 + 全長」で素材を指定するため、特定の素材コードには紐付きません。素材マスタは在庫管理のための台帳です。

## 素材コードのしくみ

素材コードは `[材種コード]-[黒皮研磨][直径]-[全長]` の形です（例 `B01B0001-A083-330`）。

- **材種コード**（8文字）… 親になる材種。詳しくは [材種](/manual/ja/masters/material-type/user) を参照。
- **黒皮・研磨**（英大文字1文字）… 表面の区分。例 `A` = 黒皮、`B` = 研磨。
- **直径**（数字3桁）… 直径 mm × 10。例 φ8.3 → `083`。
- **全長**（数字3桁）… 全長 mm。例 330mm → `330`。

黒皮・研磨などの区分は [採番構成](/manual/ja/masters/material-numbering/user) で管理します。直径・全長の構成コードは、素材の保存時に自動で登録されます。

## 一覧を見る

- 列は **素材コード / 材種 / 名称 / 直径 / 全長 / 黒皮研磨 / 状態** です。行をクリックすると詳細画面が開きます。
- 検索ボックスに **素材コード・名称** を入れて絞り込めます。
- **材種 / 黒皮研磨 / 状態** でも絞り込めます。
- 行を選択すると **一括有効化 / 一括無効化 / 一括削除** ができます。

## 新規作成

一覧右上の「新規作成」から登録します。

1. **材種** を検索して選びます。コード構成が登録済み（変換済）の材種のみ選べます。**F4 キー（詳細検索）** でメーカー・形状で絞り込みながら探すこともできます。
2. **黒皮・研磨** を選びます。
3. **直径 (mm)**（0.1〜99.9）と **全長 (mm)**（1〜999）を入力します。入力欄の下に変換後のコードが表示されます。
4. **種類** を選びます。親材種の形状に属する種類だけが表示されます（通常形状は `A0` が自動で選ばれます）。
5. 画面に素材コードのプレビューが表示されます。**名称** は「材種名 φ直径×全長」の形で自動入力されます（手で書き換えても構いません）。
6. **単位**（既定は 本）、**メーカ型式**、**呼び径**、**備考** を必要に応じて入力し、保存します。

同じ構成（材種 × 黒皮研磨 × 直径 × 全長）の素材が既にあると保存できません。

## 詳細画面

- サマリーにコード構成（材種・黒皮研磨・直径・全長・種類）と呼び径・メーカ型式・単位が表示されます。
- **概要** … 名称（日本語・英語）と備考。
- **関連** … 使用製品の説明（製品は特定の素材に紐付かないことの案内）。
- **履歴** … 変更の記録。

右上のメニューから **編集** / **無効化** / **削除** ができます。

## 編集・削除のルール

- **コード構成（材種・黒皮研磨・直径・全長・種類）は作成後変更できません。** 編集できるのは名称・単位・メーカ型式・呼び径・有効・備考です。
- 発注・入荷・在庫などで使われている素材は削除できません。その場合は無効化してください。

このアプリの利用には **マスタ権限** が必要です。初めての方は [スタートマニュアル](/manual/ja/start) もあわせてご覧ください。
