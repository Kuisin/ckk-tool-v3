操作代码 **MS05**。用于登记和管理采购、库存的材料（素材）的台账。素材是把 [材种](/manual/zh/masters/material-type/user) 与"黑皮・研磨""直径""全长"组合而成的实物棒料，用于 [素材库存](/manual/zh/apps/material-inventory/user) 以及素材的订购和入库。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- 登记素材后，即可在库存管理和素材订购中选择。
- 素材代码由构成 **自动组装**，无需手动输入。

另外，[产品](/manual/zh/masters/product/user) 以"材种 + 直径 + 全长"指定素材，不与特定的素材代码关联。素材主数据是为库存管理而设的台账。

## 素材代码的构成

素材代码的形式为 `[材种代码]-[黑皮研磨][直径]-[全长]`（例 `B01B0001-A083-330`）。

- **材种代码**（8 位）… 作为上级的材种。详见 [材种](/manual/zh/masters/material-type/user)。
- **黑皮・研磨**（大写字母 1 位）… 表面区分。例 `A` = 黑皮、`B` = 研磨。
- **直径**（数字 3 位）… 直径 mm × 10。例 φ8.3 → `083`。
- **全长**（数字 3 位）… 全长 mm。例 330mm → `330`。

黑皮・研磨等区分在 [编号构成（採番構成）](/manual/zh/masters/material-numbering/user) 中管理。直径・全长的构成代码会在保存素材时自动登记。

## 查看列表

- 列为 **素材代码 / 材种 / 名称 / 直径 / 全长 / 黑皮研磨 / 状态**。点击行可打开详情页。
- 在搜索框中输入 **素材代码・名称** 进行筛选。
- 也可按 **材种 / 黑皮研磨 / 状态** 筛选。
- 选中行后可执行 **批量启用 / 批量停用 / 批量删除**。

## 新建

从列表右上角的「新規作成」（新建）进行登记。

1. 搜索并选择 **材种**。只能选择已登记代码构成（已转换）的材种。
2. 选择 **黑皮・研磨**。
3. 输入 **直径 (mm)**（0.1〜99.9）和 **全长 (mm)**（1〜999）。输入框下方会显示换算后的代码。
4. 选择 **种类**。只显示属于上级材种形状的种类（通常形状会自动选中 `A0`）。
5. 画面上会显示素材代码的实时预览。**名称** 会以"材种名 φ直径×全长"的形式自动填入（可手动修改）。
6. 按需填写 **单位**（默认为 本）、**厂商型号**、**公称直径**、**备注**，然后保存。

若已存在相同构成（材种 × 黑皮研磨 × 直径 × 全长）的素材，则无法保存。

## 详情页

- 摘要中显示代码构成（材种・黑皮研磨・直径・全长・种类）以及公称直径・厂商型号・单位。
- **概要** … 名称（日语・英语）和备注。
- **関連（相关）** … 关于产品使用方式的说明（产品不与特定素材关联）。
- **履歴（历史）** … 变更记录。

从右上角菜单可进行 **编辑** / **停用** / **删除**。

## 编辑・删除规则

- **代码构成（材种・黑皮研磨・直径・全长・种类）创建后不可更改。** 可编辑的是名称、单位、厂商型号、公称直径、有效开关、备注。
- 被订购、入库、库存等使用中的素材无法删除。此时请改为停用。

使用本应用需要 **主数据权限（マスタ権限）**。初次使用请同时参阅 [入门手册](/manual/zh/start)。
