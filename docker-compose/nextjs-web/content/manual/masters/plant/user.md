操作コード **MS0B**。製造・在庫・出荷の拠点となる拠点を登録・管理する台帳です。[製品在庫](/manual/ja/apps/product-inventory/user) や [素材在庫](/manual/ja/apps/material-inventory/user) は拠点ごとに管理され、素材の入荷先などもここで登録した拠点から選びます。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 拠点の基本情報（コード・名称・住所・連絡先）を登録します。
- 拠点ごとの在庫サマリ（製品在庫・素材在庫）を確認できます。

## 一覧を見る

- 列は **コード / 名称 / 国 / 状態 / 更新日** です。行をクリックすると詳細画面が開きます。
- 検索ボックスに **コード・名称** を入れて絞り込めます。**状態**（有効 / 無効）でも絞り込めます。
- 行を選択すると **一括有効化 / 一括無効化 / 一括削除** ができます。

## 新規作成

一覧右上の「新規作成」から登録します。

**基本情報**

- **拠点コード** … 拠点を識別する一意のコードを手入力します（例 `F01`）。**作成後は変更できません。**
- **名称**（日本語は必須、英語は任意）/ **よみがな**。
- **有効** … オフにすると選択肢に出なくなります（過去データは残ります）。
- **備考**。

**連絡先・住所**

- **国**（既定は 日本）/ **郵便番号** / **住所**（日本語・英語）。
- **電話番号** / **メールアドレス** / **担当者**。

## 詳細画面

- サマリーにコード・名称・国・住所・連絡先が表示されます。
- **概要** … 備考。
- **関連** … この拠点の **製品在庫** と **素材在庫** のサマリ（件数と直近更新 10 行）。行をクリックすると在庫の詳細へ、リンクから在庫一覧へ移動できます。
- **履歴** … 変更の記録（いつ・誰が更新したか）。

右上のメニューから **編集** / **無効化** / **削除** ができます。

## 編集・削除のルール

- **拠点コードは作成後変更できません。** それ以外の項目は編集できます。
- 在庫などから参照されている拠点は削除できないことがあります。使わなくなった拠点は無効化してください。

このアプリの利用には **マスタ権限** が必要です。初めての方は [スタートマニュアル](/manual/ja/start) もあわせてご覧ください。
