操作コード **MS0C**。製造・在庫・出荷の拠点を登録・管理する台帳です。[製品在庫](/manual/ja/apps/product-inventory/user) や [素材在庫](/manual/ja/apps/material-inventory/user) は拠点ごとに管理され、素材の入荷先などもここで登録した拠点から選びます。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 拠点の基本情報（コード・名称・住所・連絡先）を登録します。
- 拠点をまとめる **地域** を管理します（下記「地域管理」参照）。地域は権限管理の REGION スコープの対象単位です。
- 拠点ごとの **フロアマップ**（フロアの図面）を管理します。マップの上には保管場所アプリ（MS0E）の保管場所ピンや端末管理（SY09）の端末ピンが配置されます。

拠点内の **保管場所・棚** の管理は保管場所アプリ（MS0E）へ移管されました。このアプリではフロアマップ（図面）のみを管理します。

![拠点一覧](../../assets/screenshots/master-plant-list-01.png)

## 一覧を見る

- 列は **コード / 名称 / 国 / 地域 / 状態 / 更新日** です。行をクリックすると詳細画面が開きます。
- 検索ボックスに **コード・名称** を入れて絞り込めます。**状態**（有効 / 無効）でも絞り込めます。
- 行を選択すると **一括有効化 / 一括無効化 / 一括削除** ができます。
- 右上には「新規作成」のほかに「**地域管理**」ボタンがあります。

## 新規作成

一覧右上の「新規作成」から登録します。

**基本情報**

- **拠点コード** … 拠点を識別する一意のコードを手入力します（例 `F01`）。**作成後は変更できません。**
- **名称**（日本語は必須、英語は任意）/ **よみがな**（例 ほんしゃこうじょう）。
- **有効** … オフにすると選択肢に出なくなります（過去データは残ります）。
- **備考**。

**連絡先・住所**

- **国**（既定は 日本）/ **地域** … この拠点が属する地域。REGION スコープ権限の対象地域になります（任意）。
- **郵便番号** / **住所**（日本語・英語）。
- **電話番号** / **メールアドレス** / **担当者**。

## 地域管理

一覧右上の「地域管理」から、拠点をまとめる **地域** を管理します。地域は権限管理で **REGION スコープ** の権限が参照する単位です（例: 地域 `jp` の権限を持つ人は、その地域の全拠点が対象になります）。

![地域管理](../../assets/screenshots/master-plant-regions-01.png)

- 一覧の列は **コード / 名称（日本語） / 名称（英語） / 拠点数 / 状態 / 操作**（編集・無効化・削除）です。
- 最下行にコード（例 `jp`）と名称（例 日本 / Japan）を入れて「追加」で登録します。
- 地域コードは REGION スコープ権限が参照する識別子のため **作成後は変更できません**。削除できるのは **拠点数が 0**（どの拠点からも参照されていない）の地域だけです。

## 詳細画面

- サマリーに拠点コード・名称・よみがな・国・郵便番号・住所・電話番号・メールアドレス・担当者が表示されます。
- タブは **概要**（備考）と **フロアマップ** の 2 つです。
- 右上のメニューから **編集** / **無効化** / **削除** ができます。

## フロアマップ

詳細画面の **フロアマップ** タブで、拠点のフロア図面を管理します。

- 「**フロアを追加**」でフロアを作り、**フロア名**（例 `1F 加工場`）を付けます。
- フロアごとに **図面をアップロード**（差し替えも可）します。
- **重ね表示** で複数フロアの図面を重ねて表示し、位置合わせを確認できます。
- フロアの **削除** は、そのフロアに端末や保管場所のピンが置かれている間はできません。

図面の管理はこのアプリ（MS0C）だけで行います。保管場所アプリ（MS0E）や端末管理（SY09）は、このマップの上にピンを配置するだけです。

## 編集・削除のルール

- **拠点コードは作成後変更できません。** それ以外の項目は編集できます。
- 在庫などから参照されている拠点は削除できないことがあります。使わなくなった拠点は無効化してください。

## 用語

- **地域** … 拠点をまとめるグループ。権限管理の REGION スコープの実体です。
- **フロアマップ** … 拠点のフロアごとの図面。保管場所・端末のピンの配置先になります。

このアプリの利用には **マスタ権限** が必要です。初めての方は [スタートマニュアル](/manual/ja/start) もあわせてご覧ください。
