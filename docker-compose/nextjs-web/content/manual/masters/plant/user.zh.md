操作代码 **MS0B**。用于登记和管理作为制造、库存、发货据点的工厂（拠点）的台账。[产品库存](/manual/zh/apps/product-inventory/user) 和 [素材库存](/manual/zh/apps/material-inventory/user) 按工厂管理，素材的入库地点等也从这里登记的工厂中选择。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- 登记工厂的基本信息（代码・名称・地址・联系方式）。
- 查看各工厂的库存摘要（产品库存・素材库存）。

## 查看列表

- 列为 **代码 / 名称 / 国家 / 状态 / 更新日期**。点击行可打开详情页。
- 在搜索框中输入 **代码・名称** 进行筛选。也可按 **状态**（有效 / 无效）筛选。
- 选中行后可执行 **批量启用 / 批量停用 / 批量删除**。

## 新建

从列表右上角的「新規作成」（新建）进行登记。

**基本信息**

- **工厂代码** … 手动输入用于识别工厂的唯一代码（例 `F01`）。**创建后不可更改。**
- **名称**（日语必填、英语可选）/ **读音假名**。
- **有效** … 关闭后将不再出现在选项中（过去的数据会保留）。
- **备注**。

**联系方式・地址**

- **国家**（默认为 日本）/ **邮政编码** / **地址**（日语・英语）。
- **电话号码** / **电子邮箱** / **负责人**。

## 详情页

- 摘要中显示代码・名称・国家・地址・联系方式。
- **概要** … 备注。
- **関連（相关）** … 该工厂的 **产品库存** 和 **素材库存** 摘要（件数及最近更新的 10 行）。点击行可打开库存详情，也可通过链接跳转到库存列表。
- **履歴（历史）** … 变更记录（何时、由谁更新）。

从右上角菜单可进行 **编辑** / **停用** / **删除**。

## 编辑・删除规则

- **工厂代码创建后不可更改。** 其他项目均可编辑。
- 被库存等引用的工厂可能无法删除。不再使用的工厂请改为停用。

使用本应用需要 **主数据权限（マスタ権限）**。初次使用请同时参阅 [入门手册](/manual/zh/start)。
