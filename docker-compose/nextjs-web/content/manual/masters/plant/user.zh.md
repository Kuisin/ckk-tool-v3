操作代码 **MS0C**。用于登记和管理作为制造、库存、发货据点的工厂（拠点）的台账。[产品库存](/manual/zh/apps/product-inventory/user) 和 [素材库存](/manual/zh/apps/material-inventory/user) 按工厂管理，素材的入库地点等也从这里登记的工厂中选择。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- 登记工厂的基本信息（代码・名称・地址・联系方式）。
- 管理将工厂分组的 **地域**（见下文「地域管理」）。地域是权限管理中 REGION 范围权限的对象单位。
- 管理各工厂的 **楼层平面图**（楼层图纸）。平面图上会放置保管场所应用（MS0E）的保管场所图钉和终端管理（SY09）的终端图钉。

工厂内 **保管场所・货架** 的管理已移交至保管场所应用（MS0E）。本应用只管理楼层平面图（图纸）。

![工厂列表](../../assets/screenshots/master-plant-list-01.png)

## 查看列表

- 列为 **代码 / 名称 / 国家 / 地域 / 状态 / 更新日期**。点击行可打开详情页。
- 在搜索框中输入 **代码・名称** 进行筛选。也可按 **状态**（有效 / 无效）筛选。
- 选中行后可执行 **批量启用 / 批量停用 / 批量删除**。
- 右上角除「新建」外，还有「**地域管理**」按钮。

## 新建

从列表右上角的「新建」进行登记。

**基本信息**

- **工厂代码** … 手动输入用于识别工厂的唯一代码（例 `F01`）。**创建后不可更改。**
- **名称**（日语必填、英语可选）/ **读音假名**。
- **有效** … 关闭后将不再出现在选项中（过去的数据会保留）。
- **备注**。

**联系方式・地址**

- **国家**（默认为 日本）/ **地域** … 该工厂所属的地域。将成为 REGION 范围权限的对象地域（可选）。
- **邮政编码** / **地址**（日语・英语）。
- **电话号码** / **电子邮箱** / **负责人**。

## 地域管理

从列表右上角的「地域管理」管理将工厂分组的 **地域**。地域是权限管理中 **REGION 范围** 权限所引用的单位（例：持有地域 `jp` 权限的人，其权限覆盖该地域的全部工厂）。

![地域管理](../../assets/screenshots/master-plant-regions-01.png)

- 列为 **代码 / 名称（日语） / 名称（英语） / 工厂数 / 状态 / 操作**（编辑・停用・删除）。
- 在最下面一行输入代码（例 `jp`）和名称（例 日本 / Japan），点击「添加」即可登记。
- 地域代码是 REGION 范围权限引用的标识符，**创建后不可更改**。只有 **工厂数为 0**（未被任何工厂引用）的地域才能删除。

## 详情页

- 摘要中显示工厂代码・名称・读音假名・国家・邮政编码・地址・电话号码・电子邮箱・负责人。
- 标签页只有 **概要**（备注）和 **楼层平面图** 两个。
- 从右上角菜单可进行 **编辑** / **停用** / **删除**。

## 楼层平面图

在详情页的 **楼层平面图** 标签页管理工厂的楼层图纸。

- 通过「**添加楼层**」创建楼层，并设置 **楼层名**（例 `1F 加工場`）。
- 可按楼层 **上传图纸**（也可替换）。
- 通过 **叠加显示** 可将多个楼层的图纸重叠显示，确认位置对齐。
- 若楼层上已放置终端或保管场所的图钉，则该楼层 **无法删除**。

图纸仅在本应用（MS0C）中管理。保管场所应用（MS0E）和终端管理（SY09）只在这些平面图上放置图钉。

## 编辑・删除规则

- **工厂代码创建后不可更改。** 其他项目均可编辑。
- 被库存等引用的工厂可能无法删除。不再使用的工厂请改为停用。

## 术语

- **地域** … 将工厂分组的单位。权限管理中 REGION 范围权限的实体。
- **楼层平面图** … 工厂各楼层的图纸，是保管场所・终端图钉的放置对象。

使用本应用需要 **主数据权限（マスタ権限）**。初次使用请同时参阅 [入门手册](/manual/zh/start)。
