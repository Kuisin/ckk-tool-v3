操作コード **MS04**。自社で作る製品を登録・管理する台帳です。[試算](/manual/ja/apps/trial-estimate/user) や [見積書](/manual/ja/apps/quote/user)、価格表は、ここで登録した製品を選んで作成します。

## このアプリでできること

「どんな製品を扱っているか」を登録しておきます。製品には名称のほか、どんな素材から作るか（**素材仕様**）、製品種別ごとの入力項目や追加項目（**仕様**）、製造の **工程リスト（ルート）** を記録できます。

- 製品を登録すると、試算・見積書・[価格表](/manual/ja/apps/price-list/user) で選べるようになります。
- 素材は「**材種 + 直径 + 全長**」で指定します。特定の素材コードには紐付けません。
- 仕様の項目は自由記述ではなく、**製品項目（SY03）** で定義された項目から選んで入力します。

## 一覧を見る

- 一覧の列は **製品コード / 名称 / 材種 / 単位 / 状態** です。材種の列には「材種名 φ直径×全長」の形で素材仕様が表示されます。行をクリックすると詳細画面が開きます。
- 検索ボックスに **製品コード・名称・材種** を入れて絞り込めます。**状態**（有効 / 無効）でも絞り込めます。
- 行を選択すると **一括有効化 / 一括無効化 / 一括削除** ができます。
- 行のメニューから **編集** / **複製** / **無効化** / **削除** ができます。
- 旧システムから取り込んだ製品コード未設定の製品は「**未採番**」と表示されます。

## 新規作成

一覧右上の「新規作成」から登録します。主な入力項目は次のとおりです。

**基本情報**

- **名称**（日本語は必須、英語は任意）。
- **単位**（必須）… 本 / 個 / kg / m / セット から選びます。
- **有効** … オフにすると選択肢に出なくなります。
- **備考**。

**素材仕様**

- **材種** … コード構成が登録済み（変換済）の材種のみ選べます。材種コード・名称で検索して選びます。
- **直径 (mm)** … 0.1〜99.9mm。入力するとコード（径 × 10）が表示されます。
- **全長 (mm)** … 1〜999mm。
- 材種を選んだ場合は直径・全長も必須になります。同じ材種・直径の素材を、全長に合わせて切断して使う想定です。特定の素材には紐付けません。

**製品種別**

- **製品種別（SY04）** が登録されている場合に表示されます。種別を選ぶと、その種別が予め定義した入力項目（テキスト・数値・スイッチ・選択・日付）が展開されます。項目ごとの必須設定は種別の定義に従います。

**追加項目**

- 「項目を追加」から、**製品項目（SY03）で定義された項目** を選んで値を入力します。自由なキーは使えません。追加した項目は「−」で取り除けます。

**製品コード**（`PRD-YYYYMM-NNNN`）は保存時に自動で採番されます。手入力は不要です。

## 詳細画面

サマリに製品コード・名称・材種・直径・全長・単位が表示され、下はタブに分かれています。

- **概要** … 製品種別（設定時）、仕様（項目と値の表）、備考。
- **工程** … この製品の工程リスト（ルート）。下記参照。
- **関連** … この製品に紐付く価格表エントリの一覧（顧客 / 注文種別 / 有効期間 / 状態）。クリックで価格表の詳細へ移動します。
- **履歴** … 変更の記録（いつ・誰が更新したか）。

右上のメニューから **編集** / **複製** / **無効化** / **削除** ができます。

## 工程リスト（ルート）

「工程」タブでは、この製品を作るときの工程構成を **ルート** として登録できます。登録しておくと、指示書の作成時に工程構成をプリフィルできます。

- 「ルート新規作成」で新しいルートを登録します。
- ルートは **バージョン** で管理されます。バージョンを切り替えると、そのバージョンの工程一覧（スナップショット）が表示されます。
- 「新バージョン作成」で工程構成を変えた新しい版を作れます。「編集」では名称と有効を変更、「削除」でルートを削除します。

![製品詳細の工程タブ。工程リスト（ルート）の一覧と「ルート新規作成」ボタン](../../assets/screenshots/master-product-routes-01.png)

## 用語

- **材種** … 素材の種類（メーカー・グレード・形状などの組み合わせ）。製品は材種＋寸法で素材を指定します。
- **直径 / 全長** … 素材の太さ（mm）と長さ（mm）。
- **製品種別** … 製品のタイプごとに入力項目をまとめた定義（SY04 で管理）。
- **追加項目** … 製品項目（SY03）で定義された項目から選んで付け足す仕様項目。
- **工程リスト（ルート）** … この製品を作る工程構成。バージョン管理され、指示書作成時のプリフィルに使われます。
- **単位** … 数量の数え方（本・個 など）。

初めての方は [スタートマニュアル](/manual/ja/start) もあわせてご覧ください。
