操作码 **MS04**。用于登记和管理自家制作产品的台账。[试算](/manual/zh/apps/trial-estimate/user)、[报价单](/manual/zh/apps/quote/user) 与价格表都通过选择此处登记的产品来创建。

## 本应用能做什么

登记“经营哪些产品”。产品除名称外，还可记录由何种素材制作（**素材规格**）、按产品种别定义的输入项目与追加项目（**规格**），以及制造的 **工序列表（路线）**。

- 登记产品后，即可在试算、报价单、[价格表](/manual/zh/apps/price-list/user) 中选择。
- 素材以“**材种 + 直径 + 全长**”指定，不与特定素材代码绑定。
- 规格项目不是自由填写，而是从 **产品项目（SY03）** 定义的项目中选择输入。

## 查看列表

- 列表的列为 **产品代码 / 名称 / 材种 / 单位 / 状态**。材种列以“材种名 φ直径×全长”的形式显示素材规格。点击行可打开详情页。
- 使用搜索框，按 **产品代码・名称・材种** 筛选。也可按 **状态**（有效 / 无效）筛选。
- 选中行后可执行 **批量启用 / 批量停用 / 批量删除**。
- 通过行菜单可进行 **编辑** / **复制** / **停用** / **删除**。
- 从旧系统导入、尚无产品代码的产品会显示为“**未采番**”（未编号）。

## 新建

从列表右上的“新建”登记。主要输入项如下。

**基本信息**

- **名称**（日文必填，英文选填）。
- **单位**（必填）… 从 本 / 个 / kg / m / 套 中选择。
- **有效** … 关闭后不再出现在选择列表中。
- **备注**。

**素材规格**

- **材种** … 仅可选择已登记代码结构（已转换）的材种。按材种代码・名称检索选择。
- **直径 (mm)** … 0.1〜99.9mm。输入后会显示代码（直径 × 10）。
- **全长 (mm)** … 1〜999mm。
- 选择了材种后，直径・全长也成为必填。设想是将相同材种・直径的素材按所需全长切断使用，不与特定素材绑定。

**产品种别**

- 当已登记 **产品种别（SY04）** 时显示。选择种别后，会展开该种别预先定义的输入项目（文本・数值・开关・选择・日期）。各项目是否必填遵循种别的定义。

**追加项目**

- 通过“添加项目”，从 **产品项目（SY03）定义的项目** 中选择并输入值。不能使用自由键名。已添加的项目可用“−”移除。

**产品代码**（`PRD-YYYYMM-NNNN`）在保存时自动编号，无需手动输入。

## 详情页

摘要中显示产品代码・名称・材种・直径・全长・单位，下方分为多个标签。

- **概要** … 产品种别（若设置）、规格（项目与值的表格）、备注。
- **工序** … 该产品的工序列表（路线）。见下文。
- **相关** … 与该产品关联的价格表条目列表（客户 / 订单种别 / 有效期间 / 状态）。点击可跳转到价格表详情。
- **历史** … 变更记录（何时、由谁更新）。

通过右上菜单可进行 **编辑** / **复制** / **停用** / **删除**。

## 工序列表（路线）

在“工序”标签中，可将制作该产品时的工序构成登记为 **路线**。登记后，创建指示书时可预填工序构成。

- 通过“新建路线”登记新路线。
- 路线按 **版本** 管理。切换版本可显示该版本的工序一览（快照）。
- 通过“创建新版本”可在变更工序构成后生成新的版本。“编辑”可修改名称与有效开关，“删除”可删除路线。

![产品详情页的工序标签。显示工序列表（路线）与“新建路线”按钮](../../assets/screenshots/master-product-routes-01.png)

## 术语

- **材种** … 素材的种类（厂商・牌号・形状等的组合）。产品以材种＋尺寸指定素材。
- **直径 / 全长** … 素材的粗细（mm）与长度（mm）。
- **产品种别** … 按产品类型汇总输入项目的定义（在 SY04 中管理）。
- **追加项目** … 从产品项目（SY03）定义的项目中选择补充的规格项目。
- **工序列表（路线）** … 制作该产品的工序构成。按版本管理，用于创建指示书时的预填。
- **单位** … 数量的计数方式（本・个 等）。
