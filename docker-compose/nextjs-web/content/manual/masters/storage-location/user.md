操作コード **MS0E**。拠点内の倉庫・置場（**保管場所**）とその **棚** を管理する台帳です。在庫は保管場所×棚の単位で保管され、[在庫管理（PD04）](/manual/ja/apps/product-inventory/user)の在庫移動で場所間を動かせます。[拠点](/manual/ja/masters/plant/user)（MS0C）で管理するフロアマップの上に、保管場所のピンを配置することもできます。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 拠点ごとに **保管場所**（倉庫・置場）を登録し、その配下に **棚** を登録します。
- 拠点のフロアマップ上に保管場所の **ピンを配置** します（図面そのものの管理は拠点マスタ MS0C）。
- 登録した保管場所×棚は、在庫管理（PD04）で在庫の保管単位・**在庫移動** の移動先として使われます。

## 一覧（全拠点）

開いた直後は、全拠点の保管場所を横断する一覧が表示されます。

![保管場所一覧](../../assets/screenshots/master-storage-location-01.png)

- 列は **拠点（名称＋コード） / コード / 名称 / 棚数 / マップ配置 / 状態** です。フロアマップにピンを配置済みの場所には「配置済」バッジが付きます。
- 検索ボックスに **コード・名称・拠点** を入れて絞り込めます。
- 「**拠点を選択して管理**」の選択、または行のクリックで、その拠点の管理モードに切り替わります。
- 右上の「新規作成」からは、一覧のまま保管場所を追加できます（このときは **拠点** と **フロア** も選択します）。

## 管理モード（拠点ごと）

拠点を選択すると、その拠点内の保管場所・棚をまとめて管理する画面になります。

![保管場所の管理](../../assets/screenshots/master-storage-location-manage-01.png)

- 「**保管場所を追加**」でその拠点に保管場所を登録します。
- **フロアマップ配置** … 拠点マスタ（MS0C）で登録済みのフロアマップが表示され、その上に保管場所のピンを **ドラッグで配置**・**配置解除** できます。図面の追加・差し替えはこのアプリではできません（拠点マスタ MS0C で行います）。
- 保管場所ごとのカードに名称・コード・（無効の場合は）無効バッジ・備考が表示され、「**棚を追加**」と各棚の編集・削除ができます。棚はコード＋名称のチップで一覧されます。

## 保管場所・棚の入力項目

**保管場所**

- **拠点**（一覧からの新規作成時のみ選択）/ **フロア**。
- **コード**（例 `WH1`）/ **名称（日本語）**（例 第一倉庫）/ **名称（英語）**（任意）。
- **表示順** / **有効** / **備考**。

**棚**

- **棚コード**（例 `A-1`）/ **名称（日本語・任意）** / **名称（英語）**。
- **表示順** / **有効**。

## 削除のルール

- **在庫が参照している保管場所・棚は削除できません**（「この保管場所を参照する在庫があるため削除できません（在庫移動で空にするか、無効化してください）」と表示されます。棚も同様です）。在庫管理（PD04）の在庫移動で空にするか、無効化してください。
- 保管場所を削除すると、配下の棚もまとめて削除されます（確認画面に棚の件数が表示されます）。

## 用語

- **保管場所** … 拠点内の倉庫・置場。在庫の保管単位です。
- **棚** … 保管場所の中の区画。在庫は保管場所×棚の単位で管理されます。
- **フロアマップ配置** … 拠点のフロア図面上に保管場所のピンを置くこと。図面の管理は拠点マスタ（MS0C）です。

このアプリの利用には **マスタ権限** が必要です。初めての方は [スタートマニュアル](/manual/ja/start) もあわせてご覧ください。
