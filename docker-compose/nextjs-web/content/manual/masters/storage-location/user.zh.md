操作代码 **MS0E**。用于管理各工厂内的仓库・放置区（**保管场所**）及其 **货架** 的台账。库存按保管场所×货架为单位保管，可通过库存管理（PD04）的库存移动在场所之间移动。还可以在 [工厂](/manual/zh/masters/plant/user)（MS0C）管理的楼层平面图上放置保管场所图钉。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- 按工厂登记 **保管场所**（仓库・放置区），并在其下登记 **货架**。
- 在工厂的楼层平面图上 **放置图钉** 标记保管场所（图纸本身在工厂主数据 MS0C 中管理）。
- 登记的保管场所×货架，会作为库存管理（PD04）中库存的保管单位和 **库存移动** 的目的地使用。

## 列表（全部工厂）

打开应用后，首先显示跨全部工厂的保管场所列表。

![保管场所列表](../../assets/screenshots/master-storage-location-01.png)

- 列为 **工厂（名称＋代码） / 代码 / 名称 / 货架数 / 平面图放置 / 状态**。已在楼层平面图上放置图钉的场所会显示「已放置」徽章。
- 在搜索框中输入 **代码・名称・工厂** 进行筛选。
- 通过「**选择工厂进行管理**」选择工厂，或点击行，即可切换到该工厂的管理模式。
- 通过右上角的「新建」，可直接在列表状态下添加保管场所（此时还需选择 **工厂** 和 **楼层**）。

## 管理模式（按工厂）

选择工厂后，进入统一管理该工厂内保管场所・货架的界面。

![保管场所的管理](../../assets/screenshots/master-storage-location-manage-01.png)

- 通过「**添加保管场所**」在该工厂登记保管场所。
- **楼层平面图放置** … 显示在工厂主数据（MS0C）中登记的楼层平面图，可在其上 **拖拽放置**・**取消放置** 保管场所图钉。本应用无法添加・替换图纸（请在工厂主数据 MS0C 中操作）。
- 每个保管场所以卡片显示名称・代码・（停用时的）无效徽章・备注，并可「**添加货架**」以及编辑・删除各货架。货架以代码＋名称的标签形式列出。

## 保管场所・货架的输入项目

**保管场所**

- **工厂**（仅在从列表新建时选择）/ **楼层**。
- **代码**（例 `WH1`）/ **名称（日语）**（例 第一倉庫）/ **名称（英语）**（可选）。
- **显示顺序** / **有效** / **备注**。

**货架**

- **货架代码**（例 `A-1`）/ **名称（日语・可选）** / **名称（英语）**。
- **显示顺序** / **有效**。

## 删除规则

- **被库存引用的保管场所・货架无法删除**（会提示有库存引用该保管场所，请先通过库存移动清空或改为停用；货架同理）。请先在库存管理（PD04）中通过库存移动清空，或改为停用。
- 删除保管场所时，其下的货架也会一并删除（确认对话框会显示货架数量）。

## 术语

- **保管场所** … 工厂内的仓库・放置区，是库存的保管单位。
- **货架** … 保管场所内的区画。库存按保管场所×货架为单位管理。
- **楼层平面图放置** … 在工厂的楼层图纸上放置保管场所图钉。图纸在工厂主数据（MS0C）中管理。

使用本应用需要 **主数据权限（マスタ権限）**。初次使用请同时参阅 [入门手册](/manual/zh/start)。
