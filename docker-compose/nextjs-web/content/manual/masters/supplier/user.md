操作コード **MS06**。素材を仕入れる **仕入先** と、センタレスやコーティングなど工程の一部を委託する **外注先** を登録・管理する台帳です。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

会社の基本情報に加えて、締日・支払条件・振込先口座・標準リードタイムを登録しておけます。ここで登録した外注企業は、[素材発注書](/manual/ja/apps/purchase-order/user) や [外注依頼](/manual/ja/apps/outsource-order/user) の相手先として選べるようになります。

- **外注種別** で「仕入先」（素材・資材の調達先）と「外注先」（工程の委託先）を区別します。
- 外注企業は社内で「取引先（BP）」として管理され、そのうち **仕入先・外注先ロール** が付いたものです。

利用には **マスタ権限** が必要です。

## 一覧を見る

- 一覧の列は **BPコード / 名称 / 外注種別 / 標準リードタイム / 状態** です。行をクリックすると詳細画面が開きます。
- 上部の検索ボックスに **BPコード・名称** を入れて絞り込めます。**外注種別**（仕入先 / 外注先）と **状態**（有効 / 無効）でも絞り込めます。
- 行を選択すると **一括有効化 / 一括無効化 / 一括削除** ができます。

## 新規作成

一覧右上の「新規作成」から登録します。**BPコード**（`BP-NNNNN`）は保存時に自動で採番されます。

**基本情報**

- **名称**（日本語は必須、英語は任意）/ **国** / **フリガナ** / **略称** / **法人番号**。
- **有効** … オフにすると選択肢に出なくなります（過去データは残ります）。
- **AI照合名** … 書類の自動読み取り（AI 抽出）が社名をこの取引先に結び付けるための照合リストです。表記ゆれを Enter 区切りで登録します。

**住所・連絡先**

- **郵便番号** / **住所**（日本語・英語）/ **電話番号** / **FAX** / **メールアドレス** / **Webサイト** / **備考**。

**取引条件**

- **外注種別**（必須）… 仕入先 / 外注先。
- **旧システムコード** … 旧仕入先コード（任意）。
- **締日** … 1〜31 の日付。`31` は「月末」を意味します。
- **支払サイト（日数）** / **支払日**。
- **標準リードタイム（日数）** … 依頼から入荷までの目安日数。外注依頼の入荷予定の参考になります。

**振込先**

- **銀行名** / **支店名** / **口座種別**（普通 / 当座）/ **口座番号**。

## 詳細画面

- 上部のサマリに基本情報が表示され、タイトル横に **外注種別** と状態のバッジが付きます。**概要** タブに取引条件・振込先・備考、**履歴** タブに変更の記録（いつ・誰が更新したか）が表示されます。
- 右上のメニューから **編集** / **無効化** / **削除** ができます。

![外注企業詳細。基本情報のサマリと外注種別バッジ、概要タブの取引条件・振込先](../../assets/screenshots/master-supplier-detail-01.png)

## 削除と無効化

- この取引先を参照するデータが存在する場合は削除できません。取引をやめた相手は削除ではなく **無効化** してください（選択肢に出なくなり、過去データは残ります）。

## 用語

- **仕入先** … 素材・資材を調達する相手（外注種別 = 仕入先）。
- **外注先** … 製造工程の一部を委託する相手（外注種別 = 外注先）。
- **標準リードタイム** … 依頼から入荷までにかかる標準的な日数。
- **BP（取引先）** … 顧客・仕入先・需要家などをまとめて管理する会社の単位。
