操作コード **MS0D**。機械 1 台・1 区画といった物理的な **作業場所** を、機械種別・エリアなどの **グループ** にまとめて管理する台帳です。登録した作業場所は [指示書](/manual/ja/apps/work-order/user) の工程の **作業計画** で「作業場所（任意）」として選択できます。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- **グループ**（機械種別・エリアなど）を作成し、その配下に **作業場所**（機械 1 台・1 区画）を登録します。
- グループの分類に使う **種別** を管理します（組み込みの「機械」「エリア」に加えて独自の種別を追加できます）。
- 作業場所ごとに **キャパシティ**（同時に割り当て可能な作業数）を設定します。
- 各作業場所が指示書の作業計画でどれだけ使われているかを **計画数** で確認できます。

## 画面の見かた

一覧・詳細のページ分かれはなく、1 つの管理画面で完結します。

- 画面右上に「**種別管理**」と「**グループ追加**」のボタンがあります。
- グループごとにカードが表示され、カードにはグループのコード・名称・種別・拠点・状態と、**編集 / 削除 / 場所追加** の操作が並びます。
- カード内の作業場所の表の列は **コード / 名称 / キャパシティ / 計画数 / 状態** で、行ごとに編集・削除ができます。
- まだ何も登録していないときは「グループ（機械種別・エリアなど）を作成し、配下に物理的な場所（機械 1 台・1 区画）を追加してください」という案内が表示されます。

## グループを追加する

「グループ追加」から登録します。

- **コード** … グループを識別するコード（例 `NC-LATHE`）。
- **種別** … 機械 / エリア、または種別管理で追加した種別から選択。
- **名称（日本語）**（例 NC旋盤）/ **名称（English）**（任意）。
- **拠点** … このグループが属する拠点。
- **表示順** / **備考** / **有効**。

## 作業場所を追加する

グループカードの「場所追加」から、そのグループ配下に登録します。

- **コード** … 作業場所を識別するコード（例 `NC-01`）。
- **キャパシティ** … 同時に割り当て可能な作業数。
- **名称（日本語）**（例 NC旋盤 1号機）/ **名称（English）**（任意）。
- **表示順** / **有効** / **備考**。

## 種別管理

画面右上の「種別管理」から、グループの分類に使う **種別** を管理します。

- 行ごとに **キー**（例 `line`）と **表示名（日本語）** / **English** を入力して追加します。
- **機械（machine）** と **エリア（area）** は組み込みの種別のため **削除できません**。
- 追加した種別も、いずれかのグループがその種別を使っている間は削除できません。

## 指示書の作業計画との関係

指示書詳細の工程の **作業計画** では、計画行ごとに「**作業場所（任意）**」を選択できます。選択された作業場所は計画の一覧に表示され、キオスクの工程実行画面でも確認できます。この参照数が一覧の **計画数** 列に表示されます。

## 削除のルール

- グループを削除すると、配下の作業場所もまとめて削除されます。
- 指示書の **作業計画で使用中** の作業場所は削除できません（「グループの削除に失敗しました（作業計画で使用中の場所が含まれる場合は削除できません）」と表示されます）。使わなくなった場所は無効化してください。

## 用語

- **グループ** … 作業場所をまとめる単位（機械種別・エリアなど）。拠点に属します。
- **作業場所** … 機械 1 台・1 区画といった物理的な場所。指示書の作業計画で選択されます。
- **キャパシティ** … その場所に同時に割り当て可能な作業数。

このアプリの利用には **マスタ権限** が必要です。初めての方は [スタートマニュアル](/manual/ja/start) もあわせてご覧ください。
