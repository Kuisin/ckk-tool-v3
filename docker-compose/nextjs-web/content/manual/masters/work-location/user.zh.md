操作代码 **MS0D**。将 1 台机器・1 个区域等物理 **作业场所**，按机器类别・区域等 **分组** 进行管理的台账。登记的作业场所可在 [指示单](/manual/zh/apps/work-order/user) 工序的 **作业计划** 中作为「作业场所（可选）」选择。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- 创建 **分组**（机器类别・区域等），并在其下登记 **作业场所**（1 台机器・1 个区域）。
- 管理用于分类分组的 **类别**（除内置的「机器」「区域」外，还可添加自定义类别）。
- 为每个作业场所设置 **容量**（可同时分配的作业数）。
- 通过 **计划数** 列确认各作业场所被指示单作业计划引用的数量。

![作业场所](../../assets/screenshots/master-work-location-01.png)

## 界面说明

没有单独的列表・详情页，所有操作都在一个管理界面上完成。

- 界面右上角有「**类别管理**」和「**添加分组**」按钮。
- 每个分组以卡片显示，卡片上有分组的代码・名称・类别・工厂・状态，以及 **编辑 / 删除 / 添加场所** 操作。
- 卡片内作业场所表格的列为 **代码 / 名称 / 容量 / 计划数 / 状态**，每行可编辑・删除。
- 尚未登记任何内容时，界面会提示先创建分组（机器类别・区域等），再在其下添加物理场所（1 台机器・1 个区域）。

## 添加分组

通过「添加分组」进行登记。

- **代码** … 用于识别分组的代码（例 `NC-LATHE`）。
- **类别** … 从机器 / 区域，或类别管理中添加的类别中选择。
- **名称（日语）**（例 NC旋盤）/ **名称（English）**（可选）。
- **工厂** … 该分组所属的工厂。
- **显示顺序** / **备注** / **有效**。

## 添加作业场所

通过分组卡片上的「添加场所」，在该分组下登记。

- **代码** … 用于识别作业场所的代码（例 `NC-01`）。
- **容量** … 可同时分配的作业数。
- **名称（日语）**（例 NC旋盤 1号機）/ **名称（English）**（可选）。
- **显示顺序** / **有效** / **备注**。

## 类别管理

通过界面右上角的「类别管理」，管理用于分类分组的 **类别**。

- 每行输入 **键**（例 `line`）和 **显示名（日语）** / **English** 即可添加。
- **机器（machine）** 和 **区域（area）** 是内置类别，**不可删除**。
- 已被任一分组使用的自定义类别也无法删除。

## 与指示单作业计划的关系

在指示单详情页各工序的 **作业计划** 中，每条计划行可选择「**作业场所（可选）**」。所选场所会显示在计划列表中，也会在自助终端（kiosk）的工序执行界面上显示。该引用数量显示在 **计划数** 列。

## 删除规则

- 删除分组时，其下的作业场所也会一并删除。
- 已被指示单 **作业计划使用中** 的作业场所无法删除（会提示包含作业计划使用中场所的分组无法删除）。不再使用的场所请改为停用。

## 术语

- **分组** … 将作业场所归类的单位（机器类别・区域等），属于某个工厂。
- **作业场所** … 1 台机器・1 个区域等物理场所，在指示单的作业计划中选择。
- **容量** … 该场所可同时分配的作业数。

使用本应用需要 **主数据权限（マスタ権限）**。初次使用请同时参阅 [入门手册](/manual/zh/start)。
