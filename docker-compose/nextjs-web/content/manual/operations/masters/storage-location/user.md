「資材倉庫A」のような、**物を置いておく倉庫や置場** と、その中の **棚** を登録するアプリです。操作コードは `MS0E` です。

在庫は「どの保管場所の、どの棚にあるか」まで分けて管理されます。[在庫管理](/manual/ja/operations/production/product-inventory/user)の在庫移動では、ここで登録した場所どうしで物を動かせます。

> ⚠️ このアプリは試験公開中です。ご利用の環境によっては、まだ表示されないことがあります。

## 似ている 3 つのアプリの違い

場所に関するアプリが 3 つあり、まぎらわしいのでご注意ください。

| アプリ | 何を登録するか | 例 |
|--------|----------------|-----|
| [拠点](/manual/ja/operations/masters/plant/user) | 工場そのもの | 本社工場、第二工場 |
| [作業場所](/manual/ja/operations/masters/work-location/user) | 拠点の中で作業する場所・機械 | NC旋盤 1号機、研磨エリア |
| **保管場所**（このページ） | 拠点の中で物を置く倉庫・棚 | 資材倉庫A の A-1 棚 |

**物を置く場所** はこのアプリ、**人が作業する場所** は作業場所アプリです。

## このアプリでできること

- 拠点ごとに、倉庫や置場（保管場所）を登録できます。
- その中の **棚** を登録できます。
- 拠点の図面（フロアマップ）の上に、保管場所の **印**（ピン）を置けます。
- 登録した保管場所と棚は、在庫の置き場所として選べるようになります。

## 用語（このページで出てくる言葉）

- **保管場所** … 拠点の中にある倉庫や置場のことです（例 資材倉庫A、出荷前置場）。
- **棚（たな）** … 保管場所の中の区画です（例 A-1、A-2）。在庫は「保管場所 + 棚」の単位で数えます。
- **フロアマップ** … 拠点のフロアの図面です。図面そのものの登録は[拠点](/manual/ja/operations/masters/plant/user)で行います。
- **ピン** … 図面の上に置く、保管場所の位置を示す印です。

## はじめる前に

- このアプリを使うには **マスタの権限** が必要です。
- 保管場所は必ずどれかの拠点に属します。先に[拠点](/manual/ja/operations/masters/plant/user)を登録しておいてください。
- 図面の上に印を置きたいときは、先に[拠点](/manual/ja/operations/masters/plant/user)の「フロアマップ」タブで図面を登録しておいてください。このアプリでは図面の追加や差し替えはできません。

## 画面の見かた（すべての拠点の一覧）

アプリを開くと、すべての拠点の保管場所がまとめて表示されます。

![保管場所の一覧画面](../../../assets/screenshots/master-storage-location-01.png)

- 一覧は **拠点 / コード / 名称 / 棚数 / マップ配置 / 状態** の順に並んでいます。
- 図面に印を置いてある保管場所には「**配置済**」と表示されます。
- 上の「**コード・名称・拠点で検索**」の欄で、探している場所を絞り込めます。
- 「**拠点を選択して管理**」で拠点を選ぶか、一覧の行をクリックすると、その拠点の管理画面に切り替わります。

## 保管場所を登録する

一覧の画面からでも、拠点の管理画面からでも登録できます。

1. 一覧画面の右上にある「**新規作成**」を押します。
2. 「**拠点**」で、この倉庫がある拠点を選びます。
3. 「**フロア**」で、置きたいフロアを選びます（空欄のままでもかまいません）。
4. 「**コード**」に、この場所を表す文字を入れます（例 `WH1`）。
5. 「**名称（日本語）**」に倉庫の名前を入れます（例 第一倉庫）。
6. 「**表示順**」に数字を入れます。小さい数字ほど上に出ます。
7. 「**保存**」を押します。

![保管場所の追加画面](../../../assets/screenshots/master-storage-location-new-01.png)

「フロア」を選んで保存すると、その図面の真ん中に印が仮に置かれます。あとから正しい位置へドラッグして直せます。図面がまだ無い拠点では「**この拠点にはフロアマップがありません（ピンなしで作成）**」と表示され、印なしで登録されます。

> 💡 拠点の管理画面からは、「**保管場所を追加**」を押すとその拠点の中に直接登録できます（拠点を選ぶ欄は出ません）。

## 拠点ごとの管理画面

拠点を選ぶと、その拠点の保管場所と棚をまとめて管理する画面になります。

![保管場所の管理画面](../../../assets/screenshots/master-storage-location-manage-01.png)

- 保管場所ごとにカードが並びます。カードには名称・コード・備考が出ます。無効にしている場所には「**無効**」と表示されます。
- カードの右には「**棚を追加**」「**編集**」「**削除**」のボタンが並びます。
- 登録した棚は、カードの中にコードと名称の小さな札で並びます。札のボタンから編集・削除ができます。

## 棚を登録する

1. 棚を足したい保管場所のカードで「**棚を追加**」を押します。
2. 「**棚コード**」に、棚を表す文字を入れます（例 `A-1`）。
3. 名前を付けたいときは「**名称（日本語・任意）**」に入れます（空欄でもかまいません）。
4. 「**表示順**」に数字を入れます。
5. 「**保存**」を押します。

![棚の追加画面](../../../assets/screenshots/master-storage-location-shelf-01.png)

## 図面の上に印を置く

拠点の管理画面には「**フロアマップ配置**」という欄があります。ここで、保管場所が拠点のどこにあるかを図面の上に示せます。

![フロアマップ配置の画面](../../../assets/screenshots/master-storage-location-map-01.png)

- 図面の下に、まだ置いていない保管場所が「**〈名称〉 を配置**」というボタンで並びます。押すと図面の真ん中に印が出ます。
- 印は **ドラッグ** して好きな位置へ動かせます。
- 置いた保管場所は図面の下に札で並びます。札の「×」を押すと、図面から外れます。
- フロアが 2 つ以上あるときは、上のタブでフロアを切り替えられます。「**重ね表示**」で別のフロアの図面をうすく重ねることもできます。

図面がまだ無いときは「**この拠点にはフロアマップがありません。拠点マスタ (MS0C) の「フロアマップ」タブでフロアと図面を登録してください。**」と表示されます。

## 入力項目

保管場所の登録画面で入力する項目の一覧です。

| 項目 | 何を入れるか |
|------|-------------|
| [拠点 / フロア](#field-plant) | どの拠点のどのフロアの場所かです |
| [コード / 名称（日本語・英語）](#field-code) | 場所の管理番号と名前です |
| [表示順](#field-sort-order) | 選択肢での並び順です |
| [有効 / 備考](#field-active) | 外すと保管場所の選択肢に出なくなります |

### 拠点 / フロア [#field-plant]

どの拠点のどのフロアの場所かです。**在庫はこの場所の単位で置き場所が分かります。**

### コード / 名称（日本語・英語） [#field-code]

場所の管理番号と名前です。

### 表示順 [#field-sort-order]

選択肢での並び順です。

### 有効 / 備考 [#field-active]

外すと保管場所の選択肢に出なくなります。備考は補足です。

## よくある質問・困ったとき

**Q.「この保管場所を参照する在庫があるため削除できません（在庫移動で空にするか、無効化してください）」と出ます。**
A. その場所にまだ在庫が残っています。[在庫管理](/manual/ja/operations/production/product-inventory/user)の在庫移動で中身を別の場所へ移して空にするか、編集画面で「**有効**」を切って無効にしてください。棚を消すときも同じです。

**Q. 保管場所を削除すると、中の棚はどうなりますか。**
A. 一緒に消えます。確認の画面に、消える棚の件数が表示されます。この操作は取り消せません。

**Q. 図面をアップロードするボタンがありません。**
A. 図面の登録・差し替えは[拠点](/manual/ja/operations/masters/plant/user)のアプリで行います。このアプリでは、登録済みの図面の上に印を置くことだけができます。

**Q. 一覧の「マップ配置」の列が空のままです。**
A. その保管場所はまだ図面の上に置かれていません。拠点の管理画面の「フロアマップ配置」で「〈名称〉 を配置」を押してください。置くと「**配置済**」に変わります。

**Q. 印を置こうとしたら「フロアマップが保管場所の拠点と一致しません」と出ます。**
A. 別の拠点の図面に置こうとしています。その保管場所がある拠点の管理画面を開いてから、置き直してください。

**Q. 在庫の登録画面に、作った棚が出てきません。**
A. その棚の「**有効**」が切れていないかご確認ください。無効の棚は選択肢に出ません。

**Q. 機械や作業する場所はどこで登録しますか。**
A. このアプリではなく、[作業場所](/manual/ja/operations/masters/work-location/user)で登録します。
