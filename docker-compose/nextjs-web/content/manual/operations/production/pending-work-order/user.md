「指示書をまだ作っていない注文」と「作ったけれどまだ終わっていない指示書」をまとめて確認する **未処理指示書** のアプリです。操作コードは `PD05` です。

> このアプリが属するフロー … [生産の流れ](/manual/ja/process/production)

## このアプリでできること

- 確定した注文明細のうち、指示書の手配がまだ足りていないものを一覧で見られます。
- 足りない本数が入力された状態で、[指示書](/manual/ja/operations/production/work-order/user)の新規作成へ直行できます。
- 作成済みで、まだ完了していない指示書（下書き・承認待ち・承認済・進行中）を確認できます。
- 「今日どの注文の指示書を作るか」を納期の近い順に決めるときに便利です。

## 用語（このページで出てくる言葉）

- **注文明細（ちゅうもんめいさい）** … 注文請書の 1 行分です。「この製品を何本」という受注の単位です。
- **指示書（しじしょ）** … 「この製品を何本つくる」という製造の指示です。
- **手配（てはい）** … 注文明細に対して指示書を作ることです。1 つの明細を複数の指示書に分けることもできます。
- **未手配（みてはい）** … 受注した本数のうち、まだ指示書になっていない本数です。**未手配 = 受注数 − 手配済** で計算されます。

## 開き方

ホーム画面の「生産」の中にある **未処理指示書** を押します。または、画面上の検索欄に `PD05` と入れます。閲覧には指示書の権限が必要です。

## 画面の見かた

画面にはタブが 2 枚あります。どちらも「まだ処理が終わっていないもの」だけが並ぶ作業キューです。

- **未手配** … 指示書がまだ足りていない注文明細です。件数がオレンジ色で表示されます。
- **進行中** … 作成済みで、完了・キャンセルになっていない指示書です。

上の検索欄と「**状態**」（進行中タブでは「**種別**」も）で絞り込めます。条件を消すときは「**リセット**」を押します。

### 未手配タブ

確定済みの注文明細のうち、指示書の本数が受注数に届いていないものが、**納期の早い順** に並びます。

- **注文明細番号** … クリックすると[注文明細](/manual/ja/operations/sales/order-line/user)の詳細が開きます。
- **顧客 / 製品** … 誰から受けた、どの製品の注文かです。
- **受注数** … 注文された本数です。
- **手配済** … すでに指示書に割り当てた本数の合計です。キャンセルした指示書の分は数えません。また、完了した指示書で不良が出て本数が足りなかった場合、その不足分は未手配に戻ります。
- **未手配** … 受注数 − 手配済。オレンジ色のバッジで表示されます。
- **在庫引当** … 製品在庫から引き当て済みの本数です。この分は「在庫分」の指示書に回せます。
- **納期 / 状態** … 納入予定日と、明細の状態（確定・製造中・一部出荷）です。

### 進行中タブ

完了・キャンセルになっていない指示書が並びます。行をクリックすると[指示書](/manual/ja/operations/production/work-order/user)の詳細が開きます。

- **指示書番号 / 注文明細番号** … 注文に紐づかない指示書には「**在庫向け**」のバッジが付きます。
- **種別** … 「製造分」か「在庫分」かです。
- **予定数量 / 承認状態 / 状態** … 何本作る予定か、承認がどこまで進んだか、指示書がどの段階か（下書き・承認待ち・承認済・進行中）です。

完了した指示書はこの画面には出ません。[指示書](/manual/ja/operations/production/work-order/user)の一覧（`PD02`）で確認してください。

## 未手配の注文から指示書を作る

1. 「**未手配**」タブで、指示書を作りたい行を探します。
2. 行の右端にある「**指示書作成**」を押します。
3. 指示書の新規作成画面が開きます。その注文明細が選ばれ、種別は「**製造分**」、数量には **未手配の本数** が入った状態で始まります。
4. 内容を確認して保存します。以降の手順は[指示書](/manual/ja/operations/production/work-order/user)のマニュアルをご覧ください。

保存すると、その分だけ「手配済」が増えます。未手配が 0 本になった明細は、このタブから消えます。

## よくある質問・困ったとき

**Q. 一覧にあった注文明細が消えました。**
A. 受注数のすべてが指示書に割り当てられた（未手配が 0 本になった）ためです。作った指示書は「進行中」タブか、指示書の一覧（`PD02`）で確認できます。

**Q. 指示書をキャンセルしたら、注文が未手配タブに戻ってきました。**
A. 正しい動きです。キャンセルした指示書の本数は「手配済」から外れるので、その分が未手配に戻り、作り直しの対象になります。

**Q. 未手配タブに「指示書待ちの注文明細はありません」と表示されます。**
A. 指示書の手配が必要な注文明細が今は無い、という意味です。注文明細は確定すると（枝番が付くと）ここに出てきます。

**Q. 完了した指示書はどこで見られますか？**
A. この画面は作業キューなので、完了・キャンセルした指示書は出ません。指示書の一覧（`PD02`）で状態を「完了」にして絞り込んでください。

**Q. 1 つの注文を複数の指示書に分けられますか？**
A. できます。「指示書作成」で数量を減らして保存すれば、残りの本数はまた未手配としてこの一覧に残ります。
