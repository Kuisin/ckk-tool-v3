製品や素材が **どこに何本あるか** を確認するアプリです。置き場所を変えたときの記録もここで行います。操作コードは `PD04` です。

> ⚠️ このアプリは今のところ **テスト用の環境だけ** で使えます。本番で使えるようになるまでに、画面や手順が変わることがあります。

## このアプリでできること

- できあがった製品が、どの拠点のどの棚に何本あるかを確認できます。
- 取り置き（予約）されている分と、まだ自由に使える分を分けて確認できます。
- 品物を別の棚や別の倉庫に移したとき、その記録を残せます。
- 在庫が動いた記録（いつ・何が・何本）を後から確認できます。

画面は 4 つのタブに分かれています。

- **製品** … できあがった製品と半製品の在庫です（このページで説明します）。
- **素材** / **仕掛品** … 素材の在庫と、いま作っている途中の本数です。→ [在庫管理（素材・仕掛品）](/manual/ja/operations/production/material-inventory/user)
- **ロケーション** … 拠点 → 保管場所 → 棚 の順に「どこに何があるか」を見る画面です（このページで説明します）。

以前は「製品在庫」と「素材在庫」が別々のアプリでしたが、今はこの 1 つのアプリにまとまっています。以前の画面のリンクを開いても、このアプリに自動でつながります。

> 💡 在庫の数はここで直接は直せません。数は毎日の業務にあわせて **自動で動きます**。この画面から手で行える操作は「**在庫移動**」（置き場所を変える）だけです。

## 用語（このページで出てくる言葉）

- **拠点（きょてん）** … 工場や倉庫など、大きな場所の単位です。
- **保管場所 / 棚** … 拠点の中の置き場所です。「第一倉庫」の「A-1」棚、のように 2 段階で管理します。
- **ロット** … まとめて作った製品のかたまりに付く番号です。指示書の番号がそのまま入ります。
- **予約（取り置き）** … 特定の注文のために確保されている分です。ほかの注文には使えません。
- **利用可能** … 在庫のうち、まだ予約されていない分です。実際に使える本数です。
- **半製品（はんせいひん）** … 完成する前の段階で在庫に戻した品物です。

## 在庫はどこから増えたり減ったりするのか

在庫はこの画面ではなく、ふだんの業務の操作にあわせて自動で動きます。

- **入る** … [指示書](/manual/ja/operations/production/work-order/user)のすべての工程が完了すると、良品がロット番号付きで在庫に入ります。「半製品」に振り分けた分は半製品として在庫に入ります。
- **取り置きされる** … 注文請書の画面で「**在庫照合**」を実行すると、使える在庫がその注文のために予約されます。
- **出る** … [出荷書](/manual/ja/operations/shipping/shipping-order/user)で出荷すると在庫から出て、予約も外れます。

## 製品タブの見かた

![在庫管理の製品タブ](../../../assets/screenshots/inventory-products-01.png)

- **製品** … 製品の名前と製品コードです。
- **拠点** … どの拠点にあるかです。
- **保管場所** … 「場所名 / 棚コード」の形で出ます。まだ置き場所を決めていないものは「**未割当**」と出ます。
- **ロット** … その在庫のロット番号です。
- **在庫数** … 実際にある本数です。
- **利用可能** … そのうち自由に使える本数です。予約がある場合は「予約 50」のようなバッジが付きます。
- **区分** … 「**完成品**」か「**半製品**」かです。
- **移動** … 置き場所を変えるときに押すボタンです。
- 上の検索欄に製品名や製品コードを入れて探せます。「**拠点**」「**区分**」でも絞り込めます。
- 行をクリックすると、その在庫の詳しい画面が開きます。

## 詳しい画面を見る

行をクリックすると、その在庫 1 件の詳しい画面が開きます。

![製品在庫の詳細画面](../../../assets/screenshots/inventory-product-detail-01.png)

上のほうに、製品・拠点・ロット番号・区分・在庫数・予約数・利用可能・保管場所が並びます。半製品の場合は「**発生工程**」（どの指示書のどの工程から出たか）も表示されます。

下には 2 つのタブがあります。

- **予約** … この在庫を取り置きしている注文の一覧です。状態は「**予約中**」→「**確定**」→「**解除**」と進みます。関係する注文請書番号・指示書番号も確認できます。
- **取引履歴** … 在庫が動いた記録です。

![取引履歴タブ](../../../assets/screenshots/inventory-transactions-01.png)

取引履歴の「**種別**」は次の 5 つです。

- **入庫** … 在庫が増えたとき
- **出庫** … 在庫が減ったとき
- **予約** … 注文のために取り置きされたとき
- **解除** … 取り置きが外れたとき
- **調整** … 棚卸しなどで数を合わせたとき

在庫移動をすると、移動元の「出庫」と移動先の「入庫」の 2 行が残ります。

## 置き場所を変える（在庫移動）

品物を別の棚や別の倉庫に移したら、この操作で記録します。

1. 一覧の行の右にある「**移動**」ボタンを押します（ロケーションタブの在庫のチップからも押せます）。
2. 「在庫移動」の画面が開きます。上に「現在地」と「移動可能」な本数が出ます。
3. 「**移動先の拠点**」を選びます。
4. 「**保管場所**」を選びます。
5. 「**棚**」を選びます。
6. 「**数量（本）**」に移す本数を入れます。
7. 必要なら「**備考（任意）**」を書きます。
8. 「**移動する**」を押します。

![在庫移動の画面](../../../assets/screenshots/inventory-transfer-01.png)

> ⚠️ 予約されている分は移動できません。入れられる本数の上限は「利用可能」の本数です。製品は小数では入れられません。

## ロケーションタブの見かた

「どこに何があるか」を場所の形で見る画面です。

![在庫管理のロケーションタブ](../../../assets/screenshots/inventory-locations-01.png)

- 上の「**拠点**」を選ぶと、その拠点の **保管場所のカード**（名前とコード）が並びます。
- カードの中には **棚のマス目** が並び、そこにある品物と本数が表示されます。何も入っていない棚には「**空き**」と出ます。
- 保管場所は決まっているが棚が決まっていない在庫は「**棚未割当**」の枠に、保管場所も決まっていない在庫は「**未割当（保管場所なし）**」の枠にまとまります。
- 拠点にフロアマップ（拠点の見取り図）が登録されていて、保管場所のピンが置かれていれば、**フロアマップ** も表示されます。ピンをクリックすると、その保管場所のカードまで画面が動いて目立つ表示になります。
- その拠点に何も無いときは「この拠点には保管場所も在庫もありません」という案内が出ます。

保管場所と棚そのものの登録は[保管場所](/manual/ja/operations/masters/storage-location/user)で行います。

このアプリを使うには、在庫の権限が必要です。

## 入力項目

在庫管理は基本的に**見るための画面**ですが、在庫を別の場所へ移すときだけ入力します。

| 項目 | 必須 | 何を入れるか |
|------|------|-------------|
| [移動先の拠点](#field-plant) | 必須 | どこへ移すか |
| [保管場所 / 棚](#field-location) | 任意 | 拠点の中のどこへ置くか |
| [数量](#field-quantity) | 必須 | 移す数 |
| [備考](#field-notes) | 任意 | 移動の理由など |

### 移動先の拠点 [#field-plant]

どの拠点へ移すかです。**移動元の在庫が減り、移動先の在庫が増えます。**

### 保管場所 / 棚 [#field-location]

移動先の拠点の中で、どこに置くかです。決めておくと、あとで現物を探しやすくなります。

### 数量 [#field-quantity]

移す数です。移動元にある数を超えては移せません。

### 備考 [#field-notes]

移動の理由などを残しておく欄です。移動の記録は履歴に残ります。

## よくある質問・困ったとき

**Q. 在庫の数を手で直したいのですが。**
A. この画面からできるのは「在庫移動」（置き場所を変えること）だけです。数がずれている場合は棚卸しの調整が必要なので、管理者に相談してください。

**Q.「利用可能」が 0 なのに「在庫数」があります。**
A. その分はほかの注文のために取り置き（予約）されています。「予約」タブを開くと、どの注文に取り置きされているかを確認できます。

**Q. 移動しようとしたら、入れたい本数が入りません。**
A. 移動できるのは「利用可能」の本数までです。予約されている分は動かせません。

**Q. 保管場所が「未割当」になっています。**
A. 指示書の完了などで自動的に入った在庫は、置き場所が決まっていない状態で入ります。実際の棚に置いたら「移動」で場所を記録してください。

**Q. 作っている途中の製品が「製品」タブに出てきません。**
A. 製造中の本数はまだ在庫になっていません。「**仕掛品**」タブで確認できます。在庫に入るのは、すべての工程が完了したときです。

**Q. ロケーションタブに何も出ません。**
A. その拠点にまだ保管場所が登録されていないか、在庫がありません。保管場所の登録は管理者に相談してください。
