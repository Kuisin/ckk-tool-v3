設計部門に図面の作成をお願いし、できあがった図面ファイルを **版（バージョン）ごとに残しておく** アプリです。操作コードは `SA05` です。

> ⚠️ このアプリはまだ試験公開中です。画面や手順が今後変わることがあります。

## このアプリでできること

- 設計をお願いする内容を書いて、依頼として登録できます。
- 見積のときの依頼か、受注のあとの依頼かを分けて記録できます。
- 依頼の進み具合を **未着手 → 進行中 → 完了** で管理できます。
- できあがった図面ファイルを添付し、**v1・v2 と版を分けて** 残せます。
- 製品を指定しておくと、完了したときに[製品マスタ](/manual/ja/operations/masters/product/user)の最新の図面が入れ替わります。

お客様から特別な形状の相談があり、図面が必要になったときに使います。

## 用語（このページで出てくる言葉）

- **トリガー** … 何をきっかけに設計を頼むかの区分です。**見積時** と **受注時** のどちらかを選びます。
- **見積時** … 見積書を出す前に、並行して図面を作ってもらう場合です。
- **受注時** … 注文が決まったあとで図面を作ってもらう場合です。
- **依頼内容** … 設計してほしいことを書く文章の欄です。
- **バージョン（版）** … 図面を作り直すたびに増える番号です。v1、v2 と増え、いちばん新しいものに「最新」と付きます。
- **未着手 / 進行中 / 完了** … 依頼の今の状況です。

## はじめる前に

- 図面の対象になる[製品](/manual/ja/operations/masters/product/user)が登録されていると、完了時にその製品の最新図面として残せます（製品を選ばずに依頼することもできます）。
- 「見積時」で登録する場合は、先に[見積書](/manual/ja/operations/sales/quote/user)があると、その見積と結び付けられます。
- 「受注時」で登録する場合は、先に受注明細があると結び付けられます（受注明細は[受注請書](/manual/ja/operations/sales/order-acceptance/user)の「受注確定」で作られます）。
- 完了するには **図面ファイルの添付が 1 件以上必要** です。

## 画面の見かた

アプリを開くと、これまでの依頼が一覧で表示されます。

![設計依頼書の一覧画面](../../../assets/screenshots/design-request-list-01.png)

- **依頼番号** … `DSG-` で始まる番号です。保存すると自動で付きます。
- **トリガー** … 「見積時」か「受注時」がバッジで表示されます。
- **状態** … 色つきのバッジで今の状況がわかります。灰色は「未着手」、青は「進行中」、緑は「完了」です。
- 上の検索欄に依頼番号・製品名・依頼内容の言葉を入れると絞り込めます。右側の「トリガー」「状態」でも絞り込めます。
- 行をクリックすると、その依頼の詳しい画面が開きます。

## 設計を依頼する

1. 一覧画面の右上にある「**新規作成**」を押します。
2. 「**トリガー**」で「**見積時**」か「**受注時**」を押して選びます。
3. 見積時を選んだ場合は「**見積書**」の欄で、もとになる見積書を選びます（空欄のままでも登録できます）。
4. 受注時を選んだ場合は「**受注明細**」の欄で、もとになる受注明細を検索して選びます（空欄のままでも登録できます）。
5. 「**製品**」の欄で対象の製品を選びます（空欄のままでも登録できます）。
6. 「**依頼内容**」に、設計してほしいことを書きます。
7. 「**保存**」を押します。

![設計依頼書の新規作成フォーム](../../../assets/screenshots/design-request-new-01.png)

保存すると依頼番号が付き、詳しい画面が開きます。

> ⚠️ 「トリガー」と、そこで選んだ見積書・受注明細は **あとから変えられません**。間違えたときは、新しい依頼を作り直してください。

## 依頼を進める

作った直後の状態は「**未着手**」です。

1. 設計の作業を始めるときは、画面の右上にある「**着手**」を押します。
2. 状態が「**進行中**」に変わります。

![未着手の設計依頼書](../../../assets/screenshots/design-request-detail-01.png)

未着手と進行中のあいだは、右上の「**編集**」を押すと、**製品** と **依頼内容** を直せます。

![進行中の設計依頼書（操作メニューを開いたところ）](../../../assets/screenshots/design-request-detail-02.png)

## 図面ファイルを添付する

1. 依頼の画面で「**ファイル**」タブを開きます。
2. 右上の「**アップロード**」を押します。
3. ファイルを選びます（PDF・画像・Excel・CSV。1 件 20MB まで）。
4. 必要なら「**ラベル（任意）**」に説明を書きます。
5. 「**アップロード**」を押します。

![ファイルタブ（版の一覧）](../../../assets/screenshots/design-request-files-01.png)

添付をやめたいときは、ファイルの右にあるゴミ箱のマークを押し、「**削除する**」を押します。

添付ができるのは、状態が **完了になる前** だけです。

## 依頼を完了する

1. 画面の右上の「**…**」を押します。
2. 「**完了**」を選びます。
3. 確認の画面が出るので「**完了**」を押します。

完了すると、そのときのいちばん新しい添付ファイルが **版（v1、v2 …）として登録** され、「**最新**」バッジが付きます。完了日も記録されます。製品を指定していた依頼では、その製品の最新図面もこの版に切り替わります。

完了したあとに直しが必要になったときは、「**…**」から「**差し戻し**」を押し、「**差し戻す**」を押します。状態が「進行中」に戻り、編集とファイルの追加ができるようになります（完了日は消えます）。

## 入力項目

設計依頼書の画面で入力する項目の一覧です。アプリの入力欄の横にある「?」からも、その項目の説明へ直接来られます。

| 項目 | 必須 | 何を入れるか |
|------|------|-------------|
| [トリガー](#field-trigger) | 必須 | 見積時か、受注時か |
| [見積書](#field-quote) | 条件付き | 見積時に選ぶ元の見積書 |
| [受注明細](#field-order-line) | 条件付き | 受注時に選ぶ元の受注明細 |
| [製品](#field-product) | 任意 | 図面をつくる製品 |
| [依頼内容](#field-description) | 必須 | 何を設計してほしいか |

### トリガー [#field-trigger]

その依頼が **見積のためのもの**か、**受注が決まってからのもの**かを選びます。選んだ方によって、次の「見積書」か「受注明細」のどちらを紐づけるかが変わります。

### 見積書 [#field-quote]

トリガーが見積時のときに選びます。どの見積のための設計かを残しておくと、後から経緯をたどれます。

### 受注明細 [#field-order-line]

トリガーが受注時のときに選びます。どの受注のための設計かを残します。

### 製品 [#field-product]

図面をつくる対象の製品です。**新規の製品でまだ登録が無い場合は空のままにできます** — 製品が登録された後で紐づけても構いません。

### 依頼内容 [#field-description]

何を設計してほしいかを書きます。**製造の担当者はここだけを見て図面を作る**ので、寸法・形状・参考にする既存品・注意点などを具体的に書いてください。

## よくある質問・困ったとき

**Q.「設計ファイルを添付してから完了してください」と出て完了できません。**
A. 図面ファイルがまだ添付されていません。「**ファイル**」タブから図面をアップロードしてから、もう一度「完了」を押してください。

**Q. 完了した依頼を編集できません。**
A. 完了した依頼は編集もファイルの追加もできない決まりです。直したいときは、先に「**差し戻し**」で進行中に戻してください。

**Q. トリガーや見積書の欄が変えられません。**
A. トリガーと、そこで選んだ見積書・受注明細は、作ったあとは変えられません。間違えた場合は新しい依頼を作り直し、間違えたほうはそのままにしておくか、担当者に相談してください。

**Q. 見積書や受注明細は必ず選ぶ必要がありますか。**
A. どちらも任意です。何も結び付けずに依頼を作ることもできます。

**Q.「未着手の設計依頼書のみ着手できます」と出ます。**
A. その依頼はすでに進行中か完了しています。もう一度「着手」を押す必要はありません。

**Q. 完了したあとにファイルを差し替えたいです。**
A. 「差し戻し」で進行中に戻し、新しいファイルをアップロードしてから、もう一度「完了」を押してください。前の版は残ったまま、新しい版が追加されます。
