注文請書を確定すると、その明細 1 行ごとに **注文明細** ができます。このアプリは、できあがった注文明細を注文請書をまたいで一覧し、**在庫の引き当て・製造・出荷がどこまで進んだか**を追いかけるための画面です。操作コードは `SA05` です。

> ⚠️ このアプリはまだ試験公開中です。画面や手順が今後変わることがあります。

## このアプリでできること

- 確定した注文明細を、注文請書をまたいで **まとめて一覧** できます。
- 1 行ずつ、指示書・出荷・引き当ての進み具合を確認できます。
- 在庫がどれだけ使えるかを調べて、**引き当て（予約）** をかけられます。
- 受注が取り消しになったときに、その行をキャンセルできます。

**このアプリでは注文明細を新しく作ったり、内容を直したりはできません。** 作成と修正は [注文請書](/manual/ja/operations/sales/order-acceptance/user) の明細で行います。理由は下の「[内容を直したいとき](#内容を直したいとき)」を読んでください。

## 用語（このページで出てくる言葉）

- **注文請書（じゅちゅううけしょ）** … お客様から受けた注文 1 件分の記録です。
- **注文明細（じゅちゅうめいさい）** … 注文請書の明細 1 行のことです。「どの製品を何本」の 1 行が、そのまま製造・出荷のもとになります。
- **注文確定（じゅちゅうかくてい）** … 承認済の注文請書を確定して、明細に番号を付ける操作です。
- **枝番（えだばん）** … `ORD-202608-00012-01` の最後の `-01` の部分です。注文請書の中で何行目かを表します。
- **引き当て（ひきあて）** … その受注のために在庫を取り置きすることです。ほかの受注に使われないよう予約します。
- **ロット番号** … 製造の単位に付く通し番号（例: `#9001`）です。指示書を作ると自動で付きます（指示書の書類番号 `WO-…` とは別の番号です）。

## 番号の読みかた

注文明細の番号は、注文請書の番号のうしろに枝番が付いた形です。

```
ORD-202608-00012-01
└──────┬──────┘ └┬┘
   注文請書の番号   枝番（何行目か）
```

同じ注文請書から作られた行は、前半が同じで枝番だけが違います。たとえば 3 行の注文なら `-01` `-02` `-03` の 3 件になります。

**同じ製品が 2 行に分かれていても、まとめません。** お客様の注文書で 2 行に分かれているなら、注文明細も 2 件のままです。逆に、1 行を 2 つに割ることもできません。**注文書の 1 行 = 注文明細 1 件**が守られます。

## 画面の見かた

アプリを開くと、確定済みの注文明細の一覧が表示されます。

- **注文明細番号** … 上で説明した `ORD-…-NN` の番号です。
- **顧客** … 注文をくれたお客様です。注文請書から引き継ぎます。
- **製品 / 数量 / 単価 / 金額** … 注文の中身です。
- **納期** … お客様と約束した日です。
- **状態** … 色つきのバッジで今の状況がわかります。

確定前の明細はこの一覧に出てきません。まだ番号が付いていないためです。確定前のものを見たいときは [注文請書](/manual/ja/operations/sales/order-acceptance/user) を開いてください。

### 状態の意味

| 状態 | 意味 |
| --- | --- |
| 確定 | 受注が確定し、これから製造・出荷に進む状態です。 |
| 製造中 | 指示書が承認され、工場で作りはじめた状態です。 |
| 一部出荷 | 注文本数のうち、一部だけ出荷が済んだ状態です。 |
| 出荷済 | 注文本数すべての出荷が済んだ状態です。 |
| キャンセル | 取り消した注文明細です。 |

## 詳細画面でできること

一覧から 1 行を選ぶと、その注文明細の詳細が開きます。

### 在庫を調べて引き当てる

「**在庫照合**」を押すと、その製品の在庫を調べて、**使える分だけ引き当て（予約）** します。

- 引き当てた分は、ほかの受注に取られなくなります。
- 足りない分は「不足」として表示されます。不足分は [指示書](/manual/ja/operations/production/work-order/user) を作って製造します。
- 在庫照合ができるのは **確定 / 製造中になる前** の注文明細だけです。製造が始まったあとは指示書のほうで数量を管理します。

### 製造の進み具合を見る

「指示書」タブに、この注文明細に割り当てられた指示書が並びます。**1 つの注文明細に指示書を何枚でも作れます**（在庫分と製造分に分ける、一部だけ先に作って残りをあとから足すなど）。逆に、**同じ製品なら複数の注文明細を 1 つの指示書（1 ロット）にまとめて作る**こともできます。「割当数量」がこの明細のためにつくる本数、「予定数量」がその指示書全体でつくる本数です（不良予備分のぶん多いことがあります）。

### 出荷の進み具合を見る

「出荷」タブに、この注文明細を含む出荷書が並びます。表示される数量は **この注文明細ぶんだけ** です。1 枚の出荷書に複数の注文明細をまとめて載せられるため、出荷書全体の数量とは違うことがあります。

出荷が進むと、状態が自動で「一部出荷」→「出荷済」と変わります。**注文本数を超える出荷はできません。** 超えそうなときは出荷の操作が止まり、どの注文明細で超えたかが表示されます。

### キャンセルする

受注が取り消しになったときは「キャンセル」を押します。あわせて次のことが自動で行われます。

- 引き当てていた在庫が **すべて解放** されます。
- まだ終わっていない指示書が **連鎖してキャンセル** されます（完了済みのものはそのまま残ります）。ただし、**ほかの注文明細もまとめて作っている指示書（統合ロット）はキャンセルされず**、そのまま残ります。

出荷が済んだ注文明細と、すでにキャンセルした注文明細はキャンセルできません。

## 内容を直したいとき

**確定したあとの注文明細は、数量も単価も製品も変更できません。** 注文明細は「お客様と約束した内容」そのものなので、あとから書き換えられると、製造や請求のもとになった数字が分からなくなってしまいます。

まだ確定していない（注文請書が下書きの）うちは、[注文請書](/manual/ja/operations/sales/order-acceptance/user) の明細でいくらでも直せます。**確定は「もう直さない」と決める操作** だと考えてください。

確定後に内容が変わってしまったときは、担当者に相談してください。

## 困ったときは

**一覧に出てこない**

確定前の可能性があります。[注文請書](/manual/ja/operations/sales/order-acceptance/user) を開いて、状態が「確定済」になっているか確認してください。承認と確定がまだなら、まずそちらを進めます。

**在庫照合を押せない**

すでに製造が始まっている注文明細では押せません。その場合は [指示書](/manual/ja/operations/production/work-order/user) のほうで数量を確認してください。

**出荷しようとしたら「受注数量を超える出荷になります」と出た**

その注文明細で、すでに出荷した本数と今回の本数を足すと注文本数を超えています。出荷書の本数を減らすか、対象の注文明細が正しいか確認してください。

**アプリが一覧に出てこない**

注文請書と同じ権限（`order_acceptance`）が必要です。見えない場合は管理者に連絡してください。
