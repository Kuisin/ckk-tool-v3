できあがった製品をお客様へ送るときに、**何をいくつ送ったか** を記録する **出荷書** を作るアプリです。操作コードは `SH01` です。

> ⚠️ このアプリはまだ準備中です。正式に使えるようになるまでに、画面や手順が変わることがあります。

## このアプリでできること

- 送る製品と本数をまとめた出荷書をつくれます。
- 注文請書を選ぶだけで、**でき上がった分の明細が自動で入ります**（手で打ち直す必要はありません）。
- 出荷した記録を残すと、**在庫が自動で減ります**。
- 出荷書から[納品書](/manual/ja/operations/shipping/delivery-note/user)をつくれます。
- 送らずに社内で預かる分（予備でつくった分など）も記録できます。

出荷書は、あとで[請求書](/manual/ja/operations/billing/invoice/user)をつくるときの元になる大事な書類です。

## 用語（このページで出てくる言葉）

- **注文請書（ちゅうもんうけしょ）** … 「どのお客様に、どの製品を何本、いつまでに」を決めた書類です。出荷書はこれを見ながら作ります。
- **指示書（しじしょ）** … 工場に「この製品をこれだけ作ってください」と出す書類です。作り終わった指示書の分を出荷します。
- **ロット** … 一度にまとめて作った製品のかたまりにつく番号です。指示書の番号がそのままロット番号になります。
- **発送 / 在庫保管** … 「発送」はお客様へ送る分、「在庫保管」は送らずに社内で保管しておく分です。
- **明細（めいさい）** … 出荷書の中の 1 行のこと。「どの製品を何本」を書きます。

## はじめる前に

- 出荷したい分の **注文請書** が先に登録されている必要があります。
- 製品ができ上がっていること（[指示書](/manual/ja/operations/production/work-order/user)が完了していること）を確認してください。完了した指示書の分が、明細に自動で入ります。
- 出荷書を作ったり出荷したりするには、出荷の権限が必要です。使えないときは管理者にご相談ください。

## 画面の見かた

アプリを開くと、これまでに作った出荷書の一覧が出ます。

![出荷書の一覧画面](../../../assets/screenshots/shipping-order-list-01.png)

- **出荷書番号** … `SHP-` で始まる番号です。システムが自動で付けます。
- **種別** … 青い「発送」はお客様へ送る分、灰色の「在庫保管」は社内で預かる分です。
- **状態** … 灰色は「下書き」、青は「確定」、緑は「出荷済」です。
- 上の検索欄には、出荷書番号・注文請書番号・お客様の名前・製品名を入れて絞り込めます。この検索欄は **すでに作った出荷書を探すため** のもので、新規作成のときに注文請書を選ぶ欄とは別ものです。
- 一覧に出るのは、**自分が所属している拠点から送る出荷書** です。
- 行をクリックすると、その出荷書の詳しい画面が開きます。

## 出荷書をつくる

1. 一覧画面の右上にある「**新規作成**」を押します。
2. 「**注文請書**」の欄をクリックして、出荷したい注文請書を選びます。この欄の中では、**お客様の名前・製品名・お客様の注文書番号** で探します（一覧画面の検索欄とはちがい、`ORD-` で始まる注文請書番号では探せません）。
3. でき上がった指示書の分が、**明細に自動で入ります**（1 つの指示書につき 1 行）。数量には、その指示書でできた良品の数が入ります（まだ記録がないときは作る予定だった数です）。
4. 「**種別**」で「**発送**」か「**在庫保管**」を選びます。ふつうはそのまま「発送」です。
5. 「**出荷元拠点**」で、どこから送るかを選びます。
6. 明細の「**数量**」を、実際に送る本数に直します。
7. 行を増やしたいときは「**明細を追加**」、消したいときは行の右にあるゴミ箱の印を押します。
8. 「**保存**」を押します。

![出荷書の新規作成フォーム](../../../assets/screenshots/shipping-order-new-01.png)

保存すると「**下書き**」として登録され、詳しい画面が開きます。

> 💡 注文請書を選ぶと、その注文の内容（お客様・製品・受注した本数・でき上がった指示書の件数）が青い帯で表示されます。合っているか確認してから進めてください。

> ⚠️ 注文請書は、保存したあとで変えられません。間違えたときは、その出荷書をキャンセルして作り直してください。

## 内容を確認する

![出荷書の詳しい画面](../../../assets/screenshots/shipping-order-detail-01.png)

上のほうに、出荷書番号・注文請書番号・お客様・製品・種別・出荷元拠点・数量・出荷日が並びます。

- **数量合計** … 「30 / 受注 50」のように、送る本数と注文された本数を並べて表示します。
- 下の「明細」には、製品・ロット・数量・備考が並びます。
- タブは 3 つあります。**概要** は備考、**納品書** はこの出荷書から作った納品書の一覧、**履歴** はいつ誰が変更したかの記録です。

## 出荷までの 3 段階

出荷書は「下書き → 確定 → 出荷済」と 3 段階で進みます。操作は画面右上の「**…**」（点が 3 つのボタン）から行います。

![詳しい画面の「…」メニュー](../../../assets/screenshots/shipping-order-menu-01.png)

### 1. 内容を固める（確定）

1. 出荷書の画面で右上の「**…**」を押します。
2. 「**確定**」を選びます。
3. 「確定の確認」という小さな画面が出るので、内容を読んで「**確定**」を押します。

![確定の確認画面](../../../assets/screenshots/shipping-order-confirm-01.png)

確定すると **編集ができなくなり**、代わりに納品書が作れるようになります。

### 2. 実際に送ったら（出荷）

1. 右上の「**…**」を押します。
2. 「**出荷**」を選びます。
3. 「出荷の確認」が出るので「**出荷する**」を押します。

出荷すると、その日の日付が **出荷日** として記録され、状態が「**出荷済**」になります。同時に、送った分だけ[製品在庫](/manual/ja/operations/production/product-inventory/user)が減り、注文請書のほうも「一部出荷」または「出荷済」に自動で変わります。

### まちがえたとき（キャンセル）

「下書き」のあいだだけ、右上の「**…**」から「**キャンセル**」で消せます。確定したあとは消せません。

## 送らずに社内で保管する（在庫保管）

予備で多めに作った分など、お客様へ送らずに社内で保管するときは、「**種別**」で「**在庫保管**」を選びます。

- 「在庫保管」で出荷すると、製品は保管先の在庫として **増えます**。
- 請求の対象にはなりません。注文請書の状態も変わりません。

種別で「在庫保管」を選ぶと、画面にその説明が出ます。

## 納品書をつくる

1. 出荷書の画面で「**納品書**」タブを開きます。
2. 「**納品書を作成**」を押します。
3. 出荷書があらかじめ選ばれた状態で、[納品書](/manual/ja/operations/shipping/delivery-note/user)の作成画面が開きます。

![納品書タブ](../../../assets/screenshots/shipping-order-delivery-notes-01.png)

このタブには、この出荷書から作った納品書の一覧（納品番号・納品先・方法・状態・納品日）も並びます。

## 入力項目

出荷書の画面で入力する項目の一覧です。アプリの入力欄の横にある「?」からも、その項目の説明へ直接来られます。

| 項目 | 必須 | 何を入れるか |
|------|------|-------------|
| [注文請書](#field-sales-order) | 必須 | どの受注に対する出荷か |
| [種別](#field-type) | 必須 | 発送か、在庫保管か |
| [出荷元拠点](#field-plant) | 必須 | どの拠点から出すか |
| [備考](#field-notes) | 任意 | 出荷書全体への補足 |
| [製品](#field-product) | 必須 | 出す製品 |
| [ロット（在庫）](#field-lot) | 必須 | どの製造分から出すか |
| [数量](#field-quantity) | 必須 | 出す本数 |

### 注文請書 [#field-sales-order]

どの受注に対する出荷かを選びます。選ぶと、その受注の製品と残りの数量が分かります。

### 種別 [#field-type]

出荷の種類です。**発送だけが納品書・請求へ進みます。**

- **発送** … お客様へ送るもの。納品書・請求へ進みます
- **在庫保管** … 予備に作った分を社内に置いておくもの。**請求には進みません**

### 出荷元拠点 [#field-plant]

どの拠点から出すかです。**この拠点の在庫が減ります**ので、実際に荷物を出す拠点を選んでください。

### 備考 [#field-notes]

出荷書全体への補足です。明細ごとの補足は、各行の備考に書きます。

### 製品 [#field-product]

出す製品です。注文請書を選ぶと、その受注の製品から選べます。

### ロット（在庫）[#field-lot]

どの製造分（ロット）から出すかを選びます。**ロット番号は指示書の番号と同じ**で、これによって「どの製造分をどのお客様へ出したか」が後から追えます。選べるのは、出荷元拠点に在庫があるロットだけです。

### 数量 [#field-quantity]

出す本数です。ロットの在庫数を超えては出せません。分けて出す場合は、出荷書を分けて作ります。

## よくある質問・困ったとき

**Q. 新規作成の「注文請書」の欄で、出荷したい注文請書が検索しても出てきません。**
A. この欄には **お客様の名前・製品名・お客様の注文書番号** を入れてください。ここでは `ORD-` で始まる注文請書番号では見つかりません（一覧画面の上にある検索欄とは別ものです。そちらでは注文請書番号でも探せます）。それでも出ないときは、その注文請書がすでに「出荷済」またはキャンセルになっている可能性があります。

**Q. 注文請書を選んだのに、明細が 1 行しか入りません。**
A. まだ完了した指示書がないときは、空の行が 1 行だけ入ります。製品ができ上がってから作り直すか、送る本数を手で入れてください。

**Q.「受注数量 50 を超える出荷になります（累計 60）」と出て、出荷できません。**
A. 同じ注文請書で、注文された本数より多く送ろうとしています。この出荷書の数量を減らすか、これまでの出荷分を確認してください。

**Q.「在庫が不足」と出て、出荷できません。**
A. 出荷元の拠点に、送る本数ぶんの在庫がありません。[製品在庫](/manual/ja/operations/production/product-inventory/user)で数を確かめてから、もう一度お試しください。

**Q. 内容をまちがえたので直したいのですが、「編集」が出てきません。**
A. 編集できるのは「下書き」のあいだだけです。確定したあとは直せないので、その出荷書はそのままにして、正しい内容で新しく作り直してください。

**Q. 出荷したのに、注文請書が「出荷済」になりません。**
A. 種別が「在庫保管」になっていないか確認してください。「在庫保管」は社内で預かる記録なので、注文請書の状態は変わりません。また、注文された本数の一部だけを送った場合は「一部出荷」になります。
