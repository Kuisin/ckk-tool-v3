どのアプリを社内のみなさんの画面に出すかを、**スイッチで切り替える** アプリです。操作コードは `SY05` です。

スイッチを切ると、そのアプリはみなさんのホーム画面から消えます。データは消えません。

## このアプリでできること

- システムに入っているアプリを、すべて一覧で見られます。
- アプリごとに、**練習用の画面** と **本番の画面** で、出す・出さないを別々に切り替えられます。
- 新しいアプリの準備ができたら、本番のスイッチを入れて公開できます。
- 一時的にアプリを隠したいときにも使います。

## 用語（このページで出てくる言葉）

- **dev（検証）** … 練習・確認用の画面のことです。実際の仕事のデータではなく、試すための場所です。
- **main（本番）** … みなさんが日々の仕事で使う、本物の画面のことです。
- **操作コード** … アプリごとに決まっている 4 文字の記号です（`SA02` など）。画面上の検索欄に入れると、そのアプリに飛べます。

## はじめる前に

- このアプリを開くには **システム管理の権限** が必要です。開けない場合は、システム管理者にご相談ください。
- スイッチを切り替えると、**全員の画面にすぐ反映されます**。仕事中の時間帯に本番のスイッチを切ると、その場でアプリが使えなくなります。切り替えるタイミングにご注意ください。

## 開き方

ホーム画面の「システム」の中にある **アプリ管理** を押します。または、画面上の検索欄に `SY05` と入れます。

## 画面の見かた

アプリを開くと、システムに入っているアプリが一覧で並びます。

![アプリ管理の一覧画面](../../../assets/screenshots/settings-apps-01.png)

- **カテゴリ** … そのアプリの分類です（販売 / 購買 / 生産 / 出荷 / 請求 / マスタ / ドキュメント / システム）。
- **アプリ** … アプリの名前です。
- **操作コード** … `SY05` などの 4 文字の記号です。
- **dev（検証）** … 練習用の画面に出すかどうかのスイッチです。
- **main（本番）** … 本番の画面に出すかどうかのスイッチです。

上の検索欄「**アプリ名・操作コードで検索**」に文字を入れると、探しているアプリだけが残ります。「**カテゴリ**」で分類ごとに絞り込むこともできます。条件を全部消したいときは「**リセット**」を押します。

![カテゴリで絞り込んだところ](../../../assets/screenshots/settings-apps-filter-01.png)

## 出す・出さないを切り替える

1. 切り替えたいアプリの行を探します。
2. 「**dev（検証）**」または「**main（本番）**」のスイッチを押します。
3. 画面の右下に「**有効化しました**」または「**無効化しました**」と出れば、切り替わっています。

![スイッチを切り替えたところ](../../../assets/screenshots/settings-apps-switch-01.png)

切り替えは **すぐに全員の画面へ反映されます**。押し直せば、いつでも元に戻せます。

> ⚠️ 切り替えに失敗すると、スイッチが自動で元の位置に戻り、赤い「**エラー**」の表示が出ます。そのときは切り替わっていません。

## 2 つのスイッチの違い

同じアプリでも、練習用と本番でスイッチが分かれています。もともとの状態が違うので、次の点にご注意ください。

- **dev（検証）** … 何もしなければ **出ている** 状態です。隠したいアプリだけスイッチを切ります。
- **main（本番）** … 何もしなければ **出ていない** 状態です。**スイッチを入れたアプリだけ** が本番に出ます。

つまり、**「main のスイッチを入れる」ことが、そのアプリの社内公開そのもの** です。入れる前に、練習用の画面で十分に確認しておいてください。

まだ本番に出していないアプリは、練習用の画面ではオレンジ色の「**DEV**」という印が付いて表示されます。「これはまだ本番では使えないアプリです」という目印です。

## スイッチを切るとどうなるか

![アプリの一覧（ランチャー）](../../../assets/screenshots/launcher-01.png)

- そのアプリが、みなさんのホーム画面とアプリの一覧から **消えます**。
- 操作コードを入れても出てこなくなります。
- お気に入りに入れていた人の画面からも消えます。
- 以前のアドレスを直接開いても、開けなくなります。
- **入力したデータは消えません。** スイッチを入れ直せば、そのまま元どおり使えます。

## よくある質問・困ったとき

**Q. スイッチを押したら、赤い「エラー」が出て元に戻りました。**
A. 切り替える権限が無いか、通信に失敗しています。切り替えにはシステム管理者の権限が必要です。システム管理者にご依頼ください。

**Q. スイッチを入れたのに、ある人の画面にアプリが出てきません。**
A. スイッチは「アプリを画面に出すかどうか」の設定です。それとは別に、その人がそのアプリを使う権限を持っている必要があります。[ユーザー管理](/manual/ja/operations/system/user-management/user)でその人の権限を確認してください。

**Q. 使いたいアプリが、この一覧に載っていません。**
A. この一覧は、システムに組み込まれているアプリから自動で作られます。新しいアプリを増やすには開発側の作業が必要です。システム管理者にご相談ください。

**Q. 間違えて本番のスイッチを切ってしまいました。**
A. もう一度押して入れ直せば、すぐに元に戻ります。データは消えていません。

**Q. 誰がいつ切り替えたのか知りたいです。**
A. [操作履歴](/manual/ja/operations/system/activity-log/user)で確認できます。「**対象**」を「**アプリ管理**」で絞り込むと、切り替えの記録だけが並びます。

**Q. メンテナンスのあいだだけアプリを隠したいです。**
A. そのアプリのスイッチを切ってください。作業が終わったら入れ直せば再開できます。データはそのまま残ります。
