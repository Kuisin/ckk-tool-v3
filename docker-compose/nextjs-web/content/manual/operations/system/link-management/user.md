---
メモ・コメントの本文に貼られた **外部サイトへのリンク** を一覧で確認し、危険なサイトへの移動を **ブロック** できるアプリです。操作コードは `SY0B` です。

## このアプリでできること

- 社内の文書（見積書・注文請書・指示書などのメモ・コメント）に貼られた外部リンクを、一覧で確認できます。
- リンクが何回クリックされたか、最後にいつ使われたかを確認できます。
- 危険・不要なサイトのホスト名を指定して、そこへの移動をブロックできます。
- ブロックは **あとから追加しても、すでに貼られている過去のリンクに効きます**。

## 用語（このページで出てくる言葉）

- **短縮リンク** … メモ・コメントに外部の URL を貼ると、保存時に自動で `/l/xxxxxxxx` という社内アドレスに置き換わります。実際の移動先はこのアプリの索引にだけ記録されます。
- **確認ページ** … 短縮リンクを押したときに一度だけ経由するページです。移動先のサイト名・URL を見せてから、押した人が「続行して移動」を選びます。
- **ホスト名** … `example.com` のような、サイトのアドレスの中心部分です。ブロックはこのホスト名の単位で指定します。

## はじめる前に

このアプリを開くには **システム管理の権限** が必要です。開けない場合は、システム管理者にご相談ください。

## 開き方

ホーム画面の「システム」の中にある **リンク管理** を押します。または、画面上の検索欄に `SY0B` と入れます。

## 画面の見かた

画面には「索引」と「ブロック」の 2 つのタブがあります。

### 索引タブ

社内の文書に貼られた外部リンクの一覧です。

- **短縮コード** … `/l/xxxxxxxx` の部分です。押すと確認ページが開きます。
- **ホスト** … 移動先のサイト名です。ブロック中のリンクには「**ブロック中**」の印が付きます。
- **遷移先** … 実際の URL です。マウスを乗せると全文が見られます。
- **利用** … このリンクが確認ページで「続行して移動」された回数です。
- **最終利用** … 最後に使われた日時です。まだ使われていなければ「—」です。

同じ移動先の URL は、何度貼られても 1 つの短縮コードにまとまります。

### ブロックタブ

移動を禁止するホスト名の一覧と、新規追加の欄です。

- **ホスト名** … ブロックしたいサイトのアドレス（例: `evil.example`）です。そのサブドメイン（`sub.evil.example` など）も一緒にブロックされます。
- **理由** … 任意の備考です（例: 「フィッシング報告あり」）。
- **該当リンク** … すでに索引されているリンクのうち、このブロックに引っかかる件数です。影響範囲の目安として見てください。
- **有効** … スイッチで一時的にオン・オフできます。オフにすると、削除せずにブロックを止められます。

## ブロックを追加する

1. 「**ブロック**」タブを開きます。
2. 「**ホスト名**」に、ブロックしたいサイトのアドレスを入力します。URL をそのまま貼ってもホスト名だけを拾います。
3. 必要であれば「**理由**」を入力します。
4. 「**追加**」を押します。

追加すると、そのホストへのリンクは **確認ページを開いた時点でブロック表示** になります。すでに文書に貼られている過去のリンクにも、その場で効きます。

## ブロックを解除する

一時的に止めたいだけなら、その行の「**有効**」スイッチを切ります。完全に消したいときは、行の操作から「**削除**」を選びます。削除すると、以後そのホストへのリンクは通常どおり開けるようになります。

## 閲覧側で何が起きるか

社内のメモ・コメントに外部の URL を貼って保存すると、自動で短縮リンクに置き換わります。誰かがそのリンクを押すと、まず確認ページが開き、移動先のサイト名・URL を見てから「**続行して移動**」を押して初めて外部サイトへ移動します。ブロック対象のホストであれば、確認ページに理由とともに「移動できません」と表示され、そこで止まります。

## よくある質問・困ったとき

**Q. 索引に、身に覚えのないリンクがあります。**
A. どの文書に貼られたリンクかまではこの画面では分かりません。心当たりがなければ、まずそのホストをブロックし、社内の周知や調査は別途行ってください。

**Q. ブロックしたのに、まだそのサイトへ行けてしまいます。**
A. ブロック判定は確認ページを開いた瞬間に行われます。「有効」スイッチが入っているか、ホスト名の指定が正しいか（サブドメインまで含めた形になっているか）をご確認ください。

**Q. サブドメインだけをブロックしたいのですが。**
A. ホスト名の指定は「そのホストと、そのサブドメインすべて」が対象になります。特定のサブドメインだけを狙って親ドメインを除外する、という細かい指定はできません。

**Q. ブロックの「削除」を押したら、元の文書からもリンクが消えますか。**
A. 消えません。削除で消えるのはブロック指定だけです。文書のメモ・コメント本文はこのアプリからは編集できません。索引のリンク自体を消す機能もありません。
