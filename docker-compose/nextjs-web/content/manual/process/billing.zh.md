本页说明如何将已交付的部分结算为请款单，并发行、送出、登记入账。

## 整体流程

```
结算日处理 ──→ 生成请款单 ──→ 发行 ──→ 送出 ──→ 入账 ──→ 交付会计
（按客户结算）  （汇总交付分）（PDF） （交客户）（登记）（弥生 CSV）
```

## 各阶段的负责人与应用

| 阶段 | 做什么 | 负责 | 使用的应用 |
|------|--------|------|-----------|
| 1. 结算 | 按各客户的结算日汇总该期间的交付 | 财务 | [结算日处理](/manual/zh/operations/billing/billing-closing/user)（`BL02`） |
| 2. 确认内容 | 确认明细与金额 | 财务 | [请款单](/manual/zh/operations/billing/invoice/user)（`BL01`） |
| 3. 发行 | 发行 PDF | 财务 | [请款单](/manual/zh/operations/billing/invoice/user)（`BL01`） |
| 4. 送出 | 送交客户并标记为已送出 | 财务 | [请款单](/manual/zh/operations/billing/invoice/user)（`BL01`） |
| 5. 登记入账 | 确认收款后标记为已支付 | 财务 | [请款单](/manual/zh/operations/billing/invoice/user)（`BL01`） |
| 6. 交付会计 | 导出弥生会计用 CSV | 财务 | [结算日处理](/manual/zh/operations/billing/billing-closing/user)（`BL02`） |

## 各阶段会发生什么

### 1. 结算（结算日处理）

按各客户设定的**结算日**汇总该期间已交付的部分。结算日与付款周期取自[客户主数据](/manual/zh/operations/masters/business-partner/user)。结算后会由该期间的交付生成请款单。

### 2〜5. 请款单

确认请款单的明细与金额（小计・消费税・合计）后发行，发行后会保存 PDF。送交客户后标记为「已送出」，确认收款后标记为「已支付」。**这些状态即为资金记录**，请依实际情况变更。

### 6. 交付会计

已结算的部分可导出为弥生会计用 CSV。导出后，该结算日处理变为「已导出」。

## 单据的状态

| 单据 | 状态变化 |
|------|---------|
| 结算日处理 | 未处理 → 已处理 → 已导出 |
| 请款单 | 草稿 → 已发行 → 已送出 → 已支付 |

## 容易卡住的地方

**请款单中缺少某笔交付**
请确认送货单是否已标记为「已交付」。此外，发货单类别为「库存保管」的不列入请款。

**结算期间不符**
请确认客户主数据的结算日・付款周期・付款日设定，请款依该设定进行。

**金额与预期不符**
明细来源为送货单。请确认送货单的单价・数量，以及是否记载价格的设定。
