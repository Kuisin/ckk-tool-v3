受注が確定してから、在庫を確認し、承認を取り、工程を実行して、出荷できる製品になるまでの流れをまとめたページです。「いまどの段階で、次に誰が何をするのか」を確認するときに開いてください。

## 全体の流れ

```
注文請書 ──→ 在庫を確認 ──→ 指示書を作る ──→ 承認 ──→ 工程を実行 ──→ 完了
（受注確定）（足りる？）  （在庫分／製造分）（第一・第二）（現場が記録）（在庫へ）
                  │
                  └─ 素材が足りなければ 購買へ
```

## 段階ごとの担当とアプリ

| 段階 | 何をするか | 担当 | 使うアプリ |
|------|-----------|------|-----------|
| 1. 製品在庫を確認する | すでに在庫がある分と、新しく作る分を分けます | 生産管理 | [在庫管理](/manual/ja/operations/production/product-inventory/user)（`PD04`） |
| 2. 素材を確認する | 作るのに必要な素材が足りるかを見ます | 生産管理 | [在庫管理](/manual/ja/operations/production/material-inventory/user)（`PD04`） |
| 3. 指示書を作る | 在庫分・製造分に分け、工程を順番に並べます | 社内営業補助 | [指示書](/manual/ja/operations/production/work-order/user)（`PD02`） |
| 4. 承認を受ける | 第一承認・第二承認を経て製造を始められる状態にします | 承認者 | [承認管理](/manual/ja/operations/production/approval/user)（`PD03`） |
| 5. 工程を実行する | 現場が開始・完了と本数を記録します | 製造 | [指示書](/manual/ja/operations/production/work-order/user) / 現場タブレット |
| 6. 完了する | 全工程が終わると製品在庫になります | 製造・生産管理 | [在庫管理](/manual/ja/operations/production/product-inventory/user) |

## それぞれの段階でおきること

### 1〜2. 在庫の確認

まず製品在庫を見て、**在庫から出せる分**と**新しく作る分**に分けます。作る分については素材が足りるかを確認し、足りなければ[購買の流れ](/manual/ja/process/purchasing)へ進みます。外から買った半製品は指示書を作らず、素材として受け入れるだけです。

### 3. 指示書を作る

在庫分と製造分でそれぞれ指示書を作り、工程を順番に並べます。同じ受注元・製品で前回の指示書があればコピーできます（内容が変わっている場合は警告が出ます）。工程ごとに社内で行うか外注に出すかを決め、外注にすると[外注依頼](/manual/ja/operations/purchasing/outsource-order/user)の一覧に出てきます。

### 4. 承認

指示書は承認されるまで製造を始められません。**第一承認（生産判断）→ 第二承認（部門承認）** の順に進みます。差し戻された場合は内容を直して、もう一度承認を依頼します。

### 5. 工程の実行

現場が工程ごとに開始・完了を記録します。受け入れた本数と、良品・不良（半製品・廃棄・工程分岐）の内訳を入力します。**一時停止と再開ができ**、作業時間は区切りごとに積み上がります。現場のタブレットからも同じ操作ができます。

不良が出た場合は、その分を別の工程系列（分岐）へ流して手直しすることもできます。

### 6. 完了

すべての工程が終わると、その指示書の製品が在庫に入り、[出荷の流れ](/manual/ja/process/shipping)へ進めるようになります。

## 書類の状態

| 書類 | 状態の移り変わり |
|------|-----------------|
| 注文請書 | 下書き → 確定 → 製造中 → 一部出荷 → 出荷済（キャンセルあり） |
| 指示書 | 下書き → 承認待ち → 承認済 → 進行中 → 完了（キャンセルあり） |
| 指示書の承認 | 第一承認待ち → 第一承認済 → 第二承認待ち → 承認済（差し戻しあり） |
| 工程 | 未着手 → 進行中 → 完了（キャンセルあり。一時停止中は進行中のまま） |

## 止まりやすいところ

**工程を開始できない**
前の工程がまだ完了していないか、指示書が承認されていない可能性があります。指示書の状態と、前工程の完了を確認してください。

**指示書が承認されない**
第一承認と第二承認は別の人が行います。承認管理でどちらの段階で止まっているかを確認してください。

**完了した指示書の工程を見たい**
完了・キャンセル後も工程は開けます。ボタンが「詳細」になり、実績や検査記録を見返せます。

**本数が合わない**
受入数と、良品・不良の合計が一致している必要があります。不良は半製品・廃棄・工程分岐のどれかに分けて入力してください。
