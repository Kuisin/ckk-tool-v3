本页说明从发现材料不足，到下单、收货，直至可作为库存使用为止的流程。需要确认「现在处于哪个阶段、接下来由谁做什么」时请打开本页。

## 整体流程

```
采购申请 ──→ 审批 ──→ 材料采购单 ──→ 审批 ──→ 下单 ──→ 材料到货 ──→ 库存增加
（需要）   （是否必要）（向谁采购）  （金额可否）（发给对方）（已送达）
```

紧急或金额较小时，也可以不经采购申请，**直接从采购单**开始。从外部采购的半成品不需要指示书，只作为材料受入即可。

## 各阶段的负责人与应用

| 阶段 | 做什么 | 负责 | 使用的应用 |
|------|--------|------|-----------|
| 1. 列出所需材料 | 填写材料・数量・希望交期，以及需要的理由 | 生产管理・现场 | [采购申请](/manual/zh/operations/purchasing/purchase-request/user)（`PU01`） |
| 2. 审批申请 | 判断是否确有必要，审批或退回 | 审批者 | [采购申请](/manual/zh/operations/purchasing/purchase-request/user)（`PU01`） |
| 3. 制作采购单 | 确定供应商・单价・预计到货日 | 采购担当 | [材料采购单](/manual/zh/operations/purchasing/purchase-order/user)（`PU02`） |
| 4. 审批采购单 | 确认金额与条件后审批 | 审批者 | [材料采购单](/manual/zh/operations/purchasing/purchase-order/user)（`PU02`） |
| 5. 下单 | 审批通过后向供应商下单 | 采购担当 | [材料采购单](/manual/zh/operations/purchasing/purchase-order/user)（`PU02`） |
| 6. 登记收货 | 登记送达的数量与日期 | 收货担当 | [材料到货](/manual/zh/operations/purchasing/material-receipt/user)（`PU03`） |
| （并行）委外加工 | 将部分加工委托给外部公司 | 生产管理 | [外协委托](/manual/zh/operations/purchasing/outsource-order/user)（`PU04`） |

## 各阶段会发生什么

### 1〜2. 申请与审批（采购申请）

填写所需材料・数量・到货基地・希望交期，并写明**为何需要**后申请审批。审批人会依据该理由判断，写清用于哪个产品的哪道工序会更快通过。被退回时请修改内容后重新申请。

### 3〜5. 下单（材料采购单）

由已审批的申请生成采购单（也可不经申请直接制作）。在此确定 **供应商・单价・预计到货日**。单价之后也会作为试算中材料费的参考，请填写实际的交易价格。审批通过后下单，状态变为「已下单」。

### 6. 收货（材料到货）

登记送达的材料。**库存会按登记的到货日在指定基地增加。** 与采购数量不一致也没关系 — 分批送达时仅登记已送达的部分，其余作为下一次到货登记。全部送达后采购单变为「到货完成」。

### 关于外协委托

外协不是从采购申请或采购单产生的，而是来自 **指示书的工序**。将工序的实施地点选为「外协」并指定外协厂商后，就会出现在[外协委托](/manual/zh/operations/purchasing/outsource-order/user)一览中。外协委托画面用于查看状况，无法在其中新建外协。

## 单据的状态

| 单据 | 状态变化 |
|------|---------|
| 采购申请 | 草稿 → 审批申请中 → 已审批 → 已下单（可退回・取消） |
| 材料采购单 | 草稿 → 审批申请中 → 已审批 → 已下单 → 到货完成（可取消） |

## 容易卡住的地方

**申请无法通过审批**
请确认申请理由是否只写了「因为需要」。写明用于哪个产品的哪道工序、何时需要，才便于判断。

**库存没有增加**
可能尚未登记到货。请在材料到货中登记送达数量、到货日与接收基地。

**库存进到了别的基地**
到货基地选错了。请选择货物实际送达的基地。

**采购单迟迟不变为「到货完成」**
采购数量中仍有未登记的部分。分批送达时，请在每次送达时登记到货。
