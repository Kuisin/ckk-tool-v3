本页说明从确定单价到接受订单、再交给生产指示为止的流程。需要确认「现在处于哪个阶段、接下来由谁做什么」时请打开本页。各应用的详细操作可从下表的链接查看。

## 整体流程

```
试算 ──→ 价格表 ──→ 报价单 ──→ 订单受理书 ──→ 订单请书 ──→ 指示书
（计算单价）（客户价格）（提交客户）（接受订单）（确定受订）（生产指示）
                              ↑          │
                              └─ 价格不一致时返回调整
```

没有图纸的产品，会与该流程并行起草 **设计委托书**。

## 各阶段的负责人与应用

| 阶段 | 做什么 | 负责 | 使用的应用 |
|------|--------|------|-----------|
| 1. 计算单价 | 根据材料费与加工费计算该产品的报价单价 | 内勤销售 | [试算](/manual/zh/operations/sales/trial-estimate/user)（`SA01`） |
| 2. 确定客户价格 | 按客户与产品的组合制作价格表，并设定数量越多单价越低 | 内勤销售 | [价格表](/manual/zh/operations/sales/price-list/user)（`SA02`） |
| 3. 出具报价单 | 以价格表的单价制作报价单，并将 PDF 提交客户 | 内勤销售 | [报价单](/manual/zh/operations/sales/quote/user)（`SA03`） |
| 4. 接受订单 | 导入客户送来的订单，确认内容后受理 | 销售助理 | [订单受理书](/manual/zh/operations/sales/order-acceptance/user)（`SA04`） |
| 5. 确定受订 | 依受理内容生成订单请书（按产品） | 销售助理 | 订单请书（`PD01`） |
| 6. 指示生产 | 分为库存与制造，排列工序生成指示书 | 销售助理 | [指示书](/manual/zh/operations/production/work-order/user)（`PD02`） |
| （并行）没有图纸时 | 起草设计委托书，由制造制作图纸 | 内勤销售 / 销售助理 → 制造 | [设计委托书](/manual/zh/operations/sales/design-request/user)（`SA05`） |

## 各阶段会发生什么

### 1. 计算单价（试算）

输入产品的材料、尺寸与加工条件后，会计算出报价单价。试算先以草稿保存，内容确定后设为「确定」。**只有确定后的试算才能作为价格表单价的来源。** 一旦被价格表使用，试算会变为「已登记到价格表」并无法直接编辑（需要重做时请复制）。

### 2. 确定客户价格（价格表）

按客户与产品的组合建立 1 份价格表。可按订单类别（正式・测试・样品・其他）分别持有价格，并可按数量区间改变单价。可选择已确定的试算作为单价来源，也可手动输入。

### 3. 出具报价单（报价单）

选择客户与产品后，会从价格表自动带入单价。**价格表中没有的产品不会带入单价并显示警告** — 此时请先制作试算与价格表。内容无误后执行「发行」，PDF 会被保存，即可提交客户。

### 4. 接受订单（订单受理书）

导入客户送来的订单（传真・PDF）。系统会自动读取，您在画面上确认并修正结果。若报价价格与订单价格不一致会当场显示，必要时返回报价单调整。内容确定后申请审批，审批通过即可进入下一阶段。

### 5〜6. 确定受订与指示生产（订单请书・指示书）

订单受理书确定后，会按明细生成 **订单请书**。接着针对该订单请书制作 **指示书**，区分从库存出货的部分与新制造的部分，并依序排列工序。之后进入生产流程。

## 单据的状态

| 单据 | 状态变化 |
|------|---------|
| 试算 | 草稿 → 确定 → 已登记到价格表 |
| 报价单 | 草稿 → 已发行 → 已受理 / 已拒绝 / 已过期 |
| 订单受理书 | 导入中 → 草稿 → 审批申请中 → 已审批 → 已展开 → 已归档 |
| 订单请书 | 草稿 → 确定 → 制造中 → 部分发货 → 已发货 |
| 指示书 | 草稿 → 待审批 → 已审批 → 进行中 → 完成 |
| 设计委托书 | 未开始 → 进行中 → 完成 |

## 容易卡住的地方

**报价单没有带入单价**
价格表中没有该客户・产品的行。请先依「试算 → 价格表」的顺序建立，再重新制作报价单。

**试算无法编辑**
被价格表使用过的试算会变为「已登记到价格表」而无法编辑。请复制后重新制作。这是为了避免过去报价的金额在事后发生变化。

**订单价格与报价不一致**
在订单受理书画面会显示差异。请返回报价单调整价格后，再修正订单受理书的内容。

**订单受理书无法进入下一步**
请确认是否已申请审批、审批者是否已通过。通过后即可展开为订单请书与指示书。
