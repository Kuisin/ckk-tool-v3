本页说明如何将完成的产品送出，并发行送货单直至交付为止的流程。

## 整体流程

```
制作发货单 ──→ 确定 ──→ 发货 ──→ 制作送货单 ──→ 发行 ──→ 交付
（选择订单请书）      （库存减少）（送达方・是否记载价格）    （进入请款）
```

仅存放在公司内的部分，以发货单的「库存保管」类别登记（不进入请款）。

## 各阶段的负责人与应用

| 阶段 | 做什么 | 负责 | 使用的应用 |
|------|--------|------|-----------|
| 1. 制作发货单 | 选择订单请书，确定发出的明细与批次 | 发货担当 | [发货单](/manual/zh/operations/shipping/delivery-order/user)（`SH01`） |
| 2. 确定 | 确定内容，进入可发货状态 | 发货担当 | [发货单](/manual/zh/operations/shipping/delivery-order/user)（`SH01`） |
| 3. 发货 | 实际送出。库存减少 | 发货担当 | [发货单](/manual/zh/operations/shipping/delivery-order/user)（`SH01`） |
| 4. 制作送货单 | 确定送达方，以及是否记载价格 | 发货担当 | [送货单](/manual/zh/operations/shipping/delivery-note/user)（`SH02`） |
| 5. 发行・交付 | 发行 PDF，送达后标记为已交付 | 发货担当 | [送货单](/manual/zh/operations/shipping/delivery-note/user)（`SH02`） |

## 各阶段会发生什么

### 1〜3. 发货单

选择**订单请书**后，可发货的订单明细会按分组填入，数量来自指示书的完成数。**批次**按分组选择。批次与指示书编号相同，可据此留下发出的是哪一批制造。同时选择发货基地（**该基地的库存会减少**）。不能超过接单余量发货；不足接单余量时会出现「部分发货」确认。

类别有两种:

- **发送** … 送交客户。会进入送货单与请款
- **库存保管** … 作为备用制作并存放在公司内。不进入请款

确定后发货，库存减少，订单明细的状态变为「部分发货」或「已发货」。

### 4〜5. 送货单

依据发货单制作送货单。此处主要确定两点:

- **交付方式** … 交付给受订客户（通常），或直接送交最终需求方
- **记载价格** … 是否在送货单上记载单价与金额。**直送最终需求方时通常不记载**

发行后会保存 PDF。送达后标记为「已交付」。完成到此步骤的发货，即为[请款流程](/manual/zh/process/billing)的对象。

## 单据的状态

| 单据 | 状态变化 |
|------|---------|
| 发货单 | 草稿 → 确定 → 已发货 |
| 送货单 | 草稿 → 已发行 → 已交付 |

## 容易卡住的地方

**无法选择想发出的批次**
该产品在所选发货基地可能没有库存。请确认基地，或在[库存管理](/manual/zh/operations/production/product-inventory/user)中查找有库存的基地。

**库存没有减少**
请确认发货单是否停留在「确定」。库存在登记发货时减少。

**不想在送货单上显示金额**
请取消送货单的「记载价格」。直送最终需求方时通常如此处理。

**在请款中找不到**
可能尚未交付，或发货单的类别为「库存保管」。
