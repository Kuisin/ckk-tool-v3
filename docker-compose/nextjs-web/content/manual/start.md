CKK 業務管理システムへようこそ。このページは **初めて使う方** 向けの入門ガイドです。専門用語は最後の「用語集」で説明します。

## このシステムとは

見積・受注・製造・出荷・請求までを 1 つにまとめた社内システムです。まずは営業に関わる 3 つのアプリ（**試算・価格表・見積書**）から使い始めます。

- **試算** … 「この製品はいくらで作れるか」を原価から計算します。
- **価格表** … 顧客ごとの販売単価を登録しておく台帳です。
- **見積書** … お客様に提出する見積書を作ります。単価は価格表から自動で入ります。

この 3 つは **試算 → 価格表 → 見積書** の順につながっています（下の「4. 販売の流れ」参照）。

## 1. ログイン

1. ブラウザで社内ポータルの URL を開きます。
2. **SSO（社内アカウント）** のボタンでサインインします。開発用アカウントは、画面下部の「開発用アカウントでログイン」ボタンを押すと表示される入力欄から使えます。
3. ログインできたら、右上の丸いアイコン（アバター）をクリックして、自分の名前・所属が正しいか確認します。

![ログイン画面](./assets/screenshots/login-01.png)

## 2. 画面の見かた

- **左上のロゴ** をクリック → 使えるアプリの一覧（ランチャー）が開きます。
- **中央の検索ボックス** … アプリ名や「操作コード」（例 `SA01`）を入力して Enter すると、その画面へ直接移動します。
- **右上のベル** … お知らせ（通知）。**アバター** … プロフィール・通知設定・ホーム画面設定・ログアウト。
- **ホーム画面** … 使えるアプリがカテゴリ別に並びます。権限のないアプリは表示されません。また、環境（本番 / 開発）によって公開されているアプリも異なります。

![アプリランチャー](./assets/screenshots/launcher-01.png)

![ホーム画面](./assets/screenshots/home-01.png)

## 3. 操作コード（画面番号）

各画面には 4 文字の番号があります。覚えておくと検索ボックスからすぐ移動できます。

- `SA01` 試算 / `SA02` 価格表 / `SA03` 見積書
- `MS01` 取引先 / `MS0B` 承認設定

## 4. 販売の流れ（まずはこれだけ）

販売は **試算 → 価格表 → 見積書 → 注文請書** の順に進みます。
それぞれの業務で誰が何をして、どのアプリを使うのかは
[販売の流れ](/manual/ja/process/sales) にまとめてあります。

- 単価を計算する … [試算](/manual/ja/operations/sales/trial-estimate/user)（`SA01`）
- 顧客ごとの価格を決める … [価格表](/manual/ja/operations/sales/price-list/user)（`SA02`）
- 見積書を出す … [見積書](/manual/ja/operations/sales/quote/user)（`SA03`）

各アプリの詳しい操作と入力欄の意味は、左の **操作方法** から開いてください。

## 5. 困ったときは

- **画面が見当たらない** … 権限が足りない可能性があります。管理者に相談してください。
- **通知が来た** … 右上のベルから内容を確認できます。
- **自分の設定を変えたい** … 右上のアバターメニューの「プロフィール」から通知先メールやパスワードを、「ホーム画面設定」からお気に入りアプリや表示方法を変更できます（「ユーザー設定マニュアル」参照）。

## 用語集

- **試算（しさん）** … 原価から販売単価を計算すること。見積の下準備。
- **参照単価 / 仕入実績** … 素材をいくらで仕入れたか（過去の購買履歴）。試算の材料費はこの実績価格を基に自動計算されます。
- **工具種（こうぐしゅ）** … 製品の種類。標準では 丸棒・円筒・OH付 の 3 種類があり（管理者が追加できます）、種類ごとに入力項目や計算式が変わります。
- **ロット** … まとめて作る本数（数量）のまとまり。数量が多いほど 1 本あたりの単価は下がります。
- **注文種別** … 本番・テスト・サンプル（金額 0）・その他 の区分。同じ製品でも種別ごとに価格を分けられます。
- **段取り / 形状出し** … 加工前の準備費用。数量で割って 1 本あたりに按分します。
- **確定 / 下書き** … 下書き（編集中）→ 確定（内容を固定）の状態。確定した試算は価格表作成時に選択できます。
