操作代码 **SY07**。面向管理员、可横向查看系统全体操作历史（审计日志）的应用。可追踪「谁・何时・改了哪些数据・如何修改」。

## 本应用能做什么

- 跨全部应用・全部记录，查看数据的创建・更新・删除历史。
- 按记录・用户・变更内容搜索，按操作类型・对象筛选。
- 在历史详情页面查看变更前后的数据（JSON），并直接跳转到被变更记录的画面。
- 数据来源与各单据详情画面的「历史」标签相同 — 本应用是横向查看全体的画面。

使用本应用需要 **系统（system）权限**。历史为 **只读**，无法在此画面编辑・删除。

## 打开方式

- 主页（系统）→ **操作历史**，或在搜索框输入 `SY07`。

## 记录哪些操作

每次保存业务数据时，都会附带变更前后的快照自动记录。操作类型如下。

- **创建** … 新建记录。
- **更新** … 修改既有记录（变更字段的差异会被汇总）。
- **删除** … 删除记录。
- **初始数据** / **迁移** … 系统的初始投入・迁移处理。

浏览・登录・PDF 下载等「只看不改」的操作不在记录范围内（仅记录数据变更）。

## 列表说明

- **日时** … 操作发生的时间。默认按最新在前排序。
- **操作** … 创建 / 更新 / 删除 等。
- **对象** … 被变更数据的种类。例：报价单、试算、价格表、工厂、应用管理。
- **记录** … 业务标识符（单据号 `QOT-…` / `EST-…`、主数据 ID 等。等宽显示）。
- **用户** … 操作用户的显示名。系统处理显示为「系统」。
- **变更内容** … 变更摘要。更新时按字段显示差异，如「状态: DRAFT → CONFIRMED」。

列表显示最新 **300 条**。搜索框可跨记录・用户名・变更内容搜索，用 **操作** 和 **对象** 下拉筛选，用 **重置** 清空全部条件。点击行进入详情。

## 历史详情

点击行后，打开该条记录的详情（「操作历史 #编号」）。

- **概要** … 日时 / 操作 / 对象 / 记录 / 用户 / 相关页面。用户名链接到 [用户管理](/manual/zh/system/user-management/user) 的详情。
- **跳转到相关页面** … 当能确定被变更记录的画面时，右上角会显示「打开〈应用〉」按钮，可直接跳转到该记录的详情（或筛选后的应用列表）。
- **变更内容（摘要）** … 与列表相同的差异摘要。
- **变更前（before） / 变更后（after）** … 记录的快照原始数据（JSON），可准确确认哪些字段发生了什么变化（创建时变更前为「无」，删除时变更后为「无」）。

![操作历史详情（相关页面链接与变更前后 JSON）](../../assets/screenshots/settings-activity-detail-01.png)

## 常见问题

- **只想看某个单据的历史** … 打开该单据的详情画面，查看「历史」标签更快。在本画面可按单据号搜索。
- **看不到较早的历史** … 本画面仅显示最新 300 条。更早的调查请与系统管理员商量。
- **没有登录或 PDF 输出的记录** … 它们不在本历史的记录范围内（仅记录数据的创建・更新・删除）。
- **对象「应用管理」是什么** … 是在 [应用管理](/manual/zh/system/app-management/user) 中切换应用显示开关的记录。
