操作代码 **SY05**。按环境（**dev** = 验证 / **main** = 正式）切换各应用显示开关的应用。一个开关即可发布或隐藏应用。

## 本应用能做什么

- 查看系统中登记的全部应用一览（含类别・操作代码）。
- 按应用分别切换 **dev（验证）** 和 **main（正式）** 的开关。
- 按应用名・操作代码搜索，按类别筛选。

使用本应用需要 **系统（system）权限**（切换需要更新权限）。切换会立即反映到所有用户的画面。

## 打开方式

- 主页（系统）→ **应用管理**，或在搜索框输入 `SY05`。

## 环境的概念

显示开关按环境分别管理，默认行为也因环境而异。

- **dev（验证）** … 默认 **显示**。只有明确关闭（OFF）的应用才会隐藏。
- **main（正式）** … 默认 **隐藏**。**只有明确开启（ON）的应用才会显示**。这是为了让正式环境的启动器只保留「已发布应用」的机制。

也就是说，**把 main 开关打开本身就是正式发布**。切换前请确认该应用已在 dev 充分验证。另外，main 为 OFF 的应用，在 dev 环境中会带「未发布（DEV）」缎带显示。

## 关闭（OFF）后会发生什么

- 该应用会从启动器・主页・操作代码搜索中消失。
- 直接输入 URL 也无法访问（画面防护）。
- 数据不会被删除。重新开启后可恢复原样使用。

## 列表说明

- **类别** … 销售 / 采购 / 生产 / 发货 / 开票 / 主数据 / 文档 / 系统 徽章。
- **应用** … 应用名。
- **操作代码** … `SA02` 等跳转代码（等宽显示）。
- **dev（验证）** / **main（正式）** … 各环境的显示开关。

切换后会显示「已启用 / 已停用」的通知并立即生效。失败时开关会复原并显示错误。

## 切换记录

所有开关操作都会记录到审计日志，可在 [操作历史](/manual/zh/system/activity-log/user)（对象「应用管理」）中确认「谁・何时・把哪个应用・在哪个环境」进行了切换。

## 常见问题

- **想向正式环境发布新应用** … dev 验证完成后，把该应用的 **main（正式）** 开关打开。
- **想因维护临时隐藏应用** … 关闭对应环境的开关。数据保持不变，重新开启即可恢复。
- **想向列表添加应用** … 列表由系统内置的应用登记簿生成。添加需要开发侧的支持。
- 各用户的权限可在 [用户管理](/manual/zh/system/user-management/user) 中确认。
