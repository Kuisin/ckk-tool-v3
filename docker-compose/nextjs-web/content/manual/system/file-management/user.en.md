Operation code **SY06**. Browse, download, upload, and delete uploaded files and system-generated document PDFs in a Finder-style screen.

## What you can do with this app

- Navigate folders and switch between three views: **list / icons / columns**.
- Select a file to preview it (images and PDFs) with its metadata in the right-hand pane, and **open / download / delete** it.
- **Upload** files into folders you can write to.
- **Search across all folders** by file name or path, and toggle the display of **system files**.
- System administrators can grant per-user, per-folder read/write access via **Folder permissions**.

Any logged-in user can open this app (no dedicated permission required). However, **the files you see are filtered by your permissions** (next section).

## Which files you can see (access model)

Only files matching at least one of the following are shown.

1. **System administrators** (system admin action) … can view and manage everything.
2. **Folder permissions** … folders individually granted by an administrator (including everything below the folder), as either **read** or **read/write**.
3. **App permissions** … files generated by the system are visible to users with read access to the owning app. For example, the quote permission reveals the quote PDF folder, and the kiosk permission reveals QR card print PDFs.

## How to open

- Home (System) → **File Management**, or type `SY06` in the search box.

## Reading the screen

- A folder breadcrumb (**All** > folder > …) is shown at the top; click a segment to navigate.
- Choose the view (**list / icons / columns**) with the segmented control. The columns view is a Finder-style Miller-column layout.
- List view columns: **Name** (icon: red for PDF, blue for images; system-generated files carry a "System" badge) / **Size** / **Updated**.
- The search box ("search by file name or path") searches across all folders.
- Turn ON the **System files** switch to also list system-generated files such as document PDFs (hidden by default).
- Selecting a file opens the right-hand preview with path, size, updated time, and type, plus **Open** (new tab) / **Download** / **Delete** (only where you have write access).

## Upload

1. Open the target folder and press **Upload** in the top right (shown only in folders you can write to).
2. On save, the file name is automatically rewritten to "timestamp + identifier + original name" — a **systematic naming scheme** that prevents collisions and makes every file traceable to when it was registered.

## Delete

Pressing **Delete** in the preview shows a confirmation dialog. **This cannot be undone.** Document PDFs are referenced from quotes, invoices, and other documents — avoid deleting files tied to business data.

## Folder permissions (system administrators only)

The **Folder permissions** button in the top right manages per-user folder access.

- **Grant** … choose a folder (path prefix; everything below it is covered) and a user, optionally enable "allow writing", then press **Grant**.
- **Granted** … the current grants (folder / user / permission: read-write or read). Remove grants that are no longer needed.
- System administrators always have access to every folder regardless of grants.

## FAQ

- **A red warning "Cannot connect to storage (SeaweedFS)" appears** … The file storage is down or misconfigured. While disconnected, the file list is not shown. Contact your system administrator.
- **A file I expect is missing** … You may lack access (see "Which files you can see" above). Also, system-generated files are hidden unless the **System files** switch is ON.
- **I deleted a file by mistake** … It cannot be restored from this screen. Ask your system administrator about restoring from backup.
- For the documents that generate these files, see each app's manual (e.g. [Quote](/manual/en/apps/quote/user), [Invoice](/manual/en/apps/invoice/user)).
