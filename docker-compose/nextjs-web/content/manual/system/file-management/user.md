操作コード **SY06**。アップロードしたファイルや、システムが生成した帳票 PDF を、Finder 風の画面で閲覧・ダウンロード・アップロード・削除できるアプリです。

## このアプリでできること

- フォルダをたどってファイルを一覧し、**リスト / アイコン / カラム** の 3 つの表示を切り替えられます。
- ファイルを選ぶと右側のプレビューで内容（画像・PDF）とメタ情報を確認でき、**開く / ダウンロード / 削除** ができます。
- 書き込みできるフォルダには **アップロード** ができます。
- ファイル名・パスでの **全フォルダ横断検索** と、**システムファイル** の表示切り替えができます。
- システム管理者は **フォルダ権限** で、ユーザーごとにフォルダ単位の閲覧・書き込みを付与できます。

このアプリはログインしていれば誰でも開けます（専用の権限は不要）。ただし **表示されるファイルは権限で絞られます**（次項）。

## 閲覧できるファイル（アクセスの仕組み）

次のいずれかに当てはまるファイルだけが表示されます。

1. **システム管理者**（system の管理権限）… すべてのファイルを閲覧・操作できます。
2. **フォルダ権限** … 管理者から個別に付与されたフォルダ（配下すべて）。**読み取り** または **読み書き** のどちらかです。
3. **アプリ権限** … システムが生成したファイルは、生成元アプリの閲覧権限があれば見られます。例えば見積書の権限があれば見積書 PDF のフォルダが、キオスク管理の権限があれば QR カード印刷 PDF が表示されます。

## 開き方

- ホーム（システム）→ **ファイル管理**、または検索ボックスで `SY06`。

## 画面の見方

- 上部にフォルダのパンくず（**すべて** > フォルダ > …）が表示され、クリックで移動できます。
- 表示切替（**リスト / アイコン / カラム**）はセグメントで選びます。カラム表示は階層を横に並べる Finder 風の表示です。
- リスト表示の列は **名前**（アイコン: PDF は赤、画像は青。システム生成ファイルには「システム」バッジ）/ **サイズ** / **更新日時**。
- 検索ボックス（「ファイル名・パスで検索」）はフォルダをまたいで全体を検索します。
- **システムファイル** スイッチを ON にすると、システムが生成したファイル（帳票 PDF など）も一覧に表示されます（既定では非表示）。
- ファイルを選ぶと右側にプレビューが開き、パス・サイズ・更新日時・種類の確認と、**開く**（新しいタブ）/ **ダウンロード** / **削除**（書き込み権限がある場合のみ）ができます。

## アップロード

1. アップロードしたいフォルダを開き、右上の **アップロード** を押します（書き込みできるフォルダでのみ表示されます）。
2. ファイル名は保存時に「日時 + 識別子 + 元のファイル名」の形式へ自動的に変更されます。同名ファイルの衝突を防ぎ、いつ登録されたファイルかを追跡できるようにするための **系統的な命名** です。

## 削除

プレビューの **削除** を押すと確認ダイアログが表示されます。**この操作は取り消せません**。帳票 PDF は見積書・請求書などの文書から参照されているため、業務データに紐づくファイルの削除は避けてください。

## フォルダ権限（システム管理者のみ）

右上の **フォルダ権限** ボタンから、ユーザーごとのフォルダ権限を管理できます。

- **権限を付与** … フォルダ（パスの前方一致。配下すべてが対象）とユーザーを選び、必要なら「書き込みも許可」を ON にして **付与** します。
- **付与済み** … 現在の付与一覧（フォルダ / ユーザー / 権限: 読み書き・読み取り）。不要になった付与は削除できます。
- システム管理者は付与に関係なく常に全フォルダへアクセスできます。

## よくある質問

- **画面上部に赤い警告「ストレージ（SeaweedFS）に接続できません」が出る** … ファイルストレージが停止しているか、接続設定に問題があります。この間、ファイル一覧は表示されません。システム管理者に連絡してください。
- **あるはずのファイルが見えない** … 閲覧権限がない可能性があります（上記「閲覧できるファイル」参照）。また、システム生成ファイルは **システムファイル** スイッチを ON にしないと表示されません。
- **誤って削除してしまった** … この画面からは復元できません。システム管理者にバックアップからの復旧を相談してください。
- ファイルの生成元となる文書の操作は各アプリのマニュアル（例: [見積書](/manual/ja/apps/quote/user)、[請求書](/manual/ja/apps/invoice/user)）を参照してください。
