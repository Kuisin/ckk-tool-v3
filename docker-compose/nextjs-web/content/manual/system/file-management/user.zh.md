操作代码 **SY06**。以 Finder 风格的画面浏览・下载・上传・删除上传文件和系统生成的单据 PDF 的应用。

## 本应用能做什么

- 逐层浏览文件夹，并在 **列表 / 图标 / 分栏** 3 种视图间切换。
- 选中文件后，可在右侧预览内容（图片・PDF）和元信息，并进行 **打开 / 下载 / 删除**。
- 对可写入的文件夹进行 **上传**。
- 按文件名・路径进行 **跨全部文件夹的搜索**，并切换 **系统文件** 的显示。
- 系统管理员可通过 **文件夹权限**，按用户授予文件夹级的读取・写入权限。

只要已登录，任何人都能打开本应用（无需专用权限）。但 **能看到的文件会按权限过滤**（见下节）。

## 能看到哪些文件（访问机制）

只有符合以下任一条件的文件才会显示。

1. **系统管理员**（system 的管理权限）… 可查看・操作全部文件。
2. **文件夹权限** … 管理员单独授予的文件夹（含其下所有内容），分 **读取** 或 **读写** 两种。
3. **应用权限** … 系统生成的文件，持有生成来源应用的查看权限即可看到。例如持有报价单权限即可看到报价单 PDF 文件夹，持有 kiosk 管理权限即可看到 QR 卡打印 PDF。

## 打开方式

- 主页（系统）→ **文件管理**，或在搜索框输入 `SY06`。

## 画面说明

- 顶部显示文件夹面包屑（**全部** > 文件夹 > …），点击即可跳转。
- 视图切换（**列表 / 图标 / 分栏**）通过分段控件选择。分栏视图是横向排列层级的 Finder 风格显示。
- 列表视图的列为 **名称**（图标：PDF 红色、图片蓝色。系统生成文件带「系统」徽章）/ **大小** / **更新时间**。
- 搜索框（「按文件名・路径搜索」）会跨文件夹搜索全部内容。
- 打开 **系统文件** 开关后，系统生成的文件（单据 PDF 等）也会显示在列表中（默认隐藏）。
- 选中文件后右侧打开预览，可确认路径・大小・更新时间・类型，并进行 **打开**（新标签页）/ **下载** / **删除**（仅在有写入权限时）。

## 上传

1. 打开目标文件夹，按右上角的 **上传**（仅在可写入的文件夹显示）。
2. 保存时文件名会自动改写为「日期时间 + 标识符 + 原文件名」的格式。这是防止同名冲突并可追溯登记时间的 **系统化命名**。

## 删除

按预览中的 **删除** 会显示确认对话框。**此操作无法撤销**。单据 PDF 被报价单・发票等单据引用，请避免删除与业务数据关联的文件。

## 文件夹权限（仅系统管理员）

通过右上角的 **文件夹权限** 按钮管理各用户的文件夹权限。

- **授予权限** … 选择文件夹（路径前缀匹配，覆盖其下全部内容）和用户，如有需要打开「同时允许写入」，然后按 **授予**。
- **已授予** … 当前授予一览（文件夹 / 用户 / 权限：读写・读取）。不再需要的授予可删除。
- 系统管理员无论是否授予，始终可访问全部文件夹。

## 常见问题

- **画面顶部出现红色警告「无法连接存储（SeaweedFS）」** … 文件存储已停止或连接设置有问题。此期间不会显示文件列表。请联系系统管理员。
- **看不到应该存在的文件** … 可能没有查看权限（参见上文「能看到哪些文件」）。另外，系统生成文件需打开 **系统文件** 开关才会显示。
- **误删了文件** … 无法从此画面恢复。请与系统管理员商量从备份恢复。
- 生成这些文件的单据操作请参见各应用手册（例：[报价单](/manual/zh/apps/quote/user)、[发票](/manual/zh/apps/invoice/user)）。
