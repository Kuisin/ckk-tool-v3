操作コード **SY08**。拠点フロアの共有タブレット（キオスク端末）にログインするための **QRカード** を発行・割当・管理するアプリです。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- QRカードの **発行**（まとめて 1〜100 枚）
- カードの **ユーザーへの割当**（1 ユーザーにつき 1 枚。有効期間付きのテンポラリカードも可）
- 印刷シートからの **カード印刷**（A4 に名刺サイズ 10 枚）
- カードの **一時停止 / 再開 / 取り消し**、**PIN のリセット / ロック解除**
- カードごとの **同時ログイン上限** と **有効期間** の設定、最近のログインの確認

このアプリの利用には **キオスク管理（kiosk）権限** が必要です。

## カードの状態

- **未割当** … 発行済みで、まだ誰にも割り当てていない状態。
- **割当済** … ユーザーに割り当てられ、ログインに使える状態。
- **一時停止** … 一時的にログインを止めた状態。「再開」で戻せます。
- **取り消し** … 完全に無効化した状態。**元に戻せません**（紛失・退職時など）。

## 発行から利用開始まで

1. **カードを発行** で枚数（1〜100）を指定します。カードは「未割当」で作られます。
2. 行メニューの **ユーザーに割当** で割当先を選びます。割当できるのは有効なユーザーのみで、**1 ユーザーにつき 1 枚** です。詳細画面からの割当では **有効開始日 / 有効終了日** も設定でき、期間を設定するとテンポラリカードになります（期間外はログイン不可。終了日はその日いっぱい有効）。
3. カードにチェックを付けて **選択したカードを印刷**（または行メニューの **印刷**）を押すと、印刷シートが別タブで開きます。A4 縦に名刺サイズ（91×55mm）のカードが **1 ページ 10 枚**（2 列 × 5 行）並び、四隅のトンボに合わせて断裁できます。
4. 印刷したカードを本人に渡します。タブレットで QR をかざし、初回に **PIN** を設定するとログインできます。

一覧のカード ID はセキュリティのため **末尾 8 文字のみ** 表示されます。フル ID は印刷シートの QR にだけ含まれます。

## 一覧・検索

- カード ID・ユーザー名で検索、状態で絞り込みできます。
- 列: **カードID**（マスク表示）/ **割当ユーザー** / **状態** / **PIN**（設定済・未設定、ロック中）/ **有効期間**（無期限または期間。期限切れ・開始前の警告バッジ付き）/ **最終使用** / **使用回数**。
- 行をクリックするとカード詳細が開きます。

## PIN の操作

- PIN は本人がタブレットで設定します。管理者が PIN の値を見たり設定したりすることはできません。
- PIN を連続で間違えると一定時間ロックされ、一覧の PIN 列に「ロック中」と表示されます（回数・時間は [キオスク設定](/manual/ja/system/kiosk-settings/user) の認証ポリシー参照）。
- **PINロック解除** … ロックだけを解除します。PIN はそのまま残ります。
- **PINリセット** … PIN を消去します。本人が PIN を忘れたときに使います。次回ログイン時に新しい PIN を設定します。

## 停止・取り消し・上限

- **一時停止** … このカードでのログインを止めます。「再開」で元に戻せます。
- **取り消し** … カードを完全に無効化します。**元に戻せません**。実行すると、そのカードで開いているキオスクセッションも即時失効します。割当先を変えたいときは、既存カードを取り消してから別のカードを割り当てます（割当済カードの付け替えはできません）。
- **同時ログイン上限**（詳細画面）… 1 枚のカードで同時にログインできる端末数（1〜10）。上限を超えてログインすると、最も古い端末のセッションから自動的にログアウトされます。
- **有効期間を編集**（詳細画面）… 期間の延長・短縮、無期限への変更ができます。期間外のカードはログインできません。
- 詳細画面の **最近のログイン** で、そのカードの直近のログイン（端末・拠点・日時）を確認できます。

## よくある質問

- **カードを紛失した** … そのカードを **取り消し** て、新しいカードを発行・割当してください。
- **期限切れの警告が出ている** … カードの有効期間を過ぎています。詳細画面の「有効期間を編集」で延長するか、カードを取り消してください。
- 端末側の管理（リンク・有効化・フロアマップ）は [端末管理](/manual/ja/system/kiosk-device/user) を参照してください。タブレット本体の詳細な導入手順は社内ドキュメントを参照してください。
