操作代码 **SY08**。用于签发・分配・管理登录工厂现场共享平板（kiosk 终端）所用 **QR 卡片** 的应用。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- QR 卡的 **签发**（一次 1〜100 张）
- 卡片 **分配给用户**（每位用户 1 张。也可设置有效期，作为临时卡）
- 从打印页 **打印卡片**（A4 每页 10 张名片尺寸）
- 卡片的 **暂停 / 恢复 / 作废**、**PIN 重置 / 解锁**
- 设置每张卡的 **同时登录上限** 和 **有效期**，查看最近登录

使用本应用需要 **kiosk 管理（kiosk）权限**。

## 卡片状态

- **未分配** … 已签发但尚未分配给任何人。
- **已分配** … 已分配给用户、可用于登录。
- **暂停** … 临时停止登录。可用「恢复」还原。
- **作废** … 完全失效。**无法撤销**（丢失・离职等场合）。

## 从签发到开始使用

1. 用 **签发卡片** 指定张数（1〜100）。卡片以「未分配」状态创建。
2. 用行菜单的 **分配给用户** 选择分配对象。只能分配给有效用户，且 **每位用户 1 张**。从详情页面分配时还可设置 **有效开始日 / 有效结束日**，设置期间后即成为临时卡（期间外无法登录。结束日当天全天有效）。
3. 勾选卡片后按 **打印所选卡片**（或行菜单的 **打印**），打印页会在新标签页打开。A4 纵向排列名片尺寸（91×55mm）卡片，**每页 10 张**（2 列 × 5 行），可按四角裁切标记裁切。
4. 把打印好的卡片交给本人。在平板上扫描 QR，首次登录时设置 **PIN** 即可使用。

出于安全考虑，列表中的卡片 ID 仅显示 **末尾 8 位**。完整 ID 只存在于打印页的 QR 中。

## 列表与搜索

- 可按卡片 ID・用户名搜索，按状态筛选。
- 列：**卡片ID**（掩码显示）/ **分配用户** / **状态** / **PIN**（已设置・未设置、锁定中）/ **有效期**（无期限或期间，附过期・未开始警告徽章）/ **最后使用** / **使用次数**。
- 点击行打开卡片详情。

## PIN 操作

- PIN 由本人在平板上设置。管理员无法查看或设置 PIN 的值。
- PIN 连续输错会锁定一段时间，列表的 PIN 列显示「锁定中」（次数・时长见 [Kiosk 设置](/manual/zh/system/kiosk-settings/user) 的认证策略）。
- **PIN 解锁** … 仅解除锁定。PIN 本身保留。
- **PIN 重置** … 清除 PIN，用于本人忘记 PIN 时。下次登录时设置新 PIN。

## 暂停・作废・上限

- **暂停** … 停止此卡的登录。可用「恢复」还原。
- **作废** … 使卡片完全失效。**无法撤销**。执行后，该卡当前打开的 kiosk 会话也会立即失效。想更换分配对象时，先作废现有卡片，再分配另一张卡（已分配的卡不能直接改绑他人）。
- **同时登录上限**（详情页面）… 一张卡可同时登录的终端数（1〜10）。超出上限登录时，最早终端的会话会被自动登出。
- **编辑有效期**（详情页面）… 可延长・缩短或改回无期限。期间外的卡片无法登录。
- 详情页面的 **最近登录** 可查看该卡最近的登录（终端・工厂・时间）。

## 常见问题

- **卡片丢失了** … 请 **作废** 该卡，并签发・分配新卡。
- **显示过期警告** … 卡片已超过有效期。请在详情页面「编辑有效期」延长，或作废该卡。
- 终端侧的管理（链接・启用・楼层平面图）请参见 [终端管理](/manual/zh/system/kiosk-device/user)。平板本体的详细导入步骤请参见内部文档。
