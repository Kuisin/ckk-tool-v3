操作コード **SY09**。拠点フロアの共有タブレット（キオスク端末）を登録・管理するアプリです。リンク・有効化・フロアマップ配置・利用履歴の確認ができます。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 端末プロファイルの作成と、タブレットの **リンク**・**有効化**
- 端末情報の編集（名称・拠点・場所）、無効化・再有効化、リンク解除、取り消し
- **フロアマップ** への端末ピンの配置と、オンライン状態の表示
- 利用履歴（誰がいつ使ったか）の確認

このアプリの利用には **キオスク管理（kiosk）権限** が必要です。

## 端末の状態

- **リンク待ち** … プロファイルだけ作成済みで、タブレットが未リンクの状態。
- **有効化待ち** … タブレットとリンク済みで、有効化を待っている状態。
- **有効** … キオスクとして利用できる状態。
- **無効** … 一時的に停止中。「再有効化」で戻せます。
- **取り消し** … 完全に無効化した状態。**元に戻せません**。

## 端末の登録（リンク → 有効化）

登録は「プロファイル先行」です。タブレット本体の準備（専用アプリのインストール等）は社内ドキュメントを参照してください。

1. **端末プロファイル作成** で端末名・拠点・場所（任意）を入力します。状態は「リンク待ち」になります。
2. タブレットの設定画面に **12 文字のリンクコード**（QR 付き・**10 分間有効**）が表示されます。
3. 一覧の行メニュー **端末をリンク** でそのコードを入力するか、**QR をカメラでスキャン** します。成功すると「有効化待ち」になります。
4. **有効化** を押すと「有効」になり、タブレット側が自動で検知してログイン画面に切り替わります。

コードが期限切れの場合は、タブレット側で再表示してやり直してください。リンクできるのは「リンク待ち」のプロファイルだけで、有効化できるのは「有効化待ち」の端末だけです。

## 一覧の見かた

- 列: **端末名** / **場所** / **拠点** / **状態** / **リンク**（リンク日時。未リンクは「未リンク」）/ **オンライン** / **利用者** / **最終アクティビティ** / **有効化者**。
- **オンライン** … 有効な端末の接続状態を緑 / 灰のドットで表示します。通常はリアルタイムで更新され、接続できないときは 30 秒ごとの自動更新、または直近 5 分の活動から判定します。
- **利用者** … いまその端末にログインしているユーザー。
- 端末名・場所・拠点で検索、拠点・状態で絞り込みできます。行をクリックすると **端末詳細** が開き、最近の利用者と利用履歴を確認できます。

## 編集

- **編集** で端末名・拠点・場所を変更できます。**拠点を変更するとフロアマップ上のピンは解除** されます（マップは拠点単位のため）。

## 端末の交換・停止

- **リンク解除** … タブレットをプロファイルから切り離し、「リンク待ち」に戻します。名称・拠点・場所・マップのピンは残り、その端末のセッションと認証情報は破棄されます。端末の交換・故障時に使い、新しいタブレットを同じプロファイルに再リンクします。
- **鍵リセット** … 端末の交換・初期化を行った際に、端末アプリの登録情報をリセットする操作です。次にその端末のアプリが接続したときに新しく登録されます。
- **無効化 / 再有効化** … 一時的に使用を止める / 再開します。無効化中はキオスクとして使えません。
- **取り消し** … 端末を完全に無効化します。**元に戻せません**。開いているセッションも失効します。使い直すには新しいプロファイルからの再登録が必要です。
- **削除** … リンク前（リンク待ち）のプロファイルのみ削除できます。

## フロアマップ

一覧右上の **フロアマップ** から開きます。拠点を選ぶと、フロアごとのタブにマップと端末ピンが表示されます。ピンの色はオンライン状態と連動し（オンライン = 緑 / オフライン = 灰）、ログイン中のユーザー名も表示されます。保管場所アプリ（MS0E）で配置された保管場所のピンも参照表示されます。

編集モード（スイッチ）でできること:

- ピンを **ドラッグ** して位置を移動します（位置は自動保存）。
- サイドバーの未配置端末をクリックすると中央に配置され、ドラッグで調整できます。
- 配置済み端末の **ピンを解除** でピンを外します。
- フロアの **追加・名称変更・削除** ができます（端末が配置されているフロアは削除できません）。
- **図面画像** のアップロード / 差し替えができます（PNG / JPG / WEBP / SVG）。

## よくある質問

- **リンクコードが受け付けられない** … コードは 12 文字・10 分間有効です。期限切れの場合はタブレット側で再表示してください。リンクできるのは「リンク待ち」のプロファイルだけです。
- **オンラインにならない** … 端末が「有効」でネットワークに接続しているか確認してください。表示は直近の活動から判定されるため、反映まで少し時間がかかることがあります。
- ログイン用 QR カードの発行・割当は [QRカード管理](/manual/ja/system/kiosk-card/user) を参照してください。キオスクに表示するアプリと認証ポリシーは [キオスク設定](/manual/ja/system/kiosk-settings/user) を参照してください。タブレット本体の詳細な導入手順は社内ドキュメントを参照してください。
