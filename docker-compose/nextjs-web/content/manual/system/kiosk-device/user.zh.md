操作代码 **SY09**。用于注册・管理工厂现场共享平板（kiosk 终端）的应用：链接・启用・楼层平面图布置以及使用记录的查看。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- 创建终端档案，并对平板进行 **链接**・**启用**
- 编辑终端信息（名称・工厂・位置）、停用・重新启用、解除链接、作废
- 在 **楼层平面图** 上布置终端图钉并查看在线状态
- 查看使用记录（谁在何时使用）

使用本应用需要 **kiosk 管理（kiosk）权限**。

## 终端状态

- **待链接** … 仅创建了档案，平板尚未链接。
- **待启用** … 已与平板链接，等待启用。
- **有效** … 可作为 kiosk 使用。
- **无效** … 临时停用中。可用「重新启用」还原。
- **作废** … 完全失效。**无法撤销**。

## 终端注册（链接 → 启用）

注册采用「档案先行」方式。平板本体的准备（安装专用应用等）请参见内部文档。

1. 用 **创建终端档案** 输入终端名・工厂・位置（可选）。状态变为「待链接」。
2. 平板的设置画面会显示 **12 位链接代码**（附 QR，**10 分钟有效**）。
3. 用列表行菜单的 **链接终端** 输入该代码，或 **用相机扫描 QR**。成功后状态变为「待启用」。
4. 按 **启用** 后状态变为「有效」，平板侧会自动检测并切换到登录画面。

代码过期时，请在平板侧重新显示后重试。只有「待链接」的档案可以链接，只有「待启用」的终端可以启用。

## 列表说明

- 列：**终端名** / **位置** / **工厂** / **状态** / **链接**（链接时间。未链接显示「未链接」）/ **在线** / **使用者** / **最后活动** / **启用者**。
- **在线** … 以绿 / 灰圆点显示有效终端的连接状态。通常实时更新；无法建立实时连接时，回退为每 30 秒自动刷新，或按最近 5 分钟的活动判定。
- **使用者** … 当前登录在该终端上的用户。
- 可按终端名・位置・工厂搜索，按工厂・状态筛选。点击行打开 **终端详情**，可查看最近使用者和使用记录。

## 编辑

- **编辑** 可修改终端名・工厂・位置。**变更工厂后，楼层平面图上的图钉会被解除**（平面图按工厂管理）。

## 终端的更换・停止

- **解除链接** … 将平板从档案上分离，回到「待链接」。名称・工厂・位置・平面图图钉保留，该终端的会话和认证信息被销毁。用于终端更换・故障时，将新平板重新链接到同一档案。
- **密钥重置** … 在更换・初始化终端后使用的操作，重置终端应用的登记信息。该终端的应用下次连接时会重新登记。
- **停用 / 重新启用** … 临时停止 / 恢复使用。停用中无法作为 kiosk 使用。
- **作废** … 使终端完全失效。**无法撤销**。已打开的会话也会失效。要再次使用，需从新档案重新注册。
- **删除** … 仅可删除链接前（待链接）的档案。

## 楼层平面图

从列表右上角的 **楼层平面图** 打开。选择工厂后，按楼层的标签页显示平面图和终端图钉。图钉颜色与在线状态联动（在线 = 绿 / 离线 = 灰），并显示登录中用户的姓名。在保管场所应用（MS0E）中布置的保管场所图钉也会以只读方式显示。

编辑模式（开关）下可以：

- **拖动** 图钉移动位置（位置自动保存）。
- 点击侧栏中未布置的终端，会放置到中央，可再拖动调整。
- 用已布置终端的 **解除图钉** 移除图钉。
- **添加・重命名・删除楼层**（有终端布置的楼层无法删除）。
- 上传 / 替换 **图纸图片**（PNG / JPG / WEBP / SVG）。

## 常见问题

- **链接代码不被接受** … 代码为 12 位、10 分钟有效。过期时请在平板侧重新显示。只有「待链接」的档案可以链接。
- **一直不显示在线** … 请确认终端为「有效」且已连接网络。显示按最近的活动判定，反映可能稍有延迟。
- 登录用 QR 卡的签发・分配请参见 [QR卡管理](/manual/zh/system/kiosk-card/user)。kiosk 上显示的应用和认证策略请参见 [Kiosk 设置](/manual/zh/system/kiosk-settings/user)。平板本体的详细导入步骤请参见内部文档。
