操作コード **SY0A**。共有タブレット（キオスク端末）のランチャーに表示するアプリの選択と、認証ポリシーの確認ができるアプリです。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- キオスクの **ランチャーに表示するアプリ** をスイッチで ON/OFF できます。
- キオスクの **認証ポリシー**（セッション時間・PIN・ロックなどのルール）を確認できます（現在は参照のみ）。

このアプリの利用には **キオスク管理（kiosk）権限** が必要です（切り替えには更新権限）。

## 開き方

- ホーム（システム）→ **キオスク設定**、または検索ボックスで `SY0A`。

## ランチャーに表示するアプリ

共有端末（キオスク）のランチャーに載せるアプリをスイッチで選びます。**無効にすると、権限を持つ利用者にもそのアプリは表示されません**。変更後に **保存** を押すと反映されます。

現在キオスクで提供されているアプリは **工程実行**（権限コード: `work_order`）のみです。今後アプリが追加されると、この一覧に並びます。

![キオスク設定（表示アプリと認証ポリシー）](../../assets/screenshots/kiosk-settings-01.png)

## 認証ポリシー（参照のみ）

キオスクのログイン・セッションのルールが表形式で表示されます。現在の値は端末アプリ側で固定されており、この画面からは変更できません（編集可能化は次回対応予定です）。

| 項目 | 値 |
| --- | --- |
| セッション最大時間 | 8 時間 |
| アイドル自動ログアウト | 5 分 |
| PIN 再入力（端末未使用） | 48 時間 |
| PIN 再入力（経過） | 14 日 |
| PIN 連続失敗の上限 | 5 回 |
| PIN ロック時間 | 15 分 |
| 端末トークン有効期間 | 30 日 |

## よくある質問

- **キオスクにアプリが表示されない** … この画面のスイッチが ON か、利用者がそのアプリの権限（例: 工程実行は `work_order`）を持っているかを確認してください。両方を満たしたアプリだけがランチャーに表示されます。
- 端末の登録・有効化は [端末管理](/manual/ja/system/kiosk-device/user)、ログイン用 QR カードは [QRカード管理](/manual/ja/system/kiosk-card/user) を参照してください。
