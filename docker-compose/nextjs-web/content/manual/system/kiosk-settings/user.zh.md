操作代码 **SY0A**。选择共享平板（kiosk 终端）启动器上显示的应用，并查看认证策略的应用。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- 用开关切换 **kiosk 启动器上显示的应用**。
- 查看 kiosk 的 **认证策略**（会话时长・PIN・锁定等规则）（目前仅供参照）。

使用本应用需要 **kiosk 管理（kiosk）权限**（切换需要更新权限）。

## 打开方式

- 主页（系统）→ **Kiosk 设置**，或在搜索框输入 `SY0A`。

## 启动器上显示的应用

用开关选择要放到共享终端（kiosk）启动器上的应用。**停用后，即使持有权限的使用者也看不到该应用**。修改后按 **保存** 生效。

目前 kiosk 上提供的应用只有 **工序执行**（权限代码：`work_order`）。今后新增的 kiosk 应用会陆续出现在此列表中。

![Kiosk 设置（显示应用与认证策略）](../../assets/screenshots/kiosk-settings-01.png)

## 认证策略（仅供参照）

kiosk 的登录・会话规则以表格显示。当前值在终端应用侧固定，无法从此画面修改（可编辑化计划在后续版本支持）。

| 项目 | 值 |
| --- | --- |
| 会话最长时间 | 8 小时 |
| 空闲自动登出 | 5 分钟 |
| PIN 重新输入（终端未使用） | 48 小时 |
| PIN 重新输入（经过时间） | 14 天 |
| PIN 连续失败上限 | 5 次 |
| PIN 锁定时长 | 15 分钟 |
| 终端令牌有效期 | 30 天 |

## 常见问题

- **kiosk 上不显示应用** … 请确认此画面的开关为 ON，且使用者持有该应用的权限（例：工序执行需要 `work_order`）。只有同时满足两个条件的应用才会显示在启动器上。
- 终端的注册・启用请参见 [终端管理](/manual/zh/system/kiosk-device/user)，登录用 QR 卡请参见 [QR卡管理](/manual/zh/system/kiosk-card/user)。
