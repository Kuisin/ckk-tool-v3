操作コード **SY01**。システムに登録されている全ユーザーの一覧と、各ユーザーのロール割当・所属拠点・実効権限を確認できる **閲覧専用** のアプリです。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 全ユーザーを一覧で確認し、検索・絞り込みができます。
- ユーザーごとの詳細画面で、ロール割当の履歴・所属拠点・**実効権限**（権限コード × アクション × スコープ）を確認できます。

このアプリの利用には **システム（system）権限** が必要です。基本は閲覧専用で、ユーザーの作成・編集・削除はこの画面からはできません（ユーザー情報は社内の認証基盤との同期などで管理されます）。唯一の例外は **所属拠点** で、システム管理権限（system の管理アクション）を持つ管理者だけが編集できます。

## 開き方

- ホーム（システム）→ **ユーザー管理**、または検索ボックスで `SY01`。

## 一覧・検索

一覧には次の列が表示されます。

- **ユーザー名** … ログインに使う ID（等幅表示）。
- **表示名** … 画面に表示される氏名。
- **メール** … 登録メールアドレス（無い場合は「—」）。
- **区分** … **システム** / **社員** / **ゲスト** のバッジ。
- **ロール** … 割り当てられているロールのバッジ（複数可）。
- **状態** … **有効** / **無効**。
- **最終ログイン** … 最後にログインした日時（未ログインは「—」）。

検索ボックスはユーザー名・表示名・メール・ロール名を横断して検索します。**区分** と **状態** のセレクトで絞り込み、**リセット** で条件を全部クリアできます。行をクリックすると詳細へ移動します。

![ユーザー管理の一覧画面](../../assets/screenshots/settings-users-list-01.png)

## ユーザー詳細

詳細画面は概要と 3 つのカードで構成されます。

- **概要** … ユーザー名・区分・メール・**ログイン方式**（**パスワード + SSO** か **SSO のみ** か）・最終ログイン・社員 ID。
- **ロール割当** … 割当の履歴一覧。ロール名・rolename（システム内部名）・状態・割当日・解除日時が表示され、過去に解除された割当も残ります。
- **所属拠点** … PLANT / REGION スコープ権限の対象になる拠点です。通常はバッジ表示のみですが、システム管理権限を持つ管理者には拠点の選択欄と「保存」ボタンが表示され、所属拠点を編集できます。
- **実効権限** … 有効なロール経由でこのユーザーに与えられている権限の一覧。権限コード（例: `quote`、`master`、`system`）ごとに、アクション（READ / CREATE / UPDATE / ADMIN など）とスコープが表示されます。

![ユーザー詳細（ロール割当・所属拠点・実効権限）](../../assets/screenshots/settings-users-detail-01.png)

## 実効権限の読み方

- 権限はロールに紐づいており、ユーザーは複数のロールを持てます。
- 同じ権限・アクションの行が複数表示されることがあります（複数ロールから付与されている場合）。実際にできることは、表示された行すべての **和集合** です。
- スコープはその操作が及ぶ範囲です（ALL = 全体、PLANT = 所属拠点、REGION = 所属地域、OWN = 自分のデータ など）。PLANT / REGION スコープで対象拠点が限定されている場合は、スコープの横に拠点コードが表示されます。

## よくある質問

- **ユーザーを追加・編集したい** … この画面ではできません。システム管理者に依頼してください。
- **ロールを変更したい** … この画面は確認専用です。ロール割当の変更はシステム管理者が行います。
- **権限が想定と違う** … 詳細画面の「実効権限」と「所属拠点」を確認してください。PLANT / REGION スコープの権限は所属拠点が空だと対象範囲がありません。
- 誰がいつ何を変更したかは [操作履歴](/manual/ja/system/activity-log/user) で確認できます。アプリの表示 ON/OFF は [アプリ管理](/manual/ja/system/app-management/user) を参照してください。
