操作代码 **SY01**。用于查看系统内全部用户的一览，以及各用户的角色分配、所属工厂和实际生效权限的 **只读** 应用。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

- 以列表方式查看全部用户，并进行搜索和筛选。
- 在各用户的详情页面查看角色分配（含历史）、所属工厂，以及该用户的 **实际生效权限**（权限代码 × 操作 × 范围）。

使用本应用需要 **系统（system）权限**。本应用基本为只读 — 无法在此画面创建、编辑或删除用户（用户信息通过与公司认证基础设施的同步等方式管理）。唯一的例外是 **所属工厂**，只有持有系统管理权限（system 的管理操作）的管理员才能编辑。

## 打开方式

- 主页（系统）→ **用户管理**，或在搜索框输入 `SY01`。

## 列表与搜索

列表显示以下列。

- **用户名** … 登录用 ID（等宽显示）。
- **显示名** … 画面上显示的姓名。
- **邮箱** … 登记的邮箱地址（没有时显示「—」）。
- **类别** … **系统** / **员工** / **访客** 徽章。
- **角色** … 已分配角色的徽章（可多个）。
- **状态** … **有效** / **无效**。
- **最后登录** … 最后一次登录的时间（从未登录显示「—」）。

搜索框可跨用户名・显示名・邮箱・角色名搜索。可用 **类别** 和 **状态** 下拉筛选，用 **重置** 清空全部条件。点击行进入详情。

![用户管理列表画面](../../assets/screenshots/settings-users-list-01.png)

## 用户详情

详情页面由概要和 3 个卡片构成。

- **概要** … 用户名・类别・邮箱・**登录方式**（**密码 + SSO** 或 **仅 SSO**）・最后登录・员工 ID。
- **角色分配** … 分配历史一览：角色名・rolename（系统内部名）・状态・分配日・解除日时。过去已解除的分配也会保留显示。
- **所属工厂** … PLANT / REGION 范围权限的对象工厂。通常仅以徽章显示；持有系统管理权限的管理员会看到工厂选择框和「保存」按钮，可编辑所属工厂。
- **实际生效权限** … 该用户通过有效角色获得的权限一览。按权限代码（如 `quote`、`master`、`system`）显示操作（READ / CREATE / UPDATE / ADMIN 等）和范围。

![用户详情（角色分配・所属工厂・实际生效权限）](../../assets/screenshots/settings-users-detail-01.png)

## 如何解读实际生效权限

- 权限与角色绑定，一个用户可持有多个角色。
- 同一权限・操作可能显示多行（由多个角色分别授予时）。用户实际能做的事是所有显示行的 **并集**。
- 范围表示操作所及的范围（ALL = 全部、PLANT = 所属工厂、REGION = 所属地域、OWN = 本人数据等）。当 PLANT / REGION 范围限定了对象工厂时，范围旁会显示工厂代码。

## 常见问题

- **想添加・编辑用户** … 无法在此画面操作。请联系系统管理员。
- **想变更角色** … 此画面仅供查看。角色分配的变更由系统管理员进行。
- **权限与预期不符** … 请查看详情页面的「实际生效权限」和「所属工厂」。所属工厂为空时，PLANT / REGION 范围的权限没有对象范围。
- 谁在何时改了什么，可在 [操作历史](/manual/zh/system/activity-log/user) 中确认。应用的显示开关请参见 [应用管理](/manual/zh/system/app-management/user)。
