操作代码 **DC01**。本页介绍「手册」应用本身的使用方法。所有用户均可使用（无需权限）。

## 此应用的功能

无需离开系统，即可阅读系统内所有应用的操作手册。手册提供 **日本語・English・中文** 三种语言。

- 通过左侧边栏，可按 **应用操作手册**（各应用的操作步骤）、**主数据操作手册**（主数据的登记与管理）与 **系统管理手册**（面向系统管理员的设置与管理）三个分组打开各页面。
- 初次使用请从 [开始手册](/manual/zh/start) 读起。

## 打开方式

- 点击主页或启动器中的 **手册（マニュアル）**，或在搜索框中输入 `DC01`。
- 如果其他画面中带有手册链接，点击即可直接跳转到对应页面。

## 切换语言

- 点击侧边栏顶部（移动端为页面顶部工具栏）的 **日本語 / English / 中文**，即可切换显示语言。
- 在页面之间移动时语言保持不变。手册内的链接也会跳转到相同语言的页面。

## 搜索

- 点击侧边栏的 **搜索** 按钮，或按键盘 **⌘K**（Windows 为 Ctrl+K）打开搜索窗口。
- 输入关键词后，将在所有手册的正文中查找匹配内容。点击结果即可跳转到该页面。
- 搜索对象为当前显示语言的手册。

## 常见问题

- **手册中描述的画面找不到** … 部分应用目前仅在开发环境（dev）中开放。请确认手册开头的注意事项。此外，没有权限的应用不会显示在主页上。
- **内容与实际画面不一致** … 系统更新时，画面可能先于手册发生变化。发现问题请联系管理员。
