# 承認管理 — 操作マニュアル

操作コード **PD03**。承認待ちの依頼を文書の種類をまたいで一覧し、自分が承認すべきものをまとめて確認できます。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

各アプリで出された **承認依頼のうち、まだ処理されていないもの** だけが並ぶ「承認待ちの受信箱」です。対象になる文書は次のとおりです。

- **指示書** … 第一承認・第二承認（[指示書](/docs/apps/work-order/user) PD02）。
- **素材発注書** … 発注前の承認（[素材発注書](/docs/apps/purchase-order/user) PU03）。
- **購買依頼** … [購買依頼](/docs/apps/purchase-request/user) PU04。
- **受注請書** … 一覧に表示されます（専用の承認画面は未実装のため、行クリックでの遷移はありません）。

承認や差し戻しの操作そのものは、この一覧から開いた **各文書の詳細画面** で行います。処理が済んだ依頼は一覧から自動的に消えます。

## 一覧の見かた

- 列は **種別**（指示書 / 素材発注書 / 購買依頼 / 受注請書のバッジ）、**対象番号**、**段階**（第一 / 第二）、**依頼者**、**依頼日時**、**備考** です。
- 並び順は依頼日時の古い順（先に来た依頼が上）です。
- 検索ボックスで **対象番号・依頼者・備考** を検索でき、**種別** と **段階** で絞り込めます。
- 「旧データ」バッジ … 承認依頼の記録方式を切り替える前に出された依頼です。内容は同じように処理できます。

## 承認・差し戻しのしかた

1. 一覧の行をクリックすると、対象文書の詳細画面が開きます（指示書 → 指示書詳細、素材発注書 → 発注書詳細）。
2. 詳細画面の **承認状況** パネルで「第一承認」または「第二承認」「差し戻し」を押します。差し戻しには理由の入力が必要です。
3. 指示書は第一承認 → 第二承認の 2 段階です。第二承認が済むと製造を開始できる状態になります。

承認できるのは、その段階の **承認グループのメンバー**（または有効期間内の **代理者**）だけです。メンバーでない場合はボタンが表示されず、その旨のメッセージが出ます。代理で承認した記録には「（代理: 原承認者）」が付きます。グループと代理の設定は [承認グループ](/docs/masters/approval-group/user) マスタで行います。

## 承認詳細画面

指示書の承認は、専用の承認詳細画面（`/production/approvals/指示書番号`）でも行えます。指示書詳細と同じ内容を、承認状況パネルを最上部にしたレイアウトで表示します（通知のリンクなどから開いたときに使われます）。

## よくある質問

**Q. 一覧に何も表示されません。** — 承認待ちの依頼がない状態です。処理済み・差し戻し済みの依頼は表示されません。

**Q. 承認ボタンが出ません。** — 現在の段階（第一 / 第二）の承認グループに所属していないか、承認権限がありません。管理者に確認してください。

このアプリの利用には承認（approve）権限が必要です。
