# 审批管理（承認管理） — 操作手册

操作代码 **PD03**。跨文档类型统一列出待审批的申请，方便集中查看需要自己审批的事项。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

这是一个只显示**尚未处理的审批申请**的"审批收件箱"。涉及的文档类型如下：

- **制造指示单（指示書）** … 第一审批・第二审批（[指示書](/docs/apps/work-order/user) PD02）。
- **素材订购单（素材発注書）** … 下单前的审批（[素材発注書](/docs/apps/purchase-order/user) PU03）。
- **采购申请（購買依頼）** … [購買依頼](/docs/apps/purchase-request/user) PU04。
- **订单受理（受注請書）** … 会显示在列表中（专用审批画面尚未实现，点击该类行不会跳转）。

实际的审批・驳回操作在从此列表打开的**各文档详情页**中进行。处理完毕的申请会自动从列表中消失。

## 列表说明

- 列包括：**类别**（指示書 / 素材発注書 / 購買依頼 / 受注請書的徽章）、**对象编号**、**阶段**（第一 / 第二）、**申请人**、**申请时间**、**备注**。
- 按申请时间从旧到新排序（先提交的申请排在上面）。
- 搜索框可按**对象编号・申请人・备注**搜索，还可按**类别**和**阶段**筛选。
- "旧データ"（旧数据）徽章 … 表示在审批申请记录方式切换之前提交的申请，处理方式与其他申请相同。

## 如何审批・驳回

1. 点击列表中的行，打开对象文档的详情页（指示書 → 指示書详情，素材発注書 → 订购单详情）。
2. 在详情页的**审批状态**面板中点击"第一承認"（第一审批）、"第二承認"（第二审批）或"差し戻し"（驳回）。驳回时必须填写理由。
3. 指示書采用第一审批 → 第二审批的两级流程。第二审批通过后即可开始生产。

只有该阶段**审批组的成员**（或有效期内的**代理人**）才能审批或驳回。若不是成员，则不会显示按钮，并有相应提示。代理审批的记录会标注"（代理: 原审批人）"。审批组和代理设置在[审批组](/docs/masters/approval-group/user)主数据中维护。

## 审批详情画面

指示書的审批也可以在专用的审批详情画面（`/production/approvals/指示单编号`）中进行。其内容与指示書详情相同，但把审批状态面板放在最上方（例如从通知链接打开时使用）。

## 常见问题

**Q. 列表中什么都没有。** — 说明当前没有待审批的申请。已处理・已驳回的申请不会显示。

**Q. 看不到审批按钮。** — 您不属于当前阶段的审批组，或没有审批权限。请与管理员确认。

使用此应用需要审批（approve）权限。
