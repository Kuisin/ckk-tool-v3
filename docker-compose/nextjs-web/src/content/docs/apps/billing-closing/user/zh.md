# 结算日处理 — 操作手册

操作代码 **BL02**。按每个客户的结算日（締日）汇总未开票的出货并生成发票的月度处理。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

用于每月一次的"结账"。将目标月份的未开票出货（**已出货 × 发货**的[出货单](/docs/apps/shipping-order/user)）按客户汇总为结算行，再从结算行生成[发票](/docs/apps/invoice/user)（草稿）。

- 类型为"库存保管"的出货在开票流程之外，不计入汇总。
- 已成为某张发票明细的出货不再算作"未开票"，因此不会重复开票。
- 操作本应用需要结算日处理权限（billing_closing）。

## 结算日如何确定

- 每个客户的结算日来自[客户](/docs/masters/customer/user)主数据中的**締日**（结算日）设置（未设置时为月末）。
- 结算日之后出货的部分不计入当月结算，按下月处理。

## 执行结算日处理

1. 点击列表页右上角的**締日処理を実行**（执行结算日处理）。
2. 选择目标**年、月**后点击**実行**（执行）。
3. 目标月份的未开票出货按客户汇总，创建或更新**未处理（未処理 / PENDING）**的行（会显示创建 / 更新 / 已处理跳过的件数）。
4. 多次执行也是安全的：已处理的行会被跳过，未处理的行会刷新为最新金额。
5. 根据服务器配置，当月的处理也可能每天早晨自动执行。

## 生成发票

1. 从列表打开结算行，可确认目标出货列表（出货单号、出货日期、数量、金额）。
2. 点击**請求書を生成**（生成发票）：根据目标出货的明细创建发票（草稿），该行变为**已处理（処理済 / PROCESSED）**，并直接跳转到生成的发票详情页。
3. 消费税与付款期限根据客户主数据的税区分和付款账期自动计算。
4. 之后的开具、寄送、收款记录以及弥生会计 CSV 导出在[发票](/docs/apps/invoice/user)应用中进行。

## 状态

- **未处理（未処理 / PENDING）**：已创建结算行，可以生成发票。
- **已处理（処理済 / PROCESSED）**：已生成发票，可通过详情页的"生成請求書"跳转到发票。
- 弥生 CSV 的导出情况记录在发票一侧（弥生导出时间）。

## 列表与搜索

- 可按客户名搜索，并按状态筛选。点击行即可进入详情页。
