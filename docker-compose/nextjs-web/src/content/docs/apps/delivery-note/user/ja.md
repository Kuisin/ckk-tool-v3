# 納品書 — 操作マニュアル

操作コード **SH02**。出荷書から納品書（DRN-YYYYMM-NNNNN）を作成し、発行・納品の管理と PDF 出力を行います。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

出荷した製品に添付・送付する **納品書** を作ります。[出荷書](/docs/apps/shipping-order/user)（確定済み・出荷済みのもの）を選ぶと、納品先と明細が自動で入ります。

- 納品先は出荷書 → 注文請書の[顧客](/docs/masters/customer/user)（＋支店）から自動で決まります（変更不可）。
- 納品方法（通常納品 / ユーザー直送）と価格記載の有無を選べます。
- 納品書 PDF を出力して同梱・送付できます。
- 操作には納品書の権限（delivery_note）が必要です。

## 納品方法と価格記載

- **通常納品**：受注先（顧客）へ納品書を同梱する通常のパターンです。価格記載は既定で「あり」です。
- **ユーザー直送**：[最終需要家](/docs/masters/end-user/user)へ直接送るパターンです。**届け先（最終需要家）** の選択が必須で、価格記載は既定で「なし」になります。
- **価格記載** を「なし」にすると、単価・金額は保存されず、画面にも PDF にも表示されません。

## 作成方法

1. 一覧の「新規作成」を押します（出荷書詳細の「納品書を作成」からも開けます — その場合は出荷書が選択済みになります）。
2. **出荷書** を選びます。明細（製品・数量・単価 = 注文請書の受注単価）が自動で入ります。
3. **納品方法** と **価格記載** を設定します。ユーザー直送のときは **届け先（最終需要家）** を選びます。
4. 明細は修正できますが、出荷書に含まれない製品や、出荷数量を超える数量は登録できません。
5. 保存すると **下書き** になります。出荷書と納品先は作成後に変更できません。

## 状態と操作

操作は詳細画面右上のメニューから行います。

- **下書き（DRAFT）**：編集できます。内容が固まったら **発行** します（発行後は編集不可）。
- **発行済（ISSUED）**：お客様へ届いたら **納品済みにする** を押します。納品日は当日で記録されます。
- **納品済（DELIVERED）**：完了状態です。

- **PDF** ボタンでいつでも納品書 PDF を出力できます。

## 請求との関係

- 納品書番号は[請求書](/docs/apps/invoice/user)の明細に「由来」としてリンク表示されます（請求書自体は[締日処理](/docs/apps/billing-closing/user)で出荷書から生成されます）。

## 一覧・検索

- 納品番号・出荷書番号・納品先で検索でき、納品方法・状態で絞り込めます。
- 行をクリックすると詳細画面へ移動します。
