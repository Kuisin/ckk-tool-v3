# Invoice — User Manual

Operation code **BL01**. Manage the issuing, sending, and payment of invoices (請求書, INV-YYYYMM-NNNNN) generated by the billing closing, and output PDFs and Yayoi accounting CSV files.

> This app is currently available **in the development (dev) environment only**. Screens and steps may change before the production release.

## What you can do with this app

Manage **invoices (請求書)** to customers. Invoices are not created by hand on this screen — they are generated automatically by **"請求書を生成" (Generate invoice) in the [billing closing](/docs/apps/billing-closing/user) (BL02)**. Line items are built from shipped [shipping orders](/docs/apps/shipping-order/user).

- Each line item shows linked source shipping order and [delivery note](/docs/apps/delivery-note/user) numbers, so you can jump to the original documents.
- Consumption tax is calculated automatically from the [customer](/docs/masters/customer/user) master's tax type (taxable 10% / reduced rate 8% / exempt 0%).
- The payment due date is set automatically as "closing date + the customer's payment terms (30 days when not set)".
- Using this app requires the invoice permission (invoice).

## Reading the detail page

- The top section shows the invoice number, customer (plus branch), billing period, subtotal, consumption tax, total amount (tax included), due date, issue date, and Yayoi export timestamp.
- The line-item table lists the description (product name + lot), quantity, unit price, amount, and linked source shipping order / delivery note.
- The **履歴** (History) tab shows the operation history.

## Statuses and actions

Actions are in the menu at the top right of the detail page. The status moves forward in order; there is no edit screen.

- **Draft (下書き / DRAFT)**: the state right after generation. After checking the contents, press **発行** (Issue) — the issue date is recorded as today.
- **Issued (発行済 / ISSUED)**: once sent to the customer, press **送付済みにする** (Mark sent).
- **Sent (送付済 / SENT)**: once payment is confirmed, press **入金済みにする** (Mark paid).
- **Paid (支払済 / PAID)**: final state.

## PDF and Yayoi accounting CSV

- The **PDF** button outputs the invoice PDF.
- **弥生会計CSV** in the menu downloads a journal-entry CSV that can be imported into Yayoi Kaikei Next (debit: accounts receivable / credit: sales and provisional consumption tax received, UTF-8 with BOM).
- Exporting records the timestamp, shown in the detail page's "弥生エクスポート" field.
- CSV export requires the billing-closing export permission (EXPORT on billing_closing).

## List and search

- Search by invoice number or customer; filter by status.
- Click a row to open the detail page.
