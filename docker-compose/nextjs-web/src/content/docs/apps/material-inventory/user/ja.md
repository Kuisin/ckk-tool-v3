# 素材在庫 — 操作マニュアル

操作コード **PD05**。素材の在庫数・予約数と、入荷予定を含めた「いつ・どれだけ使えるか」（ATP）を確認する台帳です。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

素材在庫は **照会専用** の画面です。数量をここで直接編集することはありません — 在庫は業務の操作に連動して自動的に動きます。

- **入庫** … [素材入荷](/docs/apps/material-receipt/user)（PU01）で入荷を登録すると、入荷先拠点の在庫に入庫されます。
- **予約** … 製造分の [指示書](/docs/apps/work-order/user) が承認されると、使用素材が予定数量ぶん予約されます。
- **消費（出庫）** … 指示書の全工程が完了すると、予約されていた素材が消費されます。
- **入荷予定** … 発注済み（発注書が「発注済」）の [素材発注書](/docs/apps/purchase-order/user) の明細から、次回入荷日と入荷予定量が表示されます。

## 一覧の見かた

在庫 1 行 = 素材 × 拠点です。

- 列は **素材**（素材コード + 名称）、**拠点**、**在庫数**（単位付き）、**予約数**、**利用可能**（在庫数 − 予約数）、**次回入荷**（発注済み明細の直近の入荷予定日）、**更新日** です。
- 素材コード・名称で検索でき、**拠点** で絞り込めます。
- 行をクリックすると詳細画面が開きます。

## 詳細画面

サマリには素材・拠点・在庫数・予約数・利用可能・次回入荷・保管場所が表示されます。

**ATP タイムライン** タブ … 「現時点の利用可能数」から始まり、入荷予定日ごとに利用可能数がどう積み上がるかを時系列で表示します。

- 列は **時点**（現時点 → 入荷予定日。日付未設定の発注は「未定」）、**入荷量**、**利用可能**（累積）、**参照**（発注番号）。
- 利用可能がマイナスの時点は赤字で表示されます — 予約（製造コミット）が手持ち + 入荷予定を上回っている状態で、発注判断のシグナルです。

**取引履歴** タブ … 在庫が動いた記録です。種別は **入庫 / 出庫 / 予約 / 解除 / 調整** で、日時・数量・参照（指示書番号・入荷など）・備考が残ります。

## よくある質問

**Q. 予約数が在庫数より多いのですが。** — 異常ではありません。指示書の承認時は在庫が足りなくても予約されます（不足 = 発注が必要というシグナル）。ATP タイムラインで入荷後に足りるかを確認してください。

**Q. 在庫数を手で直したい。** — この画面からは編集できません。数量のずれは棚卸調整として管理者側の対応が必要です。

このアプリの利用には在庫（inventory）権限が必要です。製品の在庫は [製品在庫](/docs/apps/product-inventory/user)（PD04）で確認します。
