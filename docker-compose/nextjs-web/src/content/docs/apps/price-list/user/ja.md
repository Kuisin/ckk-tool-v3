# 価格表 — 操作マニュアル

操作コード **SA01**。顧客ごとの製品単価を管理します。見積書の単価はここから自動解決されます。

## このアプリでできること

[顧客](/docs/masters/customer/user)ごとに「この[製品](/docs/masters/product/user)はいくら」という **販売単価** を登録しておく台帳です。登録しておくと、見積書を作るときに単価が自動で入ります。

- 単価は多くの場合、製品にリンクした **試算（SA05）** の計算結果から取り込みます（手入力も可）。
- 1 つの価格表（顧客×製品）の中に、**注文種別ごとの価格** と、数量が多いほど安くする **数量段階（本数 → 倍率）** を設定できます。
- **有効期間** を設定でき、その期間の価格として管理されます。

## 価格表エントリ

1 エントリ = **顧客 + 製品**（作成後は変更不可）。注文種別（本番 / テスト / サンプル / その他）ごとの価格はエントリ内の **バリアント** として持ちます。

- バリアントごとに **基準単価**・**有効期間**（テスト・サンプルは終了日必須）・状態・試算リンクを持ちます。
- **数量段階（tier）**：本数範囲ごとの倍率（例：1〜99 本 = ×1.05、100 本〜 = ×1.00）。単価 = 基準単価 × 倍率（行ごとに手動上書き可）。

## 作成方法

1. 一覧の「新規作成」から **顧客と製品** を選びます。
2. 注文種別ごとに価格を設定します。選んだ製品に **リンク済みの確定試算（SA05）** があれば、**価格ソース** として選択でき、その見積単価が基準単価に入ります（推奨）。
3. 試算が無い場合や別の単価にしたい場合は、**手動設定**（カスタム基準単価・確認あり）も可能です。
4. 試算をソースに使うと、その試算は使用済み（REGISTERED）としてロックされます。

## 注文種別（バリアント）の追加・編集

- 詳細画面 →「編集」で、注文種別の追加・削除、基準単価・有効期間・数量段階を変更できます。
- 値引きルールはバリアントごとに詳細画面の「値引き設定」タブで登録します。

## 一覧・検索

- 顧客・製品・注文種別・状態で絞り込めます。1 行 = 顧客×製品（注文種別はバッジ表示）。
- 同じ顧客×製品の価格表は 1 つだけです。重複作成はエラーになります（既存を編集してください）。
