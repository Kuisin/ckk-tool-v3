# 价格表 — 操作手册

操作码 **SA01**。管理按客户的产品单价。报价单的单价会自动从此处解析。

## 本应用能做什么

按[客户](/docs/masters/customer/user)登记每个[产品](/docs/masters/product/user) **销售单价** 的台账。登记后，制作报价单时单价会自动填入。

- 单价通常取自与产品关联的 **试算（SA05）** 的计算结果（也可手动输入）。
- 在一个价格表（客户×产品）中，可设置 **按订单类型的价格** 与 **数量阶梯（数量 → 倍率）**，数量越多越便宜。

## 价格表条目

一个条目 = **客户 + 产品**（创建后不可更改）。各订单类型（正式 / 测试 / 样品 / 其他）的价格作为条目内的 **变体（variant）** 管理。

- 每个变体拥有各自的 **基准单价**、**有效期**（测试・样品必须设置结束日）、状态与试算关联。
- **数量阶梯（tier）**：按数量区间的倍率（例：1–99 件 = ×1.05，100 件以上 = ×1.00）。单价 = 基准单价 × 倍率（可按行手动覆盖）。

## 创建方式

1. 从列表的“新建”选择 **客户与产品**。
2. 按订单类型设置价格。若所选产品有 **已确定并关联的试算（SA05）**，可将其选为 **价格来源**，其估算单价会填入基准单价（推荐）。
3. 没有试算或需要不同单价时，也可 **手动设置**（自定义基准单价，需确认）。
4. 将试算用作来源后，该试算会被锁定为已使用（REGISTERED）。

## 订单类型（变体）的添加与编辑

- 在详情页 →「编辑」中，可添加/删除订单类型，修改基准单价、有效期与数量阶梯。
- 折扣规则按变体在详情页的「折扣设置」标签中登记。

## 列表与检索

- 可按客户、产品、订单类型、状态筛选。一行 = 客户×产品（订单类型以徽章显示）。
- 相同客户×产品的价格表只能有一个，重复创建会报错（请编辑现有条目）。
