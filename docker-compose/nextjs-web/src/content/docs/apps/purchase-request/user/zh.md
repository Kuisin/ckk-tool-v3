# 采购申请 — 操作手册

操作码 **PU04**。管理素材采购单前置阶段的内部申请（「希望采购这种素材」），流程为 申请 → 审批 → 转换为采购单。申请编号为 **PRQ-YYYYMM-NNNNN**。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

带审批流程的素材采购申请（購買依頼）应用。在申请阶段 **不确定供应商与单价** — 只需填写买什么、送到哪个工厂、买多少、何时要，然后提交审批。

- 审批通过的申请可通过「转换为采购单」生成[素材采购单（素材発注書，PU03）](/docs/apps/purchase-order/user)（草稿）。供应商在转换时指定，单价在采购单侧输入。
- 审批请求同时会显示在[审批管理（承認管理，PD03）](/docs/apps/approval/user)中，由审批组成员（或代理人）处理。
- 创建・编辑需要采购（下单）权限。

## 状态与流程

- **草稿（下書き）** — 刚创建的状态。可编辑・取消。点击「申请审批」进入审批流程。
- **审批中（承認依頼中）** — 仅第一审批组成员（或代理人）可以「批准」「退回」。
- **已批准（承認済）** — 可以「转换为采购单」。转换前也可以取消（必须填写理由）。
- **退回（差し戻し）** — 带理由被退回的状态。详情页会显示理由，可编辑后再次申请审批。
- **已下单（発注済）** — 已转换为采购单。详情页会显示到对应素材采购单的链接。
- **取消（キャンセル）** — 转换前的申请以带理由的方式撤回的状态。

## 创建方式

1. 打开列表的「新建」，输入 **申请理由**（可选）与 **备注**。
2. 添加明细。一行 = [素材](/docs/masters/material/user) × 入库工厂 × 数量・单位 × 期望交期（可选）。没有单价栏。
3. 保存后成为草稿。确认内容后点击「申请审批」，审批流程即开始。

只有在草稿・退回状态下才能编辑。

## 转换为采购单

1. 在已批准申请的详情页点击「转换为采购单」。
2. 选择 **供应商** 并点击「转换」，即生成继承明细的素材采购单（草稿）并跳转到其页面。
3. 单价以 0 日元复制，请在采购单的编辑页面输入单价后，再进行采购单的审批申请。

## 列表与检索 / 详情页

- 列表列：申请编号 / 申请人 / 素材（首条明细＋其余 N 件）/ 明细数 / 状态 / 期望交期 / 更新日。可用搜索框（申请编号、申请人、素材）与状态筛选。
- 详情页包含 申请 → 审批 → 转换为采购单 的步骤显示、审批记录（代理审批标注「（代理: 原审批人）」）、流转历史，以及标签页（明细 / 概要 / 历史）。

## 常见问题

**看不到批准按钮** — 只有第一审批组的成员（或有效期内的代理人）才能批准・退回。审批组在审批组主数据中管理。

**被退回的申请会怎样？** — 状态变为「退回」，可编辑后再次「申请审批」，无需重新创建。
