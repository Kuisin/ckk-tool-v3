# 出货单 — 操作手册

操作代码 **SH01**。依据订单回执（注文請書）创建并管理记录产品出货的出货单（出荷書，SHP-YYYYMM-NNNNN）。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 本应用能做什么

这是在成品出厂时创建**出货单（出荷書）**的台账。出货单是开票流程的起点：可从它创建[送货单](/docs/apps/delivery-note/user)，已出货的发货部分会在[结算日处理](/docs/apps/billing-closing/user)中汇总为发票。

- 选择订单回执（注文請書）后，会根据已完成的[作业指示书](/docs/apps/work-order/user)（批次）自动生成明细行。
- 出货后会从[产品库存](/docs/apps/product-inventory/user)扣减库存，并自动更新订单回执的出货状态（部分出货 / 已出货）。
- 操作本应用需要出货单权限（shipping_order）。

## 类型（发货与库存保管）

- **发货（発送）**：向客户发货的正常出货。出货时扣减库存，并成为开票对象。
- **库存保管（在庫保管）**：将备用生产品等不发出、而是作为库存保管的记录。它在开票流程之外，不改变订单回执的出货状态。执行"出货"后，数量会入库到保管工厂的库存。

## 创建方法

1. 在列表页点击**新規作成**（新建）。
2. 搜索并选择**订单回执（注文請書）**。每个已完成的作业指示书（批次）自动生成一行明细（批次 = 指示书编号，数量 = 最终工序的良品数）。
3. 选择**类型**（发货 / 库存保管）和**出货工厂**。
4. 明细行（产品、批次、数量、备注）可以添加、删除和修改。
5. 保存后登记为**草稿**。创建后无法更改订单回执。

## 状态与操作

操作在详情页右上角的菜单中进行。状态分三个阶段推进。

- **草稿（下書き / DRAFT）**：可以编辑和**取消**（删除）。内容确定后点击**確定**（确认）。
- **已确认（確定 / CONFIRMED）**：不可再编辑，可以开始创建送货单。实际出货时点击**出荷**（出货）。
- **已出货（出荷済 / SHIPPED）**：记录出货日期，扣减库存，并更新订单回执的出货状态（部分出货 / 已出货）。

- 发货的累计出货数量超过订单数量时会报错（防超发保护）。
- 出货工厂库存不足时也无法出货，请先确认库存。

## 与送货单的联动

- 在详情页的**納品書**（送货单）标签页可查看由此出货单创建的送货单列表。
- 确认后，可在同一标签页通过**納品書を作成**（创建送货单）创建[送货单](/docs/apps/delivery-note/user)。

## 列表与搜索

- 可按出货单号、订单回执编号、客户、产品搜索，并按类型、状态筛选。
- 点击行即可进入详情页。
