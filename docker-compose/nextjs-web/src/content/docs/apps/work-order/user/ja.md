# 指示書 — 操作マニュアル

操作コード **PD02**。製造現場への作業指示（指示書）を作成し、承認から工程の実行・完了までを管理します。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

指示書は「この注文請書の製品を、この工程の並びで、何本作るか」を決める文書です。指示書番号は通し連番で、そのまま **ロット番号** になります。

- 注文請書を選び、工程カタログから **工程ワークフロー** を組み立てて作成します。
- 作成後に **承認依頼** を出し、第一承認 → 第二承認を経て製造を開始できます。
- 各工程は **工程実行画面** で開始・数量入力・完了を記録します。
- 全工程が完了すると、良品が [製品在庫](/docs/apps/product-inventory/user) にロット入庫されます。

指示書のもとになる **注文請書** は `/production/sales-orders` で管理します（[受注請書](/docs/apps/order-acceptance/user) の取込画面から開けます）。注文請書の詳細では、確定・在庫照合（在庫の引当予約）・キャンセルができ、在庫が足りない分はそのまま指示書の作成に進めます。

## 作成方法

1. 一覧の「新規作成」を開きます（注文請書詳細からも、その注文請書を選択済みの状態で開けます）。
2. **注文請書** を検索して選び、**種別**（在庫分 / 製造分）と **予定数量** を入力します。
3. 製造分の場合は **使用素材** を選びます。在庫の充足・不足がその場に表示されます（不足でも保存はできます — 発注判断の目安です）。
4. **検査表テンプレート** を必要に応じて選びます。
5. **工程** をカタログのカテゴリ別チェックリストから選びます。前提工程が足りない場合は赤い警告が出て保存できません。「必須工程を自動追加」を押すと、不足している前提工程をまとめて追加できます。
6. 社内・外注どちらも可能な工程は、**実施場所**（社内 → 工場 / 外注 → 外注先）を指定します。
7. 保存すると **下書き** の指示書ができ、工程はカタログの既定順に並びます。

## 状態と承認フロー

指示書の状態は **下書き → 承認待ち → 承認済 → 進行中 → 完了**（またはキャンセル）と進みます。

- **承認依頼** … 下書きの詳細画面から実行します。承認待ちになり、対象の注文請書は編集ロックされます。
- **第一承認**（工場長・部長クラス）→ **第二承認**（部長クラス） … 各承認グループのメンバー（または期間内の代理者）だけが承認・差し戻しできます。承認状況は詳細画面のステッパーで確認できます。
- 第二承認が済むと指示書は **承認済** になり、工程を開始できます。製造分は使用素材が自動で **予約** されます。
- **差し戻し** … 理由の入力が必須です。指示書は下書きに戻り、修正後に「再承認依頼」できます。

承認操作は [承認管理](/docs/apps/approval/user)（PD03）の一覧からも対象を開いて行えます。

## 工程の実行

詳細画面の「工程ワークフロー」から各工程の実行画面を開きます（タブレットでの操作を想定した大きめのボタンです）。

1. **工程開始** … 前の工程が完了していれば押せます。開始できない理由（依存工程が未完了など）は画面に表示されます。開始すると自分の **セッションロック** がかかり、他のユーザーは操作できません。
2. **数量・不良の入力** … **受入数**（前工程の良品数が自動で入ります）、**良品数**、不良の内訳（**半製品** / **廃棄** / **手直し**）を入力します。「良品 + 不良の合計 = 受入数」が合わないと警告が出て完了できません。
3. **検査工程** では検査表の項目ごとに実測値と合否を記録します。全項目合格で **合格**、1 つでも不合格なら **不合格** になります。検査承認工程では、合格した検査記録を承認できます。
4. **不良記録** … 不良種類と内容を任意で記録できます（[不良種類](/docs/masters/defect-type/user) から選択）。
5. **工程完了** … 数量を確定して次の工程に進めます。

外注工程では **依頼日・入荷予定日・入荷日・外注費** を記録できます。入荷日を入れると指示書の作成者に通知が届きます。

- **中断（巻き戻し）** … 進行中の工程を理由付きで未着手に戻します。入力中の数量は保存されません。
- **巻き戻し** … 完了済みの工程を理由付きで未着手に戻します。後続工程が着手済みの場合や、指示書が完了して在庫計上済みの場合は巻き戻せません。

## 分岐（手直し・再投入）

完了した工程のメニューから **分岐追加** ができます。追加する工程の系列・流す数量・合流先（未着手の工程）を指定すると、手直し分などを別系列で流せます。分岐がある指示書は、工程ワークフローの上部に分岐図（DAG）が表示されます。

## 完了と在庫

全工程が完了すると指示書は自動的に **完了** になり、最終工程の良品がロット番号付きで製品在庫に入庫されます。半製品に振り分けた分は半製品在庫として入庫されます。予約していた素材は消費（出庫）されます。

## 一覧・検索・その他の操作

- 一覧は指示書番号・注文請書番号・製品で検索でき、種別・状態で絞り込めます。
- **編集** … 下書きのみ。**キャンセル** … 下書き・承認待ちのみ（注文請書のロックも解除されます）。
- **コピー** … 工程・実施場所・検査表を引き継いだ下書きを、選んだ注文請書に対して作成します。コピー元は詳細に記録され、より新しい版がある場合は警告が出ます。

このアプリの利用には指示書（work_order）の権限が必要です。
