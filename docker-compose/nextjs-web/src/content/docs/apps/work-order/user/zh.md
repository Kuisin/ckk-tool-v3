# 制造指示单（指示書） — 操作手册

操作代码 **PD02**。创建面向生产现场的作业指示（指示書），并管理从审批到工序执行、完成的全过程。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

指示書用来规定"针对这份订单回执（注文請書）的产品，按什么工序顺序、生产多少支"。指示单编号为全局连续编号，同时就是**批次（Lot）编号**。

- 选择注文請書，从工序目录中组装**工序工作流**。
- 创建后提交**审批申请**，经第一审批 → 第二审批后即可开始生产。
- 每道工序在**工序执行画面**中进行开始、数量录入和完成操作。
- 全部工序完成后，良品会作为批次入库到[产品库存](/docs/apps/product-inventory/user)。

作为指示書来源的**注文請書**在 `/production/sales-orders` 中管理（可从[订单受理（受注請書）](/docs/apps/order-acceptance/user)的导入画面打开）。在注文請書详情页可以执行确认、库存核对（对可用产品库存做预约分配）、取消等操作，库存不足的部分可直接转入指示書的创建。

## 创建方法

1. 从列表点击"新規作成"（新建）打开（也可从注文請書详情页打开，此时该注文請書已预先选中）。
2. 搜索并选择**注文請書**，输入**类别**（在庫分 库存供货 / 製造分 生产供货）和**计划数量**。
3. 選择製造分时需选择**使用素材**。库存是否充足会即时显示（不足也可以保存 — 仅作为采购判断的提示）。
4. 按需选择**检查表模板**。
5. 从按类别分组的目录清单中选择**工序**。若缺少前置工序会显示红色警告且无法保存。点击"必須工程を自動追加"（自动添加必需工序）可一次性补齐缺少的前置工序。
6. 对既可内制也可外协的工序，指定**实施地点**（内制 → 工厂 / 外协 → 外协厂商）。
7. 保存后生成**草稿**状态的指示書，工序按目录默认顺序排列。

## 状态与审批流程

指示書的状态依次为 **下書き（草稿）→ 承認待ち（待审批）→ 承認済（已审批）→ 進行中（进行中）→ 完了（完成）**，或 キャンセル（取消）。

- **承認依頼（提交审批）** … 在草稿的详情页执行。指示書进入待审批状态，对应的注文請書会被锁定、禁止编辑。
- **第一承認**（厂长・部长级）→ **第二承認**（部长级）… 只有各审批组的成员（或有效期内的代理人）才能审批或驳回。审批进度可在详情页的步骤条中查看。
- 第二审批通过后指示書变为**已审批**，即可开始工序。製造分会自动**预约**所需素材。
- **差し戻し（驳回）** … 必须填写理由。指示書退回草稿，修改后可"再承認依頼"（重新提交审批）。

审批操作也可以在[审批管理](/docs/apps/approval/user)（PD03）的列表中打开对象后进行。

## 工序执行

从详情页的"工程ワークフロー"（工序工作流）面板打开各工序的执行画面（按钮较大，适合平板操作）。

1. **工程開始（开始工序）** … 前置工序完成后即可点击。无法开始时会显示原因（如依赖工序未完成等）。开始后会获得本人的**会话锁**，其他用户无法操作。
2. **数量・不良录入** … 输入**接收数**（自动带入上一工序的良品数）、**良品数**，以及不良明细（**半成品** / **报废** / **返工**）。若"良品 + 不良合计 ≠ 接收数"会显示警告且无法完成。
3. **检查工序**中按检查表逐项记录实测值和合格与否。全部合格记为**合格**，有一项不合格即为**不合格**。检查审批工序中可对合格的检查记录进行审批。
4. **不良记录** … 可随时记录不良类别和内容（从[不良类别](/docs/masters/defect-type/user)中选择）。
5. **工程完了（完成工序）** … 确定数量并交接到下一工序。

外协工序可记录**委托日、预计到货日、到货日、外协费用**。填写到货日后，指示書的创建者会收到通知。

- **中断（回退）** … 将进行中的工序连同理由退回未开始状态。正在输入的数量不会保存。
- **巻き戻し（回退已完成工序）** … 将已完成的工序连同理由退回未开始状态。若后续工序已开始，或指示書已完成（库存已入账），则无法回退。

## 分支（返工・再投入）

在已完成工序的菜单中可以**添加分支**：指定要追加的工序系列、流转数量、汇合目标（未开始的工序），即可让返工件等走另一条支线。含分支的指示書会在工序工作流上方显示分支图（DAG）。

## 完成与库存

全部工序完成后，指示書自动变为**完成**：末端工序的良品带批次编号入库到产品库存，划分为半成品的数量作为半成品库存入库，已预约的素材被消耗（出库）。

## 列表・搜索・其他操作

- 列表可按指示单编号、注文請書编号、产品搜索，并可按类别、状态筛选。
- **编辑** … 仅限草稿。**取消** … 仅限草稿・待审批（同时解除注文請書的锁定）。
- **复制** … 针对所选注文請書创建一份继承工序・实施地点・检查表的草稿。复制来源会被记录，若已存在更新的版本会显示警告。

使用此应用需要指示書（work_order）权限。
