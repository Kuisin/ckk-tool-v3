# 検査表テンプレート — 操作マニュアル

操作コード **MS08**。検査工程で使う検査項目のひな形（テンプレート）を登録・管理します。[指示書](/docs/apps/work-order/user) にテンプレートを紐付けると、その検査項目に沿って検査を記録できます。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 検査表テンプレート（コード・名称・関連工程）を登録します。
- テンプレートごとに **検査項目**（項目名・単位・許容値・必須/任意・表示順）を登録します。検査項目は詳細画面の「検査項目」タブでその場で追加・編集・削除します（項目の個別ページはありません）。

利用には **マスタ権限** が必要です。

## 一覧を見る

- 一覧の列は **コード / 名称 / 関連工程 / 項目数 / 状態** です。行をクリックすると詳細画面が開きます。
- 上部の検索ボックスに **コード・名称・関連工程** を入れて絞り込めます。**状態**（有効 / 無効）でも絞り込めます。
- 行を選択すると **一括有効化 / 一括無効化 / 一括削除** ができます。

## 新規作成

一覧右上の「新規作成」から登録します。

- **コード** … 英数字・ハイフン・アンダースコア（例 `INSP-DIM-01`）。一意で、**作成後は変更できません**。
- **名称**（日本語は必須、英語は任意）。
- **関連工程** … このテンプレートを既定で使う検査工程（任意）。[工程マスタ](/docs/masters/process-step/user) からコード・名称で検索して選びます。
- **有効** … オフにすると選択肢に出なくなります。

検査項目はこのフォームでは入力しません。保存後に開く詳細画面の「検査項目」タブで追加します。

## 検査項目の登録

詳細画面の **検査項目** タブ →「項目を追加」で登録します。既存の項目は行の編集・削除アイコンで操作します。

- **項目名**（日本語は必須、英語は任意）。
- **単位**（例 mm）。
- **許容値** … 下限・上限。片方だけの指定（〜以上 / 〜以下）もできます。上限は下限以上にしてください。
- **必須 / 任意** … 検査記録時に必ず入力させるかどうか。
- **表示順** … 検査表での並び順です。追加時は「既存の最大値 + 10」が初期値として入ります。

## 詳細画面

- 上部のサマリにコード・名称・関連工程・検査項目数・状態が表示されます。
- タブは **テンプレート情報**（名称・関連工程）/ **検査項目**（項目のサブテーブル）/ **履歴**（変更の記録。項目の追加・変更・削除もここに残ります）です。
- 右上のメニューから **編集** / **無効化** / **削除** ができます。

## 削除と無効化

- テンプレートを削除すると、その検査項目もまとめて削除されます。使わなくなったテンプレートは削除ではなく **無効化** をおすすめします。

## 用語

- **検査表テンプレート** … 検査項目のひな形。指示書に紐付けて検査記録に使います。
- **許容値** … 実測値が合格となる範囲（下限〜上限）。
- **関連工程** … このテンプレートを既定で使う検査工程。
