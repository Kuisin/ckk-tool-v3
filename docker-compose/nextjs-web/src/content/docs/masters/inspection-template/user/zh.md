# 检查表模板 — 操作手册

操作代码 **MS08**。登记和管理检查工序中使用的检查项目模板。将模板关联到[作业指示书（指示書）](/docs/apps/work-order/user)后，即可按其检查项目记录检查结果。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

- 登记检查表模板（代码、名称、关联工序）。
- 为每个模板登记**检查项目**（项目名、单位、容许值、必填/可选、显示顺序）。检查项目在详情页面的「检查项目」标签页中直接添加、编辑、删除（项目没有单独页面）。

使用此应用需要**主数据权限**。

## 查看列表

- 列表的列为**代码 / 名称 / 关联工序 / 项目数 / 状态**。点击行可打开详情页面。
- 在顶部搜索框输入**代码、名称或关联工序**即可筛选。也可按**状态**（有效 / 无效）筛选。
- 勾选行后可进行**批量启用 / 批量停用 / 批量删除**。

## 新建

从列表右上角的「新建」进行登记。

- **代码** … 由字母、数字、连字符和下划线组成（例 `INSP-DIM-01`）。代码唯一，**创建后不可更改**。
- **名称**（日语必填，英语可选）。
- **关联工序** … 默认使用此模板的检查工序（可选）。可在[工序主数据（工程マスタ）](/docs/masters/process-step/user)中按代码、名称搜索选择。
- **有效** … 关闭后将不再出现在选择项中。

检查项目不在此表单中输入。保存后在详情页面的「检查项目」标签页中添加。

## 登记检查项目

在详情页面的**检查项目**标签页点击「添加项目」进行登记。已有项目通过行内的编辑、删除图标操作。

- **项目名**（日语必填，英语可选）。
- **单位**（例 mm）。
- **容许值** … 下限、上限。也可只指定一侧（以上 / 以下）。上限不得低于下限。
- **必填 / 可选** … 记录检查时是否必须输入。
- **显示顺序** … 在检查表中的排列顺序。添加时默认值为「现有最大值 + 10」。

## 详情页面

- 顶部摘要显示代码、名称、关联工序、检查项目数和状态。
- 标签页为**模板信息**（名称、关联工序）/ **检查项目**（项目子表）/ **历史**（变更记录；项目的添加、修改、删除也会记录在此）。
- 通过右上角菜单可进行**编辑** / **停用** / **删除**。

## 删除与停用

- 删除模板时，其检查项目也会一并删除。不再使用的模板建议**停用**而非删除。

## 术语

- **检查表模板（検査表テンプレート）** … 检查项目的模板，关联到作业指示书用于检查记录。
- **容许值** … 实测值判定为合格的范围（下限～上限）。
- **关联工序** … 默认使用此模板的检查工序。
