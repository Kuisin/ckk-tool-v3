# 工程マスタ — 操作マニュアル

操作コード **MS07**。製造で行う工程（円筒加工・コーティング・検査など）のカタログです。[指示書](/docs/apps/work-order/user) の製造ワークフローは、ここに登録した工程を組み合わせて作られます。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

## このアプリでできること

- 工程を登録し、**カテゴリ**（材料準備 / 加工 / コーティング / 検査 / 検査承認 / 出荷）と **実施場所**（社内のみ / 社内・外注）を設定します。「社内・外注」の工程は [外注依頼](/docs/apps/outsource-order/user) で外部委託できます。
- 工程ごとに **同期可**（他工程と同時実施・記録できる）、**検査工程**、**検査承認工程**（承認必要役職も指定可）のフラグを設定できます。
- 工程どうしの **使用依存** と **実行依存** を定義できます（下記参照）。

利用には **マスタ権限** が必要です。

## 一覧を見る

- 一覧の列は **コード / 名称 / カテゴリ / 実施場所 / 同期可 / 検査 / 承認 / 表示順 / 状態** です。既定では **表示順** で並びます。
- 上部の検索ボックスに **コード・名称** を入れて絞り込めます。**カテゴリ** と **状態**（有効 / 無効）でも絞り込めます。
- 行を選択すると **一括有効化 / 一括無効化 / 一括削除** ができます。行をクリックすると詳細画面が開きます。

## 新規作成・編集

一覧右上の「新規作成」から登録します。主な入力項目は次のとおりです。

- **工程コード** … 英大文字はじまりの英大文字・数字・アンダースコア（例 `CYLINDER_MACHINING`）。**作成後は変更できません**。
- **名称**（日本語は必須、英語は任意）/ **カテゴリ** / **実施場所**。
- **同期可** / **検査工程** / **検査承認工程** … 検査承認工程をオンにすると **承認必要役職**（例「係長以上」）を入力できます。
- **表示順** … 一覧・カタログの既定の並び順です。実際の実行順は依存解決で決まります。
- **有効** / **備考**。

## 依存の定義

工程には 2 種類の依存を行単位で登録できます。各行は「依存先の工程 + 結合（AND（すべて）/ OR（いずれか））+ 備考」で、使用依存のみ **排他** スイッチがあります。

- **使用依存** … この工程を **ワークフローに含めてよい条件**（依存先工程がワークフローに存在すること）。**排他** をオンにすると逆に「依存先が存在しないこと」が条件になります。
- **実行依存** … この工程を **開始してよい条件**（依存先工程の完了）。ワークフローに存在しない依存先は満たされた扱いになります。

ルール: 自分自身は依存先にできません。同じ依存先の重複もできません。保存すると依存行はまとめて置き換わります（依存先が未選択の空行は保存されません）。

## 詳細画面

- 上部のサマリに工程コード・名称・カテゴリ・実施場所・工程フラグ・表示順が表示されます。
- **概要** タブに備考、**依存関係** タブに使用依存・実行依存の 2 表（行クリックで依存先工程へ移動）、**履歴** タブに変更の記録が表示されます。
- 右上のメニューから **編集** / **無効化** / **削除** ができます。

## 削除と無効化

- 他の工程がこの工程を依存先にしている場合、またはこの工程に関連する [検査表テンプレート](/docs/masters/inspection-template/user) がある場合は削除できません。使わなくなった工程は **無効化** してください。

## 用語

- **工程カタログ** … 製造ワークフローの部品となる工程の一覧。
- **同期可** … 他の工程と同時に実施・記録できる工程。
- **使用依存 / 実行依存** … ワークフローに「含めてよい」条件と、「開始してよい」条件。
- **排他** … 使用依存で「依存先工程が存在しないこと」を条件にする指定。
