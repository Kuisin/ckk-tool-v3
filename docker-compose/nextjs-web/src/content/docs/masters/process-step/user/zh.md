# 工序主数据 — 操作手册

操作代码 **MS07**。制造工序（圆筒加工、涂层、检查等）的目录。[作业指示书（指示書）](/docs/apps/work-order/user)的制造工作流即由此处登记的工序组合而成。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

- 登记工序，并设置**类别**（材料准备 / 加工 / 涂层 / 检查 / 检查审批 / 出货）和**实施地点**（仅公司内部 / 内部·外协）。「内部·外协」的工序可通过[外协委托（外注依頼）](/docs/apps/outsource-order/user)委托给外部。
- 可为每个工序设置以下标志：**可同步**（可与其他工序同时实施、记录）、**检查工序**、**检查审批工序**（可指定审批所需职级）。
- 可定义工序之间的**使用依赖**和**执行依赖**（见下文）。

使用此应用需要**主数据权限**。

## 查看列表

- 列表的列为**代码 / 名称 / 类别 / 实施地点 / 可同步 / 检查 / 审批 / 显示顺序 / 状态**。默认按**显示顺序**排列。
- 在顶部搜索框输入**代码或名称**即可筛选。也可按**类别**和**状态**（有效 / 无效）筛选。
- 勾选行后可进行**批量启用 / 批量停用 / 批量删除**。点击行可打开详情页面。

## 新建·编辑

从列表右上角的「新建」进行登记。主要输入项如下。

- **工序代码** … 以大写英文字母开头，由大写字母、数字和下划线组成（例 `CYLINDER_MACHINING`）。**创建后不可更改**。
- **名称**（日语必填，英语可选）/ **类别** / **实施地点**。
- **可同步** / **检查工序** / **检查审批工序** … 打开检查审批工序后，可输入**审批所需职级**（例「系长以上」）。
- **显示顺序** … 列表和目录的默认排序。实际执行顺序由依赖解析决定。
- **有效** / **备注**。

## 定义依赖

每个工序可按行登记两种依赖。每行为「依赖目标工序 + 结合方式（AND（全部）/ OR（任一））+ 备注」，仅使用依赖有**排他**开关。

- **使用依赖** … 此工序**可被纳入工作流的条件**（依赖目标工序存在于工作流中）。打开**排他**后，条件相反：目标工序不得存在。
- **执行依赖** … 此工序**可以开始的条件**（依赖目标工序已完成）。不在工作流中的依赖目标视为已满足。

规则：不能以自身为依赖目标；同一目标不可重复。保存时依赖行会整体替换（未选择目标的空行不会保存）。

## 详情页面

- 顶部摘要显示工序代码、名称、类别、实施地点、工序标志和显示顺序。
- **概要**标签页显示备注；**依赖关系**标签页显示使用依赖、执行依赖两张表（点击行可跳转到目标工序）；**历史**标签页显示变更记录。
- 通过右上角菜单可进行**编辑** / **停用** / **删除**。

## 删除与停用

- 有其他工序依赖此工序，或有关联此工序的[检查表模板（検査表テンプレート）](/docs/masters/inspection-template/user)时，无法删除。不再使用的工序请**停用**。

## 术语

- **工序目录** … 作为制造工作流构件的工序列表。
- **可同步** … 可与其他工序同时实施、记录的工序。
- **使用依赖 / 执行依赖** … 「可纳入工作流」的条件与「可以开始」的条件。
- **排他** … 使用依赖中要求「依赖目标工序不存在」的选项。
