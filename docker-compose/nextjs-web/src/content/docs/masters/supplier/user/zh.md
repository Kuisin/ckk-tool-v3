# 外协企业 — 操作手册

操作代码 **MS06**。用于登记和管理 **供应商**（仕入先 — 采购材料的公司）与 **外协厂商**（外注先 — 承接无心磨、涂层等部分工序委托的公司）的台账。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

## 此应用能做什么

除公司基本信息外，还可登记结算日、付款条件、汇款账户和标准交货周期。在此登记的外协企业，可在[材料订购单（素材発注書）](/docs/apps/purchase-order/user)和[外协委托（外注依頼）](/docs/apps/outsource-order/user)中作为对象选择。

- 通过**外协类别**区分「供应商」（材料、物资的采购对象）与「外协厂商」（工序的委托对象）。
- 外协企业在系统内部作为带有**供应商·外协厂商角色**的「业务伙伴（BP）」进行管理。

使用此应用需要**主数据权限**。

## 查看列表

- 列表的列为 **BP代码 / 名称 / 外协类别 / 标准交货周期 / 状态**。点击行可打开详情页面。
- 在顶部搜索框输入 **BP代码或名称** 即可筛选。也可按**外协类别**（供应商 / 外协厂商）和**状态**（有效 / 无效）筛选。
- 勾选行后可进行**批量启用 / 批量停用 / 批量删除**。

## 新建

从列表右上角的「新建」进行登记。**BP代码**（`BP-NNNNN`）在保存时自动编号。

**基本信息**

- **名称**（日语必填，英语可选）/ **国家** / **假名读音** / **简称** / **法人编号**。
- **有效** … 关闭后将不再出现在选择项中（历史数据保留）。
- **AI匹配名** … 供文档自动读取（AI 提取）将公司名称关联到此业务伙伴的匹配列表。将各种写法差异按 Enter 分行登记。

**地址·联系方式**

- **邮政编码** / **地址**（日语·英语）/ **电话** / **传真** / **电子邮箱** / **网站** / **备注**。

**交易条件**

- **外协类别**（必填）… 供应商 / 外协厂商。
- **旧系统代码** … 旧供应商代码（可选）。
- **结算日** … 1～31 的日期。`31` 表示「月末」。
- **付款周期（天数）** / **付款日**。
- **标准交货周期（天数）** … 从委托到到货的大致天数，可作为外协委托到货预定的参考。

**汇款账户**

- **银行名称** / **支行名称** / **账户类型**（普通 / 活期支票）/ **账号**。

## 详情页面

- 顶部摘要显示基本信息；**概要**标签页显示交易条件、汇款账户和备注；**历史**标签页显示变更记录（何时、何人更新）。
- 通过右上角菜单可进行**编辑** / **停用** / **删除**。

## 删除与停用

- 存在引用此业务伙伴的数据时无法删除。对已停止交易的对象，请使用**停用**而非删除（将不再出现在选择项中，历史数据保留）。

## 术语

- **供应商（仕入先）** … 采购材料、物资的对象（外协类别 = 供应商）。
- **外协厂商（外注先）** … 委托部分制造工序的对象（外协类别 = 外协厂商）。
- **标准交货周期** … 从委托到到货所需的标准天数。
- **BP（业务伙伴）** … 统一管理客户、供应商、最终用户等的公司单位。
