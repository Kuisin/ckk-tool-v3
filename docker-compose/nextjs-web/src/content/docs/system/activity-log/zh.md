# 操作历史 — 操作手册

操作代码 **SY07**。面向管理员的应用，可跨全系统查看操作历史（审计日志）——"谁在何时、以何种方式修改了哪条数据"。

> 本应用需要 **系统权限**。历史记录 **仅供查看**，无法在此界面编辑或删除。

## 本应用能做什么

- 跨所有应用、所有记录，查看数据的创建・更新・删除历史。
- 按记录、用户、变更内容搜索；按操作类型和对象筛选。
- 与各单据详情页的"历史"标签页数据源相同——本界面用于全局横向查看。

## 打开方式

- 主页（系统）→ **操作履歴（操作历史）**，或在搜索框输入 `SY07`。

## 记录哪些操作

每次保存业务数据时，系统会自动记录一条带变更前后快照的日志。操作类型如下。

- **创建** … 新建记录。
- **更新** … 修改现有记录（变更字段以差异形式摘要显示）。
- **删除** … 删除记录。
- **初始数据** / **迁移** … 系统执行的初始数据导入和迁移处理。

浏览、下载 PDF 等"只看不改"的操作不在记录范围内（仅记录数据变更）。

## 列表说明

- **日期时间** … 操作发生的时间。默认从新到旧排序。
- **操作** … 创建 / 更新 / 删除 等。
- **对象** … 被修改数据的种类。例如：报价单（見積書）、试算（試算）、价格表、产品、往来单位、应用管理。
- **记录** … 业务标识（`QOT-…` / `EST-…` 等单据编号、主数据 ID；等宽字体）。
- **用户** … 操作用户的显示名。系统自动执行的操作显示为"システム（系统）"。
- **变更内容** … 变更摘要。更新时按字段显示差异，如"状态：草稿 → 确定"。

列表显示最新 **300 条**。

## 搜索与筛选

- 搜索框可同时匹配记录（单据编号等）、用户名和变更内容。
- **操作** 下拉框按操作类型（创建/更新/删除 等）筛选。
- **对象** 下拉框按数据种类（报价单、产品 等）筛选。
- 点 **重置** 清除全部条件。

## 常见问题

- **只想看某一单据的历史** … 最快的方式是打开该单据的详情页查看"历史"标签页。在本界面则可按单据编号搜索。
- **看不到较早的记录** … 本界面仅显示最新 300 条。更早的记录请咨询系统管理员。
- **没有登录或 PDF 下载的记录** … 这些不在本历史的记录范围内（仅记录数据的创建・更新・删除）。
- **对象"应用管理"是什么** … 指在[应用管理](/docs/system/app-management)中切换应用显示开关的记录。
- 用户与权限的查看请参见[用户管理](/docs/system/user-management)。
