# 文件管理 — 操作手册

操作代码 **SY06**。面向管理员的文件应用：管理文件存储（SeaweedFS）中保存的文件——导入的上传文件以及系统生成的单据 PDF。可列表查看、预览、下载、删除和上传。

> 本应用需要 **系统权限**（存储操作属管理员操作）。删除无法撤销，请谨慎操作。

## 本应用能做什么

- 浏览存储中的全部文件（文件名、存储键、大小、更新时间）。
- 对每个文件进行 **预览**（在浏览器打开）、**下载**、**删除**。
- **上传** 任意文件。
- 按文件名/路径搜索，按类别（顶层文件夹）筛选。

## 打开方式

- 主页（系统）→ **ファイル管理（文件管理）**，或在搜索框输入 `SY06`。

## 列表说明

- **文件名** … 带图标（PDF 为红色、图片为蓝色、其他为灰色）。下方以等宽字体显示存储键（存储中的完整路径）。
- **类别** … 存储键顶层文件夹的徽章。例如 `pdfs`（系统生成的单据 PDF）、`uploads`（从本界面上传的文件）。无文件夹的显示"(根目录)"。
- **大小** … 文件大小（B / KB / MB / GB）。
- **更新时间** … 最后更新时间。默认按此列从新到旧排序（每页 20 条）。

右上角的 **刷新** 按钮可重新加载列表。无法连接存储时，界面顶部会显示红色警告（需要检查服务器端配置和容器运行状态）。

## 上传

1. 点击右上角的 **上传**，选择文件。
2. 文件会保存到 `uploads` 文件夹，文件名带日期时间前缀（防止同名覆盖）。
3. 完成后显示通知，列表随之更新。

## 预览与下载

- **预览** … 在新标签页中打开文件（PDF 和图片可直接预览）。
- **下载** … 下载文件。

## 删除

点击行内的 **删除** 会弹出确认对话框。**此操作无法撤销**。

> 单据 PDF（`pdfs` 目录下）被报价单（見積書）、发票（請求書）等业务单据引用。删除后相关单据可能无法再打开 PDF，请避免删除与业务数据关联的文件。

## 常见问题

- **显示"无法连接存储"** … 文件服务器（SeaweedFS）停止运行或配置有误，请联系系统管理员。
- **想知道某文件属于哪个单据** … 存储键（文件名下方的等宽文本）包含文件夹和来源信息，也可利用类别筛选。
- **误删了文件** … 无法从本界面恢复。请联系系统管理员从备份中恢复。
- 生成这些文件的单据操作请参见各应用手册，如[报价单（見積書）](/docs/apps/quote/user)、[发票（請求書）](/docs/apps/invoice/user)。
