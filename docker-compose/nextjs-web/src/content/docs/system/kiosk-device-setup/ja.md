# キオスク端末セットアップ

拠点フロアで使う共有タブレット（キオスク端末）の配布・登録マニュアル。管理者向け。QRカードの発行は QRカード管理（SY08）、端末の管理は 端末管理（SY09）で行う。

## 専用アプリ（APK）

タブレットには専用の Android アプリをインストールする。APK は次の URL で常に最新版が配布される。

- 本番: `https://ckk-kiosk.kai-lab.net/apk/ckk-kiosk.apk`
- 開発: `https://ckk-kiosk-dev.kai-lab.net/apk/ckk-kiosk-dev.apk`

## 新規端末の登録（QR プロビジョニング）

初期化直後のタブレットを、ケーブルや PC を使わずに専用キオスク端末として構成する。

1. タブレットを拠点出荷状態に初期化する
2. 初期設定の「ようこそ」画面を **6 回タップ**する（QR スキャナが起動する）
3. Wi-Fi に接続し、下のプロビジョニング QR をスキャンする
4. APK が自動でダウンロード・インストールされ、端末がキオスクモードにロックされる

## 端末のリンクと有効化（SY09）

アプリが起動したら、端末を業務システムに登録する。

1. 端末管理（SY09）で端末プロファイルを作成する
2. タブレットの画面にリンクコード（QR）が表示される（10 分間有効）
3. SY09 でそのコードをスキャンまたは入力し、プロファイルにリンクする
4. リンク済みの端末を**有効化**すると、タブレットで QR カードログインが使えるようになる

## ロックなし端末へのインストール（検証用）

キオスクロックせずに試す場合は、タブレットの Chrome で APK の URL を開き、「提供元不明のアプリ」を許可してインストールする。

## 接続インジケータ（ヘッダー右上のドット）

キオスク画面のヘッダー右上に接続状態のドットが表示される（タップで説明表示）。

- **灰**: 接続なし（サーバーに到達できない）
- **赤**: サーバーには繋がるが端末が未登録（リンクされていない）
- **橙**: 登録済みだが通常ブラウザで利用中（専用アプリのハードウェア鍵なし）
- **緑**: 専用アプリ（ハードウェア鍵）で正常に接続中
- **橙/緑の点滅**: 接続が不安定（直近に通信失敗があった）

判定はキオスク URL 自身への疎通で行うため、**インターネット接続は不要** — URL が LAN 内で解決される構成でもそのまま正しく動作する。

## オフラインモード

サーバーに到達できなくなると、Web 画面は全画面の「サーバーに接続できません」表示に切り替わり、接続が回復すると自動的に元の画面へ戻る。専用アプリ（v0.4.0 以降）はページ読み込み自体が失敗した場合もアプリ内のオフライン画面を表示し、疎通が回復した時点で自動的に再読み込みする。端末側の操作は不要。

## 画面の常時表示（時計・バッテリー・接続状態）

キオスクは全画面表示で OS のステータスバーが見えないため、アプリのヘッダー右上に**接続状態ドット・バッテリー残量・現在時刻**を常時表示する。バッテリーは充電中は緑の稲妻アイコン、残量 15% 未満は赤字になる。画面は常にダークテーマ。

## 画面スリープ（充電中はスリープしない）

- **専用アプリ**: アプリ表示中は常に画面 ON（スリープしない）
- **ブラウザ利用時**: **充電中のみ**画面をスリープさせない（バッテリー駆動時は OS の設定どおりスリープする）

## Wi-Fi（ネットワーク）を変更するには

キオスクロック中でも、管理者は一時的にロックを外して Android 設定を開ける:

1. 画面の**右上隅を 3 秒以内に 5 回タップ**する（メンテナンスダイアログが開く）
2. **管理者 PIN** を入力し「**設定を開く**」をタップ（PIN は**全端末共通・毎日 4:00 に自動更新** — 端末管理（SY09）の端末詳細「PIN・設定コード」で確認。表示は監査ログに記録される）
3. Android の設定が開くので **Wi-Fi を変更**する
4. 戻るボタン等でアプリに戻ると**自動で再ロック**される（追加操作は不要）

> 左上の 5 タップは別機能（端末設定 — 6 桁の設定コードで解錠）。ネットワーク変更は**右上**。

## 端末の更新（自動）

アプリは**自動更新**される。約 1 時間ごとに新しいリリースを確認し、見つかると業務を妨げないよう深夜（1:00〜6:00）に自動で適用・再起動する（アプリ起動直後に見つかった場合は即時適用）。新しい APK をリリースするだけでよく、端末側の作業は不要。

- キオスクロック済み端末: 完全自動（確認ダイアログなし）
- ロックなしの検証用端末: OS のインストール確認ダイアログが表示されるので「インストール」をタップする

> 自動更新に対応する前の旧バージョン（v0.2.x 以前）が入っている端末のみ、従来どおり USB 接続で `adb install -r`、または初期化して新しい QR を再スキャンして更新する。
