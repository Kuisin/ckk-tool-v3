# キオスク端末セットアップ

工場フロアで使う共有タブレット（キオスク端末）の配布・登録マニュアル。管理者向け。QRカードの発行は QRカード管理（SY08）、端末の管理は 端末管理（SY09）で行う。

## 専用アプリ（APK）

タブレットには専用の Android アプリをインストールする。APK は次の URL で常に最新版が配布される。

- 本番: `https://ckk-kiosk.kai-lab.net/apk/ckk-kiosk.apk`
- 開発: `https://ckk-kiosk-dev.kai-lab.net/apk/ckk-kiosk-dev.apk`

## 新規端末の登録（QR プロビジョニング）

初期化直後のタブレットを、ケーブルや PC を使わずに専用キオスク端末として構成する。

1. タブレットを工場出荷状態に初期化する
2. 初期設定の「ようこそ」画面を **6 回タップ**する（QR スキャナが起動する）
3. Wi-Fi に接続し、下のプロビジョニング QR をスキャンする
4. APK が自動でダウンロード・インストールされ、端末がキオスクモードにロックされる

**本番用 QR:**

![本番用プロビジョニング QR](https://ckk-kiosk.kai-lab.net/apk/provisioning-prod.png)

**開発用 QR:**

## 端末のリンクと有効化（SY09）

アプリが起動したら、端末を業務システムに登録する。

1. 端末管理（SY09）で端末プロファイルを作成する
2. タブレットの画面にリンクコード（QR）が表示される（10 分間有効）
3. SY09 でそのコードをスキャンまたは入力し、プロファイルにリンクする
4. リンク済みの端末を**有効化**すると、タブレットで QR カードログインが使えるようになる

## ロックなし端末へのインストール（検証用）

キオスクロックせずに試す場合は、タブレットの Chrome で APK の URL を開き、「提供元不明のアプリ」を許可してインストールする。

## 端末の更新

ロック済み端末にはブラウザがないため、アプリの更新は次のいずれかで行う。

- USB 接続で `adb install -r`（管理者作業）
- 端末を初期化し、新しいリリースの QR を再スキャンする（登録はやり直しになるが手順は軽い）
