# 自助终端设备设置

工厂现场共享平板（自助终端设备）的分发与注册手册。面向管理员。QR 卡在 QR卡管理（SY08）中发行，设备在 设备管理（SY09）中管理。

## 专用应用（APK）

每台平板运行专用的 Android 应用。最新 APK 始终通过以下 URL 分发：

- 生产环境: `https://ckk-kiosk.kai-lab.net/apk/ckk-kiosk.apk`
- 开发环境: `https://ckk-kiosk-dev.kai-lab.net/apk/ckk-kiosk-dev.apk`

## 注册新设备（QR 配置）

将恢复出厂设置后的平板配置为专用自助终端设备，无需数据线和电脑。

1. 将平板恢复出厂设置
2. 在初始设置的"欢迎"页面**连续点击 6 次**（会启动 QR 扫描器）
3. 连接 Wi-Fi 并扫描下方的配置 QR 码
4. APK 会自动下载并安装，设备将锁定为自助终端模式

**生产环境 QR：**

![生产环境配置 QR](https://ckk-kiosk.kai-lab.net/apk/provisioning-prod.png)

**开发环境 QR：**

> 此 QR 码与 APK 校验和绑定，每次发布后会自动更新。如需打印使用，请务必在发布后使用本页面上的最新 QR 码。

## 设备的关联与启用（SY09）

应用启动后，将设备注册到业务系统。

1. 在设备管理（SY09）中创建设备档案
2. 平板屏幕上会显示关联码（QR，10 分钟内有效）
3. 在 SY09 中扫描或输入该关联码，关联到设备档案
4. **启用**已关联的设备后，平板即可使用 QR 卡登录

## 在未锁定的平板上安装（测试用）

如需在不锁定的情况下试用，请在平板的 Chrome 中打开 APK URL，允许安装来自该来源的应用后安装。

## 设备更新（自动）

应用会**自动更新**。每小时左右检查一次新版本，发现后会在夜间（1:00–6:00）自动安装并重启，不影响日常使用（应用启动后立即发现的更新会立刻安装）。只需发布新的 APK，平板端无需任何操作。

- 已锁定的自助终端设备：完全自动（无确认对话框）
- 未锁定的测试平板：系统会显示安装确认对话框，点击"安装"即可

> 仅当设备仍运行不支持自动更新的旧版本（v0.2.x 及更早）时，才需要旧方法：通过 USB 执行 `adb install -r`，或恢复出厂设置后重新扫描新 QR 码。
