# 端末管理 — 操作マニュアル

操作コード **SY09**。工場フロアの共有タブレット（キオスク端末）を登録・管理するアプリです。リンク・有効化・フロアマップ配置・利用履歴の確認ができます。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

> このアプリの利用には **キオスク管理権限** が必要です。すべての操作は監査ログに記録されます。

## このアプリでできること

- 端末プロファイルの作成と、タブレットの **リンク**・**有効化**
- 端末情報の編集（名称・工場・場所）、無効化・再有効化、リンク解除、取り消し
- **フロアマップ** への端末ピンの配置と、オンライン状態のライブ表示
- 利用履歴（ログイン / ログアウト、オンライン / オフライン）の確認

## 端末の状態

- **リンク待ち** … プロファイルだけ作成済みで、タブレットが未リンクの状態。
- **有効化待ち** … タブレットとリンク済みで、有効化を待っている状態。
- **有効** … キオスクとして利用できる状態。
- **無効** … 一時的に停止中。「再有効化」で戻せます。
- **取り消し** … 完全に無効化した状態。**元に戻せません**。

## 端末の登録（リンク → 有効化）

登録は「プロファイル先行」です。タブレット本体の準備（専用アプリのインストール等）は [キオスク端末セットアップ](/docs/system/kiosk-device-setup) を参照してください。

1. **端末プロファイル作成** で端末名・工場・場所（任意）を入力します。状態は「リンク待ち」になります。
2. タブレットの設定画面に **12 文字のリンクコード**（QR 付き・**10 分間有効**）が表示されます。
3. 一覧の行メニュー **端末をリンク** でそのコードを入力するか、**QR をカメラでスキャン** します（スマートフォンのカメラでもスキャンできます）。成功すると「有効化待ち」になります。
4. **有効化** を押すと「有効」になり、タブレット側が自動で検知してログイン画面に切り替わります。

コードが期限切れの場合は、タブレット側で再表示してやり直してください。リンクできるのは「リンク待ち」のプロファイルだけです。

## 一覧の見かた

- **オンライン** … 有効な端末の接続状態を緑 / 灰のドットで表示します。通常はリアルタイム（WebSocket）で更新され、接続できないときは 30 秒ごとの自動更新、または直近 5 分の活動から判定します。
- **利用者** … いまその端末にログインしているユーザー。
- 端末名の下に 🔑 付きで表示されるのは、端末アプリの **アテステーション鍵**（指紋）です。
- 行をクリックすると **端末詳細** が開き、最近の利用者と利用履歴を確認できます。行メニューの **利用履歴** からも開けます。

## 編集と端末設定コード

- **編集** で端末名・工場・場所を変更できます。**工場を変更するとフロアマップ上のピンは解除** されます（マップは工場単位のため）。
- 編集画面には **端末設定コード**（6 桁）が表示されます。タブレット側でヘッダーを 5 回タップすると開く端末設定画面の解錠コードで、フロア担当者に伝えて端末のリセット・再リンクに使います。表示 / 非表示の切替と **再生成** ができます（新しいコードはその場で一度だけ表示されます）。

## 端末の交換・停止

- **リンク解除** … タブレットをプロファイルから切り離し、「リンク待ち」に戻します。名称・工場・場所・マップのピンは残り、セッション・デバイストークン・アテステーション鍵は破棄されます。端末の交換・故障時に使い、新しいタブレットを同じプロファイルに再リンクします。
- **鍵リセット** … アテステーション鍵だけを解除します。次にその端末のアプリが接続したときに新しい鍵が結び付きます（端末を初期化した場合など）。
- **無効化 / 再有効化** … 一時的に使用を止める / 再開します。無効化中はキオスクとして使えません。
- **取り消し** … 端末を完全に無効化します。**元に戻せません**。デバイストークンは破棄され、開いているセッションも失効します。使い直すには新しいプロファイルからの再登録が必要です。
- **削除** … リンク前（リンク待ち）のプロファイルのみ削除できます。

## フロアマップ

一覧右上の **フロアマップ** から開きます。工場を選ぶと、フロア（階 / エリア）ごとのタブにマップと端末ピンが表示されます。ピンの色はオンライン状態と連動し、ログイン中のユーザー名も表示されます。

編集モード（スイッチ）でできること:

- ピンを **ドラッグ** して位置を移動します（位置は自動保存）。
- サイドバーの未配置端末をクリックすると中央に配置され、ドラッグで調整できます。
- 配置済み端末の **解除** でピンを外します。
- フロアの **追加・名称変更・削除** ができます（端末が配置されているフロアは削除できません）。
- **図面画像** のアップロード / 差し替えができます（PNG / JPG / WEBP / SVG、10MB まで）。
