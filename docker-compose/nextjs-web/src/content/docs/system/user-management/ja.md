# ユーザー管理 — 操作マニュアル

操作コード **SY01**。システムに登録されている全ユーザーの一覧と、各ユーザーのロール割当・実効権限を確認できる **閲覧専用** のアプリです。

> このアプリは現在 **開発環境（dev）のみ** で公開されています。本番公開までに画面や手順が変わる場合があります。

> このアプリは **システム権限** が必要です。ユーザーの作成・編集・削除はこの画面からはできません（閲覧のみ）。

## このアプリでできること

- 全ユーザーを一覧で確認し、検索・絞り込みができます。
- ユーザーごとの詳細画面で、割り当てられたロール（履歴を含む）を確認できます。
- そのユーザーが実際に持つ **実効権限**（権限コード × アクション × スコープ）を確認できます。

## 開き方

- ホーム（システム）→ **ユーザー管理**、または検索ボックスで `SY01`。

## 一覧・検索

一覧には次の列が表示されます。

- **ユーザー名** … ログインに使う ID（等幅表示）。
- **表示名** … 画面に表示される氏名。
- **メール** … 登録メールアドレス（無い場合は「—」）。
- **区分** … **システム** / **社員** / **ゲスト** のバッジ。
- **ロール** … 現在有効なロールのバッジ（複数可）。
- **状態** … **有効** / **無効**。
- **最終ログイン** … 最後にログインした日時。

検索ボックスはユーザー名・表示名・メール・ロール名を横断して検索します。**区分** と **状態** のセレクトで絞り込み、**リセット** で条件を全部クリアできます。行をクリックすると詳細へ移動します。

## ユーザー詳細

詳細画面は 3 つのブロックで構成されます。

- **概要** … ユーザー名・区分・メール・ログイン方式（**パスワード + SSO** か **SSO のみ** か）・最終ログイン・社員 ID。
- **ロール割当** … 割り当ての履歴一覧。ロール名・rolename（システム内部名）・状態（有効/無効）・割当日・解除日時。過去に解除された割当も表示されます。
- **実効権限** … 有効なロールをすべて集約した「いまこのユーザーができること」の一覧。権限コード（例: `quote`、`master`、`system`）ごとにアクション（READ / CREATE / UPDATE など）とスコープが表示されます。

## 実効権限の読み方

- 権限はロールに紐づいており、ユーザーは複数ロールを持てます。
- 同じ権限・アクションが複数ロールから与えられている場合、**最も広いスコープだけ** が表示されます（例: PLANT と ALL の両方があれば ALL）。
- スコープはその操作が及ぶ範囲です（ALL = 全体、PLANT = 所属拠点、OWN = 自分のデータ など）。

## よくある質問

- **ユーザーを追加・編集したい** … この画面ではできません。ユーザー情報は社内の認証基盤（AD）との同期などで管理されます。システム管理者に依頼してください。
- **ロールを変更したい** … この画面は確認専用です。ロール割当の変更はシステム管理者が行います。
- **権限が想定と違う** … 詳細画面の「実効権限」を確認してください。複数ロールが集約され、アクションごとに最上位のスコープだけが有効になります。
- 誰がいつ何を変更したかは [操作履歴](/docs/system/activity-log) で確認できます。
- アプリの表示 ON/OFF は [アプリ管理](/docs/system/app-management) を参照してください。
