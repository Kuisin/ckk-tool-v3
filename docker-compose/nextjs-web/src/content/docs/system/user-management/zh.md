# 用户管理 — 操作手册

操作代码 **SY01**。**只读** 的用户名录应用：查看系统中注册的全部用户，以及每个用户的角色分配和实际生效的权限。

> 此应用目前仅在**开发环境（dev）**中开放。正式发布前，界面和操作步骤可能会有所调整。

> 本应用需要 **系统权限**。在此界面上不能创建、编辑或删除用户（仅供查看）。

## 本应用能做什么

- 以列表方式浏览全部用户，支持搜索和筛选。
- 打开用户详情，查看其角色分配（含历史记录）。
- 查看该用户的 **实际生效权限**（权限代码 × 操作 × 范围）——即用户当前实际能做的事。

## 打开方式

- 主页（系统）→ **ユーザー管理（用户管理）**，或在搜索框输入 `SY01`。

## 列表与搜索

列表显示以下各列。

- **用户名** … 登录用 ID（等宽字体）。
- **显示名** … 界面上显示的姓名。
- **邮箱** … 注册的邮箱地址（无则显示"—"）。
- **类别** … **系统** / **员工** / **访客** 徽章。
- **角色** … 当前生效角色的徽章（可有多个）。
- **状态** … **有效** / **无效**。
- **最后登录** … 最后一次登录的时间。

搜索框可同时匹配用户名、显示名、邮箱和角色名。可用 **类别** 和 **状态** 下拉框筛选，点 **重置** 清除全部条件。点击行进入详情页。

## 用户详情

详情页由三个区块组成。

- **概要** … 用户名、类别、邮箱、登录方式（**密码 + SSO** 或 **仅 SSO**）、最后登录、员工 ID。
- **角色分配** … 分配历史列表：角色名、rolename（系统内部名）、状态（有效/无效）、分配日期、解除日期。已解除的历史分配也会显示。
- **实际生效权限** … 汇总所有有效角色后的"该用户当前能做什么"清单。按权限代码（如 `quote`、`master`、`system`）显示操作（READ / CREATE / UPDATE 等）和范围。

## 如何理解实际生效权限

- 权限属于角色，一个用户可以拥有多个角色。
- 同一权限和操作由多个角色赋予时，仅显示 **最宽的范围**（例如同时有 FACTORY 和 ALL 时，只显示 ALL）。
- 范围指该操作的覆盖面（ALL = 全部、FACTORY = 所属工厂、OWN = 本人数据 等）。

## 常见问题

- **想添加或编辑用户** … 此界面上无法操作。用户信息通过与公司认证目录（AD）同步等方式管理，请联系系统管理员。
- **想变更角色** … 此界面仅供查看。角色分配的变更由系统管理员进行。
- **权限与预期不符** … 请查看详情页的"实际生效权限"。多个角色会被汇总，每个操作只取最高范围。
- 想查看谁在何时改了什么，请使用[操作历史](/docs/system/activity-log)。
- 应用的显示开关请参见[应用管理](/docs/system/app-management)。
