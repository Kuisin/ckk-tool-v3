# マニュアルの使い方

操作コード **DC01**。この「マニュアル」アプリ自体の使い方を説明します。全ユーザーが利用できます（権限は不要です）。

## このアプリでできること

システム内のすべてのアプリの操作マニュアルを、アプリを離れずに読めます。マニュアルは **日本語・English・中文** の 3 言語で用意されています。

- 左のサイドバーから、カテゴリ（販売・購買・生産・出荷・請求・マスタ・設定・システム管理）ごとにページを開けます。
- 初めての方は [スタートマニュアル](/docs/start) から読み始めてください。

## 開き方

- ホームまたはランチャーの **マニュアル**、または検索ボックスで `DC01`。
- 各画面からリンクされている場合は、そのリンクから該当ページへ直接移動できます。

## 言語の切り替え

- サイドバー上部（モバイルではページ上部のバー）の **日本語 / English / 中文** をクリックすると、表示言語が切り替わります。
- 言語はページ間を移動しても保持されます。マニュアル内のリンクも同じ言語のページへつながります。

## 検索

- サイドバーの **検索** ボタン、またはキーボードの **⌘K**（Windows は Ctrl+K）で検索ウィンドウが開きます。
- キーワードを入力すると、全マニュアルの本文から一致する箇所を探します。結果をクリックするとそのページへ移動します。
- 検索は現在の表示言語のマニュアルが対象です。

## よくある質問

- **マニュアルに書いてある画面が見当たらない** … 一部のアプリは開発環境（dev）のみで公開されています。マニュアル冒頭の注意書きを確認してください。また、権限がないアプリはホームに表示されません。
- **内容が実際の画面と違う** … システムの更新でマニュアルより先に画面が変わることがあります。気づいた点は管理者へ連絡してください。
