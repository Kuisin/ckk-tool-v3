/line/

[role_sales: Compute a unit price] <block_apply>
label: Price estimate;
desc: Compute an estimated unit price from material, dimensions, and machining conditions, then confirm it. Only a confirmed price estimate can be used as the price list's base.;
[role_sales: Create a price list] <block_apply>
label: Price list;
props: PRICE_LIST;
desc: For each customer × product, set prices by order type and quantity tier.;
[role_sales: Issue a quote] <block_apply>
label: Quote;
props: QUOTE;
desc: The unit price is auto-filled from the price list. Submit the issued PDF to the customer.;
[role_partner: Send a purchase order] <block_neutral>
label: Order;
props: ORDER_DOC;
desc: A purchase order arrives by fax, PDF, etc.;
[role_support: Check the order acceptance] <block_apply>
label: Intake / check;
props: ORDER_ACCEPT;
desc: Check and correct the imported extraction result.;
[role_system: Match the order price] <block_system>
label: Price matching;
desc: The order's price is automatically matched against the quote and price list.;
if (Price mismatch) is (Yes) than #orange
  [role_sales: Adjust the price] <block_condition>
  label: Price adjustment;
  props: QUOTE;
  desc: Either go back to the quote to fix the price, or correct and recheck the price on the order acceptance side.;
  [loop]
else
  [role_support: Request approval] <block_apply>
  label: Approval request;
  desc: Once the content is finalized, request approval. It cannot be edited while the request is pending.;
endif
if (Approval decision) is (Sent back) than #red
  [role_support: Fix and re-request] <block_reject>
  label: Sent back;
  desc: Apply the feedback, fix the content, and request approval again.;
  [loop]
else
  [role_approver: Approve the order acceptance] <block_approve>
  label: Approval;
endif
[role_support: Confirm order lines] <block_apply>
label: Confirm lines;
desc: An order line is created per line item and the amount is finalized. Production flow proceeds from here.;
[role_sales: File a design request] <block_memo>
label: (Parallel) Design request;
desc: For products without a drawing, a design request is filed in parallel with this flow, and production creates the drawing.;
